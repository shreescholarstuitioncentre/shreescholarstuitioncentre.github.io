अध्याय 3: प्रतिलोम त्रिकोणमितीय फलन

यूपी बोर्ड / एनसीईआरटी – एनिमेटेड आलेख, सूत्र, हल किए उदाहरण, प्रश्नोत्तर और बहुविकल्पीय प्रश्नों सहित नोट्स।

1. प्रतिलोम त्रिकोणमितीय फलन

1.1 परिभाषा

अध्याय 1 से: f⁻¹ तभी होता है जब f एकैकी तथा आच्छादक हो। छहों त्रिकोणमितीय फलन अपने मान दोहराते हैं, इसलिए R पर वे एकैकी नहीं हैं। यदि हम प्रत्येक को ऐसे अंतराल (शाखा) तक सीमित कर दें जहाँ वह एकैकी तथा अपने परिसर पर आच्छादक हो, तो उसका प्रतिलोम बन जाता है।

परिभाषा: y = sin⁻¹x ⇔ x = sin y, जहाँ y चुनी हुई शाखा में है। sin⁻¹x को पढ़ें “वह कोण जिसकी ज्या x है”।
सावधानी: sin⁻¹x का अर्थ 1/sin x नहीं है। यहाँ “−1” घात नहीं है; (sin x)⁻¹ = 1/sin x = cosec x।

नीला: [−π/2, π/2] पर sin x। लाल: sin⁻¹x। बिंदुकित: y = x दर्पण रेखा।

आलेख ऐसा क्यों दिखता है: f⁻¹ का आलेख, f के आलेख का रेखा y = x में दर्पण-प्रतिबिंब होता है। यहाँ नीला sine वक्र (अपनी शाखा पर) परावर्तित होकर लाल sin⁻¹ वक्र बन जाता है, इसलिए प्रांत और परिसर आपस में बदल जाते हैं।

1.2 प्रांत और परिसर

फलनप्रांतपरिसर (मुख्य मान शाखा)

1.3 मुख्य मान शाखाएँ

मुख्य मान: प्रतिलोम त्रिकोणमितीय फलन का वह मान जो उसकी मुख्य शाखा (ऊपर सारणी का परिसर) में हो।

sin x अनेक अंतरालों पर एकैकी है, जैसे [−π/2, π/2], [π/2, 3π/2]। प्रत्येक से भिन्न प्रतिलोम मिलता है। [−π/2, π/2] को मुख्य शाखा माना गया है क्योंकि इसमें 0 है और यह पूरा परिसर [−1, 1] देती है। याद रखें: sin⁻¹, tan⁻¹, cosec⁻¹ → 0 के आसपास (ऋणात्मक हो सकते हैं); cos⁻¹, cot⁻¹, sec⁻¹ → 0 से π तक (कभी ऋणात्मक नहीं)।

1.4 आलेख


y = sin⁻¹x

y = cos⁻¹x

y = tan⁻¹x (बिंदुकित: y = ±π/2)
  • sin⁻¹x: वर्धमान, मूलबिंदु से गुजरता है, (1, π/2) तथा (−1, −π/2) पर समाप्त। विषम फलन।
  • cos⁻¹x: ह्रासमान, (−1, π) से (1, 0) तक; y-अक्ष को π/2 पर काटता है।
  • tan⁻¹x: वर्धमान, विषम, अनंतस्पर्शियों y = ±π/2 (बिंदुकित) के बीच सीमित।

ऋणात्मक मान: sin⁻¹(−x) = −sin⁻¹x, tan⁻¹(−x) = −tan⁻¹x, परंतु cos⁻¹(−x) = π − cos⁻¹x। उदाहरण: cos⁻¹(−1/2) = π − π/3 = 2π/3।

1.6 प्रारंभिक गुणधर्म

  1. x ∈ [−1, 1] के लिए sin(sin⁻¹x) = x; sin⁻¹(sin x) = x केवल x ∈ [−π/2, π/2] के लिए। अन्य फलनों के लिए भी यही नियम अपनी-अपनी शाखा के साथ।
  2. sin⁻¹(1/x) = cosec⁻¹x, cos⁻¹(1/x) = sec⁻¹x (|x| ≥ 1); tan⁻¹(1/x) = cot⁻¹x (x > 0)।
  3. sin⁻¹(−x) = −sin⁻¹x; tan⁻¹(−x) = −tan⁻¹x; cosec⁻¹(−x) = −cosec⁻¹x।
  4. cos⁻¹(−x) = π − cos⁻¹x; sec⁻¹(−x) = π − sec⁻¹x; cot⁻¹(−x) = π − cot⁻¹x।
  5. sin⁻¹x + cos⁻¹x = π/2; tan⁻¹x + cot⁻¹x = π/2; sec⁻¹x + cosec⁻¹x = π/2।

1.7 मानक सर्वसमिकाएँ एवं सरलीकरण

  • tan⁻¹x + tan⁻¹y = tan⁻¹((x + y)/(1 − xy)), यदि xy < 1 (यदि x, y > 0 तथा xy > 1 तो π जोड़ें)।
  • tan⁻¹x − tan⁻¹y = tan⁻¹((x − y)/(1 + xy)), यदि xy > −1।
  • 2tan⁻¹x = tan⁻¹(2x/(1 − x²)) जब |x| < 1 = sin⁻¹(2x/(1 + x²)) जब |x| ≤ 1 = cos⁻¹((1 − x²)/(1 + x²)) जब x ≥ 0।
  • 2sin⁻¹x = sin⁻¹(2x√(1 − x²)), −1/√2 ≤ x ≤ 1/√2।
  • 3sin⁻¹x = sin⁻¹(3x − 4x³), −1/2 ≤ x ≤ 1/2; 3cos⁻¹x = cos⁻¹(4x³ − 3x), 1/2 ≤ x ≤ 1।

प्रतिस्थापन युक्तियाँ: √(1 − x²) के लिए x = sin θ या cos θ रखें; √(1 + x²) के लिए x = tan θ; √(x² − 1) के लिए x = sec θ; √((1 − x)/(1 + x)) के लिए x = cos 2θ।

2. हल किए गए उदाहरण

सरल उदा. 1. sin⁻¹(−1/2) का मुख्य मान ज्ञात कीजिए।
हल: sin⁻¹(−1/2) = −sin⁻¹(1/2) = −π/6, जो [−π/2, π/2] में है।
सरल उदा. 2. cos⁻¹(−1/2) ज्ञात कीजिए।
हल: cos⁻¹(−x) = π − cos⁻¹x ⇒ π − π/3 = 2π/3, जो [0, π] में है।
सरल उदा. 3. sin⁻¹(sin 2π/3) का मान निकालिए।
हल: 2π/3 ∉ [−π/2, π/2]। sin(2π/3) = sin(π − π/3) = sin(π/3)। अतः उत्तर π/3 है, 2π/3 नहीं।
मध्यम उदा. 4. सिद्ध कीजिए tan⁻¹(1/2) + tan⁻¹(1/3) = π/4।
उपपत्ति: x = 1/2, y = 1/3, xy = 1/6 < 1। अतः LHS = tan⁻¹((1/2 + 1/3)/(1 − 1/6)) = tan⁻¹((5/6)/(5/6)) = tan⁻¹1 = π/4 = RHS। ∎
मध्यम उदा. 5. सिद्ध कीजिए 2tan⁻¹(1/2) = tan⁻¹(4/3)।
उपपत्ति: |1/2| < 1, अतः 2tan⁻¹(1/2) = tan⁻¹(2·(1/2)/(1 − 1/4)) = tan⁻¹(1/(3/4)) = tan⁻¹(4/3)। ∎
मध्यम उदा. 6. cos(sin⁻¹(3/5)) ज्ञात कीजिए।
हल: माना θ = sin⁻¹(3/5), θ ∈ [0, π/2]। sin θ = 3/5 ⇒ cos θ = √(1 − 9/25) = 4/5।
कठिन उदा. 7. सिद्ध कीजिए sin⁻¹(12/13) + cos⁻¹(4/5) + tan⁻¹(63/16) = π।
उपपत्ति: sin⁻¹(12/13) = tan⁻¹(12/5) (त्रिभुज 5, 12, 13); cos⁻¹(4/5) = tan⁻¹(3/4) (त्रिभुज 3, 4, 5)।
यहाँ xy = (12/5)(3/4) = 9/5 > 1, अतः tan⁻¹(12/5) + tan⁻¹(3/4) = π + tan⁻¹((63/20)/(−4/5)) = π − tan⁻¹(63/16)।
इसमें tan⁻¹(63/16) जोड़ने पर π मिलता है। ∎
कठिन उदा. 8. हल कीजिए tan⁻¹(x + 1) + tan⁻¹(x − 1) = tan⁻¹(8/31)।
हल: tan⁻¹((2x)/(2 − x²)) = tan⁻¹(8/31) ⇒ 62x = 16 − 8x² ⇒ 4x² + 31x − 8 = 0 ⇒ x = 1/4 या x = −8।
शर्त (x + 1)(x − 1) < 1 जाँचें: x = 1/4 के लिए −15/16 ✔। x = −8 के लिए 63 > 1 ✘। अतः x = 1/4।
कठिन उदा. 9. सरल कीजिए tan⁻¹((√(1 + x²) − 1)/x), x ≠ 0।
हल: x = tan θ रखें। तब (sec θ − 1)/tan θ = (1 − cos θ)/sin θ = tan(θ/2)। अतः परिणाम θ/2 = (1/2)tan⁻¹x।

3. लघु एवं दीर्घ प्रश्नोत्तर (उत्तर देखने के लिए दबाएँ)

प्र.1. त्रिकोणमितीय फलनों का प्रांत सीमित क्यों किया जाता है?

वे आवर्ती हैं, अतः R पर बहु-एक हैं। शाखा तक सीमित करने से वे एकैकी तथा आच्छादक हो जाते हैं और प्रतिलोम बन पाता है।

प्र.2. cos⁻¹(√3/2) का मुख्य मान?

π/6।

प्र.3. क्या sin⁻¹x = 1/sin x है?

नहीं। sin⁻¹x प्रतिलोम फलन है; 1/sin x = cosec x।

प्र.4. tan⁻¹(1) + cos⁻¹(−1/2) + sin⁻¹(−1/2) ज्ञात कीजिए।

π/4 + 2π/3 − π/6 = (3π + 8π − 2π)/12 = 9π/12 = 3π/4।

प्र.5. cot⁻¹x का परिसर लिखिए।

(0, π), न कि (−π/2, π/2)।

प्र.6. दीर्घ: सिद्ध कीजिए sin⁻¹x + cos⁻¹x = π/2।

माना sin⁻¹x = θ, तो x = sin θ = cos(π/2 − θ)। अतः cos⁻¹x = π/2 − θ, क्योंकि θ ∈ [−π/2, π/2] होने पर π/2 − θ ∈ [0, π]। इसलिए sin⁻¹x + cos⁻¹x = θ + π/2 − θ = π/2। ∎

प्र.7. sin⁻¹(sin 3π/5) ज्ञात कीजिए और नियम बताइए।

3π/5 ∉ [−π/2, π/2]। sin(3π/5) = sin(π − 3π/5) = sin(2π/5), अतः मान 2π/5। नियम: sin(π − θ) = sin θ से कोण को [−π/2, π/2] में लाएँ।

प्र.8. sin(tan⁻¹(3/4)) का मान निकालिए।

समकोण त्रिभुज: लंब 3, आधार 4, कर्ण 5। sin = 3/5।
