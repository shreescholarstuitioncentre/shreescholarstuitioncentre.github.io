अध्याय 5: सारणिक

यूपी बोर्ड / एनसीईआरटी – एनिमेटेड चित्र, सूत्र, हल किए उदाहरण, प्रश्नोत्तर और बहुविकल्पीय प्रश्नों सहित नोट्स।

1. सारणिक

1.1 क्रम 1, 2 तथा 3 के सारणिक

परिभाषा: प्रत्येक वर्ग आव्यूह A से एक अद्वितीय वास्तविक संख्या जुड़ी होती है, जिसे उसका सारणिक कहते हैं और |A| या det A लिखते हैं।
आव्यूह और सारणिक में अंतर: आव्यूह एक सारणी है (उसका कोई मान नहीं, क्रम m × n कुछ भी); सारणिक एक संख्या है और केवल वर्ग आव्यूह का होता है। आव्यूह के लिए [ ] कोष्ठक, सारणिक के लिए ऊर्ध्वाधर रेखाएँ | |।
  • क्रम 1: A = [a] ⇒ |A| = a (यह मापांक नहीं है)।
  • क्रम 2: A = [[a, b],[c, d]] के लिए |A| = ad − bc।
  • क्रम 3: प्रथम पंक्ति के अनुदिश प्रसार: |A| = a₁₁(a₂₂a₃₃ − a₂₃a₃₂) − a₁₂(a₂₁a₃₃ − a₂₃a₃₁) + a₁₃(a₂₁a₃₂ − a₂₂a₃₁)।

क्रम 2 का सारणिक = मुख्य विकर्ण का गुणनफल − दूसरे विकर्ण का गुणनफल

1.2 सारणिकों का मान ज्ञात करना

क्रम 2 के लिए चित्र के अनुसार तिर्यक गुणन करें। क्रम 3 के लिए किसी भी पंक्ति या स्तंभ के अनुदिश प्रसार करें; जिसमें सबसे अधिक शून्य हों उसे चुनें। ऊपरी या निचले त्रिभुजाकार सारणिक का मान = विकर्ण अवयवों का गुणनफल। यदि A का क्रम n हो तो |kA| = kⁿ|A| (k|A| नहीं)।

1.3 सारणिकों के गुणधर्म

  1. |A| = |Aᵀ| (पंक्तियों और स्तंभों को आपस में बदल सकते हैं)।
  2. दो पंक्तियों (या स्तंभों) को आपस में बदलने पर चिह्न बदल जाता है।
  3. यदि दो पंक्तियाँ (या स्तंभ) समान (या समानुपाती) हों तो |A| = 0।
  4. किसी एक पंक्ति (या स्तंभ) के सभी अवयवों को k से गुणा करने पर |A|, k गुना हो जाता है। एक पंक्ति का उभयनिष्ठ गुणनखंड बाहर निकाल सकते हैं।
  5. यदि किसी पंक्ति का प्रत्येक अवयव दो पदों का योग हो तो सारणिक दो सारणिकों के योग में टूट जाता है।
  6. एक पंक्ति (स्तंभ) में दूसरी का गुणज जोड़ने पर |A| नहीं बदलता। (शून्य बनाने में काम आता है।)
  7. शून्य पंक्ति या स्तंभ ⇒ |A| = 0।
  8. समान क्रम के वर्ग आव्यूहों के लिए |AB| = |A||B|।

1.4 उपसारणिक तथा सहखंड

उपसारणिक Mᵢⱼ: i-वीं पंक्ति तथा j-वाँ स्तंभ हटाने पर शेष सारणिक। सहखंड Cᵢⱼ = (−1)i+jMᵢⱼ।

चिह्न शतरंज की तरह चलते हैं: + − + / − + − / + − +। किसी पंक्ति के अवयवों का किसी अन्य पंक्ति के सहखंडों से गुणनफल-योग सदैव 0 होता है।

1.5 पंक्ति या स्तंभ के अनुदिश प्रसार


पंक्ति 1 के अनुदिश प्रसार: प्रत्येक अवयव की पंक्ति और स्तंभ काटें

|A| = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃, और किसी भी पंक्ति या स्तंभ के अनुदिश वही मान मिलता है: |A| = Σⱼ aᵢⱼCᵢⱼ = Σᵢ aᵢⱼCᵢⱼ।

2. सारणिकों के अनुप्रयोग

2.1 त्रिभुज का क्षेत्रफल

सूत्र: शीर्ष (x₁, y₁), (x₂, y₂), (x₃, y₃) के लिए: क्षेत्रफल = ½ | det [[x₁, y₁, 1],[x₂, y₂, 1],[x₃, y₃, 1]] |।

शीर्ष A, B, C वाला त्रिभुज
  • क्षेत्रफल सदैव धनात्मक होता है, अतः निरपेक्ष मान लें।
  • तीन बिंदु संरेख हैं यदि और केवल यदि यह सारणिक 0 हो।
  • (x₁, y₁), (x₂, y₂) से गुजरने वाली रेखा: det [[x, y, 1],[x₁, y₁, 1],[x₂, y₂, 1]] = 0।

2.2 वर्ग आव्यूह का सहखंडज

परिभाषा: adj A, सहखंड आव्यूह [Cᵢⱼ] का परिवर्त है। अर्थात् (adj A)ᵢⱼ = Cⱼᵢ।
  • A(adj A) = (adj A)A = |A| I।
  • |adj A| = |A|n−1 (n = क्रम)। 2 × 2 के लिए adj [[a,b],[c,d]] = [[d, −b],[−c, a]] (विकर्ण अवयव बदलें, शेष दो के चिह्न बदलें)।
  • adj(AB) = (adj B)(adj A); adj(Aᵀ) = (adj A)ᵀ।

2.3 अव्युत्क्रमणीय तथा व्युत्क्रमणीय आव्यूह

अव्युत्क्रमणीय (singular): |A| = 0। व्युत्क्रमणीय (non-singular): |A| ≠ 0। यदि A, B समान क्रम के व्युत्क्रमणीय आव्यूह हैं तो AB भी व्युत्क्रमणीय है तथा |AB| = |A||B|।

2.4 सारणिकों द्वारा प्रतिलोम

प्रमेय: A व्युत्क्रमणीय है यदि और केवल यदि |A| ≠ 0, तथा A⁻¹ = (1/|A|) adj A।
  • |A⁻¹| = 1/|A|। (AB)⁻¹ = B⁻¹A⁻¹।
  • चरण: (1) |A| निकालें, 0 हो तो रुकें; (2) सभी सहखंड निकालें; (3) परिवर्त लेकर adj A बनाएँ; (4) |A| से भाग दें; (5) AA⁻¹ = I से जाँच करें।

3. रैखिक समीकरण निकाय

3.1 आव्यूह निरूपण

निकाय a₁x + b₁y + c₁z = d₁, a₂x + b₂y + c₂z = d₂, a₃x + b₃y + c₃z = d₃ को AX = B लिखते हैं, जहाँ A = गुणांक आव्यूह, X = [x y z]ᵀ, B = [d₁ d₂ d₃]ᵀ।

3.2 संगत एवं असंगत निकाय; हलों की संख्या

संगत = कम-से-कम एक हल विद्यमान। असंगत = कोई हल नहीं।

संगत, अद्वितीय हल (रेखाएँ एक बिंदु पर मिलती हैं)

असंगत, कोई हल नहीं (समांतर रेखाएँ)

संगत, अनंत हल (एक ही रेखा)

निकाय के 0, ठीक 1, या अनंत हल हो सकते हैं (ठीक 2 कभी नहीं)।

3.3 अद्वितीय हल

स्थिति 1: |A| ≠ 0 ⇒ A⁻¹ विद्यमान ⇒ X = A⁻¹B: अद्वितीय हल (संगत)।
स्थिति 2: |A| = 0 ⇒ (adj A)B निकालें। यदि (adj A)B ≠ O ⇒ असंगत। यदि (adj A)B = O ⇒ निकाय संगत (अनंत हल) या असंगत हो सकता है (आगे जाँचें)।

3.4 दो तथा तीन चरों वाले निकाय हल करना

AX = B लिखें, |A| निकालें, फिर A⁻¹ = adj A/|A| और X = A⁻¹B। गुणन पंक्ति-स्तंभ क्रम से सावधानी से करें और प्रतिस्थापन द्वारा उत्तर जाँचें।

4. हल किए गए उदाहरण

सरल उदा. 1. |[[2, 3],[4, 5]]| का मान ज्ञात कीजिए।
हल: 2·5 − 3·4 = 10 − 12 = −2।
सरल उदा. 2. |[[1,2,3],[0,4,5],[0,0,6]]| का मान ज्ञात कीजिए।
हल: प्रथम स्तंभ के अनुदिश प्रसार: 1·(4·6 − 5·0) − 0 + 0 = 24 (= विकर्ण का गुणनफल 1·4·6)।
सरल उदा. 3. A = [[1,2],[3,4]] के उपसारणिक तथा सहखंड ज्ञात कीजिए।
हल: M₁₁ = 4, M₁₂ = 3, M₂₁ = 2, M₂₂ = 1। C₁₁ = (+)4 = 4, C₁₂ = (−)3 = −3, C₂₁ = (−)2 = −2, C₂₂ = (+)1 = 1।
सरल उदा. 4. प्रतिलोम की सहायता से 5x + 2y = 3, 3x + 2y = 5 हल कीजिए।
हल: A = [[5,2],[3,2]], B = [3, 5]ᵀ। |A| = 10 − 6 = 4 ≠ 0। A⁻¹ = ¼[[2, −2],[−3, 5]]। X = A⁻¹B = ¼[2·3 − 2·5, −3·3 + 5·5]ᵀ = ¼[−4, 16]ᵀ। अतः x = −1, y = 4। जाँच: 5(−1) + 2·4 = 3 ✔; 3(−1) + 8 = 5 ✔।
मध्यम उदा. 5. यदि |[[x, 2],[18, x]]| = |[[6, 2],[18, 6]]| तो x ज्ञात कीजिए।
हल: x² − 36 = 36 − 36 = 0 ⇒ x² = 36 ⇒ x = ±6।
मध्यम उदा. 6. शीर्ष (1, 1), (5, 2), (3, 5) वाले त्रिभुज का क्षेत्रफल ज्ञात कीजिए।
हल: Δ = ½|det [[1,1,1],[5,2,1],[3,5,1]]|। प्रथम पंक्ति के अनुदिश: 1(2·1 − 1·5) − 1(5·1 − 1·3) + 1(5·5 − 2·3) = −3 − 2 + 19 = 14। क्षेत्रफल = ½ × 14 = 7 वर्ग इकाई।
मध्यम उदा. 7. दिखाइए कि (1, 2), (2, 4), (3, 6) संरेख हैं।
हल: det [[1,2,1],[2,4,1],[3,6,1]] = 1(4 − 6) − 2(2 − 3) + 1(12 − 12) = −2 + 2 + 0 = 0। क्षेत्रफल = 0 ⇒ संरेख। ∎
मध्यम उदा. 8. यदि A, 3 × 3 आव्यूह है तथा |A| = 4, तो |2A|, |adj A|, |A⁻¹| ज्ञात कीजिए।
हल: |2A| = 2³·4 = 32; |adj A| = |A|² = 16; |A⁻¹| = 1/|A| = 1/4।
कठिन उदा. 9. सिद्ध कीजिए |[[1,a,a²],[1,b,b²],[1,c,c²]]| = (a − b)(b − c)(c − a)।
उपपत्ति: R₁ → R₁ − R₂ तथा R₂ → R₂ − R₃ से पंक्तियाँ (0, a − b, a² − b²), (0, b − c, b² − c²), (1, c, c²) मिलती हैं।
C₁ के अनुदिश प्रसार (केवल पंक्ति 3 में अवयव 1, चिह्न +): = |[[a − b, a² − b²],[b − c, b² − c²]]|।
(a − b) तथा (b − c) बाहर निकालने पर: = (a − b)(b − c)|[[1, a + b],[1, b + c]]| = (a − b)(b − c)[(b + c) − (a + b)] = (a − b)(b − c)(c − a)। ∎
कठिन उदा. 10. A = [[1,2,3],[0,1,4],[5,6,0]] के लिए adj A तथा A⁻¹ ज्ञात कीजिए।
हल: |A| = 1(0 − 24) − 2(0 − 20) + 3(0 − 5) = −24 + 40 − 15 = 1।
सहखंड: C₁₁ = −24, C₁₂ = 20, C₁₃ = −5; C₂₁ = 18, C₂₂ = −15, C₂₃ = 4; C₃₁ = 5, C₃₂ = −4, C₃₃ = 1।
adj A = [[−24,20,−5],[18,−15,4],[5,−4,1]] का परिवर्त = [[−24,18,5],[20,−15,−4],[−5,4,1]]।
|A| = 1 होने से A⁻¹ = adj A। जाँच: प्रथम पंक्ति × प्रथम स्तंभ: 1(−24) + 2(20) + 3(−5) = 1 ✔।
कठिन उदा. 11. हल कीजिए: x + 2y + 3z = 14, y + 4z = 14, 5x + 6y = 17।
हल: गुणांक आव्यूह उदा. 10 का A है, अतः A⁻¹ = [[−24,18,5],[20,−15,−4],[−5,4,1]]। X = A⁻¹[14, 14, 17]ᵀ।
x = −24·14 + 18·14 + 5·17 = −336 + 252 + 85 = 1; y = 20·14 − 15·14 − 4·17 = 280 − 210 − 68 = 2; z = −5·14 + 4·14 + 17 = −70 + 56 + 17 = 3।
x = 1, y = 2, z = 3।
कठिन उदा. 12. संगतता जाँचिए: (i) x + y = 2, 2x + 2y = 5; (ii) x + y = 2, 2x + 2y = 4।
हल: A = [[1,1],[2,2]], |A| = 0। adj A = [[2, −1],[−2, 1]]।
(i) B = [2, 5]ᵀ: (adj A)B = [4 − 5, −4 + 5]ᵀ = [−1, 1]ᵀ ≠ O ⇒ असंगत।
(ii) B = [2, 4]ᵀ: (adj A)B = [4 − 4, −4 + 4]ᵀ = O ⇒ संगत, अनंत हल (वही रेखा x + y = 2)।

5. लघु एवं दीर्घ प्रश्नोत्तर (उत्तर देखने के लिए दबाएँ)

प्र.1. आव्यूह और सारणिक में क्या अंतर है?

आव्यूह आयताकार सारणी है जिसका कोई संख्यात्मक मान नहीं होता; सारणिक वर्ग आव्यूह से जुड़ी एक संख्या है।

प्र.2. यदि A, 3 × 3 है तथा |A| = −2 तो |3A| ज्ञात कीजिए।

3³ × (−2) = −54।

प्र.3. दो समान पंक्तियों वाले सारणिक का मान क्या है? क्यों?

0। समान पंक्तियाँ बदलने पर सारणिक वही रहता है पर चिह्न भी बदलता है, अतः |A| = −|A| ⇒ |A| = 0।

प्र.4. [[a,b],[c,d]] का adj लिखिए।

[[d, −b],[−c, a]]।

प्र.5. आव्यूह कब व्युत्क्रमणीय होता है?

जब वह वर्ग हो तथा |A| ≠ 0 हो।

प्र.6. दीर्घ: 2 × 2 आव्यूह के लिए सिद्ध कीजिए A(adj A) = |A|I।

A = [[a,b],[c,d]], adj A = [[d,−b],[−c,a]]। A(adj A) = [[ad − bc, −ab + ba],[cd − dc, −cb + da]] = [[ad − bc, 0],[0, ad − bc]] = |A|I। ∎

प्र.7. रैखिक समीकरण निकाय के ठीक दो हल क्यों नहीं हो सकते?

यदि X₁, X₂ दो हल हैं तो प्रत्येक वास्तविक k के लिए X₁ + k(X₂ − X₁) भी हल है, अतः अनंत हल हो जाते हैं।

प्र.8. यदि A, 3 × 3 है तथा |A| = 5 तो |adj A| ज्ञात कीजिए।

|A|n−1 = 5² = 25।
