Class 12 Maths — Chapter 19: Algebra of Vectors

1. Scalars and Vectors

A scalar has only magnitude (mass, time, speed). A vector has magnitude and direction (force, velocity, displacement). It is drawn as an arrow; written a or AB.

2. Magnitude and Direction

If r = xi + yj + zk, then |r| = √(x² + y² + z²)

Length of the arrow is the magnitude; the arrow-head shows direction.

3. Direction Cosines

l = cos α = x/r, m = cos β = y/r, n = cos γ = z/r
l² + m² + n² = 1

α, β, γ are the angles the vector makes with the x, y, z axes. Proof: l²+m²+n² = (x²+y²+z²)/r² = 1.

4. Direction Ratios

Any numbers a, b, c proportional to l, m, n. For r = xi+yj+zk, x, y, z are DRs. From DRs: l = a/√(a²+b²+c²), and similarly for m, n. DCs are unique (up to sign for reverse direction); DRs are not.

5. Types of Vectors

Equal: same magnitude and direction. Unit: magnitude 1, â = a/|a|. Zero: magnitude 0, no direction. Parallel (collinear): a = λb. Vectors along the same or parallel lines are collinear.

6. Position Vector and Negative

OP = r = xi+yj+zk; AB = b − a (head − tail)
−a has the same magnitude as a but opposite direction

7. Components of a Vector

Any vector splits into components along the axes: r = xi + yj + zk, where i, j, k are unit vectors along x, y, z.

8. Addition of Vectors

Triangle law: AB + BC = AC
Parallelogram law: diagonal = a + b
a + b = b + a; (a+b)+c = a+(b+c); a + 0 = a

Component form: add coefficients of i, j, k separately.

9. Multiplication by a Scalar

λa has magnitude |λ||a|; same direction if λ>0, opposite if λ<0
Unit vector: â = a/|a|; vector of magnitude m along a = m·â

10. Section Formula

Internal (m:n): r = (mb + na)/(m+n)
External (m:n): r = (mb − na)/(m−n)
Midpoint: (a+b)/2

Collinearity: A, B, C are collinear if AB = λBC.

Solved Examples (Given / To Find / To Prove / Solution)

Ex 1 (Easy). Find |a| and unit vector of a = 2i+3j+6k.
|a| = √(4+9+36) = 7.
â = (2i+3j+6k)/7.
Ex 2 (Easy). Find DCs of a = i+2j+2k and verify l²+m²+n²=1.
|a| = √(1+4+4) = 3. l=1/3, m=2/3, n=2/3.
1/9+4/9+4/9 = 1 ✓.
Ex 3 (Easy). Find AB for A(1,2,3), B(4,6,15) and |AB|.
AB = (4−1)i+(6−2)j+(15−3)k = 3i+4j+12k.
|AB| = √(9+16+144) = 13.
Ex 4 (Medium). a = 2i−j+k, b = i+3j−2k. Find a+b, a−b, |a+b|.
a+b = 3i+2j−k; a−b = i−4j+3k; |a+b| = √(9+4+1) = √14.
Ex 5 (Medium). a = i+2j−k, b = 4i−j+2k. Find P dividing AB (i) internally 2:1, (ii) externally 2:1.
(i) P = (2b+a)/3 = (9i+0j+3k)/3 = 3i+k.
(ii) P = (2b−a)/(2−1) = 7i−4j+5k.
Ex 6 (Hard). Show A(−2i+3j+5k), B(i+2j+3k), C(7i−k) are collinear.
AB = 3i−j−2k; BC = 6i−2j−4k = 2·AB.
BC ∥ AB and B is common ⇒ collinear ✓.
Ex 7 (Hard, Proof). Prove the midpoint of AB is (a+b)/2.
Put m=n=1 in the internal formula: (1·b+1·a)/(1+1) = (a+b)/2 ∎

Short & Long Questions

Q1. Define a scalar.
A quantity with magnitude only, e.g. mass.
Q2. Define a vector.
A quantity with both magnitude and direction.
Q3. What is a unit vector?
A vector of magnitude 1; â = a/|a|.
Q4. What is a zero vector?
A vector of zero magnitude and arbitrary direction, written 0.
Q5. DCs of the x-axis?
(1, 0, 0), since α=0°, β=γ=90°.
Q6. Difference between DCs and DRs?
DCs satisfy l²+m²+n²=1 and are unique; DRs are any proportional numbers.
Q7. Write AB in terms of position vectors.
AB = b − a.
Q8. When are two vectors collinear?
When a = λb for some scalar λ.
