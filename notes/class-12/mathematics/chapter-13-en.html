Integration by Substitution – Class 12 Maths Notes

Unit 3: Calculus · Chapter 13 · UP Board

1. Method of Substitution

Many integrals cannot be done with the standard table directly. The substitution method reverses the chain rule: d/dx [F(g(x))] = F′(g(x))·g′(x). So ∫ f(g(x))·g′(x) dx = F(g(x)) + C, where F is an antiderivative of f.

∫ f(g(x)) · g′(x) dx  → put t = g(x) →  ∫ f(t) dt

2. Change of Variable

Steps: (1) choose t = g(x), usually the inner or complicated part; (2) differentiate: dt = g′(x) dx; (3) replace every x and dx by t and dt (if x remains, express it through t); (4) integrate; (5) put back t = g(x). The final answer must be in x. Never leave t in the answer.

Choosing t: pick an expression whose derivative (up to a constant) is also visible in the integrand: a bracket raised to a power, the exponent of e, the denominator, a root, log x, or sin x/cos x.

3. Integration Using Standard Substitutions

(i) ∫ f′(x)/f(x) dx = log|f(x)| + C  (t = f(x))
(ii) ∫ [f(x)]ⁿ f′(x) dx = [f(x)]ⁿ⁺¹/(n+1) + C, n ≠ −1
(iii) ∫ f(ax+b) dx = F(ax+b)/a + C  (t = ax+b)
(iv) ∫ f′(x)/√f(x) dx = 2√f(x) + C
(v) ∫ tan x dx = log|sec x| + C   ∫ cot x dx = log|sin x| + C
(vi) ∫ sec x dx = log|sec x + tan x| + C
(vii) ∫ cosec x dx = log|cosec x − cot x| + C

Result (vi) comes from multiplying and dividing by (sec x + tan x) and putting t = sec x + tan x; result (vii) similarly with (cosec x − cot x).

4. Integrals Involving Algebraic Expressions

If a bracket (or root) is complicated and its derivative is present, put it equal to t. For x/√(x+1) put t = x+1 and write x = t − 1. For x²/(1+x⁶) put t = x³, since dt = 3x² dx.

5. Integrals Involving Trigonometric Expressions

Rules of thumb: for sinⁿx cos x put t = sin x; for cosⁿx sin x put t = cos x; for tanⁿx sec²x put t = tan x. If the power of sin (or cos) is odd, keep one factor aside and convert the rest with sin²x = 1 − cos²x. If both powers are even, use half-angle identities.

6. Integrals Involving Exponential and Logarithmic Functions

For e^(f(x))·f′(x) put t = f(x) → e^t. For fractions with eˣ put t = the denominator or eˣ. When log x appears with 1/x put t = log x because dt = dx/x.

7. Integrals Involving Quadratic Expressions

∫ dx/(x²+a²) = (1/a) tan⁻¹(x/a) + C
∫ dx/(x²−a²) = (1/2a) log|(x−a)/(x+a)| + C
∫ dx/(a²−x²) = (1/2a) log|(a+x)/(a−x)| + C
∫ dx/√(a²−x²) = sin⁻¹(x/a) + C
∫ dx/√(x²+a²) = log|x + √(x²+a²)| + C
∫ dx/√(x²−a²) = log|x + √(x²−a²)| + C
∫ √(a²−x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a) + C

For ax²+bx+c, complete the square: x²+4x+13 = (x+2)²+9, then put t = x+2 and use the above formulas. The trigonometric substitutions x = a sin θ, a tan θ, a sec θ (Diagram 2) prove these formulas.

Solved Examples (step by step)

1. Find ∫ x(x²+1)³ dx
Put t = x²+1 ⇒ dt = 2x dx ⇒ x dx = dt/2. Integral = ½∫ t³ dt = t⁴/8. Back: (x²+1)⁴/8 + C.
2. Find ∫ x/√(x+1) dx
Put t = x+1, x = t−1, dx = dt. ∫ (t−1)/√t dt = ∫ (t^½ − t^−½) dt = (2/3)t^(3/2) − 2t^½. Answer: (2/3)(x+1)^(3/2) − 2√(x+1) + C.
3. Find ∫ 2x/(x²+1) dx
Numerator is the derivative of the denominator. Put t = x²+1, dt = 2x dx. ∫ dt/t = log|t|. Answer: log(x²+1) + C.
4. Find ∫ tan x dx
tan x = sin x/cos x. Put t = cos x, dt = −sin x dx. ∫ = −∫ dt/t = −log|t| = −log|cos x| = log|sec x| + C.
5. Find ∫ sin³x cos x dx
Put t = sin x, dt = cos x dx. ∫ t³ dt = t⁴/4. Answer: sin⁴x/4 + C.
6. Find ∫ sin³x dx
sin³x = sin x (1 − cos²x). Put t = cos x, dt = −sin x dx. ∫ = −∫ (1 − t²) dt = −t + t³/3. Answer: −cos x + cos³x/3 + C.
7. Find ∫ sec x dx
Multiply and divide by (sec x + tan x): ∫ (sec²x + sec x tan x)/(sec x + tan x) dx. Put t = sec x + tan x, dt = (sec x tan x + sec²x) dx. ∫ dt/t = log|sec x + tan x| + C.
8. Find ∫ eˣ/(1+eˣ) dx
Put t = 1+eˣ, dt = eˣ dx. ∫ dt/t = log|t|. Answer: log(1+eˣ) + C (1+eˣ > 0).
9. Find ∫ (log x)²/x dx
Put t = log x, dt = dx/x. ∫ t² dt = t³/3. Answer: (log x)³/3 + C.
10. Find ∫ dx/(x log x)
Put t = log x, dt = dx/x. ∫ dt/t = log|t|. Answer: log|log x| + C.
11. Find ∫ e^√x/√x dx
Put t = √x, dt = dx/(2√x) ⇒ dx/√x = 2 dt. ∫ 2eᵗ dt = 2eᵗ. Answer: 2e^√x + C.
12. Find ∫ cos x/(1+sin²x) dx
Put t = sin x, dt = cos x dx. ∫ dt/(1+t²) = tan⁻¹ t. Answer: tan⁻¹(sin x) + C.
13. Find ∫ x²/(1+x⁶) dx
Put t = x³, dt = 3x² dx ⇒ x² dx = dt/3. ∫ (1/3) dt/(1+t²) = (1/3) tan⁻¹ t. Answer: (1/3) tan⁻¹(x³) + C.
14. Find ∫ dx/(x²+4x+13)
Complete the square: x²+4x+13 = (x+2)² + 3². Put t = x+2, dt = dx. ∫ dt/(t²+9) = (1/3) tan⁻¹(t/3). Answer: (1/3) tan⁻¹((x+2)/3) + C.
15. Find ∫ dx/√(x²+2x+5)
x²+2x+5 = (x+1)² + 2². Put t = x+1. ∫ dt/√(t²+4) = log|t + √(t²+4)|. Answer: log|x+1+√(x²+2x+5)| + C.
16. Find ∫ dx/(sin x cos x)
Divide top and bottom by cos²x: ∫ sec²x/tan x dx. Put t = tan x, dt = sec²x dx. ∫ dt/t = log|tan x| + C.
17. Verify: ∫ 2x/(x²+1) dx = log(x²+1) + C
d/dx log(x²+1) = (1/(x²+1))·2x = 2x/(x²+1) ✓. Verified.

Short & Long Q&A (tap to open)

Q1. State the idea behind the substitution method.
It reverses the chain rule: write the integrand as f(g(x))g′(x), put t = g(x), integrate f(t), and replace t.
Q2. Why must we convert dx also?
Because dx is part of the integral; with t = g(x), dx = dt/g′(x). Leaving it in x gives a mixed, wrong integral.
Q3. Evaluate ∫ f′(x)/f(x) dx.
Put t = f(x). The integral becomes ∫ dt/t = log|f(x)| + C.
Q4. What substitution is used for ∫ dx/√(a²−x²)?
x = a sin θ, giving ∫ dθ = θ = sin⁻¹(x/a) + C.
Q5. Is the answer allowed to contain t?
No. After integration put back t = g(x).
Q6. How do we handle ∫ dx/(ax²+bx+c)?
Complete the square and use the quadratic standard formulas.
Q7. Write the result of ∫ cosec x dx.
log|cosec x − cot x| + C.
Q8. Long: Prove ∫ dx/(x²+a²) = (1/a) tan⁻¹(x/a) + C.
Put x = a tan θ, dx = a sec²θ dθ. x²+a² = a²sec²θ. ∫ a sec²θ dθ/(a² sec²θ) = (1/a)∫ dθ = θ/a. Since tan θ = x/a, θ = tan⁻¹(x/a). Hence result.
Q9. Long: Prove ∫ dx/√(a²−x²) = sin⁻¹(x/a) + C.
Put x = a sin θ, dx = a cos θ dθ. √(a²−x²) = a cos θ. ∫ a cos θ dθ/(a cos θ) = θ = sin⁻¹(x/a). Hence proved.
Q10. Long: Evaluate ∫ (x+1)/(x²+2x+3) dx.
Put t = x²+2x+3, dt = 2(x+1) dx ⇒ (x+1)dx = dt/2. ½∫ dt/t = ½ log|t| = ½ log(x²+2x+3) + C. Check: derivative = (2x+2)/(2(x²+2x+3)) ✓.
