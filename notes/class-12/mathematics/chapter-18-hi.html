अवकल समीकरण – कक्षा 12 गणित नोट्स

इकाई 3: कलन · अध्याय 18 · यू.पी. बोर्ड

1. मूल अवधारणाएँ

अवकल समीकरण की परिभाषा

जिस समीकरण में आश्रित चर, स्वतंत्र चर और आश्रित चर के अवकलज हों, वह अवकल समीकरण कहलाता है। उदाहरण: dy/dx + y = sin x। इसे हल करना अर्थात् y को x के ऐसे फलन (बिना अवकलज) के रूप में ज्ञात करना जो समीकरण को संतुष्ट करे।

अवकल समीकरण की कोटि

समीकरण में उपस्थित उच्चतम अवकलज की कोटि ही समीकरण की कोटि है। dy/dx = x की कोटि 1 है; d²y/dx² + y = 0 की कोटि 2 है।

अवकल समीकरण की घात

समीकरण को अवकलजों में बहुपद बनाने के बाद उच्चतम कोटि वाले अवकलज की घात ही समीकरण की घात है (कोई मूल, भिन्न या अवकलज के फलन जैसे sin(dy/dx), e^(dy/dx) नहीं होने चाहिए)। यदि इसे अवकलजों में बहुपद न बनाया जा सके तो घात परिभाषित नहीं होती। उदाहरण: (d²y/dx²)³ + (dy/dx)⁴ = x की कोटि 2, घात 3 है। √(1 + (dy/dx)²) = d²y/dx² को वर्ग करने पर 1 + (y′)² = (y″)² मिलता है: कोटि 2, घात 2।

व्यापक हल

वह हल जिसमें समीकरण की कोटि के बराबर स्वेच्छ अचर हों। dy/dx = 2x के लिए: y = x² + C। ज्यामितीय रूप से यह वक्रों का कुल है (चित्र 1)।

विशिष्ट हल

अचरों को विशिष्ट मान देकर प्राप्त हल, प्रायः दी गई (प्रारंभिक) शर्तों जैसे y(0) = 1 से।

अवकल समीकरणों का निर्माण

n स्वेच्छ अचरों वाले वक्र-कुल के लिए n बार अवकलन करें और मूल समीकरण तथा अवकलजों की सहायता से अचरों का विलोपन करें। परिणाम कोटि n का अचर-रहित अवकल समीकरण होता है।

2. अवकल समीकरण हल करने की विधियाँ

चरों के पृथक्करण द्वारा हल

dy/dx = f(x)·g(y)  ⇒  dy/g(y) = f(x) dx  ⇒  ∫ dy/g(y) = ∫ f(x) dx + C

y वाले सभी पद dy के साथ और x वाले सभी पद dx के साथ करें, फिर दोनों पक्षों का समाकलन करें और एक अचर जोड़ें।

प्रथम कोटि एवं प्रथम घात के समघात अवकल समीकरण

f(x, y) घात n का समघात फलन है यदि f(λx, λy) = λⁿ f(x, y)। समीकरण dy/dx = F(y/x) समघात होता है। विधि: y = vx रखें, तब dy/dx = v + x dv/dx। समीकरण v + x dv/dx = F(v) बन जाता है, जो पृथक् होता है: dv/(F(v) − v) = dx/x। समाकलन के बाद v के स्थान पर y/x रखें। यदि dx/dy = G(x/y) के रूप में सरल हो तो x = vy रखें।

रैखिक अवकल समीकरण एवं समाकलन गुणक विधि

प्रथम कोटि का रैखिक समीकरण y और dy/dx में रैखिक होता है। समाकलन गुणक (IF) को दोनों पक्षों से गुणा करने पर बायाँ पक्ष पूर्ण अवकलज बन जाता है: d/dx (y·IF) = Q·IF।

3. मानक रूप

dy/dx + Py = Q (P, Q, x के फलन)

IF = e^(∫P dx)   ⇒   y · IF = ∫ Q · IF dx + C

याद रखें e^(log f) = f, इसलिए P = 1/x के लिए IF = e^(log x) = x। IF निकालते समय अचर नहीं जोड़ते।

dx/dy + Px = Q (P, Q, y के फलन)

IF = e^(∫P dy)   ⇒   x · IF = ∫ Q · IF dy + C

इसका प्रयोग तब करें जब समीकरण x में रैखिक हो, जैसे y dx + (x − y³) dy = 0।

प्रारंभिक शर्त वाले प्रश्न

पहले व्यापक हल निकालें, फिर दिए गए मान (x₀, y₀) रखकर C ज्ञात करें, और विशिष्ट हल लिखें। समाकलन से पहले मान न रखें।

अनुप्रयोग एवं शाब्दिक प्रश्न

कथन को समीकरण में बदलें: “N के परिवर्तन की दर N के समानुपाती है” का अर्थ dN/dt = kN, जिसका हल N = N₀e^(kt) है। यह जनसंख्या वृद्धि (k > 0), रेडियोधर्मी क्षय (k < 0) और चक्रवृद्धि ब्याज को निरूपित करता है। दिए गए दो आँकड़ों से k और N₀ ज्ञात करें, फिर पूछे गए प्रश्न का उत्तर दें (चित्र 3)।

चित्र (एनिमेटेड)

चित्र 1: dy/dx = 2x का व्यापक हल y = x² + C है, C के प्रत्येक मान के लिए एक परवलय। शर्त y(0) = 1 लगाने पर ठीक एक वक्र (धड़कता लाल वक्र) मिलता है, यही विशिष्ट हल है। चित्र 2: प्रत्येक प्रकार के लिए कौन-सी विधि प्रयोग करें। चित्र 3: समीकरण dN/dt = kN: हल N = N₀e^(kt) है, जो k > 0 पर बढ़ता (हरा) और k < 0 पर घटता (लाल) है; वक्र t = 0 से स्वयं बनते हैं।

हल किए गए उदाहरण (चरण दर चरण)

1. d²y/dx² + (dy/dx)³ + y = 0 की कोटि और घात ज्ञात कीजिए
उच्चतम अवकलज d²y/dx²: कोटि 2। उसकी घात 1 है: घात 1।
2. (d³y/dx³)² + (dy/dx)⁴ + y = 0 की कोटि और घात ज्ञात कीजिए
उच्चतम अवकलज d³y/dx³ है, अतः कोटि 3। उसकी घात 2 है, इसलिए कोटि 3, घात 2।
3. dy/dx + sin(dy/dx) = 0 की कोटि और घात ज्ञात कीजिए
कोटि 1। समीकरण dy/dx में बहुपद के रूप में नहीं लिखा जा सकता (अवकलज का sin है), अतः कोटि 1, घात परिभाषित नहीं।
4. y = Ax² का अवकल समीकरण बनाइए
एक अचर ⇒ एक बार अवकलन: dy/dx = 2Ax। समीकरण से A = y/x²। अतः dy/dx = 2y/x। उत्तर: x dy/dx − 2y = 0।
5. y = A cos x + B sin x का अवकल समीकरण बनाइए
दो अचर ⇒ दो बार अवकलन। y′ = −A sin x + B cos x; y″ = −A cos x − B sin x = −y। उत्तर: d²y/dx² + y = 0।
6. परवलयों y² = 4ax का अवकल समीकरण बनाइए
अवकलन: 2y y′ = 4a ⇒ a = y y′/2। प्रतिस्थापन: y² = 4·(y y′/2)·x = 2xy y′। y से भाग दें: 2x dy/dx − y = 0।
7. dy/dx = xy हल कीजिए
पृथक्करण: dy/y = x dx। समाकलन: log|y| = x²/2 + C₁। अतः y = e^(C₁) e^(x²/2)। उत्तर: y = A e^(x²/2), जहाँ A = ±e^(C₁)।
8. dy/dx = e^(x−y) हल कीजिए
e^(x−y) = eˣ/eʸ। पृथक्करण: eʸ dy = eˣ dx। समाकलन: eʸ = eˣ + C।
9. y(0) = 1 के साथ dy/dx = 2x हल कीजिए
समाकलन: y = x² + C। x = 0, y = 1 रखें: 1 = C। विशिष्ट हल y = x² + 1।
10. y(0) = 3 के साथ dy/dx = −2xy हल कीजिए
पृथक्करण: dy/y = −2x dx। log|y| = −x² + C₁ ⇒ y = A e^(−x²)। (0, 3) रखें: A = 3। उत्तर: y = 3e^(−x²)।
11. dy/dx = (x + y)/x हल कीजिए
समघात। y = vx रखें: v + x dv/dx = 1 + v ⇒ x dv/dx = 1 ⇒ dv = dx/x ⇒ v = log|x| + C। v = y/x रखें: y = x (log|x| + C)।
12. dy/dx = (x² + y²)/(2xy) हल कीजिए
y = vx रखें: v + x v′ = (1 + v²)/(2v) ⇒ x v′ = (1 − v²)/(2v)। पृथक्करण: 2v dv/(1 − v²) = dx/x। समाकलन: −log|1 − v²| = log|x| + c ⇒ x(1 − v²) = C। v = y/x रखें: x(1 − y²/x²) = C ⇒ x² − y² = Cx।
13. dy/dx + y = e^(−x) हल कीजिए
P = 1, IF = e^(∫1 dx) = eˣ। y eˣ = ∫ e^(−x) eˣ dx = ∫ 1 dx = x + C। उत्तर: y = (x + C) e^(−x)।
14. dy/dx + 2y = sin x हल कीजिए
IF = e^(2x)। y e^(2x) = ∫ e^(2x) sin x dx = e^(2x)(2 sin x − cos x)/5 + C। उत्तर: y = (2 sin x − cos x)/5 + C e^(−2x)।
15. dy/dx + y/x = x² हल कीजिए
P = 1/x, IF = e^(log x) = x। xy = ∫ x · x² dx = x⁴/4 + C। उत्तर: y = x³/4 + C/x।
16. x dy/dx + 2y = x² (x > 0) हल कीजिए
x से भाग दें: dy/dx + (2/x) y = x। IF = e^(2 log x) = x²। x²y = ∫ x³ dx = x⁴/4 + C। उत्तर: y = x²/4 + C/x²।
17. y dx + (x − y³) dy = 0 हल कीजिए
dx/dy + x/y = y² लिखें (x में रैखिक)। IF = e^(∫dy/y) = y। xy = ∫ y³ dy = y⁴/4 + C। उत्तर: x = y³/4 + C/y।
18. y(0) = 1 के साथ dy/dx + y tan x = sec x हल कीजिए
IF = e^(∫tan x dx) = e^(log sec x) = sec x। y sec x = ∫ sec²x dx = tan x + C ⇒ y = sin x + C cos x। (0, 1) रखें: 1 = C। उत्तर: y = sin x + cos x।
19. एक जनसंख्या अपनी स्वयं की दर के समानुपाती बढ़ती है और 10 वर्ष में दुगुनी हो जाती है। कितने वर्षों में तिगुनी होगी?
dP/dt = kP ⇒ P = P₀e^(kt)। दुगुनी: 2 = e^(10k) ⇒ k = (log 2)/10। तिगुनी: 3 = e^(kt) ⇒ t = (log 3)/k = 10 log 3/log 2 ≈ 15.85 वर्ष।
20. सत्यापित कीजिए कि y = A e^(x²/2), dy/dx = xy का हल है
dy/dx = A e^(x²/2) · x = x · y ✓। सत्यापित।

लघु एवं दीर्घ प्रश्नोत्तर (खोलने के लिए छुएँ)

Q1. अवकल समीकरण क्या है?
वह समीकरण जिसमें स्वतंत्र चर के सापेक्ष आश्रित चर के अवकलज हों।
Q2. कोटि और घात परिभाषित कीजिए।
कोटि: उच्चतम अवकलज की कोटि। घात: अवकलजों में बहुपद बनाने पर उसकी घात।
Q3. घात कब परिभाषित नहीं होती?
जब समीकरण अवकलजों में बहुपद न हो, जैसे उसमें sin(dy/dx) या e^(dy/dx) हो।
Q4. व्यापक हल में कितने स्वेच्छ अचर होते हैं?
समीकरण की कोटि के बराबर।
Q5. विशिष्ट हल क्या है?
अचरों को प्रारंभिक शर्तों से विशिष्ट मान देने पर मिला हल।
Q6. dy/dx + Py = Q का समाकलन गुणक लिखिए।
IF = e^(∫P dx)।
Q7. समघात समीकरण dy/dx = F(y/x) में कौन-सा प्रतिस्थापन लेते हैं?
y = vx, तब dy/dx = v + x dv/dx।
Q8. दीर्घ: दर्शाइए कि IF विधि से dy/dx + Py = Q हल होता है।
IF = e^(∫P dx) से गुणा करें। चूँकि d/dx(IF) = P·IF, बायाँ पक्ष d/dx (y·IF) = IF·y′ + y·P·IF हो जाता है। अतः d/dx (y·IF) = Q·IF। समाकलन: y·IF = ∫ Q·IF dx + C।
Q9. दीर्घ: (x² − y²) dx + 2xy dy = 0 हल कीजिए (समघात)।
dy/dx = (y² − x²)/(2xy)। y = vx रखें: v + x v′ = (v² − 1)/(2v) ⇒ x v′ = (v² − 1 − 2v²)/(2v) = −(1 + v²)/(2v)। पृथक्करण: 2v dv/(1 + v²) = −dx/x। समाकलन: log(1 + v²) = −log|x| + c ⇒ x(1 + v²) = C। v = y/x रखें: x + y²/x = C ⇒ x² + y² = Cx।
Q10. दीर्घ: y(π/2) = 0 के साथ dy/dx + y cot x = 2 cos x हल कीजिए।
IF = e^(∫cot x dx) = sin x। y sin x = ∫ 2 cos x sin x dx = ∫ sin 2x dx = −cos 2x/2 + C। x = π/2, y = 0 रखें: 0 = −(−1)/2 + C ⇒ C = −1/2। अतः y sin x = −cos 2x/2 − 1/2 = −(1 + cos 2x)/2 = −cos²x। उत्तर: y = −cos²x / sin x।
