1. Introduction to Differentiability

Continuity tells us a graph has no break. Differentiability tells us a graph is also smooth (no sharp corner, no vertical tangent) at that point. Geometrically, a function is differentiable at a point if a unique non-vertical tangent can be drawn there. Its slope is the derivative, which also measures the instantaneous rate of change of y with respect to x.

2. Derivative of a Function & 3. First Principles

Definition: f′(a) = limh→0 [ f(a+h) − f(a) ] / h, provided the limit exists and is finite.
General function: f′(x) = limh→0 [ f(x+h) − f(x) ] / h   (also written dy/dx, Df(x), y′).

Meaning of each part: f(a+h) − f(a) = change in y; h = change in x; their ratio = slope of the secant (chord) through P(a, f(a)) and Q(a+h, f(a+h)). As h → 0, Q slides towards P and the secant becomes the tangent.

Fig. 1: Secant PQ turns into the tangent at P as Q moves towards P.

4. Left-Hand Derivative (LHD)

Lf′(a) = limh→0⁺ [ f(a−h) − f(a) ] / (−h)  =  limx→a⁻ [ f(x) − f(a) ] / (x − a)

5. Right-Hand Derivative (RHD)

Rf′(a) = limh→0⁺ [ f(a+h) − f(a) ] / h  =  limx→a⁺ [ f(x) − f(a) ] / (x − a)

6. Differentiability at a Point

f is differentiable at x = a ⇔ Lf′(a) = Rf′(a) = finite number.
That common value is f′(a). On an interval: differentiable on (a, b) if differentiable at every point; on [a, b] if differentiable on (a, b) and RHD at a and LHD at b exist.

Steps to test: ① Write f near a on both sides. ② Find LHD. ③ Find RHD. ④ Compare. Equal and finite → differentiable; otherwise → not differentiable.

Fig. 2: y = |x| has LHD = −1 and RHD = 1 at 0, so it is not differentiable there.

7. Relationship Between Continuity and Differentiability

Theorem: Every differentiable function is continuous. Converse is false.

Proof. Let f be differentiable at a, so f′(a) = limx→a [f(x) − f(a)]/(x − a) exists.
For x ≠ a: f(x) − f(a) = [ (f(x) − f(a)) / (x − a) ] · (x − a). Take limit x → a: lim [f(x) − f(a)] = f′(a) · 0 = 0. So lim f(x) = f(a). Hence f is continuous at a. ∎

Converse counter-example: f(x) = |x| is continuous at 0 but not differentiable at 0.
Remember: Not continuous ⇒ not differentiable. Continuous ⇏ differentiable.

Solved Examples (step by step)

Easy Ex 1. Find f′(3) from first principles, f(x) = x².
f′(3) = lim [ (3+h)² − 9 ] / h = lim [ 6h + h² ] / h= lim (6 + h) = 6.
Easy Ex 2. Show f(x) = |x| is not differentiable at 0.
LHD = limh→0⁺ [ |−h| − 0 ] / (−h) = h/(−h) = −1.RHD = lim [ |h| − 0 ] / h = 1.−1 ≠ 1, so not differentiable. ∎
Easy Ex 3. Find d/dx (sin x) from first principles.
= lim [ sin(x+h) − sin x ] / h = lim 2cos(x + h/2) sin(h/2) / h= lim cos(x + h/2) · [ sin(h/2) / (h/2) ] = cos x · 1 = cos x.
Easy Ex 4. Find d/dx (eˣ).
= lim (eˣ⁺ʰ − eˣ)/h = eˣ · lim (eʰ − 1)/h = eˣ · 1 = eˣ.
Easy Ex 5. Find d/dx (log x).
= lim [ log(x+h) − log x ] / h = lim (1/h) log(1 + h/x)= (1/x) · lim log(1 + h/x)/(h/x) = 1/x.
Medium Ex 6. Test f(x) = x|x| at x = 0.
For x < 0, f(x) = −x²; for x ≥ 0, f(x) = x².LHD = limh→0⁺ [−h² − 0]/(−h) = lim h = 0.RHD = lim h²/h = 0.LHD = RHD = 0, so differentiable, f′(0) = 0.
Medium Ex 7. f(x) = x² (x ≤ 1), ax + b (x > 1) is differentiable at 1. Find a, b.
Differentiable ⇒ continuous: 1 = a + b … (i)LHD = 2x at 1 = 2; RHD = a. So a = 2.From (i): b = −1. a = 2, b = −1.
Medium Ex 8. f(x) = x sin(1/x), f(0) = 0. Continuous? Differentiable at 0?
|x sin(1/x)| ≤ |x| → 0, so limit = 0 = f(0): continuous.[f(h) − f(0)]/h = sin(1/h), which oscillates between −1 and 1; no limit.Continuous but not differentiable at 0.
Hard Ex 9. f(x) = x² sin(1/x), f(0) = 0. Show f is differentiable at 0 but f′ is not continuous at 0.
f′(0) = lim h² sin(1/h)/h = lim h sin(1/h) = 0.For x ≠ 0: f′(x) = 2x sin(1/x) − cos(1/x).As x → 0, 2x sin(1/x) → 0 but cos(1/x) oscillates; lim f′(x) does not exist. So f′ is discontinuous at 0.
Hard Ex 10. Discuss differentiability of f(x) = |x − 1| + |x − 2| at x = 1, 2.
Near 1 (x<1): f = 3 − 2x, slope −2; (1<x<2): f = 1, slope 0. LHD ≠ RHD at 1.Near 2: slope 0 on left, +2 on right. Not equal.Not differentiable at x = 1 and x = 2.

Short Questions

Q1. Define derivative of f at x = a.f′(a) = limh→0 [f(a+h) − f(a)]/h, if it exists finitely. It is the slope of the tangent at x = a.
Q2. When is a function differentiable at a point?When its LHD and RHD at that point both exist, are finite and are equal.
Q3. Is every continuous function differentiable?No. f(x) = |x| is continuous at 0 but its LHD (−1) ≠ RHD (1).
Q4. Is every differentiable function continuous?Yes. If f′(a) exists, lim [f(x) − f(a)] = f′(a)·0 = 0, so f is continuous at a.
Q5. Where is [x] not differentiable?At every integer, because it is discontinuous there.
Q6. Find d/dx (aˣ) by first principles.aˣ lim (aʰ − 1)/h = aˣ log a.
