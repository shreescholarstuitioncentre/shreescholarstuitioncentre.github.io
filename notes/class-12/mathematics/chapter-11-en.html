Chapter 11: Maxima and Minima

UP Board / NCERT style notes · Step-by-step · Animated diagrams

1. Local Maximum and Local Minimum

Local maximum: f has a local maximum at x = c if f(c) ≥ f(x) for all x in a small interval around c. f(c) is the local maximum value.
Local minimum: f(c) ≤ f(x) for all x near c. f(c) is the local minimum value.
Together they are called local extrema (turning points). A function can have many local maxima and minima, and a local minimum can even be larger than a local maximum.

2. Absolute Maximum and Absolute Minimum

Absolute (global) maximum on an interval I: f(c) ≥ f(x) for every x in I. Absolute minimum: f(c) ≤ f(x) for every x in I.
Extreme Value Theorem: a function continuous on a closed interval [a, b] always attains its absolute maximum and absolute minimum on [a, b].

3. Critical Points & 4. Stationary Points

Critical point: a point c in the domain where f′(c) = 0 or f′(c) does not exist.
Stationary point: a point where f′(c) = 0 (tangent is horizontal).
Every stationary point is a critical point, but not conversely: f(x) = |x| has a critical point at 0 (f′ does not exist) which is not stationary.
Necessary condition: if f has a local extremum at c and f′(c) exists, then f′(c) = 0. Not sufficient: f(x) = x³ has f′(0) = 0 but no extremum.

Fig. 1: On [a, b] the red dot visits every critical point. Absolute extrema occur at critical points or at end points.

5. First Derivative Test

Let c be a critical point (f continuous at c).
① f′ changes + to − as x increases through c ⇒ local maximum.
② f′ changes − to + ⇒ local minimum.
③ f′ does not change sign ⇒ neither (point of inflection).

6. Second Derivative Test

Let f′(c) = 0 and f″ exist at c.
① f″(c) < 0 ⇒ local maximum. ② f″(c) > 0 ⇒ local minimum. ③ f″(c) = 0 ⇒ test fails, use the first derivative test.
Reason: f″ < 0 means f′ is decreasing, so f′ goes from + to − through 0.
Higher-order test: if f′(c) = … = f⁽ⁿ⁻¹⁾(c) = 0 and f⁽ⁿ⁾(c) ≠ 0: n even and f⁽ⁿ⁾ < 0 ⇒ max; n even and f⁽ⁿ⁾ > 0 ⇒ min; n odd ⇒ neither.

Fig. 2: y = x³ has a horizontal tangent at O, yet the curve keeps rising. f′ does not change sign, so it is neither a maximum nor a minimum.

7. Finding Maximum and Minimum Values

Local extrema: ① find f′(x); ② solve f′(x) = 0 (also note points where f′ does not exist); ③ apply the first or second derivative test; ④ compute f(c).
Absolute extrema on [a, b]: ① find all critical points inside (a, b); ② compute f at each critical point and at a and b; ③ the largest value is the absolute maximum, the smallest is the absolute minimum.

8. Optimization Problems

Steps: ① Read carefully and draw a figure. ② Name the quantity Q to maximise/minimise. ③ Use the given constraint to write Q in one variable. ④ Find dQ/dx = 0. ⑤ Confirm max/min with d²Q/dx² (or first derivative test). ⑥ Check the value is in the allowed domain and state the answer with units.

9. Real-Life Applications

Maximum profit, minimum cost of material, largest area for a given fence, largest volume of a box or tank, shortest distance or least travel time, and least surface area for a given volume (tins, tanks) are all solved by this method.

Solved Examples (step by step)

Easy Ex 1. Find the local minimum value of f(x) = x² − 6x + 5.
f′ = 2x − 6 = 0 ⇒ x = 3. f″ = 2 > 0 ⇒ local minimum.f(3) = 9 − 18 + 5 = −4.
Easy Ex 2. Find the critical points of f(x) = x³ − 3x².
f′ = 3x² − 6x = 3x(x − 2) = 0 ⇒ x = 0, 2. (f′ exists everywhere.)
Medium Ex 3. Show f(x) = |x| has a critical point at 0 that is not stationary; find its absolute minimum.
LHD = −1, RHD = 1 ⇒ f′(0) does not exist: critical point, but f′ ≠ 0 anywhere, so no stationary point.|x| ≥ 0 = f(0) for all x: absolute minimum 0 at x = 0.
Medium Ex 4. Find local maxima and minima of f(x) = 2x³ − 21x² + 36x − 20.
f′ = 6x² − 42x + 36 = 6(x − 1)(x − 6) = 0 ⇒ x = 1, 6. f″ = 12x − 42.f″(1) = −30 < 0 ⇒ local maximum, f(1) = 2 − 21 + 36 − 20 = −3.f″(6) = 30 > 0 ⇒ local minimum, f(6) = 432 − 756 + 216 − 20 = −128.
Medium Ex 5. Use the first derivative test for f(x) = x³ − 6x² + 9x + 15.
f′ = 3(x − 1)(x − 3). Critical points 1, 3.x < 1: f′ > 0; 1 < x < 3: f′ < 0; x > 3: f′ > 0.At 1: + to − ⇒ local maximum f(1) = 19. At 3: − to + ⇒ local minimum f(3) = 15.
Medium Ex 6. Find absolute max and min of f(x) = x³ − 3x on [0, 2].
f′ = 3x² − 3 = 0 ⇒ x = ±1; only x = 1 lies in [0, 2].f(0) = 0, f(1) = −2, f(2) = 2.Absolute maximum 2 at x = 2; absolute minimum −2 at x = 1.
Medium Ex 7. Find absolute extrema of f(x) = sin x + cos x on [0, π].
f′ = cos x − sin x = 0 ⇒ x = π/4 in [0, π].f(π/4) = √2; f(0) = 1; f(π) = −1.Absolute maximum √2 at π/4; absolute minimum −1 at x = π.
Hard Ex 8. Decide the nature of x = 0 for f(x) = x³ and f(x) = x⁴.
x³: f′ = 3x² ≥ 0, f′(0) = 0, f″(0) = 0, f‴(0) = 6 ≠ 0, n = 3 odd ⇒ neither (inflection).x⁴: f′ = 4x³, f″(0) = 0, f‴(0) = 0, f⁗(0) = 24 > 0, n = 4 even ⇒ local minimum, value 0.
Medium Ex 9. Find the minimum value of f(x) = x + 1/x for x > 0.
f′ = 1 − 1/x² = 0 ⇒ x = 1 (x > 0). f″ = 2/x³ = 2 > 0 ⇒ minimum.Minimum value f(1) = 2.
Easy Ex 10. Two positive numbers sum to 20. Find them if their product is maximum.
P = x(20 − x) = 20x − x². P′ = 20 − 2x = 0 ⇒ x = 10. P″ = −2 < 0 ⇒ max.Numbers: 10 and 10; maximum product 100.
Hard Ex 11. Show that the rectangle of maximum area inscribed in a circle of radius r is a square.
Sides x, y: x² + y² = 4r² (diagonal = diameter). A = xy, so A² = x²(4r² − x²) = S.S′ = 8r²x − 4x³ = 0 ⇒ x² = 2r². S″ = 8r² − 12x² = −16r² < 0 ⇒ maximum.Then y² = 4r² − 2r² = 2r² = x² ⇒ x = y: a square, area 2r². ∎
Hard Ex 12. Find the maximum volume of a right circular cylinder inscribed in a sphere of radius R.
Cylinder radius r, height h: r² + h²/4 = R². V = πr²h = π(R²h − h³/4).V′ = π(R² − 3h²/4) = 0 ⇒ h = 2R/√3. V″ = −3πh/2 < 0 ⇒ maximum.r² = R² − R²/3 = 2R²/3. V = π(2R²/3)(2R/√3) = 4πR³/(3√3).
Medium Ex 13. Profit P(x) = −2x² + 80x − 200. Find the number of units for maximum profit.
P′ = −4x + 80 = 0 ⇒ x = 20. P″ = −4 < 0 ⇒ maximum.P(20) = −800 + 1600 − 200 = ₹600 at 20 units.
Hard Ex 14. Find the point on y = x² nearest to (0, 5).
D² = x² + (x² − 5)² = x⁴ − 9x² + 25. Let u = x² ≥ 0: D² = u² − 9u + 25.d/du = 2u − 9 = 0 ⇒ u = 9/2; second derivative 2 > 0 ⇒ minimum.x = ±3/√2, y = 9/2. Minimum D² = 81/4 − 81/2 + 25 = 19/4, so D = √19/2. Points (±3/√2, 9/2).
Hard Ex 15. An open tank with a square base must hold volume V. Show least material is used when depth = half the base side.
Base side x, depth h: V = x²h. Surface S = x² + 4xh = x² + 4V/x.S′ = 2x − 4V/x² = 0 ⇒ x³ = 2V ⇒ h = V/x² = x/2. S″ = 2 + 8V/x³ > 0 ⇒ minimum. ∎

Short Questions

Q1. Define a critical point.A point c in the domain with f′(c) = 0 or f′(c) not existing.
Q2. Are all critical points stationary points?No. Stationary points need f′ = 0; for |x| at 0, f′ does not exist.
Q3. Is f′(c) = 0 enough for an extremum?No. For x³ at 0, f′ = 0 but there is no extremum.
Q4. What does f″(c) > 0 with f′(c) = 0 imply?Local minimum at c.
Q5. Where do absolute extrema of a continuous function on [a, b] occur?At critical points inside (a, b) or at the end points a, b.
Q6. Maximum value of sin x?1, at x = π/2.

Long Questions

Q7. Show that of all rectangles of given perimeter, the square has the maximum area.Perimeter 2p, sides x and p − x. A = x(p − x), A′ = p − 2x = 0 ⇒ x = p/2, A″ = −2 < 0. Both sides p/2: a square.
Q8. Show that a closed cylinder of given volume has minimum surface area when h = 2r.S = 2πr² + 2V/r; S′ = 4πr − 2V/r² = 0 ⇒ V = 2πr³ ⇒ h = 2r; S″ = 4π + 4V/r³ > 0 ⇒ minimum. ∎
Q9. Find local extrema of f(x) = x⁴ − 4x³.f(x) = x⁴ − 4x³: f′ = 4x²(x − 3) = 0 ⇒ x = 0, 3. At 0 f′ does not change sign (negative on both sides) ⇒ no extremum. At 3: − to + ⇒ local minimum f(3) = 81 − 108 = −27.
