अध्याय 9: अवकलज के अनुप्रयोग

उ.प्र. बोर्ड / एन.सी.ई.आर.टी. शैली के नोट्स · चरणबद्ध · एनिमेटेड चित्र

1. राशियों के परिवर्तन की दर

यदि y = f(x), तो dy/dx, x के सापेक्ष y के परिवर्तन की दर है। किसी बिंदु x = x₀ पर इसे [dy/dx]x=x₀ = f′(x₀) लिखते हैं। यदि dy/dx > 0 हो, तो x बढ़ने पर y बढ़ता है; यदि dy/dx < 0 हो, तो y घटता है। समय t पर निर्भर राशियों के लिए dx/dt, समय के सापेक्ष x के परिवर्तन की दर है।

प्राचलिक रूप: यदि x = φ(t) और y = ψ(t), तो dy/dx = (dy/dt)/(dx/dt)।
संबद्ध दरें (शृंखला नियम): यदि V, r पर और r, t पर निर्भर है, तो dV/dt = (dV/dr)(dr/dt)।

2. वास्तविक जीवन की समस्याओं में परिवर्तन की दर

आकृतिसूत्रदरें
वृत्तA = πr², C = 2πrdA/dt = 2πr dr/dt
गोलाV = (4/3)πr³, S = 4πr²dV/dt = 4πr² dr/dt; dS/dt = 8πr dr/dt
घन (कोर x)V = x³, S = 6x²dV/dt = 3x² dx/dt; dS/dt = 12x dx/dt
शंकुV = (1/3)πr²hगुणन नियम से अवकलन
शाब्दिक प्रश्नों के चरण: ① चित्र बनाइए, चरों के नाम लिखिए। ② चरों के बीच संबंध लिखिए। ③ t के सापेक्ष अवकलन कीजिए। ④ दिए गए मान अवकलन के बाद रखिए। ⑤ उत्तर इकाई सहित लिखिए और चिह्न का अर्थ बताइए (ऋणात्मक = घट रहा है)।

3. वर्धमान फलन एवं 4. ह्रासमान फलन

अंतराल I में निरंतर वर्धमान: x₁ < x₂ ⇒ f(x₁) < f(x₂)।
निरंतर ह्रासमान: x₁ < x₂ ⇒ f(x₁) > f(x₂)।  अचर: f(x₁) = f(x₂)।
प्रमेय। माना f, [a, b] में संतत तथा (a, b) में अवकलनीय है। तब
(a, b) में f′(x) > 0 ⇒ f निरंतर वर्धमान; f′(x) < 0 ⇒ निरंतर ह्रासमान; f′(x) = 0 ⇒ अचर।

उपपत्ति (वर्धमान स्थिति)। a ≤ x₁ < x₂ ≤ b लीजिए। LMVT से ∃ c ∈ (x₁, x₂): f(x₂) − f(x₁) = f′(c)(x₂ − x₁)। चूँकि f′(c) > 0 और x₂ − x₁ > 0, अतः f(x₂) > f(x₁)। ∎

अंतराल ज्ञात करने की विधि: ① f′(x) ज्ञात कीजिए। ② f′(x) = 0 हल करके क्रांतिक बिंदु पाइए। ③ ये बिंदु वास्तविक रेखा को अंतरालों में बाँटते हैं। ④ प्रत्येक अंतराल में f′ का चिह्न जाँचिए।

चित्र 1: गतिमान स्पर्श रेखा बाईं ओर ऋणात्मक प्रवणता (गिरता), तल पर शून्य और दाईं ओर धनात्मक प्रवणता (चढ़ता) दर्शाती है।

5. सन्निकटन में अवकलज के अनुप्रयोग

x में छोटे परिवर्तन Δx के लिए: Δy ≈ dy = f′(x) Δx, अतः f(x + Δx) ≈ f(x) + f′(x) Δx।
निरपेक्ष त्रुटि = Δx; सापेक्ष त्रुटि = Δx/x; प्रतिशत त्रुटि = (Δx/x) × 100।

विधि: पास का सुविधाजनक मान x (पूर्ण वर्ग/घन) चुनिए, छोटे अंतर को Δx लीजिए, f(x) और f′(x) निकालिए, फिर f′(x)Δx जोड़िए।

6. उच्चतम एवं निम्नतम मान (परिचय)

स्थानीय उच्चतम c पर: c के पास सभी x के लिए f(c) ≥ f(x)। स्थानीय निम्नतम: पास में f(c) ≤ f(x)।
क्रांतिक बिंदु: वह c जहाँ f′(c) = 0 हो या f′(c) विद्यमान न हो। आवश्यक प्रतिबंध: अवकलनीय फलन के स्थानीय चरम बिंदु पर f′(c) = 0।
[a, b] में परम उच्चतम/निम्नतम: सभी क्रांतिक बिंदुओं तथा सिरों a, b पर f के मानों की तुलना कीजिए।

चित्र 2: पहाड़ी की चोटी और घाटी के तल पर स्पर्श रेखा (हरी) क्षैतिज होती है।

7. प्रथम अवकलज परीक्षण

माना f क्रांतिक बिंदु c पर संतत है।
① c पर f′ का चिह्न + से − बदले ⇒ स्थानीय उच्चतम।
② f′ का चिह्न − से + बदले ⇒ स्थानीय निम्नतम।
③ f′ का चिह्न न बदले ⇒ कोई नहीं (नति परिवर्तन बिंदु)।

8. द्वितीय अवकलज परीक्षण

माना f′(c) = 0 और c पर f″ विद्यमान है।
① f″(c) < 0 ⇒ स्थानीय उच्चतम। ② f″(c) > 0 ⇒ स्थानीय निम्नतम। ③ f″(c) = 0 ⇒ परीक्षण असफल; प्रथम अवकलज परीक्षण लगाइए।

9. अवकलजों पर आधारित व्यावहारिक समस्याएँ

चरण: ① जिस राशि का उच्चतम/निम्नतम मान चाहिए उसे पहचानिए। ② दी गई शर्त से उसे एक चर में लिखिए। ③ f′ = 0 हल कीजिए। ④ f″ से उच्चतम/निम्नतम जाँचिए। ⑤ जाँचिए कि उत्तर मान्य प्रांत में है, फिर अंतिम मान इकाई सहित लिखिए।

हल सहित उदाहरण (चरण-दर-चरण)

सरल उदा. 1. वृत्त की त्रिज्या 0.7 सेमी/से की दर से बढ़ रही है। उसकी परिधि के बढ़ने की दर ज्ञात कीजिए।
C = 2πr ⇒ dC/dt = 2π · dr/dt = 2π(0.7) = 1.4π सेमी/से।
सरल उदा. 2. r = 5 सेमी पर वृत्त के क्षेत्रफल के परिवर्तन की दर r के सापेक्ष ज्ञात कीजिए।
A = πr² ⇒ dA/dr = 2πr = 10π = 10π सेमी²/सेमी।
मध्यम उदा. 3. गोलाकार गुब्बारे की त्रिज्या 2 सेमी/से की दर से बढ़ रही है। r = 10 सेमी पर आयतन के बढ़ने की दर ज्ञात कीजिए।
V = (4/3)πr³ ⇒ dV/dt = 4πr² dr/dt = 4π(100)(2) = 800π सेमी³/से।
मध्यम उदा. 4. 5 मी लंबी सीढ़ी दीवार से दूर खिसक रही है और उसका निचला सिरा 2 मी/से की दर से बढ़ रहा है। जब निचला सिरा दीवार से 3 मी दूर हो तब ऊपरी सिरा कितनी तेजी से नीचे खिसक रहा है?
x² + y² = 25। जब x = 3, तब y = 4।2x dx/dt + 2y dy/dt = 0 ⇒ dy/dt = −(x/y) dx/dt = −(3/4)(2) = −3/2।ऊपरी सिरा 1.5 मी/से की दर से नीचे खिसक रहा है।
मध्यम उदा. 5. घन की कोर 3 सेमी/से की दर से बढ़ रही है। कोर = 10 सेमी पर आयतन और पृष्ठीय क्षेत्रफल के बढ़ने की दर ज्ञात कीजिए।
dV/dt = 3x² dx/dt = 3(100)(3) = 900 सेमी³/से।dS/dt = 12x dx/dt = 12(10)(3) = 360 सेमी²/से।
सरल उदा. 6. f(x) = x² − 4x + 6 के वर्धमान और ह्रासमान अंतराल ज्ञात कीजिए।
f′ = 2x − 4 = 0 ⇒ x = 2।x > 2: f′ > 0 ⇒ (2, ∞) में वर्धमान। x < 2: f′ < 0 ⇒ (−∞, 2) में ह्रासमान।
मध्यम उदा. 7. f(x) = 2x³ − 3x² − 36x + 7 के एकदिष्ट अंतराल ज्ञात कीजिए।
f′ = 6x² − 6x − 36 = 6(x − 3)(x + 2)।x < −2 और x > 3 पर f′ > 0: (−∞, −2) ∪ (3, ∞) में वर्धमान।−2 < x < 3 पर f′ < 0: (−2, 3) में ह्रासमान।
कठिन उदा. 8. सिद्ध कीजिए कि f(x) = x³ − 3x² + 3x − 100, R पर वर्धमान है।
f′ = 3x² − 6x + 3 = 3(x − 1)² ≥ 0 सभी x के लिए।f′ = 0 केवल x = 1 पर (विलगित बिंदु), अतः दोनों ओर f′ > 0; f, R पर निरंतर वर्धमान है। ∎
सरल उदा. 9. √25.3 का सन्निकट मान ज्ञात कीजिए।
f(x) = √x, x = 25, Δx = 0.3; f(25) = 5; f′(x) = 1/(2√x) = 0.1।Δy = 0.1 × 0.3 = 0.03 ⇒ √25.3 ≈ 5.03।
कठिन उदा. 10. (3.968)^(3/2) का सन्निकट मान ज्ञात कीजिए।
f(x) = x^(3/2), x = 4, Δx = −0.032; f(4) = 8; f′ = (3/2)√x = 3।Δy = 3 × (−0.032) = −0.096 ⇒ मान ≈ 8 − 0.096 = 7.904।
मध्यम उदा. 11. गोले की त्रिज्या 9 सेमी है और उसमें संभावित त्रुटि 0.03 सेमी है। आयतन में सन्निकट त्रुटि ज्ञात कीजिए।
ΔV ≈ dV = 4πr² Δr = 4π(81)(0.03) = 9.72π सेमी³।
सरल उदा. 12. द्वितीय अवकलज परीक्षण से f(x) = x³ − 3x के स्थानीय चरम मान ज्ञात कीजिए।
f′ = 3x² − 3 = 0 ⇒ x = ±1। f″ = 6x।f″(1) = 6 > 0 ⇒ स्थानीय निम्नतम, मान f(1) = −2।f″(−1) = −6 < 0 ⇒ स्थानीय उच्चतम, मान f(−1) = 2।
मध्यम उदा. 13. प्रथम अवकलज परीक्षण से (0, π/2) में f(x) = sin x + cos x का स्थानीय उच्चतम मान ज्ञात कीजिए।
f′ = cos x − sin x = 0 ⇒ x = π/4।x < π/4 पर f′ > 0; x > π/4 पर f′ < 0: चिह्न + से − बदला।π/4 पर स्थानीय उच्चतम, मान √2।
कठिन उदा. 14. दिखाइए कि f(x) = x⁴ के लिए 0 पर द्वितीय अवकलज परीक्षण असफल है, और 0 की प्रकृति ज्ञात कीजिए।
f′ = 4x³ = 0 पर x = 0; f″ = 12x² = 0 पर 0: परीक्षण असफल।प्रथम अवकलज परीक्षण: x < 0 पर f′ < 0 और x > 0 पर f′ > 0 (− से +): स्थानीय निम्नतम, f(0) = 0।
मध्यम उदा. 15. योग 16 वाली दो धनात्मक संख्याएँ ज्ञात कीजिए जिनके घनों का योग निम्नतम हो।
संख्याएँ x और 16 − x। S = x³ + (16 − x)³।S′ = 3x² − 3(16 − x)² = 0 ⇒ x = 16 − x ⇒ x = 8।S″ = 6x + 6(16 − x) = 96 > 0 ⇒ निम्नतम। संख्याएँ: 8 और 8; निम्नतम योग = 1024।
मध्यम उदा. 16. एक किसान के पास आयताकार खेत के लिए 200 मी बाड़ है। अधिकतम क्षेत्रफल ज्ञात कीजिए।
2(x + y) = 200 ⇒ y = 100 − x। A = x(100 − x)।A′ = 100 − 2x = 0 ⇒ x = 50; A″ = −2 < 0 ⇒ उच्चतम।y = 50, अतः खेत वर्गाकार; अधिकतम क्षेत्रफल = 2500 मी²।
कठिन उदा. 17. 18 सेमी भुजा के वर्गाकार गत्ते के कोनों से x भुजा के वर्ग काटकर खुला डिब्बा बनाया गया। अधिकतम आयतन के लिए x ज्ञात कीजिए।
V = x(18 − 2x)² = 4x³ − 72x² + 324x।V′ = 12x² − 144x + 324 = 12(x − 3)(x − 9) = 0 ⇒ x = 3 (x = 9 अस्वीकार, क्योंकि 18 − 2x = 0)।x = 3 पर V″ = 24x − 144 = −72 < 0 ⇒ उच्चतम। x = 3 सेमी, V = 3 × 12² = 432 सेमी³।
