1. Binary Operations

1.1 Definition

Definition: A binary operation ∗ on a non-empty set A is a function ∗ : A × A → A. It takes two elements a, b of A and gives one element a ∗ b, which must also be in A.

Binary operation: two inputs, one output

“Binary” means two inputs. Usual operations +, −, ×, ÷ are binary operations on suitable sets. Other operations can be defined by a rule, e.g. a ∗ b = a + b − ab or a ∗ b = |a − b|.

1.3 Closure Property

Definition: A is closed under ∗ if a ∗ b ∈ A for all a, b ∈ A. Closure is the same as saying ∗ is a binary operation on A.

Closed: a∗b stays in A

Not closed: a∗b leaves A

How to check: take a, b ∈ A, compute a ∗ b, and see whether it always lies in A. To disprove, give one pair whose result lies outside A.

1.4 Commutative Binary Operation

Definition: ∗ is commutative if a ∗ b = b ∗ a for all a, b ∈ A.

+ and × are commutative on N, Z, R. − and ÷ are not (3 − 2 ≠ 2 − 3). To disprove, one counter-example is enough.

1.5 Associative Binary Operation

Definition: ∗ is associative if (a ∗ b) ∗ c = a ∗ (b ∗ c) for all a, b, c ∈ A.

+ and × are associative. − is not: (8 − 3) − 2 = 3 but 8 − (3 − 2) = 7. Find LHS and RHS separately and compare.

1.6 Identity Element

Definition: e ∈ A is the identity for ∗ if a ∗ e = e ∗ a = a for all a ∈ A.
  • Identity for + is 0; for × is 1; for ∗ defined as a ∗ b = a + b − ab it is 0.
  • Identity, if it exists, is unique. (If e and e′ are identities, e = e ∗ e′ = e′.)
  • Method: put a ∗ e = a and solve for e; then check e ∗ a = a also holds and e ∈ A.
  • − on Z has no identity: a − 0 = a but 0 − a ≠ a.

1.7 Inverse of an Element

Definition: Let e be the identity. b ∈ A is the inverse of a if a ∗ b = b ∗ a = e. We write b = a⁻¹.
  • Inverse exists only if the identity exists.
  • For an associative operation, inverse of an element is unique.
  • Under +, inverse of a is −a; under ×, inverse of a is 1/a (a ≠ 0). In Z under ×, only 1 and −1 have inverses.
  • Method: solve a ∗ b = e for b and check b ∈ A.

1.8 Checking Properties – Step by Step

  1. Closure: is a ∗ b ∈ A always?
  2. Commutative: compare a ∗ b and b ∗ a.
  3. Associative: compute (a ∗ b) ∗ c and a ∗ (b ∗ c).
  4. Identity: solve a ∗ e = a.
  5. Inverse: solve a ∗ b = e.

2. Solved Examples

Easy Ex 1. Is − a binary operation on N?
Solution: Take 2, 5 ∈ N. 2 − 5 = −3 ∉ N. Not closed, so not a binary operation.
Easy Ex 2. Is a ∗ b = a² + b² commutative on R?
Solution: b ∗ a = b² + a² = a² + b² = a ∗ b. Yes, commutative.
Easy Ex 3. How many binary operations on {1,2,3}? How many commutative?
Solution: n = 3. Total = 3⁹ = 19683. Commutative = 33·4/2 = 3⁶ = 729.
Medium Ex 4. On R, a ∗ b = a + b − ab. Show it is commutative and associative; find identity and inverse.
Solution: Commutative: b ∗ a = b + a − ba = a ∗ b.
Associative: (a ∗ b) ∗ c = (a + b − ab) + c − (a + b − ab)c = a + b + c − ab − bc − ca + abc. a ∗ (b ∗ c) gives the same expression. So associative.
Identity: a ∗ e = a ⇒ a + e − ae = a ⇒ e(1 − a) = 0 ⇒ e = 0. Also 0 ∗ a = a.
Inverse: a ∗ b = 0 ⇒ a + b − ab = 0 ⇒ b(1 − a) = −a ⇒ b = a/(a − 1). Exists for a ≠ 1; so 1 has no inverse.
Medium Ex 5. On R − {−1}, a ∗ b = a + b + ab. Show ∗ is a binary operation; find identity and inverse.
Solution: Note a + b + ab = (a + 1)(b + 1) − 1. If it were −1, then (a + 1)(b + 1) = 0, impossible as a, b ≠ −1. So closed.
Identity: a + e + ae = a ⇒ e(1 + a) = 0 ⇒ e = 0.
Inverse: a + b + ab = 0 ⇒ b = −a/(1 + a), which is ≠ −1 and exists since a ≠ −1.
Hard Ex 6. On W (whole numbers), a ∗ b = |a − b|. Check all properties.
Solution: Closed: |a − b| ≥ 0 is a whole number. Commutative: |a − b| = |b − a|.
Not associative: (1 ∗ 2) ∗ 3 = 1 ∗ 3 = 2, but 1 ∗ (2 ∗ 3) = 1 ∗ 1 = 0.
Identity: a ∗ 0 = |a| = a and 0 ∗ a = a, so e = 0.
Inverse: a ∗ a = 0, so every element is its own inverse.
Hard Ex 7. On Q⁺, a ∗ b = ab/4. Find identity and inverse of a.
Solution: Associative: (a ∗ b) ∗ c = abc/16 = a ∗ (b ∗ c).
Identity: ae/4 = a ⇒ e = 4. Inverse: ab/4 = 4 ⇒ b = 16/a ∈ Q⁺.

3. Short & Long Q&A (tap to see answer)

Q1. Define a binary operation.

A function ∗ : A × A → A; every ordered pair of A is sent to a unique element of A.

Q2. Is ÷ a binary operation on Z? Why?

No. 1 ÷ 2 ∉ Z, and division by 0 is undefined.

Q3. Show that identity element is unique.

Let e, e′ be identities. Then e ∗ e′ = e′ (since e is identity) and e ∗ e′ = e (since e′ is identity). So e = e′.

Q4. Does − on Z have an identity?

No. a − e = a gives e = 0, but 0 − a = −a ≠ a. 0 is only a right identity.

Q5. Is a ∗ b = a on N commutative?

No. 2 ∗ 3 = 2 but 3 ∗ 2 = 3. It is associative though: (a ∗ b) ∗ c = a = a ∗ (b ∗ c).

Q6. Long: show inverse is unique for an associative ∗ with identity e.

Let b and c both be inverses of a. b = b ∗ e = b ∗ (a ∗ c) = (b ∗ a) ∗ c = e ∗ c = c. ∎

Q7. Find the identity of ∗ on Z: a ∗ b = a + b + 1.

a + e + 1 = a ⇒ e = −1. Inverse of a: a + b + 1 = −1 ⇒ b = −a − 2.

Q8. Is ∗ on N, a ∗ b = LCM(a, b), associative? Identity?

Yes, associative (LCM of three numbers). Identity is 1 since LCM(a, 1) = a. Only 1 has an inverse.

4. MCQs

1. Number of binary operations on a set of 2 elements: (a) 4 (b) 8 (c) 16 (d) 2

(c) 2⁴ = 16.

2. Number of commutative binary operations on a 3-element set: (a) 9 (b) 81 (c) 729 (d) 19683

(c) 3⁶ = 729.

3. Identity of ∗ on R, a ∗ b = a + b − ab: (a) 1 (b) 0 (c) −1 (d) none

(b) 0.

4. Which is NOT associative on R: (a) + (b) × (c) − (d) max

(c) subtraction.

5. Inverse of 2 under a ∗ b = ab/4 on Q⁺: (a) 2 (b) 4 (c) 8 (d) 1/2

(c) 2b/4 = 4 ⇒ b = 8.
