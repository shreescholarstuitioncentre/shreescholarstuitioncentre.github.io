प्रतिस्थापन द्वारा समाकलन – कक्षा 12 गणित नोट्स

इकाई 3: कलन · अध्याय 13 · यू.पी. बोर्ड

1. प्रतिस्थापन विधि

बहुत-से समाकल मानक सारणी से सीधे हल नहीं होते। प्रतिस्थापन विधि शृंखला नियम को उलटती है: d/dx [F(g(x))] = F′(g(x))·g′(x)। अतः ∫ f(g(x))·g′(x) dx = F(g(x)) + C, जहाँ F, f का प्रतिअवकलज है।

∫ f(g(x)) · g′(x) dx  → t = g(x) रखें →  ∫ f(t) dt

2. चर परिवर्तन

चरण: (1) t = g(x) चुनें, प्रायः अंदर वाला या जटिल भाग; (2) अवकलन करें: dt = g′(x) dx; (3) प्रत्येक x और dx को t और dt से बदलें (यदि x बचे तो उसे t के पदों में लिखें); (4) समाकलन करें; (5) t = g(x) वापस रखें। अंतिम उत्तर x में ही होना चाहिए। उत्तर में t कभी न छोड़ें।

t का चयन: ऐसा व्यंजक चुनें जिसका अवकलज (एक अचर तक) समाकल्य में दिखता हो: घात वाला कोष्ठक, e का घातांक, हर, मूल, log x, या sin x/cos x।

3. मानक प्रतिस्थापनों द्वारा समाकलन

(i) ∫ f′(x)/f(x) dx = log|f(x)| + C  (t = f(x))
(ii) ∫ [f(x)]ⁿ f′(x) dx = [f(x)]ⁿ⁺¹/(n+1) + C, n ≠ −1
(iii) ∫ f(ax+b) dx = F(ax+b)/a + C  (t = ax+b)
(iv) ∫ f′(x)/√f(x) dx = 2√f(x) + C
(v) ∫ tan x dx = log|sec x| + C   ∫ cot x dx = log|sin x| + C
(vi) ∫ sec x dx = log|sec x + tan x| + C
(vii) ∫ cosec x dx = log|cosec x − cot x| + C

परिणाम (vi) में अंश-हर को (sec x + tan x) से गुणा करके t = sec x + tan x रखते हैं; परिणाम (vii) में इसी प्रकार (cosec x − cot x) से।

4. बीजीय व्यंजकों वाले समाकल

यदि कोष्ठक (या मूल) जटिल हो और उसका अवकलज उपस्थित हो, तो उसे t के बराबर रखें। x/√(x+1) में t = x+1 रखें और x = t − 1 लिखें। x²/(1+x⁶) में t = x³ रखें क्योंकि dt = 3x² dx।

5. त्रिकोणमितीय व्यंजकों वाले समाकल

सामान्य नियम: sinⁿx cos x में t = sin x; cosⁿx sin x में t = cos x; tanⁿx sec²x में t = tan x। यदि sin (या cos) की घात विषम हो तो एक गुणनखंड अलग रखें और शेष को sin²x = 1 − cos²x से बदलें। यदि दोनों घातें सम हों तो अर्धकोण सर्वसमिकाएँ प्रयोग करें।

6. चरघातांकी एवं लघुगणकीय फलनों वाले समाकल

e^(f(x))·f′(x) में t = f(x) रखें, तब e^t मिलता है। eˣ वाले भिन्नों में हर या eˣ को t रखें। जब log x के साथ 1/x हो तो t = log x रखें क्योंकि dt = dx/x।

7. द्विघात व्यंजकों वाले समाकल

∫ dx/(x²+a²) = (1/a) tan⁻¹(x/a) + C
∫ dx/(x²−a²) = (1/2a) log|(x−a)/(x+a)| + C
∫ dx/(a²−x²) = (1/2a) log|(a+x)/(a−x)| + C
∫ dx/√(a²−x²) = sin⁻¹(x/a) + C
∫ dx/√(x²+a²) = log|x + √(x²+a²)| + C
∫ dx/√(x²−a²) = log|x + √(x²−a²)| + C
∫ √(a²−x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a) + C

ax²+bx+c के लिए पूर्ण वर्ग बनाएँ: x²+4x+13 = (x+2)²+9, फिर t = x+2 रखकर ऊपर के सूत्र लगाएँ। त्रिकोणमितीय प्रतिस्थापन x = a sin θ, a tan θ, a sec θ (चित्र 2) इन सूत्रों को सिद्ध करते हैं।

8. प्रतिस्थापन पर आधारित प्रश्न: त्वरित मार्गदर्शिका

समाकल्य में होरखें
(ax+b)ⁿ, √(ax+b)t = ax+b
f′(x)/f(x)t = f(x)
e^(f(x)) f′(x)t = f(x)
(log x)ⁿ/xt = log x
√(a²−x²)x = a sin θ
√(a²+x²) या a²+x²x = a tan θ
√(x²−a²)x = a sec θ

चित्र (एनिमेटेड)

चित्र 1: प्रतिस्थापन विधि के पाँच चरणों का प्रवाह; हरे तीर कार्य की दिशा दिखाते हैं। चित्र 2: त्रिकोणमितीय प्रतिस्थापनों के पीछे के तीन समकोण त्रिभुज। प्रत्येक में θ, a और x के पदों में भुजाएँ तथा उसे बनाने वाला प्रतिस्थापन दिखाया गया है। ये उत्तर को θ से वापस x में बदलने में सहायक हैं।

हल किए गए उदाहरण (चरण दर चरण)

1. ∫ x(x²+1)³ dx ज्ञात कीजिए
t = x²+1 रखें ⇒ dt = 2x dx ⇒ x dx = dt/2। समाकल = ½∫ t³ dt = t⁴/8। वापस: (x²+1)⁴/8 + C।
2. ∫ x/√(x+1) dx ज्ञात कीजिए
t = x+1, x = t−1, dx = dt। ∫ (t−1)/√t dt = ∫ (t^½ − t^−½) dt = (2/3)t^(3/2) − 2t^½। उत्तर: (2/3)(x+1)^(3/2) − 2√(x+1) + C।
3. ∫ 2x/(x²+1) dx ज्ञात कीजिए
अंश हर का अवकलज है। t = x²+1, dt = 2x dx। ∫ dt/t = log|t|। उत्तर: log(x²+1) + C।
4. ∫ tan x dx ज्ञात कीजिए
tan x = sin x/cos x। t = cos x, dt = −sin x dx। ∫ = −∫ dt/t = −log|t| = −log|cos x| = log|sec x| + C।
5. ∫ sin³x cos x dx ज्ञात कीजिए
t = sin x, dt = cos x dx। ∫ t³ dt = t⁴/4। उत्तर: sin⁴x/4 + C।
6. ∫ sin³x dx ज्ञात कीजिए
sin³x = sin x (1 − cos²x)। t = cos x, dt = −sin x dx। ∫ = −∫ (1 − t²) dt = −t + t³/3। उत्तर: −cos x + cos³x/3 + C।
7. ∫ sec x dx ज्ञात कीजिए
अंश-हर को (sec x + tan x) से गुणा करें: ∫ (sec²x + sec x tan x)/(sec x + tan x) dx। t = sec x + tan x, dt = (sec x tan x + sec²x) dx। ∫ dt/t = log|sec x + tan x| + C।
8. ∫ eˣ/(1+eˣ) dx ज्ञात कीजिए
t = 1+eˣ, dt = eˣ dx। ∫ dt/t = log|t|। उत्तर: log(1+eˣ) + C (1+eˣ > 0)।
9. ∫ (log x)²/x dx ज्ञात कीजिए
t = log x, dt = dx/x। ∫ t² dt = t³/3। उत्तर: (log x)³/3 + C।
10. ∫ dx/(x log x) ज्ञात कीजिए
t = log x, dt = dx/x। ∫ dt/t = log|t|। उत्तर: log|log x| + C।
11. ∫ e^√x/√x dx ज्ञात कीजिए
t = √x, dt = dx/(2√x) ⇒ dx/√x = 2 dt। ∫ 2eᵗ dt = 2eᵗ। उत्तर: 2e^√x + C।
12. ∫ cos x/(1+sin²x) dx ज्ञात कीजिए
t = sin x, dt = cos x dx। ∫ dt/(1+t²) = tan⁻¹ t। उत्तर: tan⁻¹(sin x) + C।
13. ∫ x²/(1+x⁶) dx ज्ञात कीजिए
t = x³, dt = 3x² dx ⇒ x² dx = dt/3। ∫ (1/3) dt/(1+t²) = (1/3) tan⁻¹ t। उत्तर: (1/3) tan⁻¹(x³) + C।
14. ∫ dx/(x²+4x+13) ज्ञात कीजिए
पूर्ण वर्ग: x²+4x+13 = (x+2)² + 3²। t = x+2, dt = dx। ∫ dt/(t²+9) = (1/3) tan⁻¹(t/3)। उत्तर: (1/3) tan⁻¹((x+2)/3) + C।
15. ∫ dx/√(x²+2x+5) ज्ञात कीजिए
x²+2x+5 = (x+1)² + 2²। t = x+1 रखें। ∫ dt/√(t²+4) = log|t + √(t²+4)|। उत्तर: log|x+1+√(x²+2x+5)| + C।
16. ∫ dx/(sin x cos x) ज्ञात कीजिए
अंश-हर को cos²x से भाग दें: ∫ sec²x/tan x dx। t = tan x, dt = sec²x dx। ∫ dt/t = log|tan x| + C।
17. सत्यापित कीजिए: ∫ 2x/(x²+1) dx = log(x²+1) + C
d/dx log(x²+1) = (1/(x²+1))·2x = 2x/(x²+1) ✓। सत्यापित।

लघु एवं दीर्घ प्रश्नोत्तर (खोलने के लिए छुएँ)

Q1. प्रतिस्थापन विधि का मूल विचार बताइए।
यह शृंखला नियम को उलटती है: समाकल्य को f(g(x))g′(x) के रूप में लिखें, t = g(x) रखें, f(t) का समाकलन करें और t को वापस बदलें।
Q2. dx को भी क्यों बदलना पड़ता है?
क्योंकि dx समाकल का भाग है; t = g(x) लेने पर dx = dt/g′(x)। x में छोड़ने पर मिश्रित और गलत समाकल बनता है।
Q3. ∫ f′(x)/f(x) dx ज्ञात कीजिए।
t = f(x) रखें। समाकल ∫ dt/t = log|f(x)| + C हो जाता है।
Q4. ∫ dx/√(a²−x²) के लिए कौन-सा प्रतिस्थापन प्रयुक्त होता है?
x = a sin θ, जिससे ∫ dθ = θ = sin⁻¹(x/a) + C मिलता है।
Q5. क्या उत्तर में t रह सकता है?
नहीं। समाकलन के बाद t = g(x) वापस रखना आवश्यक है।
Q6. ∫ dx/(ax²+bx+c) को कैसे हल करते हैं?
पूर्ण वर्ग बनाकर द्विघात मानक सूत्र प्रयोग करते हैं।
Q7. ∫ cosec x dx का परिणाम लिखिए।
log|cosec x − cot x| + C।
Q8. दीर्घ: सिद्ध कीजिए ∫ dx/(x²+a²) = (1/a) tan⁻¹(x/a) + C।
x = a tan θ, dx = a sec²θ dθ रखें। x²+a² = a²sec²θ। ∫ a sec²θ dθ/(a² sec²θ) = (1/a)∫ dθ = θ/a। चूँकि tan θ = x/a, θ = tan⁻¹(x/a)। अतः परिणाम सिद्ध।
Q9. दीर्घ: सिद्ध कीजिए ∫ dx/√(a²−x²) = sin⁻¹(x/a) + C।
x = a sin θ, dx = a cos θ dθ रखें। √(a²−x²) = a cos θ। ∫ a cos θ dθ/(a cos θ) = θ = sin⁻¹(x/a)। अतः सिद्ध।
Q10. दीर्घ: ∫ (x+1)/(x²+2x+3) dx का मान ज्ञात कीजिए।
t = x²+2x+3, dt = 2(x+1) dx ⇒ (x+1)dx = dt/2। ½∫ dt/t = ½ log|t| = ½ log(x²+2x+3) + C। जाँच: अवकलज = (2x+2)/(2(x²+2x+3)) ✓।
