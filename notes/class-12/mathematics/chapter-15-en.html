Integration Continued – Class 12 Maths Notes

Unit 3: Calculus · Chapter 15 · UP Board

1. Integration by Partial Fractions

A rational function is P(x)/Q(x) with polynomials P, Q. If degree P < degree Q it is proper; otherwise first divide: P/Q = (quotient) + (remainder)/Q, then work with the proper part. Partial fractions split a complicated proper fraction into simple fractions, each of which can be integrated by standard results.

2. Integration of Rational Functions: Method

(1) Make the fraction proper. (2) Factorise Q(x). (3) Write the form for each factor (Diagram 1). (4) Multiply by Q(x) and find the constants by putting convenient values of x (roots of the factors) or by comparing coefficients. (5) Integrate each term. (6) Verify by differentiating or by recombining.

3. Integrals Involving Linear Factors

(px+q)/((x−a)(x−b)) = A/(x−a) + B/(x−b),   A = (pa+q)/(a−b), B = (pb+q)/(b−a)

Cover-up shortcut: to get A, cover the factor (x−a) and put x = a in the rest. Then ∫ A/(x−a) dx = A log|x−a|.

4. Integrals Involving Repeated Factors

For (x−a)², write A/(x−a) + B/(x−a)². For (x−a)³ add a third term C/(x−a)³. Integrals: ∫ dx/(x−a)² = −1/(x−a), ∫ dx/(x−a)³ = −1/(2(x−a)²). Cover-up gives only the highest-power constant; find the others by comparing coefficients.

5. Integrals Involving Quadratic Factors

An irreducible quadratic x²+c (or ax²+bx+c with b²−4ac < 0) takes a linear numerator: (Ax+B)/(x²+c). Integrate as A/2·log(x²+c) + B·(1/√c) tan⁻¹(x/√c).

6. Integrals of the Form ∫ dx/(x²+a²), ∫ dx/√(x²±a²)

∫ dx/(x²+a²) = (1/a) tan⁻¹(x/a) + C
∫ dx/(x²−a²) = (1/2a) log|(x−a)/(x+a)| + C
∫ dx/(a²−x²) = (1/2a) log|(a+x)/(a−x)| + C
∫ dx/√(a²−x²) = sin⁻¹(x/a) + C
∫ dx/√(x²+a²) = log|x + √(x²+a²)| + C
∫ dx/√(x²−a²) = log|x + √(x²−a²)| + C

7. Integrals Involving Quadratic Expressions: ∫ dx/(ax²+bx+c)

Take a common if a ≠ 1, then complete the square: x²+bx+c = (x + b/2)² + (c − b²/4). Put t = x + b/2. The integral becomes one of the three forms with t² + k², t² − k² or k² − t².

8. Integrals Involving Square Roots: ∫ dx/√(ax²+bx+c)

Again complete the square under the root and use sin⁻¹ (if k² − t²) or log (if t² ± k²). If a ≠ 1, take 1/√a outside.

9. Integrals of the Form ∫ (px+q)/(ax²+bx+c) dx

Write px + q = A·(2ax + b) + B  [(2ax+b) is the derivative of the denominator]
⇒ A log|ax²+bx+c| + B ∫ dx/(ax²+bx+c)

Find A by comparing x-coefficients (A = p/2a) and B by comparing constants. The same trick works for (px+q)/√(ax²+bx+c): result A·2√(ax²+bx+c) + B ∫ dx/√(ax²+bx+c).

10. Integrals of the Form ∫ √(ax²+bx+c) dx

Complete the square, put t = x + b/2, and use the next three formulas (§11). Do not try to remove the root by other substitutions.

11. Integrals Involving √(a²−x²), √(x²−a²), √(x²+a²)

∫ √(a²−x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a) + C
∫ √(x²+a²) dx = (x/2)√(x²+a²) + (a²/2) log|x + √(x²+a²)| + C
∫ √(x²−a²) dx = (x/2)√(x²−a²) − (a²/2) log|x + √(x²−a²)| + C

The first is proved geometrically in Diagram 2; all three follow by parts with u = √(…), v = 1.

Solved Examples (step by step)

1. Find ∫ dx/((x−1)(x−2))
Let 1/((x−1)(x−2)) = A/(x−1) + B/(x−2). Multiply: 1 = A(x−2) + B(x−1). x = 1: 1 = −A ⇒ A = −1. x = 2: 1 = B. ∫ = −log|x−1| + log|x−2|. Answer: log|(x−2)/(x−1)| + C.
2. Find ∫ (x+3)/((x−1)(x+1)) dx
(x+3) = A(x+1) + B(x−1). x = 1: 4 = 2A ⇒ A = 2. x = −1: 2 = −2B ⇒ B = −1. Answer: 2 log|x−1| − log|x+1| + C.
3. Find ∫ (3x+5)/((x−1)(x+3)) dx
3x+5 = A(x+3) + B(x−1). x = 1: 8 = 4A ⇒ A = 2. x = −3: −4 = −4B ⇒ B = 1. Answer: 2 log|x−1| + log|x+3| + C.
4. Find ∫ x²/(x²−1) dx
Improper (degrees equal). x²/(x²−1) = 1 + 1/(x²−1). ∫ dx/(x²−1) = ½ log|(x−1)/(x+1)| (a = 1). Answer: x + ½ log|(x−1)/(x+1)| + C.
5. Find ∫ (x+1)/(x−1)² dx
Write x+1 = (x−1) + 2. So integrand = 1/(x−1) + 2/(x−1)². Answer: log|x−1| − 2/(x−1) + C.
6. Find ∫ dx/(x(x+1)²)
1/(x(x+1)²) = A/x + B/(x+1) + C/(x+1)². 1 = A(x+1)² + Bx(x+1) + Cx. x = 0: A = 1. x = −1: 1 = −C ⇒ C = −1. Coefficient of x²: 0 = A + B ⇒ B = −1. ∫ = log|x| − log|x+1| + 1/(x+1). Answer: log|x/(x+1)| + 1/(x+1) + C.
7. Find ∫ dx/((x+1)(x²+1))
Let = A/(x+1) + (Bx+C)/(x²+1). 1 = A(x²+1) + (Bx+C)(x+1). x = −1: 1 = 2A ⇒ A = ½. x²: 0 = A + B ⇒ B = −½. Constant: 1 = A + C ⇒ C = ½. ∫ = ½ log|x+1| − ¼ log(x²+1) + ½ tan⁻¹x. Answer: ½ log|x+1| − ¼ log(x²+1) + ½ tan⁻¹x + C.
8. Find ∫ dx/(x(x²+1))
1/(x(x²+1)) = 1/x − x/(x²+1) (check: (x²+1−x²)/(x(x²+1)) ✓). ∫ = log|x| − ½ log(x²+1). Answer: log|x| − ½ log(x²+1) + C.
9. Find ∫ dx/(x²−9)
Here a = 3. Using the formula: (1/6) log|(x−3)/(x+3)| + C.
10. Find ∫ dx/√(x²+9)
a = 3. Answer: log|x + √(x²+9)| + C.
11. Find ∫ dx/(x²+2x+10)
x²+2x+10 = (x+1)² + 3². Put t = x+1. ∫ dt/(t²+9) = (1/3) tan⁻¹(t/3). Answer: (1/3) tan⁻¹((x+1)/3) + C.
12. Find ∫ dx/(x²−6x+5)
x²−6x+5 = (x−3)² − 2². t = x−3: ∫ dt/(t²−4) = (1/4) log|(t−2)/(t+2)|. Answer: (1/4) log|(x−5)/(x−1)| + C.
13. Find ∫ dx/√(2x−x²)
2x − x² = 1 − (x−1)². Put t = x−1. ∫ dt/√(1−t²) = sin⁻¹t. Answer: sin⁻¹(x−1) + C.
14. Find ∫ (2x+3)/(x²+4x+7) dx
Derivative of denominator = 2x+4. Write 2x+3 = 1·(2x+4) − 1. ∫ = log(x²+4x+7) − ∫ dx/((x+2)²+3). Second: (1/√3) tan⁻¹((x+2)/√3). Answer: log(x²+4x+7) − (1/√3) tan⁻¹((x+2)/√3) + C.
15. Find ∫ (3x+1)/√(x²+2x+2) dx
Derivative of x²+2x+2 is 2x+2. 3x+1 = (3/2)(2x+2) − 2. First part: (3/2)·2√(x²+2x+2) = 3√(x²+2x+2). Second: −2 ∫ dx/√((x+1)²+1) = −2 log|x+1+√(x²+2x+2)|. Answer: 3√(x²+2x+2) − 2 log|x+1+√(x²+2x+2)| + C.
16. Find ∫ √(9−x²) dx
a = 3. Answer: (x/2)√(9−x²) + (9/2) sin⁻¹(x/3) + C.
17. Find ∫ √(x²+4) dx
a = 2. Answer: (x/2)√(x²+4) + 2 log|x + √(x²+4)| + C.
18. Find ∫ √(x²−9) dx
a = 3. Answer: (x/2)√(x²−9) − (9/2) log|x + √(x²−9)| + C.
19. Find ∫ √(x²+2x+5) dx
x²+2x+5 = (x+1)² + 2². t = x+1, a = 2. Answer: ((x+1)/2)√(x²+2x+5) + 2 log|x+1+√(x²+2x+5)| + C.
20. Find ∫ √(3−2x−x²) dx
3−2x−x² = 4 − (x+1)². t = x+1, a = 2. Answer: ((x+1)/2)√(3−2x−x²) + 2 sin⁻¹((x+1)/2) + C.
21. Verify: ∫ dx/(x²−1) = ½ log|(x−1)/(x+1)| + C
d/dx = ½[1/(x−1) − 1/(x+1)] = ½·2/(x²−1) = 1/(x²−1) ✓. Verified.

Short & Long Q&A (tap to open)

Q1. What is a proper rational function?
P(x)/Q(x) with degree of P less than degree of Q.
Q2. What do we do for an improper fraction?
Divide P by Q first, giving quotient + proper fraction, and integrate both parts.
Q3. Write the partial-fraction form for 1/((x−a)(x−b)).
A/(x−a) + B/(x−b).
Q4. Write the form for a repeated factor (x−a)².
A/(x−a) + B/(x−a)².
Q5. Why is the numerator (Ax+B) for a quadratic factor?
The numerator is always one degree less than the factor; for a quadratic that is a linear polynomial.
Q6. Write ∫ dx/(a²−x²).
(1/2a) log|(a+x)/(a−x)| + C.
Q7. How is ∫ dx/(ax²+bx+c) solved?
Complete the square and reduce to a standard form.
Q8. Long: Prove ∫ dx/(x²−a²) = (1/2a) log|(x−a)/(x+a)| + C.
1/(x²−a²) = (1/2a)[1/(x−a) − 1/(x+a)] (since (x+a)−(x−a) = 2a). Integrating: (1/2a)[log|x−a| − log|x+a|] = (1/2a) log|(x−a)/(x+a)| + C.
Q9. Long: Prove ∫ √(a²−x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a) + C.
By parts with u = √(a²−x²), v = 1: I = x√(a²−x²) + ∫ x²/√(a²−x²) dx. Now x² = a² − (a²−x²), so ∫ x²/√ dx = a² sin⁻¹(x/a) − I. Hence I = x√(a²−x²) + a² sin⁻¹(x/a) − I ⇒ 2I = x√(a²−x²) + a² sin⁻¹(x/a). Divide by 2.
Q10. Long: Find ∫ (x+1)/(x²+x+1) dx.
Derivative of denominator = 2x+1. x+1 = ½(2x+1) + ½. ∫ = ½ log(x²+x+1) + ½ ∫ dx/((x+½)² + 3/4). Second integral = (2/√3) tan⁻¹((2x+1)/√3). So answer = ½ log(x²+x+1) + (1/√3) tan⁻¹((2x+1)/√3) + C.
