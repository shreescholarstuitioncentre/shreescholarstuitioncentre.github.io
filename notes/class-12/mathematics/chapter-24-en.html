Class 12 Maths — Chapter 24: Probability and Distributions

1. Conditional Probability

P(A|B) = P(A∩B) / P(B), P(B) ≠ 0

It is the probability of A when B has already happened. The sample space shrinks to B.

2. Multiplication Theorem and Independent Events

P(A∩B) = P(A)·P(B|A) = P(B)·P(A|B)
Independent: P(A∩B) = P(A)·P(B), and P(A|B) = P(A)

Events are independent when one does not affect the other. If A, B are independent, so are A and B′, A′ and B, A′ and B′.

3. Total Probability Theorem

P(A) = P(E₁)P(A|E₁) + P(E₂)P(A|E₂) + … + P(Eₙ)P(A|Eₙ)

E₁…Eₙ are mutually exclusive and exhaustive events (a partition of the sample space).

4. Bayes' Theorem

P(Eᵢ|A) = P(Eᵢ)P(A|Eᵢ) / Σ P(Eⱼ)P(A|Eⱼ)

It finds the probability of a cause Eᵢ after the effect A is observed.

5. Random Variables and Probability Distribution

X: x₁ x₂ … xₙ ; P(X): p₁ p₂ … pₙ with every pᵢ ≥ 0 and Σpᵢ = 1

A random variable is a real-valued function on the sample space. A discrete random variable takes countable values. The table of values with probabilities is its probability distribution.

6. Mean, Variance and Standard Deviation

Mean E(X) = μ = Σ xᵢpᵢ
Variance Var(X) = Σ xᵢ²pᵢ − μ²
SD = √Var(X)

7. Bernoulli Trials

Conditions: finite n; independent trials; two outcomes (success, failure); constant p, q = 1−p

Example: tossing a coin n times, with a head as success.

8. Binomial Distribution

P(X = r) = ⁿCᵣ pʳ q ⁿ⁻ʳ, r = 0, 1, …, n
Mean = np; Variance = npq; SD = √(npq)

Solved Examples (Given / To Find / To Prove / Solution)

Ex 1 (Easy). A die is thrown. A = even number, B = number ≥ 4. Find P(A|B).
A∩B = {4, 6} ⇒ P(A∩B) = 2/6; P(B) = 3/6.
P(A|B) = (2/6)/(3/6) = 2/3.
Ex 2 (Easy). Two cards are drawn without replacement. Find P(both aces).
P = (4/52)(3/51) = 12/2652 = 1/221.
Ex 3 (Easy). A, B independent, P(A) = 1/2, P(B) = 1/3. Find P(A∩B) and P(A∪B).
P(A∩B) = 1/6.
P(A∪B) = 1/2 + 1/3 − 1/6 = 2/3.
Ex 4 (Medium). Bag I: 3 red, 4 black; Bag II: 5 red, 6 black. A bag is chosen at random and a ball drawn. Find P(red).
P(red) = ½·(3/7) + ½·(5/11) = 3/14 + 5/22 = 33/154 + 35/154 = 68/154 = 34/77.
Ex 5 (Medium, Bayes). In Ex 4 the ball is red. Find the probability it came from Bag I.
P(I|red) = (½·3/7) / (34/77) = (33/154)/(68/154) = 33/68.
Ex 6 (Medium). Two coins are tossed, X = number of heads. Find the distribution, mean, variance.
X = 0, 1, 2 with P = 1/4, 1/2, 1/4.
Mean = 0 + 1/2 + 2/4 = 1. E(X²) = 0 + 1/2 + 4/4 = 3/2.
Var = 3/2 − 1 = 1/2; SD = 1/√2.
Ex 7 (Hard). X takes 0, 1, 2, 3 with P = k, 2k, 3k, 4k. Find k, mean, variance.
10k = 1 ⇒ k = 1/10.
Mean = (0 + 2 + 6 + 12)/10 = 2.
E(X²) = (0 + 2 + 12 + 36)/10 = 5. Var = 5 − 4 = 1.
Ex 8 (Medium). A fair coin is tossed 6 times. Find P(exactly 4 heads).
P = ⁶C₄ (½)⁶ = 15/64.
Ex 9 (Medium). A die is thrown 4 times. Find P(at least one six).
P = 1 − (5/6)⁴ = 1 − 625/1296 = 671/1296.
Ex 10 (Medium). Binomial with n = 10, p = 0.3: mean, variance, SD.
Mean = np = 3; Var = npq = 10(0.3)(0.7) = 2.1; SD = √2.1.
Ex 11 (Proof). If A and B are independent, prove A and B′ are independent.
P(A∩B′) = P(A) − P(A∩B) = P(A) − P(A)P(B) = P(A)(1 − P(B)) = P(A)P(B′) ∎

Short & Long Questions

Q1. Define conditional probability.
P(A|B) = P(A∩B)/P(B), the probability of A given B has occurred.
Q2. Condition for independence?
P(A∩B) = P(A)P(B).
Q3. State total probability theorem.
P(A) = ΣP(Eᵢ)P(A|Eᵢ) for a partition E₁…Eₙ.
Q4. State Bayes' theorem.
P(Eᵢ|A) = P(Eᵢ)P(A|Eᵢ) / ΣP(Eⱼ)P(A|Eⱼ).
Q5. Sum of probabilities in a distribution?
1.
Q6. Formula for variance?
Σx²p − (Σxp)².
Q7. What are Bernoulli trials?
Independent trials with two outcomes and constant success probability.
Q8. Mean and variance of binomial?
np and npq.
