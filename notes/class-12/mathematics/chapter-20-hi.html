कक्षा 12 गणित — अध्याय 20: सदिश राशियों का गुणनफल

1. अदिश गुणनफल: परिभाषा

a·b = |a||b| cosθ, 0 ≤ θ ≤ π

परिणाम एक अदिश होता है। θ वह कोण है जो a और b को एक ही बिंदु से खींचने पर बनता है। यदि कोई सदिश शून्य हो तो a·b = 0।

2. अदिश गुणनफल: घटक रूप और गुण

a·b = a₁b₁ + a₂b₂ + a₃b₃
i·i = j·j = k·k = 1; i·j = j·k = k·i = 0

गुण: a·b = b·a; a·(b+c) = a·b + a·c; (λa)·b = λ(a·b); a·a = |a|²; |a+b|² = |a|² + 2a·b + |b|²; |a·b| ≤ |a||b|।

3. दो सदिशों के बीच कोण और लंबवत् सदिश

cosθ = a·b / (|a||b|)
a ⊥ b ⇔ a·b = 0 (a, b अशून्य)

4. प्रक्षेप और किया गया कार्य

a का b पर प्रक्षेप = a·b / |b|
सदिश प्रक्षेप = (a·b/|b|²) b
कार्य W = F·d

प्रक्षेप, a की b की रेखा पर पड़ी छाया की लंबाई है। कार्य, बल और बल की दिशा में विस्थापन का गुणनफल है।

5. सदिश गुणनफल: परिभाषा

a × b = |a||b| sinθ n̂

परिणाम एक सदिश होता है जो a और b दोनों के लंबवत् है; n̂ की दिशा दायें हाथ के नियम से मिलती है। a ∥ b हो तो a×b = 0।

6. सदिश गुणनफल: घटक रूप

a × b = | i j k ; a₁ a₂ a₃ ; b₁ b₂ b₃ | (सारणिक)
i×j = k, j×k = i, k×i = j

7. सदिश गुणनफल के गुण

a×b = −(b×a) (क्रमविनिमेय नहीं)
a×(b+c) = a×b + a×c; a×a = 0
|a×b|² + (a·b)² = |a|²|b|²

8. समांतर और संरेख सदिश

a ∥ b ⇔ a × b = 0 ⇔ a₁/b₁ = a₂/b₂ = a₃/b₃

बिंदु A, B, C संरेख हैं यदि AB × AC = 0।

9. समांतर चतुर्भुज और त्रिभुज का क्षेत्रफल

आसन्न भुजाएँ a, b वाले समांतर चतुर्भुज का क्षेत्रफल = |a×b|
विकर्ण d₁, d₂ हों तो क्षेत्रफल = ½|d₁×d₂|
त्रिभुज ABC का क्षेत्रफल = ½|AB×AC|

हल किए गए उदाहरण (दिया है / ज्ञात करें / सिद्ध करें / हल)

उदाहरण 1 (सरल)। a = 2i+3j−k, b = i−j+2k के लिए a·b ज्ञात कीजिए।
a·b = (2)(1)+(3)(−1)+(−1)(2) = 2−3−2 = −3।
उदाहरण 2 (सरल)। a = i+j और b = j+k के बीच कोण ज्ञात कीजिए।
a·b = 1; |a| = |b| = √2।
cosθ = 1/2 ⇒ θ = 60°।
उदाहरण 3 (मध्यम)। λ का मान ज्ञात कीजिए यदि a = 2i+λj+k और b = i−2j+3k लंबवत् हैं।
a·b = 0 ⇒ 2 − 2λ + 3 = 0 ⇒ λ = 5/2।
उदाहरण 4 (मध्यम)। a = 2i+3j+2k का b = i+2j+k पर प्रक्षेप ज्ञात कीजिए।
a·b = 2+6+2 = 10; |b| = √6।
प्रक्षेप = 10/√6 = 5√6/3।
उदाहरण 5 (मध्यम)। बल F = 3i+2j−4k द्वारा कण को (1,2,3) से (5,4,1) तक ले जाने में किया गया कार्य ज्ञात कीजिए।
d = 4i+2j−2k। W = F·d = 12+4+8 = 24 इकाई।
उदाहरण 6 (मध्यम)। a = i+2j+3k, b = 3i−j+2k के लिए a×b ज्ञात कीजिए।
a×b = i(4+3) − j(2−9) + k(−1−6) = 7i+7j−7k।
|a×b| = 7√3।
उदाहरण 7 (कठिन)। आसन्न भुजाओं a = 3i+j+4k, b = i−j+k वाले समांतर चतुर्भुज का क्षेत्रफल ज्ञात कीजिए।
a×b = i(1+4) − j(3−4) + k(−3−1) = 5i+j−4k।
क्षेत्रफल = √(25+1+16) = √42।
उदाहरण 8 (कठिन)। A(1,1,1), B(1,2,3), C(2,3,1) वाले त्रिभुज का क्षेत्रफल ज्ञात कीजिए।
AB = j+2k; AC = i+2j।
AB×AC = −4i+2j−k; परिमाण = √21।
क्षेत्रफल = √21/2।
उदाहरण 9 (सिद्ध कीजिए)। |a×b|² + (a·b)² = |a|²|b|²।
LHS = |a|²|b|²sin²θ + |a|²|b|²cos²θ = |a|²|b|²(sin²θ+cos²θ) = |a|²|b|² ∎
उदाहरण 10 (सिद्ध कीजिए)। यदि |a+b| = |a−b| तो a ⊥ b।
वर्ग करने पर: |a|²+2a·b+|b|² = |a|²−2a·b+|b|²।
4a·b = 0 ⇒ a·b = 0 ⇒ a ⊥ b ∎

नहीं। a×b = −(b×a)।
प्र.5 i×j का मान?
k।
प्र.6 सदिशों के समांतर होने की शर्त?
a×b = 0।

आसन्न भुजाओं a, b के लिए |a×b|।
प्र.8 त्रिभुज के क्षेत्रफल का सूत्र?
½|AB×AC|।
