Chapter 1: Relations and Functions

UP Board / NCERT – Notes in simple words with examples, figures, Q&A and MCQs.

1. Relations

1.1 Definition of a Relation

Definition: If A and B are two non-empty sets, a relation R from A to B is any subset of the Cartesian product A × B.
If (a, b) ∈ R we write a R b (“a is related to b”). If A = B, R is a relation on A.
  • A × B = {(a, b) : a ∈ A, b ∈ B}.
  • If n(A) = m and n(B) = n, then n(A × B) = mn, so the total number of relations from A to B = 2mn.
  • Domain of R = set of all first elements; Range = set of all second elements; Codomain = B.

Example: A = {1, 2, 3}, R = {(a, b) : b = a + 1}. Then R = {(1,2), (2,3)}. Domain = {1, 2}, Range = {2, 3}.

1.2 Types of Relations

  • Empty relation: R = ∅ (no element is related to any element).
  • Universal relation: R = A × A (every element is related to every element).
  • Identity relation: IA = {(a, a) : a ∈ A}.

Empty and universal relations are called trivial relations.

1.3 Reflexive Relation

Definition: R on A is reflexive if (a, a) ∈ R for every a ∈ A.

Trick: in the matrix/list of pairs, all “diagonal” pairs must be present. If even one (a, a) is missing → not reflexive.

Examples: “x = y”, “x ≤ y”, “x is a divisor of y” on N are reflexive. “x < y” is not.

1.4 Symmetric Relation

Definition: R is symmetric if (a, b) ∈ R ⇒ (b, a) ∈ R.

Examples: “x = y”, “x is a sibling of y”, “|x − y| is even” are symmetric. “x ≤ y”, “x < y” are not.

1.5 Transitive Relation

Definition: R is transitive if (a, b) ∈ R and (b, c) ∈ R ⇒ (a, c) ∈ R.

Examples: “x < y”, “x ≤ y”, “x divides y”, “x = y” are transitive. “x is perpendicular to y” is not (if a ⊥ b and b ⊥ c then a ∥ c).

1.6 Equivalence Relation

Definition: R is an equivalence relation if it is reflexive + symmetric + transitive.

Equivalence class of a: [a] = {x ∈ A : (x, a) ∈ R}. Equivalence classes partition A into disjoint sets whose union is A.

2. Functions

2.1 Definition of a Function

Definition: A relation f from A to B is a function if every element of A has exactly one image in B. Written f : A → B, y = f(x).

Vertical line test: every vertical line cuts the graph at most once. “One element of A going to two elements of B” is not a function; an element of A left without an arrow is also not a function.

2.2 Domain, Codomain and Range

  • Domain = A (all inputs). Codomain = B (the set where outputs are allowed to lie). Range = {f(x) : x ∈ A} ⊆ B (outputs actually obtained).

Example: f : R → R, f(x) = x². Domain = R, Codomain = R, Range = [0, ∞).

2.3 One-one (Injective) Function

Definition: f is one-one if different elements have different images: f(x₁) = f(x₂) ⇒ x₁ = x₂.

Method: take f(x₁) = f(x₂), simplify, and show x₁ = x₂. To disprove, give two different inputs with the same output. Horizontal line test: no horizontal line cuts the graph twice. If n(A) = m, n(B) = n, number of one-one functions = nPm (n ≥ m).

2.4 Onto (Surjective) Function

Definition: f is onto if Range = Codomain, i.e. for every y ∈ B there is some x ∈ A with f(x) = y.

Method: take y ∈ B, solve y = f(x) for x in terms of y, and check that x lies in A.

2.5 Bijective Function

Definition: f is bijective if it is both one-one and onto. If n(A) = n(B) = n, number of bijections = n!.

2.6 Composite Function

Definition: If f : A → B and g : B → C, then gof : A → C, (gof)(x) = g(f(x)).
  • First apply f, then g (work from the inside out).
  • In general gof ≠ fog (not commutative).
  • h o (g o f) = (h o g) o f (associative).
  • If f and g are one-one, gof is one-one; if both onto, gof is onto.

2.7 Inverse of a Function

Definition: f : A → B has an inverse f⁻¹ : B → A if and only if f is bijective. Then f⁻¹(y) = x ⇔ f(x) = y.
  • f⁻¹of = IA and fof⁻¹ = IB. (f⁻¹)⁻¹ = f.
  • (gof)⁻¹ = f⁻¹ o g⁻¹ (order reverses).
  • Finding f⁻¹: put y = f(x), solve for x, replace y by x.

3. Solved Examples (step by step)

Easy Ex 1. A = {1,2,3}, R = {(1,1),(2,2),(1,2),(2,1)}. Is R reflexive?
Solution: Step 1: Reflexive needs (1,1), (2,2), (3,3).
Step 2: (1,1) ∈ R, (2,2) ∈ R but (3,3) ∉ R.
Step 3: So R is not reflexive. (R is symmetric, and also transitive.)
Easy Ex 2. Find the number of relations from A = {1,2} to B = {a,b,c}.
Solution: n(A×B) = 2×3 = 6. Number of subsets = 2⁶ = 64.
Medium Ex 3. To prove: R = {(a,b) : |a − b| is even} on Z is an equivalence relation.
Proof: (i) Reflexive: |a − a| = 0, which is even ⇒ (a,a) ∈ R.
(ii) Symmetric: if |a − b| is even then |b − a| = |a − b| is even ⇒ (b,a) ∈ R.
(iii) Transitive: let |a − b| and |b − c| be even. Then a − b = 2m, b − c = 2n. Adding: a − c = 2(m + n), even ⇒ (a,c) ∈ R.
Hence R is reflexive, symmetric and transitive, so R is an equivalence relation. ∎
Medium Ex 4. To show: f : R → R, f(x) = 3x + 2 is bijective; find f⁻¹.
Solution: One-one: f(x₁) = f(x₂) ⇒ 3x₁ + 2 = 3x₂ + 2 ⇒ x₁ = x₂.
Onto: let y ∈ R. y = 3x + 2 ⇒ x = (y − 2)/3 ∈ R and f(x) = y. So onto.
Hence bijective. Inverse: f⁻¹(y) = (y − 2)/3, i.e. f⁻¹(x) = (x − 2)/3.
Hard Ex 5. f : N → N, f(x) = x². Show f is one-one but not onto. Also show g : R → R, g(x) = x² is neither.
Solution: x₁² = x₂² with x₁, x₂ > 0 ⇒ x₁ = x₂, so f is one-one. 2 ∈ N but no natural number has square 2 ⇒ not onto.
For g: g(2) = g(−2) = 4 ⇒ not one-one. −1 ∈ codomain has no pre-image ⇒ not onto.
Hard Ex 6. f(x) = 2x + 1, g(x) = x². Find fog, gof and (gof)⁻¹ condition.
Solution: (fog)(x) = f(g(x)) = f(x²) = 2x² + 1.
(gof)(x) = g(f(x)) = (2x + 1)² = 4x² + 4x + 1.
Clearly fog ≠ gof. (gof is not one-one on R, since g is not, so its inverse does not exist on R.)

4. Short & Long Q&A (tap to see answer)

Q1. Define a relation. How many relations are there from A to B with n(A)=m, n(B)=n?

A subset of A × B. Total = 2mn, as A × B has mn elements and each can be in or out.

Q2. Is “x < y” on R an equivalence relation?

No. It is transitive but not reflexive (a < a is false) and not symmetric.

Q3. Difference between range and codomain?

Codomain is the set of allowed outputs; range is the set of outputs actually obtained. Range ⊆ codomain; they are equal only for onto functions.

Q4. Why is f : R → R, f(x) = x³ bijective?

x₁³ = x₂³ ⇒ x₁ = x₂ (one-one). For any y, x = y1/3 ∈ R gives f(x) = y (onto).

Q5. When does f⁻¹ exist?

Only when f is bijective: one-one makes the inverse single-valued; onto makes it defined on all of B.

Q6. If f(x)=x+1, g(x)=2x, find (gof)(3) and (fog)(3).

(gof)(3) = g(4) = 8; (fog)(3) = f(6) = 7.

Q7. Long: Prove (gof)⁻¹ = f⁻¹ o g⁻¹.

Let f, g be bijective. (gof)o(f⁻¹og⁻¹) = g o (f o f⁻¹) o g⁻¹ = g o I o g⁻¹ = g o g⁻¹ = I. Similarly (f⁻¹og⁻¹)o(gof) = I. Hence f⁻¹og⁻¹ is the inverse of gof. ∎

Q8. Number of one-one and onto functions from a 3-element set to a 3-element set?

3! = 6.

5. MCQs

1. A relation on A that is reflexive, symmetric and transitive is called: (a) partial (b) equivalence (c) universal (d) identity

(b) equivalence.

2. If n(A)=3, n(B)=2, number of relations from A to B: (a) 6 (b) 8 (c) 32 (d) 64

(d) 2⁶ = 64.

3. f(x) = |x| from R to R is: (a) one-one (b) onto (c) bijective (d) neither

(d) f(1) = f(−1) and negatives have no image.

4. Number of functions from a set of 2 elements to a set of 3 elements: (a) 6 (b) 8 (c) 9 (d) 5

(c) 3² = 9.

5. Inverse of f(x) = 2x − 3 is: (a) (x+3)/2 (b) (x−3)/2 (c) 2x+3 (d) x/2 − 3

(a) y = 2x − 3 ⇒ x = (y + 3)/2.
