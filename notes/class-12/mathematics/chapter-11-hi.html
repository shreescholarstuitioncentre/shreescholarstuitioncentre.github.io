अध्याय 11: उच्चतम एवं निम्नतम मान

उ.प्र. बोर्ड / एन.सी.ई.आर.टी. शैली के नोट्स · चरणबद्ध · एनिमेटेड चित्र

1. स्थानीय उच्चतम एवं स्थानीय निम्नतम

स्थानीय उच्चतम: f का x = c पर स्थानीय उच्चतम तब होता है जब c के आसपास के किसी छोटे अंतराल के सभी x के लिए f(c) ≥ f(x) हो। f(c) स्थानीय उच्चतम मान कहलाता है।
स्थानीय निम्नतम: c के पास सभी x के लिए f(c) ≤ f(x)। f(c) स्थानीय निम्नतम मान है।
इन दोनों को स्थानीय चरम मान (मोड़ बिंदु) कहते हैं। एक फलन के कई स्थानीय उच्चतम और निम्नतम हो सकते हैं, और कोई स्थानीय निम्नतम मान किसी स्थानीय उच्चतम मान से बड़ा भी हो सकता है।

2. परम उच्चतम एवं परम निम्नतम

अंतराल I में परम (निरपेक्ष) उच्चतम: I के प्रत्येक x के लिए f(c) ≥ f(x)। परम निम्नतम: I के प्रत्येक x के लिए f(c) ≤ f(x)।
चरम मान प्रमेय: बंद अंतराल [a, b] में संतत फलन [a, b] में अपना परम उच्चतम और परम निम्नतम मान अवश्य प्राप्त करता है।

3. क्रांतिक बिंदु एवं 4. स्थिर बिंदु

क्रांतिक बिंदु: प्रांत का वह बिंदु c जहाँ f′(c) = 0 हो अथवा f′(c) विद्यमान न हो।
स्थिर बिंदु: वह बिंदु जहाँ f′(c) = 0 हो (स्पर्श रेखा क्षैतिज)।
प्रत्येक स्थिर बिंदु क्रांतिक बिंदु होता है, पर विलोम सत्य नहीं: f(x) = |x| का 0 पर क्रांतिक बिंदु है (f′ विद्यमान नहीं), परंतु वह स्थिर बिंदु नहीं है।
आवश्यक प्रतिबंध: यदि c पर f का स्थानीय चरम मान हो और f′(c) विद्यमान हो, तो f′(c) = 0। पर्याप्त नहीं: f(x) = x³ के लिए f′(0) = 0 है परंतु कोई चरम मान नहीं।

चित्र 1: [a, b] में लाल बिंदु प्रत्येक क्रांतिक बिंदु से गुजरता है। परम चरम मान क्रांतिक बिंदुओं या सिरों पर मिलते हैं।

5. प्रथम अवकलज परीक्षण

माना c क्रांतिक बिंदु है (f, c पर संतत)।
① c से गुजरते समय f′ का चिह्न + से − हो ⇒ स्थानीय उच्चतम।
② f′ का चिह्न − से + हो ⇒ स्थानीय निम्नतम।
③ f′ का चिह्न न बदले ⇒ कोई नहीं (नति परिवर्तन बिंदु)।

6. द्वितीय अवकलज परीक्षण

माना f′(c) = 0 और c पर f″ विद्यमान है।
① f″(c) < 0 ⇒ स्थानीय उच्चतम। ② f″(c) > 0 ⇒ स्थानीय निम्नतम। ③ f″(c) = 0 ⇒ परीक्षण असफल, प्रथम अवकलज परीक्षण लगाइए।
कारण: f″ < 0 का अर्थ है f′ घट रहा है, अतः f′ शून्य से गुजरते हुए + से − हो जाता है।
उच्च कोटि परीक्षण: यदि f′(c) = … = f⁽ⁿ⁻¹⁾(c) = 0 और f⁽ⁿ⁾(c) ≠ 0: n सम और f⁽ⁿ⁾ < 0 ⇒ उच्चतम; n सम और f⁽ⁿ⁾ > 0 ⇒ निम्नतम; n विषम ⇒ कोई नहीं।

चित्र 2: y = x³ के मूलबिंदु पर स्पर्श रेखा क्षैतिज है, फिर भी वक्र बढ़ता रहता है। f′ का चिह्न नहीं बदलता, अतः यह न उच्चतम है न निम्नतम।

7. उच्चतम एवं निम्नतम मान ज्ञात करना

स्थानीय चरम मान: ① f′(x) ज्ञात कीजिए; ② f′(x) = 0 हल कीजिए (जहाँ f′ विद्यमान नहीं उन बिंदुओं को भी देखिए); ③ प्रथम या द्वितीय अवकलज परीक्षण लगाइए; ④ f(c) निकालिए।
[a, b] में परम चरम मान: ① (a, b) के सभी क्रांतिक बिंदु ज्ञात कीजिए; ② प्रत्येक क्रांतिक बिंदु तथा a, b पर f का मान निकालिए; ③ सबसे बड़ा मान परम उच्चतम और सबसे छोटा मान परम निम्नतम है।

8. इष्टतमीकरण (अनुकूलतम) की समस्याएँ

चरण: ① प्रश्न ध्यान से पढ़िए और चित्र बनाइए। ② जिस राशि Q का उच्चतम/निम्नतम मान चाहिए उसका नाम रखिए। ③ दी गई शर्त से Q को एक चर में लिखिए। ④ dQ/dx = 0 हल कीजिए। ⑤ d²Q/dx² (या प्रथम अवकलज परीक्षण) से जाँचिए। ⑥ देखिए कि मान स्वीकार्य प्रांत में है और उत्तर इकाई सहित लिखिए।

9. उच्चतम-निम्नतम के वास्तविक जीवन में अनुप्रयोग

अधिकतम लाभ, सामग्री की न्यूनतम लागत, दी गई बाड़ से अधिकतम क्षेत्रफल, डिब्बे या टंकी का अधिकतम आयतन, न्यूनतम दूरी या न्यूनतम यात्रा समय, तथा दिए गए आयतन के लिए न्यूनतम पृष्ठीय क्षेत्रफल (डिब्बे, टंकियाँ) जैसी समस्याएँ इसी विधि से हल होती हैं।

हल सहित उदाहरण (चरण-दर-चरण)

सरल उदा. 1. f(x) = x² − 6x + 5 का स्थानीय निम्नतम मान ज्ञात कीजिए।
f′ = 2x − 6 = 0 ⇒ x = 3। f″ = 2 > 0 ⇒ स्थानीय निम्नतम।f(3) = 9 − 18 + 5 = −4।
सरल उदा. 2. f(x) = x³ − 3x² के क्रांतिक बिंदु ज्ञात कीजिए।
f′ = 3x² − 6x = 3x(x − 2) = 0 ⇒ x = 0, 2। (f′ सर्वत्र विद्यमान है।)
मध्यम उदा. 3. दिखाइए कि f(x) = |x| का 0 पर क्रांतिक बिंदु है जो स्थिर बिंदु नहीं है; इसका परम निम्नतम ज्ञात कीजिए।
LHD = −1, RHD = 1 ⇒ f′(0) विद्यमान नहीं: क्रांतिक बिंदु, पर f′ कहीं भी 0 नहीं, अतः स्थिर बिंदु नहीं।सभी x के लिए |x| ≥ 0 = f(0): x = 0 पर परम निम्नतम 0।
मध्यम उदा. 4. f(x) = 2x³ − 21x² + 36x − 20 के स्थानीय उच्चतम और निम्नतम ज्ञात कीजिए।
f′ = 6x² − 42x + 36 = 6(x − 1)(x − 6) = 0 ⇒ x = 1, 6। f″ = 12x − 42।f″(1) = −30 < 0 ⇒ स्थानीय उच्चतम, f(1) = 2 − 21 + 36 − 20 = −3।f″(6) = 30 > 0 ⇒ स्थानीय निम्नतम, f(6) = 432 − 756 + 216 − 20 = −128।
मध्यम उदा. 5. f(x) = x³ − 6x² + 9x + 15 पर प्रथम अवकलज परीक्षण लगाइए।
f′ = 3(x − 1)(x − 3)। क्रांतिक बिंदु 1, 3।x < 1: f′ > 0; 1 < x < 3: f′ < 0; x > 3: f′ > 0।1 पर: + से − ⇒ स्थानीय उच्चतम f(1) = 19। 3 पर: − से + ⇒ स्थानीय निम्नतम f(3) = 15।
मध्यम उदा. 6. [0, 2] में f(x) = x³ − 3x के परम उच्चतम और निम्नतम ज्ञात कीजिए।
f′ = 3x² − 3 = 0 ⇒ x = ±1; केवल x = 1 ही [0, 2] में है।f(0) = 0, f(1) = −2, f(2) = 2।परम उच्चतम 2 (x = 2 पर); परम निम्नतम −2 (x = 1 पर)।
मध्यम उदा. 7. [0, π] में f(x) = sin x + cos x के परम चरम मान ज्ञात कीजिए।
f′ = cos x − sin x = 0 ⇒ [0, π] में x = π/4।f(π/4) = √2; f(0) = 1; f(π) = −1।परम उच्चतम √2 (π/4 पर); परम निम्नतम −1 (x = π पर)।
कठिन उदा. 8. f(x) = x³ तथा f(x) = x⁴ के लिए x = 0 की प्रकृति निर्धारित कीजिए।
x³: f′ = 3x² ≥ 0, f′(0) = 0, f″(0) = 0, f‴(0) = 6 ≠ 0, n = 3 विषम ⇒ कोई चरम मान नहीं (नति परिवर्तन)।x⁴: f′ = 4x³, f″(0) = 0, f‴(0) = 0, f⁗(0) = 24 > 0, n = 4 सम ⇒ स्थानीय निम्नतम, मान 0।
मध्यम उदा. 9. x > 0 के लिए f(x) = x + 1/x का निम्नतम मान ज्ञात कीजिए।
f′ = 1 − 1/x² = 0 ⇒ x = 1 (x > 0)। f″ = 2/x³ = 2 > 0 ⇒ निम्नतम।निम्नतम मान f(1) = 2।
सरल उदा. 10. दो धनात्मक संख्याओं का योग 20 है। संख्याएँ ज्ञात कीजिए यदि उनका गुणनफल अधिकतम हो।
P = x(20 − x) = 20x − x²। P′ = 20 − 2x = 0 ⇒ x = 10। P″ = −2 < 0 ⇒ उच्चतम।संख्याएँ: 10 और 10; अधिकतम गुणनफल 100।
कठिन उदा. 11. सिद्ध कीजिए कि r त्रिज्या के वृत्त में अंतर्लिखित अधिकतम क्षेत्रफल वाला आयत वर्ग होता है।
भुजाएँ x, y: x² + y² = 4r² (विकर्ण = व्यास)। A = xy, अतः A² = x²(4r² − x²) = S।S′ = 8r²x − 4x³ = 0 ⇒ x² = 2r²। S″ = 8r² − 12x² = −16r² < 0 ⇒ उच्चतम।तब y² = 4r² − 2r² = 2r² = x² ⇒ x = y: वर्ग, क्षेत्रफल 2r²। ∎
कठिन उदा. 12. R त्रिज्या के गोले में अंतर्लिखित लंब वृत्तीय बेलन का अधिकतम आयतन ज्ञात कीजिए।
बेलन की त्रिज्या r, ऊँचाई h: r² + h²/4 = R²। V = πr²h = π(R²h − h³/4)।V′ = π(R² − 3h²/4) = 0 ⇒ h = 2R/√3। V″ = −3πh/2 < 0 ⇒ उच्चतम।r² = R² − R²/3 = 2R²/3। V = π(2R²/3)(2R/√3) = 4πR³/(3√3)।
मध्यम उदा. 13. लाभ P(x) = −2x² + 80x − 200 है। अधिकतम लाभ के लिए इकाइयों की संख्या ज्ञात कीजिए।
P′ = −4x + 80 = 0 ⇒ x = 20। P″ = −4 < 0 ⇒ उच्चतम।P(20) = −800 + 1600 − 200 = ₹600, 20 इकाइयों पर।
कठिन उदा. 14. y = x² पर वह बिंदु ज्ञात कीजिए जो (0, 5) के निकटतम हो।
D² = x² + (x² − 5)² = x⁴ − 9x² + 25। माना u = x² ≥ 0: D² = u² − 9u + 25।d/du = 2u − 9 = 0 ⇒ u = 9/2; द्वितीय अवकलज 2 > 0 ⇒ निम्नतम।x = ±3/√2, y = 9/2। निम्नतम D² = 81/4 − 81/2 + 25 = 19/4, अतः D = √19/2। बिंदु (±3/√2, 9/2)।
कठिन उदा. 15. वर्गाकार आधार वाली खुली टंकी का आयतन V है। सिद्ध कीजिए कि न्यूनतम सामग्री तब लगती है जब गहराई आधार की भुजा की आधी हो।
आधार की भुजा x, गहराई h: V = x²h। पृष्ठ S = x² + 4xh = x² + 4V/x।S′ = 2x − 4V/x² = 0 ⇒ x³ = 2V ⇒ h = V/x² = x/2। S″ = 2 + 8V/x³ > 0 ⇒ निम्नतम। ∎
