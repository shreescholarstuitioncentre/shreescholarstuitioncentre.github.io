खंडशः समाकलन – कक्षा 12 गणित नोट्स

इकाई 3: कलन · अध्याय 14 · यू.पी. बोर्ड

1. खंडशः समाकलन का सूत्र

यह गुणनफल नियम की उलटी क्रिया है। चूँकि d(uv)/dx = u·dv/dx + v·du/dx, समाकलन करने पर uv = ∫u (dv/dx) dx + ∫v (du/dx) dx। पुनर्व्यवस्थित करने पर:

∫ u·v dx = u ∫ v dx − ∫ [ (du/dx) ∫ v dx ] dx

शब्दों में: (प्रथम × द्वितीय) का समाकल = प्रथम × द्वितीय का समाकल − (प्रथम का अवकलज × द्वितीय का समाकल) का समाकल। इसका प्रयोग तब करें जब समाकल्य दो भिन्न प्रकार के फलनों का गुणनफल हो और किसी प्रतिस्थापन से हल न हो।

2. प्रथम एवं द्वितीय फलन का चयन

गलत चयन से समाकल कठिन हो जाता है। ILATE नियम प्रयोग करें: I – प्रतिलोम त्रिकोणमितीय, L – लघुगणकीय, A – बीजीय, T – त्रिकोणमितीय, E – चरघातांकी। जो फलन सूची में पहले आए उसे प्रथम फलन u लें; दूसरा v होगा। कारण: शुरू वाले फलन अवकलन करने पर सरल हो जाते हैं (log x → 1/x, tan⁻¹x → 1/(1+x²), xⁿ → nxⁿ⁻¹), और अंत वाले (e, sin, cos) का समाकलन आसान होता है।

ध्यान दें: जब केवल एक ही फलन दिखे (∫ log x dx, ∫ tan⁻¹x dx), तो समाकल्य को log x · 1 लिखें और 1 को द्वितीय फलन लें।

3. फलनों के गुणनफल का समाकलन

चरण: (1) ILATE से u चुनें; (2) v लिखें; (3) du/dx और ∫v dx ज्ञात करें (इस चरण में अचर नहीं लगाते); (4) सूत्र लगाएँ; (5) शेष समाकल हल करें; (6) अंत में C जोड़ें। शेष समाकल मूल से सरल होना चाहिए; यदि नहीं, तो फलनों की अदला-बदली करें।

4. बीजीय एवं त्रिकोणमितीय गुणनफल

∫ x sin x dx = −x cos x + sin x + C
∫ x cos x dx = x sin x + cos x + C

ILATE में x (बीजीय) sin x या cos x से पहले आता है, इसलिए u = x। ∫ x sec²x dx = x tan x − log|sec x| + C।

5. बीजीय एवं चरघातांकी गुणनफल

∫ x eˣ dx = eˣ (x − 1) + C
∫ x e^(ax) dx = e^(ax) (x/a − 1/a²) + C
∫ eˣ [f(x) + f′(x)] dx = eˣ f(x) + C
∫ e^(ax) sin bx dx = e^(ax)(a sin bx − b cos bx)/(a²+b²) + C
∫ e^(ax) cos bx dx = e^(ax)(a cos bx + b sin bx)/(a²+b²) + C

अंतिम दो चक्रीय समाकल हैं: खंडशः दो बार लगाने पर मूल समाकल फिर आ जाता है; उसे बाएँ पक्ष में लाकर हल करें।

6. बीजीय एवं लघुगणकीय गुणनफल

∫ log x dx = x log x − x + C
∫ x log x dx = (x²/2) log x − x²/4 + C
∫ xⁿ log x dx = xⁿ⁺¹/(n+1) · log x − xⁿ⁺¹/(n+1)² + C
∫ tan⁻¹x dx = x tan⁻¹x − ½ log(1+x²) + C
∫ sin⁻¹x dx = x sin⁻¹x + √(1−x²) + C

7. बार-बार खंडशः समाकलन

जब u = xⁿ और n ≥ 2 हो, तो सूत्र n बार लगाएँ; हर बार घात एक घटती है। चित्र 2 की सारणी (DI) विधि इसे शीघ्र करती है: u का शून्य आने तक अवकलन करें, v का उतनी ही बार समाकलन करें, और तिरछे गुणा करें, चिह्न बारी-बारी से। इसे तभी प्रयोग करें जब एक फलन बहुपद हो।

8. खंडशः समाकलन पर आधारित निश्चित समाकल

∫ₐᵇ u v dx = [ u ∫v dx ]ₐᵇ − ∫ₐᵇ [ (du/dx) ∫v dx ] dx

पहले uv वाले पद पर सीमाएँ लगाएँ, फिर शेष को उन्हीं सीमाओं में समाकलित करें। निश्चित समाकल में अचर C नहीं आता।

चित्र (एनिमेटेड)

चित्र 1: ILATE क्रम। तीर दिखाता है कि I सिरे के सबसे निकट वाला फलन u (प्रथम फलन) चुना जाता है। चित्र 2: ∫ x³eˣ dx के लिए बार-बार खंडशः समाकलन। बाएँ स्तंभ में 0 आने तक अवकलन करें, दाएँ स्तंभ में समाकलन करें, और बाएँ की प्रत्येक प्रविष्टि को अगली दाएँ प्रविष्टि से बारी-बारी से चिह्न +, −, +, − के साथ जोड़ें। उत्तर = x³eˣ − 3x²eˣ + 6xeˣ − 6eˣ + C = eˣ(x³ − 3x² + 6x − 6) + C।

हल किए गए उदाहरण (चरण दर चरण)

1. ∫ x sin x dx ज्ञात कीजिए
ILATE: x बीजीय, sin x त्रिकोणमितीय, अतः u = x, v = sin x। ∫v dx = −cos x, du/dx = 1। सूत्र: x(−cos x) − ∫ 1·(−cos x) dx = −x cos x + sin x। उत्तर: −x cos x + sin x + C।
2. ∫ x cos x dx ज्ञात कीजिए
u = x, v = cos x। ∫v dx = sin x। = x sin x − ∫ sin x dx = x sin x + cos x + C।
3. ∫ x eˣ dx ज्ञात कीजिए
u = x, v = eˣ। = x eˣ − ∫ eˣ dx = x eˣ − eˣ। उत्तर: eˣ(x − 1) + C।
4. ∫ x log x dx ज्ञात कीजिए
L, A से पहले आता है, अतः u = log x, v = x। ∫v dx = x²/2, du/dx = 1/x। = (x²/2) log x − ∫ (1/x)(x²/2) dx = (x²/2) log x − ∫ x/2 dx। उत्तर: (x²/2) log x − x²/4 + C।
5. ∫ log x dx ज्ञात कीजिए
इसे log x · 1 लिखें। u = log x, v = 1। = x log x − ∫ (1/x)·x dx = x log x − ∫ 1 dx। उत्तर: x log x − x + C।
6. ∫ x² eˣ dx ज्ञात कीजिए
u = x², v = eˣ। = x²eˣ − ∫ 2x eˣ dx = x²eˣ − 2∫ x eˣ dx। उदाहरण 3 से ∫ x eˣ dx = eˣ(x−1)। = x²eˣ − 2eˣ(x−1)। उत्तर: eˣ(x² − 2x + 2) + C।
7. ∫ x² sin x dx ज्ञात कीजिए
u = x², v = sin x। = −x² cos x + ∫ 2x cos x dx = −x² cos x + 2(x sin x + cos x) (उदाहरण 2)। उत्तर: −x² cos x + 2x sin x + 2 cos x + C।
8. ∫ tan⁻¹x dx ज्ञात कीजिए
इसे tan⁻¹x · 1 लिखें। u = tan⁻¹x, v = 1। = x tan⁻¹x − ∫ x/(1+x²) dx। अंतिम समाकल में t = 1+x², x dx = dt/2 रखें: = ½ log(1+x²)। उत्तर: x tan⁻¹x − ½ log(1+x²) + C।
9. ∫ sin⁻¹x dx ज्ञात कीजिए
u = sin⁻¹x, v = 1। = x sin⁻¹x − ∫ x/√(1−x²) dx। t = 1−x², x dx = −dt/2 रखें: ∫ = −½ ∫ t^(−½) dt = −√t = −√(1−x²)। उत्तर: x sin⁻¹x + √(1−x²) + C।
10. ∫ eˣ sin x dx ज्ञात कीजिए
माना I = ∫ eˣ sin x dx। u = sin x, v = eˣ लें: I = eˣ sin x − ∫ eˣ cos x dx। पुनः खंडशः: ∫ eˣ cos x dx = eˣ cos x + ∫ eˣ sin x dx = eˣ cos x + I। अतः I = eˣ sin x − eˣ cos x − I ⇒ 2I = eˣ(sin x − cos x)। उत्तर: I = eˣ(sin x − cos x)/2 + C।
11. ∫ eˣ (1/x − 1/x²) dx ज्ञात कीजिए
माना f(x) = 1/x, तब f′(x) = −1/x²। समाकल्य eˣ[f + f′] है। अतः eˣ/x + C।
12. ∫ eˣ (sin x + cos x) dx ज्ञात कीजिए
f = sin x, f′ = cos x। अतः समाकल = eˣ sin x + C।
13. ∫ x sec²x dx ज्ञात कीजिए
u = x, v = sec²x। ∫v dx = tan x। = x tan x − ∫ tan x dx = x tan x − log|sec x| + C।
14. ∫ x² log x dx ज्ञात कीजिए
u = log x, v = x²। = (x³/3) log x − ∫ (1/x)(x³/3) dx = (x³/3) log x − ∫ x²/3 dx। उत्तर: (x³/3) log x − x³/9 + C।
15. ∫₀¹ x eˣ dx का मान ज्ञात कीजिए
अनिश्चित: eˣ(x−1)। सीमाएँ लगाएँ: [eˣ(x−1)]₀¹ = e·0 − e⁰(−1) = 0 + 1। उत्तर: 1।
16. ∫₁ᵉ log x dx का मान ज्ञात कीजिए
प्रतिअवकलज x log x − x। e पर: e·1 − e = 0। 1 पर: 1·0 − 1 = −1। मान = 0 − (−1) = 1।
17. ∫₀^(π/2) x sin x dx का मान ज्ञात कीजिए
प्रतिअवकलज: −x cos x + sin x। π/2 पर: −(π/2)(0) + 1 = 1। 0 पर: 0 + 0 = 0। मान = 1।
18. सत्यापित कीजिए: ∫ x eˣ dx = eˣ(x − 1) + C
d/dx [eˣ(x−1)] = eˣ(x−1) + eˣ·1 = eˣ·x = x eˣ ✓। सत्यापित।

लघु एवं दीर्घ प्रश्नोत्तर (खोलने के लिए छुएँ)

Q1. खंडशः समाकलन का सूत्र लिखिए।
∫ u v dx = u ∫v dx − ∫ [ (du/dx) ∫v dx ] dx।
Q2. ILATE क्या है?
प्रथम फलन चुनने का नियम: प्रतिलोम त्रिकोणमितीय, लघुगणकीय, बीजीय, त्रिकोणमितीय, चरघातांकी; जो पहले आए वह u।
Q3. ∫v dx ज्ञात करते समय अचर क्यों नहीं जोड़ते?
यह केवल सहायक चरण है; अंतिम C अंत में जोड़ा जाता है। यहाँ अतिरिक्त अचर केवल कट जाता।
Q4. ∫ log x dx कैसे ज्ञात करते हैं?
इसे log x · 1 मानकर खंडशः लगाएँ: x log x − x + C।
Q5. खंडशः समाकलन कब नहीं लगाना चाहिए?
जब सरल प्रतिस्थापन से काम चल जाए, जैसे ∫ x eˣ² dx (t = x² रखें), या जब शेष समाकल और कठिन हो जाए।
Q6. चक्रीय समाकल क्या है?
वह जिसमें खंडशः दो बार लगाने पर मूल समाकल वापस आ जाए, जैसे ∫ eˣ sin x dx; इसे I में समीकरण की तरह हल करें।
Q7. शॉर्टकट ∫ eˣ[f(x)+f′(x)] dx लिखिए।
= eˣ f(x) + C।
Q8. दीर्घ: खंडशः समाकलन का सूत्र व्युत्पन्न कीजिए।
माना u और v अवकलनीय हैं। गुणनफल नियम: d(uv)/dx = u (dv/dx) + v (du/dx)। समाकलन करें: uv = ∫ u (dv/dx) dx + ∫ v (du/dx) dx। w = dv/dx रखें तो v = ∫w dx। तब ∫ u w dx = u ∫ w dx − ∫ (du/dx)(∫ w dx) dx। w के स्थान पर v लिखने पर सूत्र मिलता है।
Q9. दीर्घ: ∫ x² e^(2x) dx का मान ज्ञात कीजिए।
u = x², v = e^(2x)। ∫v dx = e^(2x)/2। = x² e^(2x)/2 − ∫ x e^(2x) dx। पुनः: ∫ x e^(2x) dx = x e^(2x)/2 − e^(2x)/4। अतः परिणाम = x² e^(2x)/2 − x e^(2x)/2 + e^(2x)/4 + C = e^(2x)(2x² − 2x + 1)/4 + C। अवकलन से जाँच: e^(2x)[(2x²−2x+1)/2 + (4x−2)/4] = e^(2x)(x²) ✓।
Q10. दीर्घ: सिद्ध कीजिए ∫ x tan⁻¹x dx = ((x²+1)/2) tan⁻¹x − x/2 + C।
u = tan⁻¹x, v = x। = (x²/2) tan⁻¹x − ∫ x²/(2(1+x²)) dx। अब x²/(1+x²) = 1 − 1/(1+x²)। अतः ∫ = ½(x − tan⁻¹x)। परिणाम = (x²/2) tan⁻¹x − x/2 + ½ tan⁻¹x = ((x²+1)/2) tan⁻¹x − x/2 + C।
