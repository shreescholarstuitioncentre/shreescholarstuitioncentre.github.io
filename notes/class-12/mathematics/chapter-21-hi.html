कक्षा 12 गणित — अध्याय 21: अदिश त्रिक गुणनफल

1. अदिश त्रिक गुणनफल: परिभाषा

[a b c] = a · (b × c)

पहले b×c (एक सदिश) निकालते हैं, फिर उसका a से अदिश गुणनफल लेते हैं। परिणाम एक अदिश होता है। इसे (a×b)·c भी लिखते हैं, क्योंकि a·(b×c) = (a×b)·c।

2. घटक रूप और सारणिक

[a b c] = | a₁ a₂ a₃ ; b₁ b₂ b₃ ; c₁ c₂ c₃ |
= a₁(b₂c₃−b₃c₂) − a₂(b₁c₃−b₃c₁) + a₃(b₁c₂−b₂c₁)

a, b, c के घटकों को क्रम से पंक्तियों में लिखिए और प्रथम पंक्ति से विस्तार कीजिए। चिह्न का क्रम + − + याद रखें।

3. गुण

चक्रीय: [a b c] = [b c a] = [c a b]
दो सदिश आपस में बदलने पर चिह्न बदलता है: [a c b] = −[a b c]
[a a b] = 0 (दो सदिश समान)
[λa b c] = λ[a b c]; [a+d b c] = [a b c]+[d b c]
[i j k] = 1

4. तीन सदिशों की समतलीयता

a, b, c समतलीय ⇔ [a b c] = 0

यदि सदिश एक ही समतल में हों तो b×c उस समतल के लंबवत् होता है, इसलिए a·(b×c) = 0।

5. समांतरषष्ठफलक का आयतन

V = |[a b c]| = |a·(b×c)|

आधार का क्षेत्रफल = |b×c|; ऊँचाई = a का b×c पर प्रक्षेप। अतः आयतन = आधार × ऊँचाई।

6. चतुष्फलक का आयतन

V = ⅙ |[AB AC AD]|

उन्हीं तीन कोरों पर बना चतुष्फलक, समांतरषष्ठफलक का छठा भाग होता है।

हल किए गए उदाहरण (दिया है / ज्ञात करें / सिद्ध करें / हल)

उदाहरण 1 (सरल)। a = 2i+j−k, b = i+3j+2k, c = i+2k के लिए [a b c] ज्ञात कीजिए।
पंक्तियाँ (2,1,−1), (1,3,2), (1,0,2)।
= 2(6−0) − 1(2−2) + (−1)(0−3) = 12 − 0 + 3 = 15।
उदाहरण 2 (सरल)। दिखाइए कि [i j k] = 1 और [i k j] = −1।
[i j k] = i·(j×k) = i·i = 1।
[i k j] = i·(k×j) = i·(−i) = −1।
उदाहरण 3 (मध्यम)। क्या a = 2i+j−k, b = i+3j+2k, c = j+k समतलीय हैं?
पंक्तियाँ (2,1,−1),(1,3,2),(0,1,1)।
= 2(3−2) − 1(1−0) + (−1)(1−0) = 2−1−1 = 0 ⇒ समतलीय।
उदाहरण 4 (मध्यम)। λ का मान ज्ञात कीजिए यदि 2i−j+k, i+2j−3k, 3i+λj+5k समतलीय हैं।
सारणिक = 2(10+3λ) + 1(5+9) + 1(λ−6) = 28+7λ।
शून्य रखने पर λ = −4।
उदाहरण 5 (मध्यम)। कोरों 2i−3j+4k, i+2j−k, 3i−j+2k वाले समांतरषष्ठफलक का आयतन ज्ञात कीजिए।
[a b c] = 2(4−1) + 3(2+3) + 4(−1−6) = 6+15−28 = −7।
V = |−7| = 7 घन इकाई।
उदाहरण 6 (कठिन)। A(1,1,1), B(3,1,1), C(1,4,1), D(1,1,6) वाले चतुष्फलक का आयतन ज्ञात कीजिए।
AB = 2i, AC = 3j, AD = 5k। [AB AC AD] = 2·3·5 = 30।
V = 30/6 = 5 घन इकाई।
उदाहरण 7 (सिद्ध कीजिए)। [a a c] = 0।
a×c, a के लंबवत् है, इसलिए a·(a×c) = 0 ∎
उदाहरण 8 (सिद्ध कीजिए, कठिन)। [a+b b+c c+a] = 2[a b c]।
(b+c)×(c+a) = b×c + b×a + c×a।
(a+b) से अदिश गुणा: a·(b×c) = [abc]; a·(b×a) = 0; a·(c×a) = 0; b·(b×c) = 0; b·(b×a) = 0; b·(c×a) = [bca] = [abc]।
योग = 2[a b c] ∎
