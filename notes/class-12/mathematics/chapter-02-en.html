1. Inverse Trigonometric Functions

1.1 Definition

From Chapter 1: f⁻¹ exists only if f is one-one and onto. The six trigonometric functions repeat their values, so on R they are not one-one. If we restrict each to an interval where it is one-one and onto its range (a branch), its inverse exists.

Definition: y = sin⁻¹x ⇔ x = sin y, with y in the chosen branch. Read sin⁻¹x as “the angle whose sine is x”.
Warning: sin⁻¹x is not 1/sin x. The “−1” is not a power; (sin x)⁻¹ = 1/sin x = cosec x.

Blue: sin x on [−π/2, π/2]. Red: sin⁻¹x. Dashed: y = x mirror line.

Why the graph looks like this: the graph of f⁻¹ is the mirror image of the graph of f in the line y = x. Here the blue sine curve (on its branch) reflects into the red sin⁻¹ curve, so domain and range swap places.

1.3 Principal Value Branches

Principal value: the value of an inverse trigonometric function lying in its principal branch (the range in the table above).

sin x is one-one on many intervals, e.g. [−π/2, π/2], [π/2, 3π/2]. Each gives a different inverse. The branch [−π/2, π/2] is chosen as the principal one because it contains 0 and covers the whole range [−1, 1]. Remember: sin⁻¹, tan⁻¹, cosec⁻¹ → around 0 (can be negative); cos⁻¹, cot⁻¹, sec⁻¹ → from 0 to π (never negative).

Negative values: sin⁻¹(−x) = −sin⁻¹x, tan⁻¹(−x) = −tan⁻¹x, but cos⁻¹(−x) = π − cos⁻¹x. Example: cos⁻¹(−1/2) = π − π/3 = 2π/3.

1.6 Elementary Properties

  1. sin(sin⁻¹x) = x for x ∈ [−1, 1]; sin⁻¹(sin x) = x only for x ∈ [−π/2, π/2]. Same pattern for the others with their branches.
  2. sin⁻¹(1/x) = cosec⁻¹x, cos⁻¹(1/x) = sec⁻¹x (|x| ≥ 1); tan⁻¹(1/x) = cot⁻¹x (x > 0).
  3. sin⁻¹(−x) = −sin⁻¹x; tan⁻¹(−x) = −tan⁻¹x; cosec⁻¹(−x) = −cosec⁻¹x.
  4. cos⁻¹(−x) = π − cos⁻¹x; sec⁻¹(−x) = π − sec⁻¹x; cot⁻¹(−x) = π − cot⁻¹x.
  5. sin⁻¹x + cos⁻¹x = π/2; tan⁻¹x + cot⁻¹x = π/2; sec⁻¹x + cosec⁻¹x = π/2.

1.7 Standard Identities and Simplification

  • tan⁻¹x + tan⁻¹y = tan⁻¹((x + y)/(1 − xy)), if xy < 1 (if xy > 1 with x, y > 0, add π).
  • tan⁻¹x − tan⁻¹y = tan⁻¹((x − y)/(1 + xy)), if xy > −1.
  • 2tan⁻¹x = tan⁻¹(2x/(1 − x²)) for |x| < 1 = sin⁻¹(2x/(1 + x²)) for |x| ≤ 1 = cos⁻¹((1 − x²)/(1 + x²)) for x ≥ 0.
  • 2sin⁻¹x = sin⁻¹(2x√(1 − x²)), −1/√2 ≤ x ≤ 1/√2.
  • 3sin⁻¹x = sin⁻¹(3x − 4x³), −1/2 ≤ x ≤ 1/2; 3cos⁻¹x = cos⁻¹(4x³ − 3x), 1/2 ≤ x ≤ 1.

Substitution tips: for √(1 − x²) put x = sin θ or cos θ; for √(1 + x²) put x = tan θ; for √(x² − 1) put x = sec θ; for √((1 − x)/(1 + x)) put x = cos 2θ.

2. Solved Examples

Easy Ex 1. Find the principal value of sin⁻¹(−1/2).
Solution: sin⁻¹(−1/2) = −sin⁻¹(1/2) = −π/6, which lies in [−π/2, π/2].
Easy Ex 2. Find cos⁻¹(−1/2).
Solution: cos⁻¹(−x) = π − cos⁻¹x ⇒ π − π/3 = 2π/3, in [0, π].
Easy Ex 3. Evaluate sin⁻¹(sin 2π/3).
Solution: 2π/3 ∉ [−π/2, π/2]. sin(2π/3) = sin(π − π/3) = sin(π/3). So the answer is π/3, not 2π/3.
Medium Ex 4. Prove tan⁻¹(1/2) + tan⁻¹(1/3) = π/4.
Proof: x = 1/2, y = 1/3, xy = 1/6 < 1. So LHS = tan⁻¹((1/2 + 1/3)/(1 − 1/6)) = tan⁻¹((5/6)/(5/6)) = tan⁻¹1 = π/4 = RHS. ∎
Medium Ex 5. Prove 2tan⁻¹(1/2) = tan⁻¹(4/3).
Proof: |1/2| < 1, so 2tan⁻¹(1/2) = tan⁻¹(2·(1/2)/(1 − 1/4)) = tan⁻¹(1/(3/4)) = tan⁻¹(4/3). ∎
Medium Ex 6. Find cos(sin⁻¹(3/5)).
Solution: Let θ = sin⁻¹(3/5), θ ∈ [0, π/2]. sin θ = 3/5 ⇒ cos θ = √(1 − 9/25) = 4/5.
Hard Ex 7. Prove sin⁻¹(12/13) + cos⁻¹(4/5) + tan⁻¹(63/16) = π.
Proof: sin⁻¹(12/13) = tan⁻¹(12/5) (triangle 5, 12, 13); cos⁻¹(4/5) = tan⁻¹(3/4) (triangle 3, 4, 5).
Here xy = (12/5)(3/4) = 9/5 > 1, so tan⁻¹(12/5) + tan⁻¹(3/4) = π + tan⁻¹((63/20)/(−4/5)) = π − tan⁻¹(63/16).
Adding tan⁻¹(63/16) gives π. ∎
Hard Ex 8. Solve tan⁻¹(x + 1) + tan⁻¹(x − 1) = tan⁻¹(8/31).
Solution: tan⁻¹((2x)/(2 − x²)) = tan⁻¹(8/31) ⇒ 62x = 16 − 8x² ⇒ 4x² + 31x − 8 = 0 ⇒ x = 1/4 or x = −8.
Check the condition (x + 1)(x − 1) < 1: for x = 1/4 it is −15/16 ✔. For x = −8 it is 63 > 1 ✘. So x = 1/4.
Hard Ex 9. Simplify tan⁻¹((√(1 + x²) − 1)/x), x ≠ 0.
Solution: Put x = tan θ. Then (sec θ − 1)/tan θ = (1 − cos θ)/sin θ = tan(θ/2). So the result is θ/2 = (1/2)tan⁻¹x.

3. Short & Long Q&A (tap to see answer)

Q1. Why do we restrict the domain of trigonometric functions?

They are periodic, hence many-one on R. Restricting to a branch makes them one-one and onto, so the inverse exists.

Q2. Principal value of cos⁻¹(√3/2)?

π/6.

Q3. Is sin⁻¹x = 1/sin x?

No. sin⁻¹x is the inverse function; 1/sin x = cosec x.

Q4. Find tan⁻¹(1) + cos⁻¹(−1/2) + sin⁻¹(−1/2).

π/4 + 2π/3 − π/6 = (3π + 8π − 2π)/12 = 9π/12 = 3π/4.

Q5. Write the range of cot⁻¹x.

(0, π), not (−π/2, π/2).

Q6. Long: Prove sin⁻¹x + cos⁻¹x = π/2.

Let sin⁻¹x = θ, so x = sin θ = cos(π/2 − θ). Hence cos⁻¹x = π/2 − θ, because π/2 − θ ∈ [0, π] when θ ∈ [−π/2, π/2]. So sin⁻¹x + cos⁻¹x = θ + π/2 − θ = π/2. ∎

Q7. Find sin⁻¹(sin 3π/5)... and give the rule.

3π/5 ∉ [−π/2, π/2]. sin(3π/5) = sin(π − 3π/5) = sin(2π/5), so the value is 2π/5. Rule: bring the angle into [−π/2, π/2] using sin(π − θ) = sin θ.

Q8. Evaluate sin(tan⁻¹(3/4)).

Triangle with opposite 3, adjacent 4, hypotenuse 5. sin = 3/5.

4. MCQs

1. Principal value of tan⁻¹(−√3): (a) π/3 (b) −π/3 (c) 2π/3 (d) −2π/3

(b) −π/3.

2. sin⁻¹x + cos⁻¹x = ? (a) π (b) π/2 (c) 0 (d) π/4

(b) π/2.

3. Range of sec⁻¹x: (a) [0, π] (b) [0, π] − {π/2} (c) (0, π) (d) [−π/2, π/2]

(b).

4. sin⁻¹(sin 5π/6) = ? (a) 5π/6 (b) π/6 (c) −π/6 (d) π/3

(b) sin(5π/6) = sin(π/6).

5. 2tan⁻¹(1) = ? (a) π/4 (b) π/2 (c) π (d) 0

(b) 2·π/4 = π/2.
