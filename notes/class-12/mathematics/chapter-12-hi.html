इकाई 3: कलन · अध्याय 12 · यू.पी. बोर्ड

1. समाकलन: अवकलन की व्युत्क्रम क्रिया

अवकलन पूछता है: “F(x) की परिवर्तन दर क्या है?” समाकलन उलटा पूछता है: “किस फलन की यह परिवर्तन दर है?”

यदि d/dx [F(x)] = f(x), तो ∫ f(x) dx = F(x) + C

पद: ∫ = समाकलन चिह्न; f(x) = समाकल्य; dx = चर x दर्शाता है; F(x) = प्रतिअवकलज (आदि फलन); C = समाकलन अचर।

+C क्यों? किसी अचर का अवकलज 0 होता है। इसलिए x², x²+5, x²−7 सभी का अवकलज 2x है। अतः ∫2x dx = x² + C; अनंत प्रतिअवकलज होते हैं, जो केवल एक अचर से भिन्न होते हैं।

2. अनिश्चित समाकलन

सीमाओं के बिना ∫ f(x) dx अनिश्चित समाकल कहलाता है। यह वक्रों का एक कुल y = F(x) + C दर्शाता है, जो सब समान्तर होते हैं (एक ही x पर ढाल समान)। कोई बिंदु, जैसे (0,1), देने पर C निश्चित हो जाता है।

d/dx [∫ f(x) dx] = f(x)  |  ∫ f′(x) dx = f(x) + C

3. समाकलन के मूल नियम

(i) ∫ k·f(x) dx = k ∫ f(x) dx (k अचर)
(ii) ∫ [f(x) ± g(x)] dx = ∫ f dx ± ∫ g dx
(iii) ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1
(iv) ∫ (ax+b)ⁿ dx = (ax+b)ⁿ⁺¹ / [a(n+1)] + C
(v) ∫ 1 dx = x + C, ∫ k dx = kx + C

नियम (iii) का अर्थ: घात में 1 जोड़ें, फिर नई घात से भाग दें। n = −1 छोड़ा गया है क्योंकि तब शून्य से भाग होगा; उस स्थिति में लघुगणक मिलता है।

5. बीजीय फलनों का समाकलन

समाकल्य को xⁿ वाले अलग-अलग पदों में तोड़ें: कोष्ठक खोलें, हर के पद से पद-पद भाग दें, या मूल को घात में लिखें (√x = x^½, 1/x² = x⁻²)। फिर नियम (iii) लगाएँ।

6. त्रिकोणमितीय फलनों का समाकलन

सारणी सीधे प्रयोग करें; ax+b होने पर a से भाग दें: ∫ sin(ax+b) dx = −cos(ax+b)/a + C। वर्गों के लिए सर्वसमिकाएँ:

sin²x = (1−cos 2x)/2   cos²x = (1+cos 2x)/2   tan²x = sec²x − 1   cot²x = cosec²x − 1

7. चरघातांकी फलनों का समाकलन

∫ eˣ dx = eˣ + C (eˣ का अवकलज वही रहता है)। ∫ e^(ax) dx = e^(ax)/a + C। ∫ aˣ dx = aˣ/log a + C (a > 0, a ≠ 1)।

8. लघुगणकीय फलनों का समाकलन

लघुगणक उत्तर के रूप में आता है: ∫ (1/x) dx = log|x| + C तथा ∫ dx/(ax+b) = (1/a) log|ax+b| + C। मापांक इसलिए लगता है कि log केवल धनात्मक मानों के लिए परिभाषित है। साथ ही ∫ log x dx = x log x − x + C (खंडशः समाकलन से)।

9. अनिश्चित समाकलों के गुण

1. ∫ [f+g] = ∫f + ∫g
2. ∫ k f = k ∫ f
3. d/dx ∫ f dx = f(x)
4. यदि ∫f dx = F + C तो ∫ f(ax+b) dx = F(ax+b)/a + C
5. एक ही f के दो समाकल केवल एक अचर से भिन्न होते हैं।

10. अवकलन द्वारा सत्यापन

किसी भी उत्तर की जाँच के लिए उसका अवकलन करें। यदि समाकल्य वापस मिल जाए तो उत्तर सही है (अचर C समाप्त हो जाता है)। परीक्षा में समय हो तो यह अवश्य करें।

चित्र (एनिमेटेड)

चित्र 1: अवकलन और समाकलन एक-दूसरे की उलटी क्रियाएँ हैं। F(x)+C का अवकलन करने पर f(x) मिलता है और f(x) का समाकलन करने पर फिर F(x)+C मिलता है। चित्र 2: वक्र y = x² के नीचे का क्षेत्रफल भरता हुआ दिखाया गया है। समाकलन ऐसी ही बहुत छोटी पट्टियों को जोड़ता है; इसका प्रतिअवकलज x³/3 + C है।

हल किए गए उदाहरण (चरण दर चरण)

1. ∫ x⁵ dx ज्ञात कीजिए
घात नियम: n = 5। ∫ x⁵ dx = x⁶/6 + C।
2. ∫ (3x² + 2x + 5) dx ज्ञात कीजिए
पद-पद समाकलन: 3·x³/3 + 2·x²/2 + 5x = x³ + x² + 5x + C।
3. ∫ (√x + 1/√x) dx ज्ञात कीजिए
इसे x^½ + x^(−½) लिखें। समाकल: x^(3/2)/(3/2) + x^(1/2)/(1/2)। उत्तर: (2/3)x^(3/2) + 2√x + C।
4. ∫ (x+1)²/x dx ज्ञात कीजिए
विस्तार: (x² + 2x + 1)/x = x + 2 + 1/x। समाकलन: x²/2 + 2x + log|x| + C।
5. ∫ (2x+3)⁴ dx ज्ञात कीजिए
यहाँ a = 2, n = 4। परिणाम = (2x+3)⁵ / (2·5) = (2x+3)⁵/10 + C।
6. ∫ sin²x dx ज्ञात कीजिए
sin²x = (1 − cos 2x)/2। ∫ = x/2 − (1/2)(sin 2x/2) = x/2 − sin 2x/4 + C।
7. ∫ (sin 3x + cos 5x) dx ज्ञात कीजिए
−cos 3x/3 + sin 5x/5 + C (प्रत्येक को x के गुणांक से भाग दें)।
8. ∫ (e³ˣ + 5ˣ) dx ज्ञात कीजिए
e³ˣ/3 + 5ˣ/log 5। उत्तर: e³ˣ/3 + 5ˣ/log 5 + C।
9. ∫ tan²x dx ज्ञात कीजिए
tan²x = sec²x − 1। ∫ = tan x − x + C।
10. ∫ dx/(1 + cos 2x) ज्ञात कीजिए
1 + cos 2x = 2cos²x, अतः समाकल्य = ½ sec²x। उत्तर: ½ tan x + C।
11. ∫ dx/(3x + 5) ज्ञात कीजिए
∫ dx/(ax+b) = (1/a) log|ax+b| का प्रयोग करें। उत्तर: (1/3) log|3x+5| + C।
12. सत्यापित कीजिए: ∫ cos²x dx = x/2 + sin 2x/4 + C
दाएँ पक्ष का अवकलन: 1/2 + (2cos 2x)/4 = (1 + cos 2x)/2 = cos²x ✓। सत्यापित।
13. एक वक्र की प्रवणता 2x है और वह (1, 3) से गुजरता है। उसका समीकरण ज्ञात कीजिए।
dy/dx = 2x ⇒ y = x² + C। बिंदु (1,3) रखने पर 3 = 1 + C ⇒ C = 2। y = x² + 2।

लघु एवं दीर्घ प्रश्नोत्तर (खोलने के लिए छुएँ)

Q1. समाकलन की परिभाषा लिखिए।
यह अवकलन की उलटी क्रिया है: ऐसा फलन F ज्ञात करना जिसका अवकलज f हो।
Q2. C क्यों जोड़ा जाता है?
अचर का अवकलज शून्य होता है, इसलिए प्रतिअवकलज अद्वितीय नहीं होते; C सभी संभावित अचरों को दर्शाता है।
Q3. क्या n = −1 के लिए ∫ xⁿ dx सूत्र मान्य है?
नहीं। n = −1 पर सूत्र असफल है; ∫ dx/x = log|x| + C।
Q4. क्या ∫ f(x)g(x) dx = ∫f · ∫g होता है?
नहीं। गुणनफल का समाकल समाकलों का गुणनफल नहीं होता (प्रतिस्थापन या खंडशः विधि प्रयोग करें)।
Q5. ∫ sec x tan x dx लिखिए।
sec x + C।
Q6. ∫ eˣ dx क्या है?
eˣ + C।
Q7. ज्यामितीय रूप से ∫ f(x) dx क्या है?
समान्तर वक्रों का कुल y = F(x) + C।
Q8. दीर्घ: सिद्ध कीजिए ∫ [f(x) + g(x)] dx = ∫ f dx + ∫ g dx।
माना ∫f dx = F, ∫g dx = G, अर्थात् F′ = f, G′ = g। तब d/dx (F + G) = f + g। अतः F + G, f + g का प्रतिअवकलज है, यानी ∫(f+g) dx = F + G + C = ∫f dx + ∫g dx।
Q9. दीर्घ: ∫ (x³ − 2/x² + 4eˣ) dx हल कीजिए और सत्यापित कीजिए।
= x⁴/4 − 2·x⁻¹/(−1) + 4eˣ = x⁴/4 + 2/x + 4eˣ + C। सत्यापन: d/dx = x³ − 2/x² + 4eˣ ✓।
