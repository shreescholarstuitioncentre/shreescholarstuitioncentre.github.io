समाकलन (निरंतर) – कक्षा 12 गणित नोट्स

इकाई 3: कलन · अध्याय 15 · यू.पी. बोर्ड

1. आंशिक भिन्नों द्वारा समाकलन

परिमेय फलन P(x)/Q(x) होता है, जहाँ P, Q बहुपद हैं। यदि P की घात < Q की घात हो तो यह उचित है; अन्यथा पहले भाग दें: P/Q = (भागफल) + (शेषफल)/Q, फिर उचित भाग पर कार्य करें। आंशिक भिन्न किसी जटिल उचित भिन्न को सरल भिन्नों में तोड़ते हैं, जिनका समाकलन मानक सूत्रों से हो जाता है।

2. परिमेय फलनों का समाकलन: विधि

(1) भिन्न को उचित बनाएँ। (2) Q(x) के गुणनखंड करें। (3) प्रत्येक गुणनखंड का रूप लिखें (चित्र 1)। (4) Q(x) से गुणा करके सुविधाजनक x मान (गुणनखंडों के मूल) रखकर या गुणांकों की तुलना करके अचर ज्ञात करें। (5) प्रत्येक पद का समाकलन करें। (6) अवकलन से या पुनः जोड़कर सत्यापित करें।

3. रैखिक गुणनखंडों वाले समाकल

(px+q)/((x−a)(x−b)) = A/(x−a) + B/(x−b),   A = (pa+q)/(a−b), B = (pb+q)/(b−a)

ढकने की युक्ति: A पाने के लिए गुणनखंड (x−a) को ढकें और शेष में x = a रखें। तब ∫ A/(x−a) dx = A log|x−a|।

4. पुनरावृत्त गुणनखंडों वाले समाकल

(x−a)² के लिए A/(x−a) + B/(x−a)² लिखें। (x−a)³ के लिए तीसरा पद C/(x−a)³ जोड़ें। समाकल: ∫ dx/(x−a)² = −1/(x−a), ∫ dx/(x−a)³ = −1/(2(x−a)²)। ढकने की युक्ति केवल उच्चतम घात वाला अचर देती है; शेष गुणांकों की तुलना से मिलते हैं।

5. द्विघात गुणनखंडों वाले समाकल

अखंडनीय द्विघात x²+c (या ax²+bx+c जिसमें b²−4ac < 0) का अंश रैखिक होता है: (Ax+B)/(x²+c)। समाकलन: A/2·log(x²+c) + B·(1/√c) tan⁻¹(x/√c)।

6. ∫ dx/(x²+a²), ∫ dx/√(x²±a²) रूप के समाकल

∫ dx/(x²+a²) = (1/a) tan⁻¹(x/a) + C
∫ dx/(x²−a²) = (1/2a) log|(x−a)/(x+a)| + C
∫ dx/(a²−x²) = (1/2a) log|(a+x)/(a−x)| + C
∫ dx/√(a²−x²) = sin⁻¹(x/a) + C
∫ dx/√(x²+a²) = log|x + √(x²+a²)| + C
∫ dx/√(x²−a²) = log|x + √(x²−a²)| + C

7. द्विघात व्यंजकों वाले समाकल: ∫ dx/(ax²+bx+c)

यदि a ≠ 1 तो a उभयनिष्ठ लें, फिर पूर्ण वर्ग बनाएँ: x²+bx+c = (x + b/2)² + (c − b²/4)। t = x + b/2 रखें। समाकल t² + k², t² − k² या k² − t² वाले तीन रूपों में से एक हो जाता है।

8. वर्गमूल वाले समाकल: ∫ dx/√(ax²+bx+c)

मूल के अंदर पुनः पूर्ण वर्ग बनाएँ और sin⁻¹ (यदि k² − t²) या log (यदि t² ± k²) प्रयोग करें। यदि a ≠ 1 तो 1/√a बाहर लें।

9. ∫ (px+q)/(ax²+bx+c) dx रूप के समाकल

px + q = A·(2ax + b) + B लिखें  [(2ax+b) हर का अवकलज है]
⇒ A log|ax²+bx+c| + B ∫ dx/(ax²+bx+c)

x के गुणांकों की तुलना से A (A = p/2a) और अचर पदों की तुलना से B ज्ञात करें। यही युक्ति (px+q)/√(ax²+bx+c) में भी चलती है: परिणाम A·2√(ax²+bx+c) + B ∫ dx/√(ax²+bx+c)।

10. ∫ √(ax²+bx+c) dx रूप के समाकल

पूर्ण वर्ग बनाएँ, t = x + b/2 रखें और अगले खंड (§11) के तीन सूत्र प्रयोग करें। मूल हटाने के लिए अन्य प्रतिस्थापन न लगाएँ।

11. √(a²−x²), √(x²−a²), √(x²+a²) वाले समाकल

∫ √(a²−x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a) + C
∫ √(x²+a²) dx = (x/2)√(x²+a²) + (a²/2) log|x + √(x²+a²)| + C
∫ √(x²−a²) dx = (x/2)√(x²−a²) − (a²/2) log|x + √(x²−a²)| + C

पहला सूत्र चित्र 2 में ज्यामिति से सिद्ध है; तीनों u = √(…), v = 1 लेकर खंडशः विधि से भी मिलते हैं।

चित्र (एनिमेटेड)

चित्र 1: हर के प्रत्येक प्रकार के गुणनखंड के लिए कौन-सा आंशिक भिन्न रूप लें। चित्र 2: ∫√(a²−x²) dx की ज्यामिति। चतुर्थांश वृत्त y = √(a²−x²) के नीचे 0 से x तक का क्षेत्रफल पीले त्रिज्यखंड (a²θ/2, θ = sin⁻¹(x/a)) और नारंगी त्रिभुज (½·x·√(a²−x²)) का योग है। जोड़ने पर ∫₀ˣ √(a²−t²) dt = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a) मिलता है, जो ठीक मानक सूत्र है।

हल किए गए उदाहरण (चरण दर चरण)

1. ∫ dx/((x−1)(x−2)) ज्ञात कीजिए
माना 1/((x−1)(x−2)) = A/(x−1) + B/(x−2)। गुणा: 1 = A(x−2) + B(x−1)। x = 1: 1 = −A ⇒ A = −1। x = 2: 1 = B। ∫ = −log|x−1| + log|x−2|। उत्तर: log|(x−2)/(x−1)| + C।
2. ∫ (x+3)/((x−1)(x+1)) dx ज्ञात कीजिए
(x+3) = A(x+1) + B(x−1)। x = 1: 4 = 2A ⇒ A = 2। x = −1: 2 = −2B ⇒ B = −1। उत्तर: 2 log|x−1| − log|x+1| + C।
3. ∫ (3x+5)/((x−1)(x+3)) dx ज्ञात कीजिए
3x+5 = A(x+3) + B(x−1)। x = 1: 8 = 4A ⇒ A = 2। x = −3: −4 = −4B ⇒ B = 1। उत्तर: 2 log|x−1| + log|x+3| + C।
4. ∫ x²/(x²−1) dx ज्ञात कीजिए
अनुचित भिन्न (घातें बराबर)। x²/(x²−1) = 1 + 1/(x²−1)। ∫ dx/(x²−1) = ½ log|(x−1)/(x+1)| (a = 1)। उत्तर: x + ½ log|(x−1)/(x+1)| + C।
5. ∫ (x+1)/(x−1)² dx ज्ञात कीजिए
x+1 = (x−1) + 2 लिखें। अतः समाकल्य = 1/(x−1) + 2/(x−1)²। उत्तर: log|x−1| − 2/(x−1) + C।
6. ∫ dx/(x(x+1)²) ज्ञात कीजिए
1/(x(x+1)²) = A/x + B/(x+1) + C/(x+1)²। 1 = A(x+1)² + Bx(x+1) + Cx। x = 0: A = 1। x = −1: 1 = −C ⇒ C = −1। x² का गुणांक: 0 = A + B ⇒ B = −1। ∫ = log|x| − log|x+1| + 1/(x+1)। उत्तर: log|x/(x+1)| + 1/(x+1) + C।
7. ∫ dx/((x+1)(x²+1)) ज्ञात कीजिए
माना = A/(x+1) + (Bx+C)/(x²+1)। 1 = A(x²+1) + (Bx+C)(x+1)। x = −1: 1 = 2A ⇒ A = ½। x²: 0 = A + B ⇒ B = −½। अचर: 1 = A + C ⇒ C = ½। ∫ = ½ log|x+1| − ¼ log(x²+1) + ½ tan⁻¹x। उत्तर: ½ log|x+1| − ¼ log(x²+1) + ½ tan⁻¹x + C।
8. ∫ dx/(x(x²+1)) ज्ञात कीजिए
1/(x(x²+1)) = 1/x − x/(x²+1) (जाँच: (x²+1−x²)/(x(x²+1)) ✓)। ∫ = log|x| − ½ log(x²+1)। उत्तर: log|x| − ½ log(x²+1) + C।
9. ∫ dx/(x²−9) ज्ञात कीजिए
यहाँ a = 3। सूत्र से: (1/6) log|(x−3)/(x+3)| + C।
10. ∫ dx/√(x²+9) ज्ञात कीजिए
a = 3। उत्तर: log|x + √(x²+9)| + C।
11. ∫ dx/(x²+2x+10) ज्ञात कीजिए
x²+2x+10 = (x+1)² + 3²। t = x+1 रखें। ∫ dt/(t²+9) = (1/3) tan⁻¹(t/3)। उत्तर: (1/3) tan⁻¹((x+1)/3) + C।
12. ∫ dx/(x²−6x+5) ज्ञात कीजिए
x²−6x+5 = (x−3)² − 2²। t = x−3: ∫ dt/(t²−4) = (1/4) log|(t−2)/(t+2)|। उत्तर: (1/4) log|(x−5)/(x−1)| + C।
13. ∫ dx/√(2x−x²) ज्ञात कीजिए
2x − x² = 1 − (x−1)²। t = x−1 रखें। ∫ dt/√(1−t²) = sin⁻¹t। उत्तर: sin⁻¹(x−1) + C।
14. ∫ (2x+3)/(x²+4x+7) dx ज्ञात कीजिए
हर का अवकलज = 2x+4। 2x+3 = 1·(2x+4) − 1 लिखें। ∫ = log(x²+4x+7) − ∫ dx/((x+2)²+3)। दूसरा: (1/√3) tan⁻¹((x+2)/√3)। उत्तर: log(x²+4x+7) − (1/√3) tan⁻¹((x+2)/√3) + C।
15. ∫ (3x+1)/√(x²+2x+2) dx ज्ञात कीजिए
x²+2x+2 का अवकलज 2x+2 है। 3x+1 = (3/2)(2x+2) − 2। पहला भाग: (3/2)·2√(x²+2x+2) = 3√(x²+2x+2)। दूसरा: −2 ∫ dx/√((x+1)²+1) = −2 log|x+1+√(x²+2x+2)|। उत्तर: 3√(x²+2x+2) − 2 log|x+1+√(x²+2x+2)| + C।
16. ∫ √(9−x²) dx ज्ञात कीजिए
a = 3। उत्तर: (x/2)√(9−x²) + (9/2) sin⁻¹(x/3) + C।
17. ∫ √(x²+4) dx ज्ञात कीजिए
a = 2। उत्तर: (x/2)√(x²+4) + 2 log|x + √(x²+4)| + C।
18. ∫ √(x²−9) dx ज्ञात कीजिए
a = 3। उत्तर: (x/2)√(x²−9) − (9/2) log|x + √(x²−9)| + C।
19. ∫ √(x²+2x+5) dx ज्ञात कीजिए
x²+2x+5 = (x+1)² + 2²। t = x+1, a = 2। उत्तर: ((x+1)/2)√(x²+2x+5) + 2 log|x+1+√(x²+2x+5)| + C।
20. ∫ √(3−2x−x²) dx ज्ञात कीजिए
3−2x−x² = 4 − (x+1)²। t = x+1, a = 2। उत्तर: ((x+1)/2)√(3−2x−x²) + 2 sin⁻¹((x+1)/2) + C।
21. सत्यापित कीजिए: ∫ dx/(x²−1) = ½ log|(x−1)/(x+1)| + C
d/dx = ½[1/(x−1) − 1/(x+1)] = ½·2/(x²−1) = 1/(x²−1) ✓। सत्यापित।

लघु एवं दीर्घ प्रश्नोत्तर (खोलने के लिए छुएँ)

Q1. उचित परिमेय फलन क्या है?
P(x)/Q(x), जिसमें P की घात Q की घात से कम हो।
Q2. अनुचित भिन्न में क्या करते हैं?
पहले P को Q से भाग दें; भागफल + उचित भिन्न मिलता है, दोनों का समाकलन करें।
Q3. 1/((x−a)(x−b)) का आंशिक भिन्न रूप लिखिए।
A/(x−a) + B/(x−b)।
Q4. पुनरावृत्त गुणनखंड (x−a)² का रूप लिखिए।
A/(x−a) + B/(x−a)²।
Q5. द्विघात गुणनखंड के लिए अंश (Ax+B) क्यों होता है?
अंश की घात गुणनखंड से एक कम होती है; द्विघात के लिए वह रैखिक बहुपद है।
Q6. ∫ dx/(a²−x²) लिखिए।
(1/2a) log|(a+x)/(a−x)| + C।
Q7. ∫ dx/(ax²+bx+c) कैसे हल करते हैं?
पूर्ण वर्ग बनाकर मानक रूप में बदलते हैं।
Q8. दीर्घ: सिद्ध कीजिए ∫ dx/(x²−a²) = (1/2a) log|(x−a)/(x+a)| + C।
1/(x²−a²) = (1/2a)[1/(x−a) − 1/(x+a)] (क्योंकि (x+a)−(x−a) = 2a)। समाकलन: (1/2a)[log|x−a| − log|x+a|] = (1/2a) log|(x−a)/(x+a)| + C।
Q9. दीर्घ: सिद्ध कीजिए ∫ √(a²−x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a) + C।
u = √(a²−x²), v = 1 लेकर खंडशः: I = x√(a²−x²) + ∫ x²/√(a²−x²) dx। अब x² = a² − (a²−x²), अतः ∫ x²/√ dx = a² sin⁻¹(x/a) − I। इसलिए I = x√(a²−x²) + a² sin⁻¹(x/a) − I ⇒ 2I = x√(a²−x²) + a² sin⁻¹(x/a)। 2 से भाग दें।
Q10. दीर्घ: ∫ (x+1)/(x²+x+1) dx ज्ञात कीजिए।
हर का अवकलज = 2x+1। x+1 = ½(2x+1) + ½। ∫ = ½ log(x²+x+1) + ½ ∫ dx/((x+½)² + 3/4)। दूसरा समाकल = (2/√3) tan⁻¹((2x+1)/√3)। अतः उत्तर = ½ log(x²+x+1) + (1/√3) tan⁻¹((2x+1)/√3) + C।
