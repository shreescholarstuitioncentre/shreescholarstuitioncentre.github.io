अध्याय 6: सांतत्य

यूपी बोर्ड / एनसीईआरटी – इकाई 3 कलन। एनिमेटेड आलेख, सूत्र, हल किए उदाहरण, प्रश्नोत्तर और बहुविकल्पीय प्रश्नों सहित नोट्स।

1. सांतत्य का परिचय

विचार: कोई फलन संतत है यदि उसका आलेख कलम उठाए बिना खींचा जा सके: न छिद्र, न उछाल, न विच्छेद। औपचारिक रूप से हम सीमा का प्रयोग करते हैं ताकि “विच्छेद नहीं है” एक सटीक कथन बन जाए।

स्मरण: limx→c f(x) तभी विद्यमान है जब बायाँ पक्ष सीमा LHL = limx→c⁻ f(x) तथा दायाँ पक्ष सीमा RHL = limx→c⁺ f(x) दोनों विद्यमान और बराबर हों।

2. एक बिंदु पर सांतत्य

परिभाषा: f, x = c पर संतत है यदि limx→c f(x) = f(c)। इसका अर्थ तीन बातें एक साथ हैं: (1) f(c) परिभाषित हो; (2) limx→c f(x) विद्यमान हो (LHL = RHL); (3) सीमा, f(c) के बराबर हो।

x = a पर सांतत्य: दोनों पक्षों की सीमाएँ एक ही मान f(a) तक पहुँचती हैं

कार्य-नियम: LHL, RHL तथा f(c) निकालें। यदि LHL = RHL = f(c) तो f, c पर संतत है; अन्यथा असंतत।

2.1 असांतत्य के प्रकार


हटाने योग्य: सीमा है पर ≠ f(1)

उछाल: LHL ≠ RHL

अनंत: x = 0 पर f(x) = 1/x
  • हटाने योग्य: सीमा विद्यमान है परंतु f(c) के बराबर नहीं (या f(c) अपरिभाषित)। f(c) = सीमा परिभाषित करके दूर किया जा सकता है।
  • उछाल (अहटाने योग्य, प्रथम प्रकार): LHL और RHL दोनों विद्यमान हैं पर असमान।
  • अनंत / दोलनी (अहटाने योग्य, द्वितीय प्रकार): कोई एक पक्ष सीमा अनंत है या विद्यमान नहीं (जैसे 0 पर 1/x, 0 पर sin(1/x))।

3. बाएँ पक्ष तथा दाएँ पक्ष से सांतत्य

c पर बाएँ से संतत: limx→c⁻ f(x) = f(c)। c पर दाएँ से संतत: limx→c⁺ f(x) = f(c)।

f, c पर संतत है यदि और केवल यदि वह c पर बाएँ तथा दाएँ दोनों से संतत हो। उदाहरण: f(x) = [x] (महत्तम पूर्णांक फलन) प्रत्येक पूर्णांक पर दाएँ से संतत है पर बाएँ से नहीं।

4. अंतराल में सांतत्य

  • विवृत अंतराल (a, b): (a, b) के प्रत्येक बिंदु पर संतत।
  • संवृत अंतराल [a, b]: (a, b) में संतत, a पर दाएँ से संतत तथा b पर बाएँ से संतत (सिरे पर केवल एक ओर ही उपलब्ध है)।
  • उदाहरण: √x, [0, ∞) में संतत है: 0 पर केवल दाएँ सांतत्य की आवश्यकता है।

5. मानक फलनों का सांतत्य

5.1 बीजीय फलन

  • अचर फलन तथा तत्समक f(x) = x सर्वत्र संतत हैं।
  • बहुपद R पर संतत होते हैं।
  • परिमेय फलन p(x)/q(x) प्रत्येक उस बिंदु पर संतत है जहाँ q(x) ≠ 0 (अर्थात् अपने प्रांत में)।
  • |x|, R पर संतत है; √x, [0, ∞) पर संतत है।

5.2 त्रिकोणमितीय फलन

  • sin x तथा cos x, R पर संतत हैं (इनमें limx→0 sin x/x = 1 काम आता है)।
  • tan x, sec x, x = (2n + 1)π/2 को छोड़कर संतत हैं; cot x, cosec x, x = nπ को छोड़कर संतत हैं। अर्थात् प्रत्येक अपने प्रांत में संतत है।
  • प्रतिलोम त्रिकोणमितीय फलन अपने प्रांतों में संतत हैं।

5.3 चरघातांकी तथा लघुगणकीय फलन

  • eˣ तथा aˣ (a > 0), R पर संतत हैं।
  • log x (तथा logₐx), (0, ∞) पर संतत है।

5.4 संतत फलनों का बीजगणित

यदि f, g, c पर संतत हैं तो f ± g, fg, kf तथा f/g (जब g(c) ≠ 0) भी संतत हैं।

6. संयुक्त फलनों का सांतत्य

प्रमेय: यदि g, c पर संतत है और f, g(c) पर संतत है तो fog, c पर संतत है।

उदाहरण: sin(x²), ecos x, |x² − 4|, log(1 + x²) वहाँ संतत हैं जहाँ आंतरिक और बाह्य फलन परिभाषित तथा संतत हों।

7. खंडशः परिभाषित फलन


खंडशः परिभाषित फलन: दोनों भाग x = 5 पर मिलने चाहिए
विधि: प्रत्येक खंड के भीतर फलन संतत होता है (प्रायः बहुपद)। केवल संधि-बिंदु c पर जाँच करें: LHL (बाएँ खंड का नियम), RHL (दाएँ खंड का नियम) तथा f(c) निकालें। अज्ञात अचरों के लिए LHL = RHL = f(c) रखकर हल करें।

8. हल किए गए उदाहरण

सरल उदा. 1. क्या f(x) = 3x² + 2x + 1, x = 1 पर संतत है?
हल: f(1) = 6। limx→1 f(x) = 3 + 2 + 1 = 6 = f(1)। हाँ, संतत है (बहुपद सर्वत्र संतत होते हैं)।
सरल उदा. 2. f(x) = |x| का x = 0 पर सांतत्य जाँचिए।
हल: LHL = limx→0⁻(−x) = 0; RHL = limx→0⁺ x = 0; f(0) = 0। तीनों बराबर ⇒ संतत।
सरल उदा. 3. x ≠ 1 के लिए f(x) = (x² − 1)/(x − 1), f(1) = 3। x = 1 पर सांतत्य की विवेचना कीजिए।
हल: x ≠ 1 के लिए f(x) = x + 1, अतः सीमा 2 है। परंतु f(1) = 3 ≠ 2 ⇒ असंतत (हटाने योग्य)। f(1) = 2 परिभाषित करने पर संतत हो जाएगा।
सरल उदा. 4. f(x) = 1/(x − 2) तथा g(x) = tan x के असांतत्य बिंदु ज्ञात कीजिए।
हल: f परिमेय है, x = 2 पर अपरिभाषित ⇒ केवल x = 2 पर असंतत। g, x = (2n + 1)π/2, n ∈ Z पर असंतत है।
मध्यम उदा. 5. f(x) = kx + 1 (x ≤ 5), 3x − 5 (x > 5), x = 5 पर संतत है। k ज्ञात कीजिए।
हल: LHL = f(5) = 5k + 1। RHL = 3(5) − 5 = 10। सांतत्य ⇒ 5k + 1 = 10 ⇒ k = 9/5।
मध्यम उदा. 6. f(x) = sin x / x (x ≠ 0), f(0) = k। 0 पर सांतत्य के लिए k ज्ञात कीजिए।
हल: limx→0 sin x / x = 1। आवश्यक है f(0) = 1, अतः k = 1।
मध्यम उदा. 7. x ≠ 3 के लिए f(x) = (x² − 9)/(x − 3), f(3) = k। 3 पर सांतत्य के लिए k ज्ञात कीजिए।
हल: x ≠ 3 के लिए f(x) = x + 3 ⇒ सीमा = 6। अतः k = 6।
मध्यम उदा. 8. दिखाइए f(x) = |x − 1| + |x − 2|, x = 1 तथा x = 2 पर संतत है।
हल: x − 1 तथा x − 2 बहुपद हैं, अतः संतत; संतत फलन का मापांक संतत होता है (|·| के साथ संयोजन); संतत फलनों का योग संतत होता है। अतः f प्रत्येक वास्तविक संख्या पर संतत है। ∎
कठिन उदा. 9. दिखाइए f(x) = [x], x = 2 पर असंतत है।
हल: LHL = limx→2⁻[x] = 1; RHL = limx→2⁺[x] = 2; f(2) = 2। LHL ≠ RHL, अतः सीमा विद्यमान नहीं ⇒ असंतत (उछाल)। यह 2 पर दाएँ से संतत है, बाएँ से नहीं। ∎
कठिन उदा. 10. f(x) = x sin(1/x) (x ≠ 0), f(0) = 0। 0 पर सांतत्य की विवेचना कीजिए।
हल: |sin(1/x)| ≤ 1 ⇒ |x sin(1/x)| ≤ |x| → 0 जब x → 0। सैंडविच प्रमेय से lim f(x) = 0 = f(0) ⇒ संतत।
कठिन उदा. 11. f(x) = 2 (x ≤ 3), ax + b (3 < x < 5), 9 (x ≥ 5) संतत है। a, b ज्ञात कीजिए।
हल: x = 3 पर: LHL = 2, RHL = 3a + b ⇒ 3a + b = 2। x = 5 पर: LHL = 5a + b, RHL = 9 ⇒ 5a + b = 9। घटाने पर 2a = 7 ⇒ a = 7/2; तब b = 2 − 21/2 = −17/2। जाँच: 5(7/2) − 17/2 = 9 ✔।
कठिन उदा. 12. दिखाइए f(x) = sin(x²), R पर संतत है।
उपपत्ति: g(x) = x² बहुपद है, R पर संतत। h(u) = sin u, R पर संतत है। अतः f = h∘g संयुक्त फलन के सांतत्य से R पर संतत है। ∎

9. लघु एवं दीर्घ प्रश्नोत्तर (उत्तर देखने के लिए दबाएँ)

प्र.1. x = c पर सांतत्य की तीन शर्तें लिखिए।

f(c) परिभाषित हो; limx→c f(x) विद्यमान हो; सीमा = f(c)।

प्र.2. क्या f(x) = 1/x, R पर संतत है?

नहीं: यह 0 पर परिभाषित नहीं है। यह अपने प्रांत R − {0} के प्रत्येक बिंदु पर संतत है।

प्र.3. हटाने योग्य असांतत्य क्या है?

सीमा विद्यमान है परंतु f(c) से भिन्न है (या f(c) अपरिभाषित है); f(c) = सीमा परिभाषित करने से यह दूर हो जाता है।

प्र.4. क्या प्रत्येक संतत फलन अवकलनीय होता है?

नहीं। |x|, 0 पर संतत है पर वहाँ तीखा कोना है (अवकलनीय नहीं)। विलोम सत्य है: अवकलनीय ⇒ संतत (अध्याय 7)।

प्र.5. f(x) = (x + 1)/(x² − 4) कहाँ असंतत है?

हर शून्य होने पर: x = 2 तथा x = −2।

प्र.6. दीर्घ: [a, b] में सांतत्य परिभाषित कीजिए और दिखाइए कि √x, [0, 4] में संतत है।

f, [a, b] में संतत है यदि (a, b) में संतत हो, a पर दाएँ से तथा b पर बाएँ से संतत हो। √x के लिए: (0, 4) में मूल फलन होने से संतत; 0 पर limx→0⁺√x = 0 = f(0); 4 पर limx→4⁻√x = 2 = f(4)। ∎

प्र.7. क्या कोई फलन प्रत्येक बिंदु पर असंतत हो सकता है? उदाहरण दीजिए।

हाँ। f(x) = 1 (x परिमेय), 0 (x अपरिमेय): प्रत्येक अंतराल में परिमेय और अपरिमेय दोनों होते हैं, अतः कहीं भी सीमा विद्यमान नहीं।

प्र.8. यदि f, c पर संतत है और f(c) > 0 तो c के निकट क्या कह सकते हैं?

c के पर्याप्त निकट सभी x के लिए f(x) > 0 (चिह्न की स्थिरता)।

10. बहुविकल्पीय प्रश्न

1. यदि f, c पर संतत है तो: (a) LHL ≠ RHL (b) lim f(x) = f(c) (c) f(c) अपरिभाषित (d) सीमा विद्यमान नहीं

(b)।

2. f(x) = [x] असंतत है: (a) सभी वास्तविक संख्याओं पर (b) सभी पूर्णांकों पर (c) केवल 0 पर (d) कहीं नहीं

(b) सभी पूर्णांकों पर।

3. यदि x ≠ 2 के लिए f(x) = (x² − 4)/(x − 2), 2 पर संतत हो तो f(2) = ? (a) 0 (b) 2 (c) 4 (d) अपरिभाषित

(c) 4।

4. tan x असंतत है: (a) nπ (b) (2n + 1)π/2 (c) 2nπ (d) कहीं नहीं

(b)।

5. log x संतत है: (a) R (b) [0, ∞) (c) (0, ∞) (d) (−∞, 0)

(c) (0, ∞)।
