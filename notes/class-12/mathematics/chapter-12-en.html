Integration – Class 12 Maths Notes

Unit 3: Calculus · Chapter 12 · UP Board

1. Integration as the Inverse of Differentiation

Differentiation asks: “what is the rate of change of F(x)?”. Integration asks the reverse: “which function has this rate of change?”.

If d/dx [F(x)] = f(x), then ∫ f(x) dx = F(x) + C

Terms: ∫ = integral sign; f(x) = integrand; dx = tells the variable is x; F(x) = antiderivative (primitive); C = constant of integration.

Why +C? The derivative of any constant is 0. So x², x²+5, x²−7 all have derivative 2x. Hence ∫2x dx = x² + C: infinitely many antiderivatives, differing only by a constant.

2. Indefinite Integrals

∫ f(x) dx without limits is called an indefinite integral; it represents a family of curves y = F(x) + C, all parallel (same slope at the same x). Giving one point, e.g. (0,1), fixes C.

d/dx [∫ f(x) dx] = f(x)  |  ∫ f′(x) dx = f(x) + C

3. Basic Rules of Integration

(i) ∫ k·f(x) dx = k ∫ f(x) dx (k constant)
(ii) ∫ [f(x) ± g(x)] dx = ∫ f dx ± ∫ g dx
(iii) ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C, n ≠ −1
(iv) ∫ (ax+b)ⁿ dx = (ax+b)ⁿ⁺¹ / [a(n+1)] + C
(v) ∫ 1 dx = x + C, ∫ k dx = kx + C

Rule (iii) means: raise the power by 1, then divide by the new power. n = −1 is excluded because it would divide by zero; that case gives log.

5. Integration of Algebraic Functions

Break the integrand into separate terms of the form xⁿ: expand brackets, divide by the denominator term by term, or write roots as powers (√x = x^½, 1/x² = x⁻²). Then use rule (iii).

6. Integration of Trigonometric Functions

Use the table directly, and for ax+b inside, divide by a: ∫ sin(ax+b) dx = −cos(ax+b)/a + C. For squares use identities:

sin²x = (1−cos 2x)/2   cos²x = (1+cos 2x)/2   tan²x = sec²x − 1   cot²x = cosec²x − 1

7. Integration of Exponential Functions

∫ eˣ dx = eˣ + C (eˣ is its own derivative). ∫ e^(ax) dx = e^(ax)/a + C. ∫ aˣ dx = aˣ/log a + C (a > 0, a ≠ 1).

8. Integration of Logarithmic Functions

The log arises as an answer: ∫ (1/x) dx = log|x| + C and ∫ dx/(ax+b) = (1/a) log|ax+b| + C. Modulus is used since log is defined only for positive values. Also ∫ log x dx = x log x − x + C (found by parts).

9. Properties of Indefinite Integrals

1. ∫ [f+g] = ∫f + ∫g
2. ∫ k f = k ∫ f
3. d/dx ∫ f dx = f(x)
4. If ∫f dx = F + C then ∫ f(ax+b) dx = F(ax+b)/a + C
5. Two integrals of the same f differ only by a constant.

10. Verification by Differentiation

To check any answer, differentiate it. If you get the integrand back, the answer is correct (the constant C vanishes). Always do this in exams if time permits.

Solved Examples (step by step)

1. Find ∫ x⁵ dx
Power rule: n = 5. ∫ x⁵ dx = x⁶/6 + C.
2. Find ∫ (3x² + 2x + 5) dx
Integrate term by term: 3·x³/3 + 2·x²/2 + 5x = x³ + x² + 5x + C.
3. Find ∫ (√x + 1/√x) dx
Write as x^½ + x^(−½). Integrals: x^(3/2)/(3/2) + x^(1/2)/(1/2). Answer: (2/3)x^(3/2) + 2√x + C.
4. Find ∫ (x+1)²/x dx
Expand: (x² + 2x + 1)/x = x + 2 + 1/x. Integrate: x²/2 + 2x + log|x| + C.
5. Find ∫ (2x+3)⁴ dx
Here a = 2, n = 4. Result = (2x+3)⁵ / (2·5) = (2x+3)⁵/10 + C.
6. Find ∫ sin²x dx
sin²x = (1 − cos 2x)/2. ∫ = x/2 − (1/2)(sin 2x/2) = x/2 − sin 2x/4 + C.
7. Find ∫ (sin 3x + cos 5x) dx
−cos 3x/3 + sin 5x/5 + C (divide each by the coefficient of x).
8. Find ∫ (e³ˣ + 5ˣ) dx
e³ˣ/3 + 5ˣ/log 5. Answer: e³ˣ/3 + 5ˣ/log 5 + C.
9. Find ∫ tan²x dx
tan²x = sec²x − 1. ∫ = tan x − x + C.
10. Find ∫ dx/(1 + cos 2x)
1 + cos 2x = 2cos²x. So integrand = ½ sec²x. Answer: ½ tan x + C.
11. Find ∫ dx/(3x + 5)
Use ∫ dx/(ax+b) = (1/a) log|ax+b|. Answer: (1/3) log|3x+5| + C.
12. Verify: ∫ cos²x dx = x/2 + sin 2x/4 + C
Differentiate RHS: 1/2 + (2cos 2x)/4 = (1 + cos 2x)/2 = cos²x ✓. Verified.
13. Curve has slope 2x and passes through (1, 3). Find its equation.
dy/dx = 2x ⇒ y = x² + C. Put (1,3): 3 = 1 + C ⇒ C = 2. y = x² + 2.

Short & Long Q&A (tap to open)

Q1. Define integration.
It is the reverse of differentiation: finding a function F whose derivative is f.
Q2. Why is C added?
The derivative of a constant is zero, so antiderivatives are not unique; C represents all possible constants.
Q3. Is ∫ xⁿ dx valid for n = −1?
No. For n = −1 the formula fails; ∫ dx/x = log|x| + C.
Q4. Is ∫ f(x)g(x) dx = ∫f · ∫g?
No. Integral of a product is not the product of integrals (use substitution or parts).
Q5. Write ∫ sec x tan x dx.
sec x + C.
Q6. What is ∫ eˣ dx?
eˣ + C.
Q7. Geometrically, what is ∫ f(x) dx?
A family of parallel curves y = F(x) + C.
Q8. Long: Prove ∫ [f(x) + g(x)] dx = ∫ f dx + ∫ g dx.
Let ∫f dx = F, ∫g dx = G, so F′ = f, G′ = g. Then d/dx (F + G) = f + g. Hence F + G is an antiderivative of f + g, i.e. ∫(f+g) dx = F + G + C = ∫f dx + ∫g dx.
Q9. Long: Evaluate ∫ (x³ − 2/x² + 4eˣ) dx and verify.
= x⁴/4 − 2·x⁻¹/(−1) + 4eˣ = x⁴/4 + 2/x + 4eˣ + C. Verify: d/dx = x³ − 2/x² + 4eˣ ✓.
