Chapter 6: Continuity

UP Board / NCERT – Unit 3 Calculus. Notes with animated graphs, formulas, solved examples, Q&A and MCQs.

1. Introduction to Continuity

Idea: a function is continuous if its graph can be drawn without lifting the pen: no holes, no jumps, no breaks. Formally, we use limits so that “no break” is a precise statement.

Recall: limx→c f(x) exists iff the left-hand limit LHL = limx→c⁻ f(x) and the right-hand limit RHL = limx→c⁺ f(x) exist and are equal.

2. Continuity at a Point

Definition: f is continuous at x = c if limx→c f(x) = f(c). This means three things together: (1) f(c) is defined; (2) limx→c f(x) exists (LHL = RHL); (3) the limit equals f(c).

Continuity at x = a: both one-sided limits reach the same value f(a)

Working rule: compute LHL, RHL and f(c). If LHL = RHL = f(c), f is continuous at c; otherwise it is discontinuous at c.

2.1 Types of Discontinuity


Removable: limit exists but ≠ f(1)

Jump: LHL ≠ RHL

Infinite: f(x) = 1/x at x = 0
  • Removable: the limit exists but is not equal to f(c) (or f(c) is undefined). It can be removed by redefining f(c) = limit.
  • Jump (non-removable, first kind): LHL and RHL both exist but are unequal.
  • Infinite / oscillating (non-removable, second kind): a one-sided limit is infinite or does not exist (e.g. 1/x at 0, sin(1/x) at 0).

3. Left-Hand and Right-Hand Continuity

Left continuous at c: limx→c⁻ f(x) = f(c). Right continuous at c: limx→c⁺ f(x) = f(c).

f is continuous at c iff it is both left and right continuous at c. Example: f(x) = [x] (greatest integer) is right continuous but not left continuous at every integer.

4. Continuity in an Interval

  • Open interval (a, b): continuous at every point of (a, b).
  • Closed interval [a, b]: continuous on (a, b), right continuous at a and left continuous at b (only one side is available at an end-point).
  • Example: √x is continuous on [0, ∞): at 0 only right continuity is needed.

5. Continuity of Standard Functions

5.1 Algebraic Functions

  • Constant function and identity f(x) = x are continuous everywhere.
  • Polynomials are continuous on R.
  • Rational function p(x)/q(x) is continuous at every point where q(x) ≠ 0 (i.e. on its domain).
  • |x| is continuous on R; √x is continuous on [0, ∞).

5.2 Trigonometric Functions

  • sin x and cos x are continuous on R (they use limx→0 sin x/x = 1).
  • tan x, sec x are continuous except at x = (2n + 1)π/2; cot x, cosec x are continuous except at x = nπ. In other words, each is continuous on its own domain.
  • Inverse trigonometric functions are continuous on their domains.

5.3 Exponential and Logarithmic Functions

  • eˣ and aˣ (a > 0) are continuous on R.
  • log x (and logₐx) is continuous on (0, ∞).

5.4 Algebra of Continuous Functions

If f, g are continuous at c, so are f ± g, fg, kf, and f/g (when g(c) ≠ 0).

6. Continuity of Composite Functions

Theorem: If g is continuous at c and f is continuous at g(c), then fog is continuous at c.

Examples: sin(x²), ecos x, |x² − 4|, log(1 + x²) are continuous wherever the inner and outer functions are defined and continuous.

7. Piecewise-Defined Functions


Piecewise function: the two pieces must meet at x = 5
Method: Inside each piece the function is continuous (usually a polynomial). Only check the breakpoint c: find LHL (use the left rule), RHL (use the right rule) and f(c). For unknown constants, set LHL = RHL = f(c) and solve.

8. Solved Examples

Easy Ex 1. Is f(x) = 3x² + 2x + 1 continuous at x = 1?
Solution: f(1) = 6. limx→1 f(x) = 3 + 2 + 1 = 6 = f(1). Yes, continuous (polynomials are continuous everywhere).
Easy Ex 2. Check continuity of f(x) = |x| at x = 0.
Solution: LHL = limx→0⁻(−x) = 0; RHL = limx→0⁺ x = 0; f(0) = 0. All equal ⇒ continuous.
Easy Ex 3. f(x) = (x² − 1)/(x − 1) for x ≠ 1, f(1) = 3. Discuss continuity at x = 1.
Solution: For x ≠ 1, f(x) = x + 1, so the limit is 2. But f(1) = 3 ≠ 2 ⇒ discontinuous (removable). Redefining f(1) = 2 makes it continuous.
Easy Ex 4. Find points of discontinuity of f(x) = 1/(x − 2) and of g(x) = tan x.
Solution: f is rational, undefined at x = 2 ⇒ discontinuous only at x = 2. g is discontinuous at x = (2n + 1)π/2, n ∈ Z.
Medium Ex 5. f(x) = kx + 1 (x ≤ 5), 3x − 5 (x > 5) is continuous at x = 5. Find k.
Solution: LHL = f(5) = 5k + 1. RHL = 3(5) − 5 = 10. Continuity ⇒ 5k + 1 = 10 ⇒ k = 9/5.
Medium Ex 6. f(x) = sin x / x (x ≠ 0), f(0) = k. Find k for continuity at 0.
Solution: limx→0 sin x / x = 1. Need f(0) = 1, so k = 1.
Medium Ex 7. f(x) = (x² − 9)/(x − 3) for x ≠ 3, f(3) = k. Find k so that f is continuous at 3.
Solution: For x ≠ 3, f(x) = x + 3 ⇒ limit = 6. Hence k = 6.
Medium Ex 8. Show f(x) = |x − 1| + |x − 2| is continuous at x = 1 and x = 2.
Solution: x − 1 and x − 2 are polynomials, hence continuous; modulus of a continuous function is continuous (composition with |·|); a sum of continuous functions is continuous. So f is continuous at every real number. ∎
Hard Ex 9. Show f(x) = [x] is discontinuous at x = 2.
Solution: LHL = limx→2⁻[x] = 1; RHL = limx→2⁺[x] = 2; f(2) = 2. LHL ≠ RHL, so the limit does not exist ⇒ discontinuous (jump). It is right continuous at 2 but not left continuous. ∎
Hard Ex 10. f(x) = x sin(1/x) (x ≠ 0), f(0) = 0. Discuss continuity at 0.
Solution: |sin(1/x)| ≤ 1 ⇒ |x sin(1/x)| ≤ |x| → 0 as x → 0. By the squeeze theorem lim f(x) = 0 = f(0) ⇒ continuous.
Hard Ex 11. f(x) = 2 (x ≤ 3), ax + b (3 < x < 5), 9 (x ≥ 5) is continuous. Find a, b.
Solution: At x = 3: LHL = 2, RHL = 3a + b ⇒ 3a + b = 2. At x = 5: LHL = 5a + b, RHL = 9 ⇒ 5a + b = 9. Subtract: 2a = 7 ⇒ a = 7/2; then b = 2 − 21/2 = −17/2. Check: 5(7/2) − 17/2 = 9 ✔.
Hard Ex 12. Show f(x) = sin(x²) is continuous on R.
Proof: g(x) = x² is a polynomial, continuous on R. h(u) = sin u is continuous on R. Hence f = h∘g is continuous on R (continuity of composite). ∎

9. Short & Long Q&A (tap to see answer)

Q1. State the three conditions for continuity at x = c.

f(c) defined; limx→c f(x) exists; limit = f(c).

Q2. Is f(x) = 1/x continuous on R?

No: it is not defined at 0. It is continuous at every point of its domain R − {0}.

Q3. What is a removable discontinuity?

The limit exists but differs from f(c) (or f(c) is undefined); redefining f(c) = limit removes it.

Q4. Is every continuous function differentiable?

No. |x| is continuous at 0 but has a sharp corner there (not differentiable). The converse is true: differentiable ⇒ continuous (Chapter 7).

Q5. Where is f(x) = (x + 1)/(x² − 4) discontinuous?

Denominator zero: x = 2 and x = −2.

Q6. Long: Define continuity on [a, b] and show √x is continuous on [0, 4].

f is continuous on [a, b] if continuous on (a, b), right continuous at a, left continuous at b. For √x: continuous on (0, 4) as a root function; at 0, limx→0⁺√x = 0 = f(0); at 4, limx→4⁻√x = 2 = f(4). ∎

Q7. Can a function be discontinuous at every point? Give an example.

Yes. f(x) = 1 for rational x, 0 for irrational x: every interval contains both rationals and irrationals, so no limit exists anywhere.

Q8. If f is continuous at c and f(c) > 0, what can you say near c?

f(x) > 0 for all x close enough to c (sign persistence).
