कक्षा 12 गणित — अध्याय 22: त्रिविमीय ज्यामिति (सरल रेखा और समतल)

1. आकाश में बिंदु के निर्देशांक

P(x, y, z): x, y, z क्रमशः YZ, ZX, XY समतलों से दूरियाँ हैं

तीन परस्पर लंबवत् अक्ष OX, OY, OZ मूल बिंदु O पर मिलते हैं और आकाश को 8 अष्टांशों में बाँटते हैं। मूल बिंदु = (0,0,0); x-अक्ष पर बिंदु = (x,0,0); XY-समतल में बिंदु = (x,y,0)।

2. दूरी, दिक्-अनुपात और दिक्-कोज्याएँ

PQ = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
PQ के दिक्-अनुपात: x₂−x₁, y₂−y₁, z₂−z₁
दिक्-कोज्याएँ: l = (x₂−x₁)/PQ, m = (y₂−y₁)/PQ, n = (z₂−z₁)/PQ

3. रेखा का समीकरण

सदिश: r = a + λb (a = रेखा पर बिंदु, b = समांतर सदिश)
कार्तीय: (x−x₁)/a = (y−y₁)/b = (z−z₁)/c
दो बिंदुओं से: (x−x₁)/(x₂−x₁) = (y−y₁)/(y₂−y₁) = (z−z₁)/(z₂−z₁)

यहाँ a, b, c रेखा के दिक्-अनुपात हैं।

4. समांतर, प्रतिच्छेदी और विषमतलीय रेखाएँ

समांतर: b₁ = λb₂
विषमतलीय: न समांतर, न प्रतिच्छेदी (समतलीय नहीं)
समतलीय: [a₂−a₁ b₁ b₂] = 0

एक समतल की रेखाएँ या तो काटती हैं या समांतर होती हैं। विषमतलीय रेखाएँ केवल त्रिविमीय आकाश में होती हैं।

5. रेखाओं के बीच न्यूनतम दूरी

विषमतलीय: d = |(a₂−a₁)·(b₁×b₂)| / |b₁×b₂|
समांतर: d = |b×(a₂−a₁)| / |b|
रेखाएँ प्रतिच्छेद करती हैं ⇔ d = 0

6. समतल का समीकरण

सदिश: r·n = q (n = अभिलंब)
कार्तीय: ax + by + cz + d = 0
बिंदु (x₁,y₁,z₁) से: a(x−x₁)+b(y−y₁)+c(z−z₁) = 0
तीन बिंदुओं से: | x−x₁ y−y₁ z−z₁ ; x₂−x₁ y₂−y₁ z₂−z₁ ; x₃−x₁ y₃−y₁ z₃−z₁ | = 0
अंतःखंड रूप: x/p + y/q + z/r = 1

समतल के गुणांक a, b, c उसके अभिलंब के दिक्-अनुपात होते हैं।

7. कोण

दो रेखाओं के बीच: cosθ = |b₁·b₂| / (|b₁||b₂|) (लंबवत्: a₁a₂+b₁b₂+c₁c₂ = 0)
दो समतलों के बीच: cosθ = |n₁·n₂| / (|n₁||n₂|)
रेखा और समतल के बीच: sinθ = |b·n| / (|b||n|)

8. बिंदु की समतल से दूरी

D = |ax₁ + by₁ + cz₁ + d| / √(a²+b²+c²)
सदिश रूप: D = |a·n − q| / |n|

हल किए गए उदाहरण (दिया है / ज्ञात करें / सिद्ध करें / हल)

उदाहरण 1 (सरल)। P(1,2,3) और Q(3,4,4) के बीच दूरी ज्ञात कीजिए।
PQ = √(4+4+1) = 3।
उदाहरण 2 (सरल)। रेखा PQ के दिक्-अनुपात और दिक्-कोज्याएँ ज्ञात कीजिए।
दिक्-अनुपात: 2, 2, 1। दिक्-कोज्याएँ: 2/3, 2/3, 1/3।
उदाहरण 3 (सरल)। (1,2,3) से जाने वाली और 2i+j−2k के समांतर रेखा।
सदिश: r = (i+2j+3k) + λ(2i+j−2k)।
कार्तीय: (x−1)/2 = (y−2)/1 = (z−3)/(−2)।
उदाहरण 4 (सरल)। A(1,2,3) और B(3,4,4) से जाने वाली रेखा।
AB के दिक्-अनुपात: 2, 2, 1।
(x−1)/2 = (y−2)/2 = (z−3)/1।
उदाहरण 5 (मध्यम)। दिक्-अनुपात (1,2,2) और (2,3,6) वाली रेखाओं के बीच कोण।
b₁·b₂ = 2+6+12 = 20; |b₁| = 3; |b₂| = 7।
cosθ = 20/21 ⇒ θ = cos⁻¹(20/21)।
उदाहरण 6 (कठिन)। r = (i+j)+λ(2i−j+k) और r = (2i+j−k)+μ(3i−5j+2k) के बीच न्यूनतम दूरी।
b₁×b₂ = i(−2+5) − j(4−3) + k(−10+3) = 3i−j−7k; |b₁×b₂| = √59।
a₂−a₁ = i − k; अदिश गुणनफल = 3 + 0 + 7 = 10।
d = 10/√59।
उदाहरण 7 (मध्यम)। (1,2,3) से जाने वाला और अभिलंब 2i+3j−k वाला समतल।
2(x−1) + 3(y−2) − (z−3) = 0 ⇒ 2x + 3y − z − 5 = 0।
उदाहरण 8 (मध्यम)। A(1,0,0), B(0,1,0), C(0,0,1) से जाने वाला समतल।
अंतःखंड 1, 1, 1 ⇒ x/1 + y/1 + z/1 = 1 ⇒ x + y + z = 1।
उदाहरण 9 (मध्यम)। समतलों 2x+y−2z = 5 और 3x−6y−2z = 7 के बीच कोण।
n₁·n₂ = 6−6+4 = 4; |n₁| = 3; |n₂| = 7।
cosθ = 4/21।
उदाहरण 10 (मध्यम)। (1,2,3) की समतल 2x−y+2z+3 = 0 से दूरी।
D = |2−2+6+3| / √(4+1+4) = 9/3 = 3।
उदाहरण 11 (सिद्ध कीजिए)। (x−5)/7 = (y+2)/(−5) = z/1 और x/1 = y/2 = z/3 परस्पर लंबवत् हैं।
a₁a₂ + b₁b₂ + c₁c₂ = 7(1) + (−5)(2) + 1(3) = 7−10+3 = 0 ∎
