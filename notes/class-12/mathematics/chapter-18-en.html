Differential Equations – Class 12 Maths Notes

Unit 3: Calculus · Chapter 18 · UP Board

1. Basic Concepts

Definition of a Differential Equation

An equation containing a dependent variable, an independent variable and the derivatives of the dependent variable is a differential equation. Example: dy/dx + y = sin x. To solve it is to find y as a function of x (without derivatives) that satisfies it.

Order of a Differential Equation

The order is the order of the highest derivative present. dy/dx = x has order 1; d²y/dx² + y = 0 has order 2.

Degree of a Differential Equation

The degree is the power of the highest-order derivative, after the equation is made a polynomial in the derivatives (no roots, fractions or functions of a derivative such as sin(dy/dx) or e^(dy/dx)). If it cannot be made a polynomial in the derivatives, the degree is not defined. Example: (d²y/dx²)³ + (dy/dx)⁴ = x has order 2, degree 3. √(1 + (dy/dx)²) = d²y/dx² becomes 1 + (y′)² = (y″)²: order 2, degree 2.

General Solution

A solution containing as many arbitrary constants as the order of the equation. For dy/dx = 2x: y = x² + C. Geometrically it is a family of curves (Diagram 1).

Particular Solution

The solution obtained by giving particular values to the constants, usually using given (initial) conditions such as y(0) = 1.

Formation of Differential Equations

Given a family of curves with n arbitrary constants, differentiate n times and eliminate the constants using the original equation and the derivatives. The result is a differential equation of order n, free from constants.

2. Methods of Solving Differential Equations

Solution by Separation of Variables

dy/dx = f(x)·g(y)  ⇒  dy/g(y) = f(x) dx  ⇒  ∫ dy/g(y) = ∫ f(x) dx + C

Move all y terms with dy and all x terms with dx, then integrate both sides and add one constant.

Homogeneous Differential Equations of First Order and First Degree

f(x, y) is homogeneous of degree n if f(λx, λy) = λⁿ f(x, y). The equation dy/dx = F(y/x) is homogeneous. Method: put y = vx, so dy/dx = v + x dv/dx. The equation becomes v + x dv/dx = F(v), which separates: dv/(F(v) − v) = dx/x. After integration, replace v by y/x. If it is easier as dx/dy = G(x/y), put x = vy.

Linear Differential Equations and Integrating Factor Method

A first-order linear equation is linear in y and dy/dx. The integrating factor (IF) multiplies both sides to make the left side a perfect derivative: d/dx (y·IF) = Q·IF.

3. Standard Forms

dy/dx + Py = Q (P, Q functions of x)

IF = e^(∫P dx)   ⇒   y · IF = ∫ Q · IF dx + C

Remember e^(log f) = f, so for P = 1/x, IF = e^(log x) = x. No constant is added while finding IF.

dx/dy + Px = Q (P, Q functions of y)

IF = e^(∫P dy)   ⇒   x · IF = ∫ Q · IF dy + C

Use this when the equation is linear in x, for example y dx + (x − y³) dy = 0.

Initial-Condition Problems

Solve to get the general solution, substitute the given values (x₀, y₀) to find C, then write the particular solution. Do not substitute before integrating.

Applications and Word Problems

Translate the statement: “rate of change of N is proportional to N” becomes dN/dt = kN, with solution N = N₀e^(kt). This models population growth (k > 0), radioactive decay (k < 0) and compound interest. Use two given data points to find k and N₀, then answer the question asked (Diagram 3).

Solved Examples (step by step)

1. Find the order and degree of d²y/dx² + (dy/dx)³ + y = 0
Highest derivative d²y/dx²: order 2. Its power is 1: degree 1.
2. Find the order and degree of (d³y/dx³)² + (dy/dx)⁴ + y = 0
Highest derivative is d³y/dx³, so order 3. Its power is 2, so order 3, degree 2.
3. Find the order and degree of dy/dx + sin(dy/dx) = 0
Order 1. The equation cannot be written as a polynomial in dy/dx (it contains sin of the derivative), so order 1, degree not defined.
4. Form the differential equation of y = Ax²
One constant ⇒ differentiate once: dy/dx = 2Ax. From the equation A = y/x². So dy/dx = 2y/x. Answer: x dy/dx − 2y = 0.
5. Form the differential equation of y = A cos x + B sin x
Two constants ⇒ differentiate twice. y′ = −A sin x + B cos x; y″ = −A cos x − B sin x = −y. Answer: d²y/dx² + y = 0.
6. Form the differential equation of the parabolas y² = 4ax
Differentiate: 2y y′ = 4a ⇒ a = y y′/2. Substitute: y² = 4·(y y′/2)·x = 2xy y′. Divide by y: 2x dy/dx − y = 0.
7. Solve dy/dx = xy
Separate: dy/y = x dx. Integrate: log|y| = x²/2 + C₁. So y = e^(C₁) e^(x²/2). Answer: y = A e^(x²/2), where A = ±e^(C₁).
8. Solve dy/dx = e^(x−y)
e^(x−y) = eˣ/eʸ. Separate: eʸ dy = eˣ dx. Integrate: eʸ = eˣ + C.
9. Solve dy/dx = 2x with y(0) = 1
Integrate: y = x² + C. Put x = 0, y = 1: 1 = C. Particular solution y = x² + 1.
10. Solve dy/dx = −2xy with y(0) = 3
Separate: dy/y = −2x dx. log|y| = −x² + C₁ ⇒ y = A e^(−x²). Put (0, 3): A = 3. Answer: y = 3e^(−x²).
11. Solve dy/dx = (x + y)/x
Homogeneous. Put y = vx: v + x dv/dx = 1 + v ⇒ x dv/dx = 1 ⇒ dv = dx/x ⇒ v = log|x| + C. Replace v = y/x: y = x (log|x| + C).
12. Solve dy/dx = (x² + y²)/(2xy)
Put y = vx: v + x v′ = (1 + v²)/(2v) ⇒ x v′ = (1 − v²)/(2v). Separate: 2v dv/(1 − v²) = dx/x. Integrate: −log|1 − v²| = log|x| + c ⇒ x(1 − v²) = C. Put v = y/x: x(1 − y²/x²) = C ⇒ x² − y² = Cx.
13. Solve dy/dx + y = e^(−x)
P = 1, IF = e^(∫1 dx) = eˣ. y eˣ = ∫ e^(−x) eˣ dx = ∫ 1 dx = x + C. Answer: y = (x + C) e^(−x).
14. Solve dy/dx + 2y = sin x
IF = e^(2x). y e^(2x) = ∫ e^(2x) sin x dx = e^(2x)(2 sin x − cos x)/5 + C. Answer: y = (2 sin x − cos x)/5 + C e^(−2x).
15. Solve dy/dx + y/x = x²
P = 1/x, IF = e^(log x) = x. xy = ∫ x · x² dx = x⁴/4 + C. Answer: y = x³/4 + C/x.
16. Solve x dy/dx + 2y = x² (x > 0)
Divide by x: dy/dx + (2/x) y = x. IF = e^(2 log x) = x². x²y = ∫ x³ dx = x⁴/4 + C. Answer: y = x²/4 + C/x².
17. Solve y dx + (x − y³) dy = 0
Write dx/dy + x/y = y² (linear in x). IF = e^(∫dy/y) = y. xy = ∫ y³ dy = y⁴/4 + C. Answer: x = y³/4 + C/y.
18. Solve dy/dx + y tan x = sec x with y(0) = 1
IF = e^(∫tan x dx) = e^(log sec x) = sec x. y sec x = ∫ sec²x dx = tan x + C ⇒ y = sin x + C cos x. Put (0, 1): 1 = C. Answer: y = sin x + cos x.
19. A population grows at a rate proportional to itself and doubles in 10 years. In how many years will it triple?
dP/dt = kP ⇒ P = P₀e^(kt). Doubling: 2 = e^(10k) ⇒ k = (log 2)/10. Triple: 3 = e^(kt) ⇒ t = (log 3)/k = 10 log 3/log 2 ≈ 15.85 years.
20. Verify that y = A e^(x²/2) is a solution of dy/dx = xy
dy/dx = A e^(x²/2) · x = x · y ✓. Verified.

Short & Long Q&A (tap to open)

Q1. What is a differential equation?
An equation involving derivatives of a dependent variable with respect to an independent variable.
Q2. Define order and degree.
Order: the order of the highest derivative. Degree: its power after the equation is a polynomial in derivatives.
Q3. When is the degree not defined?
When the equation is not a polynomial in derivatives, e.g. it contains sin(dy/dx) or e^(dy/dx).
Q4. How many arbitrary constants are in the general solution?
As many as the order of the equation.
Q5. What is a particular solution?
A solution obtained by giving specific values to the arbitrary constants, using initial conditions.
Q6. State the integrating factor for dy/dx + Py = Q.
IF = e^(∫P dx).
Q7. What substitution is used for a homogeneous equation dy/dx = F(y/x)?
y = vx, so dy/dx = v + x dv/dx.
Q8. Long: Show that the IF method solves dy/dx + Py = Q.
Multiply by IF = e^(∫P dx). Since d/dx(IF) = P·IF, the left side becomes d/dx (y·IF) = IF·y′ + y·P·IF. So d/dx (y·IF) = Q·IF. Integrating: y·IF = ∫ Q·IF dx + C.
Q9. Long: Solve (x² − y²) dx + 2xy dy = 0 (homogeneous).
dy/dx = (y² − x²)/(2xy). Put y = vx: v + x v′ = (v² − 1)/(2v) ⇒ x v′ = (v² − 1 − 2v²)/(2v) = −(1 + v²)/(2v). Separate: 2v dv/(1 + v²) = −dx/x. Integrate: log(1 + v²) = −log|x| + c ⇒ x(1 + v²) = C. Put v = y/x: x + y²/x = C ⇒ x² + y² = Cx.
Q10. Long: Solve dy/dx + y cot x = 2 cos x with y(π/2) = 0.
IF = e^(∫cot x dx) = sin x. y sin x = ∫ 2 cos x sin x dx = ∫ sin 2x dx = −cos 2x/2 + C. Put x = π/2, y = 0: 0 = −(−1)/2 + C ⇒ C = −1/2. So y sin x = −cos 2x/2 − 1/2 = −(1 + cos 2x)/2 = −cos²x. Answer: y = −cos²x / sin x.
