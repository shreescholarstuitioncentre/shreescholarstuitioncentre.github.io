Chapter 5: Determinants

UP Board / NCERT – notes with animated figures, formulas, solved examples, Q&A and MCQs.

1. Determinants

1.1 Determinants of Order 1, 2 and 3

Definition: To every square matrix A a unique real number is attached, called its determinant, written |A| or det A.
Matrix vs determinant: a matrix is an array (it has no value, any order m × n); a determinant is a single number, defined only for square matrices. Brackets [ ] for matrix, vertical bars | | for determinant.
  • Order 1: A = [a] ⇒ |A| = a (not the modulus).
  • Order 2: |A| = ad − bc for A = [[a, b],[c, d]].
  • Order 3: expand along the first row: |A| = a₁₁(a₂₂a₃₃ − a₂₃a₃₂) − a₁₂(a₂₁a₃₃ − a₂₃a₃₁) + a₁₃(a₂₁a₃₂ − a₂₂a₃₁).

Order 2 determinant = product of main diagonal − product of other diagonal

1.2 Evaluation of Determinants

For order 2 use cross-multiplication as in the figure. For order 3 expand along any row or column; choose the one with the most zeros to save work. For an upper or lower triangular determinant, |A| = product of the diagonal elements. If A is of order n, then |kA| = kⁿ|A| (not k|A|).

1.3 Properties of Determinants

  1. |A| = |Aᵀ| (rows and columns can be interchanged).
  2. Interchanging two rows (or columns) changes the sign.
  3. If two rows (or columns) are identical (or proportional), |A| = 0.
  4. Multiplying every element of one row (or column) by k multiplies |A| by k. A common factor of one row can be taken out.
  5. If each element of a row is a sum of two terms, the determinant splits into a sum of two determinants.
  6. Adding a multiple of one row (column) to another does not change |A|. (Used to create zeros.)
  7. A zero row or column ⇒ |A| = 0.
  8. |AB| = |A||B| for square matrices of the same order.

1.4 Minors and Cofactors

Minor Mᵢⱼ: determinant left after deleting the i-th row and j-th column. Cofactor Cᵢⱼ = (−1)i+jMᵢⱼ.

Signs follow a chessboard: + − + / − + − / + − +. The sum of products of elements of a row with the cofactors of another row is always 0.

1.5 Expansion Along a Row or Column


Expansion along row 1: strike out the row and column of each element

|A| = a₁₁C₁₁ + a₁₂C₁₂ + a₁₃C₁₃, and the same value is obtained along any row or column: |A| = Σⱼ aᵢⱼCᵢⱼ = Σᵢ aᵢⱼCᵢⱼ.

2. Applications of Determinants

2.1 Area of a Triangle

Formula: For vertices (x₁, y₁), (x₂, y₂), (x₃, y₃): Area = ½ | det [[x₁, y₁, 1],[x₂, y₂, 1],[x₃, y₃, 1]] |.

Triangle with vertices A, B, C
  • Area is always positive, so take the absolute value.
  • Three points are collinear iff this determinant is 0.
  • Equation of the line through (x₁, y₁), (x₂, y₂): det [[x, y, 1],[x₁, y₁, 1],[x₂, y₂, 1]] = 0.

2.2 Adjoint of a Square Matrix

Definition: adj A is the transpose of the cofactor matrix [Cᵢⱼ]. So (adj A)ᵢⱼ = Cⱼᵢ.
  • A(adj A) = (adj A)A = |A| I.
  • |adj A| = |A|n−1 (n = order). For 2 × 2, adj [[a,b],[c,d]] = [[d, −b],[−c, a]] (swap diagonal, change signs of the other two).
  • adj(AB) = (adj B)(adj A); adj(Aᵀ) = (adj A)ᵀ.

2.3 Singular and Non-singular Matrices

Singular: |A| = 0. Non-singular: |A| ≠ 0. If A, B are non-singular of the same order, AB is non-singular, and |AB| = |A||B|.

2.4 Inverse Using Determinants

Theorem: A is invertible iff A is non-singular, and A⁻¹ = (1/|A|) adj A.
  • |A⁻¹| = 1/|A|. (AB)⁻¹ = B⁻¹A⁻¹.
  • Steps: (1) find |A|, if 0 stop; (2) find all cofactors; (3) transpose to get adj A; (4) divide by |A|; (5) verify AA⁻¹ = I.

3. Systems of Linear Equations

3.1 Matrix Representation

The system a₁x + b₁y + c₁z = d₁, a₂x + b₂y + c₂z = d₂, a₃x + b₃y + c₃z = d₃ is written AX = B with A = coefficient matrix, X = [x y z]ᵀ, B = [d₁ d₂ d₃]ᵀ.

3.2 Consistent and Inconsistent Systems; Number of Solutions

Consistent = at least one solution exists. Inconsistent = no solution.

Consistent, unique solution (lines meet at one point)

Inconsistent, no solution (parallel lines)

Consistent, infinitely many solutions (same line)

A system can have 0, exactly 1, or infinitely many solutions (never exactly 2).

3.3 Unique Solution

Case 1: |A| ≠ 0 ⇒ A⁻¹ exists ⇒ X = A⁻¹B: unique solution (consistent).
Case 2: |A| = 0 ⇒ find (adj A)B. If (adj A)B ≠ O ⇒ inconsistent. If (adj A)B = O ⇒ the system is consistent with infinitely many solutions or inconsistent (check further).

3.4 Solving 2- and 3-Variable Systems

Write AX = B, find |A|, then A⁻¹ = adj A/|A|, and X = A⁻¹B. Multiply row-by-column carefully and verify the answer by substitution.

4. Solved Examples

Easy Ex 1. Evaluate |[[2, 3],[4, 5]]|.
Solution: 2·5 − 3·4 = 10 − 12 = −2.
Easy Ex 2. Evaluate |[[1,2,3],[0,4,5],[0,0,6]]|.
Solution: Expand along the first column: 1·(4·6 − 5·0) − 0 + 0 = 24 (= product of the diagonal 1·4·6).
Easy Ex 3. Find minors and cofactors of A = [[1,2],[3,4]].
Solution: M₁₁ = 4, M₁₂ = 3, M₂₁ = 2, M₂₂ = 1. C₁₁ = (+)4 = 4, C₁₂ = (−)3 = −3, C₂₁ = (−)2 = −2, C₂₂ = (+)1 = 1.
Easy Ex 4. Solve 5x + 2y = 3, 3x + 2y = 5 using the inverse.
Solution: A = [[5,2],[3,2]], B = [3, 5]ᵀ. |A| = 10 − 6 = 4 ≠ 0. A⁻¹ = ¼[[2, −2],[−3, 5]]. X = A⁻¹B = ¼[2·3 − 2·5, −3·3 + 5·5]ᵀ = ¼[−4, 16]ᵀ. So x = −1, y = 4. Check: 5(−1) + 2·4 = 3 ✔; 3(−1) + 8 = 5 ✔.
Medium Ex 5. Find x if |[[x, 2],[18, x]]| = |[[6, 2],[18, 6]]|.
Solution: x² − 36 = 36 − 36 = 0 ⇒ x² = 36 ⇒ x = ±6.
Medium Ex 6. Find the area of the triangle with vertices (1, 1), (5, 2), (3, 5).
Solution: Δ = ½|det [[1,1,1],[5,2,1],[3,5,1]]|. Along row 1: 1(2·1 − 1·5) − 1(5·1 − 1·3) + 1(5·5 − 2·3) = −3 − 2 + 19 = 14. Area = ½ × 14 = 7 sq. units.
Medium Ex 7. Show that (1, 2), (2, 4), (3, 6) are collinear.
Solution: det [[1,2,1],[2,4,1],[3,6,1]] = 1(4 − 6) − 2(2 − 3) + 1(12 − 12) = −2 + 2 + 0 = 0. Area = 0 ⇒ collinear. ∎
Medium Ex 8. If A is a 3 × 3 matrix with |A| = 4, find |2A|, |adj A|, |A⁻¹|.
Solution: |2A| = 2³·4 = 32; |adj A| = |A|² = 16; |A⁻¹| = 1/|A| = 1/4.
Hard Ex 9. Prove |[[1,a,a²],[1,b,b²],[1,c,c²]]| = (a − b)(b − c)(c − a).
Proof: R₁ → R₁ − R₂ and R₂ → R₂ − R₃ give rows (0, a − b, a² − b²), (0, b − c, b² − c²), (1, c, c²).
Expand along C₁ (only the element 1 in row 3, sign +): = |[[a − b, a² − b²],[b − c, b² − c²]]|.
Take out (a − b) and (b − c): = (a − b)(b − c)|[[1, a + b],[1, b + c]]| = (a − b)(b − c)[(b + c) − (a + b)] = (a − b)(b − c)(c − a). ∎
Hard Ex 10. Find adj A and A⁻¹ for A = [[1,2,3],[0,1,4],[5,6,0]].
Solution: |A| = 1(0 − 24) − 2(0 − 20) + 3(0 − 5) = −24 + 40 − 15 = 1.
Cofactors: C₁₁ = −24, C₁₂ = 20, C₁₃ = −5; C₂₁ = 18, C₂₂ = −15, C₂₃ = 4; C₃₁ = 5, C₃₂ = −4, C₃₃ = 1.
adj A = transpose of [[−24,20,−5],[18,−15,4],[5,−4,1]] = [[−24,18,5],[20,−15,−4],[−5,4,1]].
Since |A| = 1, A⁻¹ = adj A. Check first row × first column: 1(−24) + 2(20) + 3(−5) = 1 ✔.
Hard Ex 11. Solve x + 2y + 3z = 14, y + 4z = 14, 5x + 6y = 17.
Solution: Coefficient matrix is the A of Ex 10, so A⁻¹ = [[−24,18,5],[20,−15,−4],[−5,4,1]]. X = A⁻¹[14, 14, 17]ᵀ.
x = −24·14 + 18·14 + 5·17 = −336 + 252 + 85 = 1; y = 20·14 − 15·14 − 4·17 = 280 − 210 − 68 = 2; z = −5·14 + 4·14 + 17 = −70 + 56 + 17 = 3.
x = 1, y = 2, z = 3.
Hard Ex 12. Test consistency: (i) x + y = 2, 2x + 2y = 5; (ii) x + y = 2, 2x + 2y = 4.
Solution: A = [[1,1],[2,2]], |A| = 0. adj A = [[2, −1],[−2, 1]].
(i) B = [2, 5]ᵀ: (adj A)B = [4 − 5, −4 + 5]ᵀ = [−1, 1]ᵀ ≠ O ⇒ inconsistent.
(ii) B = [2, 4]ᵀ: (adj A)B = [4 − 4, −4 + 4]ᵀ = O ⇒ consistent with infinitely many solutions (the same line x + y = 2).

5. Short & Long Q&A (tap to see answer)

Q1. Difference between a matrix and a determinant?

A matrix is a rectangular array with no numerical value; a determinant is a number associated with a square matrix.

Q2. If A is 3 × 3 and |A| = −2, find |3A|.

3³ × (−2) = −54.

Q3. What is the value of a determinant with two identical rows? Why?

0. Interchanging the identical rows leaves it unchanged but also changes its sign, so |A| = −|A| ⇒ |A| = 0.

Q4. Write adj of [[a,b],[c,d]].

[[d, −b],[−c, a]].

Q5. When is a matrix invertible?

When it is square and |A| ≠ 0 (non-singular).

Q6. Long: Prove A(adj A) = |A|I for a 2 × 2 matrix.

A = [[a,b],[c,d]], adj A = [[d,−b],[−c,a]]. A(adj A) = [[ad − bc, −ab + ba],[cd − dc, −cb + da]] = [[ad − bc, 0],[0, ad − bc]] = |A|I. ∎

Q7. Why can a system of linear equations never have exactly two solutions?

If X₁, X₂ are two solutions, then X₁ + k(X₂ − X₁) is a solution for every real k, giving infinitely many.

Q8. Find |adj A| if A is 3 × 3 and |A| = 5.

|A|n−1 = 5² = 25.

6. MCQs

1. |[[2,−1],[3,4]]| = ? (a) 5 (b) 11 (c) 8 (d) −5

(b) 8 + 3 = 11.

2. If |A| = 0, A is called: (a) singular (b) non-singular (c) identity (d) symmetric

(a) singular.

3. A(adj A) = ? (a) A (b) |A| (c) |A|I (d) I

(c) |A|I.

4. Area of the triangle with vertices (0,0), (4,0), (0,3): (a) 12 (b) 6 (c) 7 (d) 3

(b) ½ × 4 × 3 = 6.

5. If |A| ≠ 0, the system AX = B has: (a) no solution (b) infinitely many (c) unique solution (d) two solutions

(c) unique.
