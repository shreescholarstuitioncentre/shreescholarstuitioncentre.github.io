1. Introduction to Matrices

1.1 Concept and Definition

Definition: A matrix is an ordered rectangular arrangement of numbers (or functions) in rows (horizontal) and columns (vertical), enclosed in brackets [ ] or ( ). Each number is an element (entry).

Matrices store data compactly, e.g. marks of 3 students in 4 subjects, or the coefficients of a system of equations.

1.2 Notation


A 3×3 matrix A = [aᵢⱼ]: rows, columns and an element

Matrices are named by capital letters A, B, C. We write A = [aᵢⱼ]m×n, where aᵢⱼ is the element in the i-th row and j-th column (first subscript = row, second = column). Example: a₂₃ is in row 2, column 3.

1.3 Order of a Matrix

A matrix with m rows and n columns has order m × n (read “m by n”) and has mn elements. Rows are always written first. A 2 × 3 matrix has 6 elements. If entries come from a set of p numbers, the number of matrices of order m × n is pmn.

1.4 Equality of Matrices

Definition: A = [aᵢⱼ] and B = [bᵢⱼ] are equal if (i) they have the same order and (ii) aᵢⱼ = bᵢⱼ for all i, j.

2. Operations on Matrices

2.1 Addition and Subtraction

Rule: A ± B is defined only when A and B have the same order; add (or subtract) corresponding elements: (A ± B)ᵢⱼ = aᵢⱼ ± bᵢⱼ.

2.2 Multiplication by a Scalar

kA = [k·aᵢⱼ]: every element is multiplied by k. Also −A = (−1)A and A − B = A + (−B).

2.3 Properties of Matrix Addition

  • Commutative: A + B = B + A. Associative: (A + B) + C = A + (B + C).
  • Additive identity: A + O = A. Additive inverse: A + (−A) = O.
  • k(A + B) = kA + kB; (k + l)A = kA + lA; (kl)A = k(lA); 1·A = A.

2.4 Multiplication of Matrices

Rule: AB is defined only if number of columns of A = number of rows of B. If A is m × n and B is n × p, then AB is m × p, and (AB)ᵢⱼ = aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ + … + aᵢₙbₙⱼ.

Matrix multiplication, entry by entry

Think “row by column”: take the i-th row of A and the j-th column of B, multiply pairwise, add. Check orders first: (m × n)(n × p) → inner numbers must match, outer numbers give the answer.

2.5 Properties of Matrix Multiplication

  • Associative: (AB)C = A(BC). Distributive: A(B + C) = AB + AC; (A + B)C = AC + BC.
  • Identity: AI = IA = A. A·O = O.
  • k(AB) = (kA)B = A(kB).

2.6 Non-Commutativity

AB ≠ BA in general. Even if AB exists, BA may not exist (orders mismatch), or may have a different order, or the same order but different entries. Hence (A + B)² = A² + AB + BA + B² (not A² + 2AB + B²), and (AB)ᵏ ≠ AᵏBᵏ in general.

2.7 Non-zero Matrices with Zero Product

AB = O does not imply A = O or B = O. Example: A = [[1,0],[0,0]], B = [[0,0],[0,1]]; AB = O although both are non-zero. Likewise AB = AC does not imply B = C (no cancellation law).

3. Transpose of a Matrix

3.1 Transpose

Definition: Aᵀ (or A′) is obtained by interchanging rows and columns. If A is m × n, then Aᵀ is n × m and (Aᵀ)ᵢⱼ = aⱼᵢ.

Transpose: rows of A become columns of Aᵀ

3.2 Properties of Transpose

  • (Aᵀ)ᵀ = A   (A + B)ᵀ = Aᵀ + Bᵀ   (kA)ᵀ = kAᵀ
  • (AB)ᵀ = BᵀAᵀ (order reverses; also (ABC)ᵀ = CᵀBᵀAᵀ).

3.3 Symmetric Matrix

Definition: A square matrix with Aᵀ = A, i.e. aᵢⱼ = aⱼᵢ. Entries are mirror images across the main diagonal.

3.4 Skew-Symmetric Matrix

Definition: A square matrix with Aᵀ = −A, i.e. aᵢⱼ = −aⱼᵢ. Putting i = j gives 2aᵢᵢ = 0, so all diagonal elements are 0.
Theorems: (1) For any square A, A + Aᵀ is symmetric and A − Aᵀ is skew-symmetric. (2) Every square matrix is uniquely the sum of a symmetric and a skew-symmetric matrix: A = ½(A + Aᵀ) + ½(A − Aᵀ).

4. Elementary Operations and Inverse

4.1 Elementary Row Operations

Three operations (written with R): (i) Interchange Rᵢ ↔ Rⱼ; (ii) Multiply a row by non-zero k: Rᵢ → kRᵢ; (iii) Add a multiple of another row: Rᵢ → Rᵢ + kRⱼ.

4.2 Elementary Column Operations

The same three with columns: Cᵢ ↔ Cⱼ, Cᵢ → kCᵢ, Cᵢ → Cᵢ + kCⱼ.

4.3 Invertible Matrices and Inverse

Definition: A square matrix A of order n is invertible if there is a square matrix B of the same order with AB = BA = I. Then B = A⁻¹.
  • Only square matrices can be invertible; not all square matrices are (e.g. O).
  • (AB)⁻¹ = B⁻¹A⁻¹; (A⁻¹)⁻¹ = A; (Aᵀ)⁻¹ = (A⁻¹)ᵀ.

4.4 Uniqueness of Inverse

Theorem: The inverse of a square matrix, if it exists, is unique.
Proof: Let B and C both be inverses of A. Then B = BI = B(AC) = (BA)C = IC = C. ∎

4.5 Finding Inverse by Elementary Operations

Write A = IA and apply only row operations on A (left side) and on the I (pre-factor) together, until A becomes I: then I = BA and B = A⁻¹. (Or use only column operations with A = AI.) Never mix rows and columns. If a whole row of zeros appears on the left, A⁻¹ does not exist.

5. Solved Examples

Easy Ex 1. Construct a 2 × 2 matrix with aᵢⱼ = 2i − j.
Solution: a₁₁ = 2 − 1 = 1; a₁₂ = 2 − 2 = 0; a₂₁ = 4 − 1 = 3; a₂₂ = 4 − 2 = 2. So A = [[1, 0], [3, 2]].
Easy Ex 2. If [[x + y, 2], [5, 8]] = [[6, 2], [5, xy]], find x, y.
Solution: Equal matrices: x + y = 6 and xy = 8. Then x, y are roots of t² − 6t + 8 = 0 ⇒ t = 2, 4. So (x, y) = (2, 4) or (4, 2).
Easy Ex 3. A = [[1,2],[3,4]], B = [[5,6],[7,8]]. Find A + B and 2A − B.
Solution: A + B = [[6, 8], [10, 12]]. 2A = [[2,4],[6,8]], so 2A − B = [[−3, −2], [−1, 0]].
Medium Ex 4. Find AB for the A, B of Ex 3.
Solution: Orders 2×2 and 2×2 ⇒ AB is 2×2. (1,1): 1·5 + 2·7 = 19; (1,2): 1·6 + 2·8 = 22; (2,1): 3·5 + 4·7 = 43; (2,2): 3·6 + 4·8 = 50. AB = [[19, 22], [43, 50]].
Medium Ex 5. A = [[1,2],[3,4]], B = [[0,1],[1,0]]. Show AB ≠ BA.
Solution: AB = [[1·0+2·1, 1·1+2·0],[3·0+4·1, 3·1+4·0]] = [[2, 1], [4, 3]]. BA = [[0·1+1·3, 0·2+1·4],[1·1+0·3, 1·2+0·4]] = [[3, 4], [1, 2]]. Since the matrices differ, AB ≠ BA.
Medium Ex 6. If A = [[1,2],[2,1]], show A² − 2A − 3I = O.
Solution: A² = [[1+4, 2+2],[2+2, 4+1]] = [[5,4],[4,5]]. 2A = [[2,4],[4,2]], 3I = [[3,0],[0,3]]. A² − 2A − 3I = [[5−2−3, 4−4−0],[4−4−0, 5−2−3]] = O. ∎
Medium Ex 7. Express A = [[3,5],[1,−1]] as sum of a symmetric and a skew-symmetric matrix.
Solution: Aᵀ = [[3,1],[5,−1]]. P = ½(A + Aᵀ) = [[3,3],[3,−1]] (symmetric). Q = ½(A − Aᵀ) = [[0,2],[−2,0]] (skew-symmetric). Check: P + Q = [[3,5],[1,−1]] = A ✔.
Hard Ex 8. Prove (AB)ᵀ = BᵀAᵀ.
Proof: Let A be m × n and B be n × p. (AB)ᵀ is p × m. Its (i, j) entry = (AB)ⱼᵢ = Σₖ aⱼₖbₖᵢ. Also BᵀAᵀ is p × n times n × m = p × m, with (i, j) entry = Σₖ (Bᵀ)ᵢₖ(Aᵀ)ₖⱼ = Σₖ bₖᵢaⱼₖ. Both are equal for all i, j. ∎
Hard Ex 9. Find A⁻¹ for A = [[2,1],[1,1]] by elementary row operations.
Solution: Write A = IA: [[2,1],[1,1]] = [[1,0],[0,1]]A.
R₁ → R₁ − R₂: [[1,0],[1,1]] = [[1,−1],[0,1]]A.
R₂ → R₂ − R₁: [[1,0],[0,1]] = [[1,−1],[−1,2]]A.
So A⁻¹ = [[1,−1],[−1,2]]. Check: A·A⁻¹ = [[2−1, −2+2],[1−1, −1+2]] = I ✔.
Hard Ex 10. A = [[cos θ, sin θ],[−sin θ, cos θ]]. Show AAᵀ = I.
Solution: Aᵀ = [[cos θ, −sin θ],[sin θ, cos θ]]. AAᵀ = [[cos²θ + sin²θ, −cos θ sin θ + sin θ cos θ],[−sin θ cos θ + cos θ sin θ, sin²θ + cos²θ]] = [[1,0],[0,1]] = I. ∎

6. Short & Long Q&A (tap to see answer)

Q1. How many elements does a 3 × 4 matrix have?

3 × 4 = 12.

Q2. Is every identity matrix a scalar matrix? Is the converse true?

Yes, I is a scalar matrix with k = 1. The converse is false: [[4,0],[0,4]] is scalar but not identity.

Q3. When is AB defined? What is its order?

When columns of A = rows of B. For A m × n and B n × p, order of AB is m × p.

Q4. A is 2 × 3, B is 3 × 2. Do AB and BA both exist?

Yes. AB is 2 × 2 and BA is 3 × 3, so they are certainly unequal.

Q5. Why must diagonal entries of a skew-symmetric matrix be zero?

Aᵀ = −A gives aᵢᵢ = −aᵢᵢ, so 2aᵢᵢ = 0 and aᵢᵢ = 0.

Q6. Long: Show A + Aᵀ is symmetric and A − Aᵀ is skew-symmetric.

(A + Aᵀ)ᵀ = Aᵀ + (Aᵀ)ᵀ = Aᵀ + A = A + Aᵀ ⇒ symmetric. (A − Aᵀ)ᵀ = Aᵀ − A = −(A − Aᵀ) ⇒ skew-symmetric. ∎

Q7. Show that (AB)⁻¹ = B⁻¹A⁻¹.

(AB)(B⁻¹A⁻¹) = A(BB⁻¹)A⁻¹ = AIA⁻¹ = AA⁻¹ = I, and similarly (B⁻¹A⁻¹)(AB) = I. By uniqueness of the inverse, (AB)⁻¹ = B⁻¹A⁻¹. ∎

Q8. If AB = O, must A or B be O?

No. A = [[1,0],[0,0]], B = [[0,0],[0,1]] give AB = O with A ≠ O, B ≠ O.

7. MCQs

1. If A is 3 × 2 and B is 2 × 4, order of AB: (a) 3 × 4 (b) 2 × 2 (c) 4 × 3 (d) not defined

(a) 3 × 4.

2. For a skew-symmetric matrix, diagonal elements are: (a) 1 (b) 0 (c) equal (d) any

(b) 0.

3. (AB)ᵀ = ? (a) AᵀBᵀ (b) BᵀAᵀ (c) AB (d) BA

(b) BᵀAᵀ.

4. Number of 2 × 2 matrices with entries 0 or 1: (a) 4 (b) 8 (c) 16 (d) 2

(c) 2⁴ = 16.

5. Inverse of a matrix, if it exists, is: (a) not unique (b) unique (c) always I (d) always O

(b) unique.
