अध्याय 8: संयुक्त फलनों का अवकलन

उ.प्र. बोर्ड / एन.सी.ई.आर.टी. शैली के नोट्स · चरणबद्ध · एनिमेटेड चित्र

1. संयुक्त फलनों का अवकलज

संयुक्त फलन वह फलन है जिसके भीतर कोई दूसरा फलन हो: (f∘g)(x) = f(g(x))। उदाहरण: sin(x²) (बाहरी = sin, भीतरी = x²), e^(3x), log(sin x)। ऐसे फलनों का अवकलन सीधे मूल सारणी से नहीं होता, इसके लिए शृंखला नियम चाहिए।

2. शृंखला नियम (चेन रूल)

यदि y = f(u) और u = g(x): dy/dx = (dy/du) · (du/dx)
संक्षेप में: d/dx [f(g(x))] = f′(g(x)) · g′(x)  (भीतरी फलन पर बाहरी का अवकलज × भीतरी का अवकलज)।
लंबी शृंखला: y = f(u), u = g(v), v = h(x) ⇒ dy/dx = (dy/du)(du/dv)(dv/dx)।

विधि: ① बाहरी और भीतरी फलन पहचानिए। ② भीतरी को अपरिवर्तित रखकर बाहरी का अवकलन कीजिए। ③ भीतरी के अवकलज से गुणा कीजिए। ④ अधिक परतें हों तो बाहर से भीतर की ओर यही दोहराइए।

प्रमुख परिणाम: d/dx (sin f) = cos f · f′; d/dx (tan f) = sec²f · f′; d/dx (f ⁿ) = n fⁿ⁻¹ f′; d/dx (√f) = f′/(2√f)।

3. प्रतिलोम त्रिकोणमितीय फलनों के अवकलज

sin⁻¹x1/√(1−x²)(−1, 1)

sin⁻¹x की उपपत्ति: माना y = sin⁻¹x, अतः x = sin y, y ∈ (−π/2, π/2)।
x के सापेक्ष अवकलन: 1 = cos y · dy/dx।dy/dx = 1/cos y = 1/√(1 − sin²y) (यहाँ cos y > 0) = 1/√(1−x²)। ∎

सरलीकरण हेतु प्रतिस्थापन: √(1+x²) के लिए x = tan θ; √(1−x²) के लिए x = sin θ; a²+x² के लिए x = a tan θ।
उपयोगी सर्वसमिकाएँ: tan⁻¹[2x/(1−x²)] = 2tan⁻¹x; sin⁻¹[2x/(1+x²)] = 2tan⁻¹x; cos⁻¹[(1−x²)/(1+x²)] = 2tan⁻¹x।

4. अस्पष्ट (अव्यक्त) फलनों का अवकलन

जब y को सरलता से y = f(x) के रूप में न लिखा जा सके (जैसे x² + y² = 25), तो संबंध अस्पष्ट कहलाता है।

विधि: ① प्रत्येक पद का x के सापेक्ष अवकलन कीजिए; ② y को x का फलन मानिए, अतः d/dx(yⁿ) = n yⁿ⁻¹ · dy/dx और xy पर गुणन नियम लगाइए; ③ dy/dx वाले पदों को एक ओर लाकर हल कीजिए।

5. चरघातांकी फलन एवं उनके अवकलज

d/dx (eˣ) = eˣ; d/dx (aˣ) = aˣ log a; d/dx (e^f(x)) = e^f(x) · f′(x); d/dx (a^f(x)) = a^f(x) · log a · f′(x)।

6. लघुगणकीय फलन एवं उनके अवकलज

d/dx (log x) = 1/x; d/dx (loga x) = 1/(x log a); d/dx [log f(x)] = f′(x)/f(x)।
नियम: log(mn) = log m + log n; log(m/n) = log m − log n; log mⁿ = n log m।

7. लघुगणकीय अवकलन

इसका प्रयोग तब करते हैं जब फलन [f(x)]^g(x) रूप का हो, या घातों के लंबे गुणनफल/भागफल हों।

चरण: ① दोनों पक्षों का लघुगणक लीजिए। ② लघुगणक नियमों से सरल कीजिए। ③ दोनों पक्षों का x के सापेक्ष अवकलन कीजिए (बायाँ पक्ष (1/y) dy/dx देता है)। ④ y से गुणा कीजिए और y के स्थान पर मूल व्यंजक रखिए।

8. प्राचलिक रूप में दिए फलनों का अवकलन

यदि x = φ(t), y = ψ(t): dy/dx = (dy/dt) / (dx/dt), जहाँ dx/dt ≠ 0।

9. द्वितीय कोटि के अवकलज

d²y/dx² = d/dx (dy/dx), इसे y″ या f″(x) भी लिखते हैं।
प्राचलिक रूप में: d²y/dx² = [ d/dt (dy/dx) ] / (dx/dt)।

10. रोले की प्रमेय

यदि f (i) [a, b] में संतत, (ii) (a, b) में अवकलनीय तथा (iii) f(a) = f(b) हो, तो (a, b) में कम से कम एक बिंदु c ऐसा है कि f′(c) = 0।

तीनों शर्तें आवश्यक हैं। असफलता का उदाहरण: [−1, 1] पर f(x) = |x|, जो 0 पर अवकलनीय नहीं है और f′ कभी 0 नहीं होता।

चित्र 1: गतिमान लाल स्पर्श रेखा x = c पर क्षैतिज (प्रवणता 0) हो जाती है।

11. लैग्रांज की मध्यमान प्रमेय (LMVT)

यदि f, [a, b] में संतत तथा (a, b) में अवकलनीय है, तो (a, b) में कोई c ऐसा है कि
f′(c) = [ f(b) − f(a) ] / (b − a)।

उपपत्ति (रोले की प्रमेय से)। परिभाषित कीजिए φ(x) = f(x) − f(a) − [ (f(b) − f(a))/(b − a) ] (x − a)।
φ, [a, b] में संतत और (a, b) में अवकलनीय है।φ(a) = 0 तथा φ(b) = f(b) − f(a) − (f(b) − f(a)) = 0।रोले की प्रमेय से ∃ c: φ′(c) = 0 ⇒ f′(c) − (f(b) − f(a))/(b − a) = 0। ∎

12. रोले एवं लैग्रांज प्रमेयों की ज्यामितीय व्याख्या

रोले: यदि किसी चिकने वक्र के सिरे समान ऊँचाई पर हों, तो कम से कम एक बिंदु पर क्षैतिज स्पर्श रेखा होती है। LMVT: वक्र के किसी बिंदु पर स्पर्श रेखा जीवा AB के समांतर होती है (जीवा की प्रवणता = (f(b) − f(a))/(b − a))।

चित्र 2: जीवा के समांतर रेखा ऊपर खिसककर वक्र को C पर छूती है: f′(c) = AB की प्रवणता।

हल सहित उदाहरण (चरण-दर-चरण)

सरल उदा. 1. sin(x²) का अवकलन कीजिए।
बाहरी = sin u, भीतरी u = x²। dy/dx = cos(x²) · 2x = 2x cos x²।
सरल उदा. 2. log(sec x) का अवकलन कीजिए।
dy/dx = (1/sec x) · sec x tan x = tan x।
सरल उदा. 3. यदि x² + y² = 25, तो dy/dx ज्ञात कीजिए।
2x + 2y dy/dx = 0 ⇒ dy/dx = −x/y।
सरल उदा. 4. यदि x = a cos θ, y = a sin θ, तो dy/dx ज्ञात कीजिए।
dx/dθ = −a sin θ, dy/dθ = a cos θ। dy/dx = −cot θ।
मध्यम उदा. 5. y = xˣ का अवकलन कीजिए।
log y = x log x।(1/y) y′ = log x + 1।y′ = xˣ (1 + log x)।
मध्यम उदा. 6. यदि x³ + y³ = 3axy, तो dy/dx ज्ञात कीजिए।
3x² + 3y² y′ = 3a(y + x y′)।y′(y² − ax) = ay − x²।y′ = (ay − x²)/(y² − ax)।
मध्यम उदा. 7. tan⁻¹[(√(1+x²) − 1)/x] का अवकलन कीजिए।
x = tan θ रखने पर: (sec θ − 1)/tan θ = (1 − cos θ)/sin θ = tan(θ/2)।अतः y = θ/2 = ½ tan⁻¹x। dy/dx = 1/[2(1+x²)]।
मध्यम उदा. 8. यदि y = a sin x + b cos x, तो सिद्ध कीजिए y″ + y = 0।
y′ = a cos x − b sin x; y″ = −a sin x − b cos x = −y। अतः y″ + y = 0। ∎
कठिन उदा. 9. y = x^(sin x) + (sin x)^x का अवकलन कीजिए।
माना u = x^(sin x): log u = sin x log x ⇒ u′ = x^(sin x) [ sin x/x + cos x log x ]।माना v = (sin x)^x: log v = x log sin x ⇒ v′ = (sin x)^x [ log sin x + x cot x ]।y′ = u′ + v′।
कठिन उदा. 10. यदि x = a(θ − sin θ), y = a(1 − cos θ), तो d²y/dx² ज्ञात कीजिए।
dy/dx = a sin θ / [a(1 − cos θ)] = cot(θ/2)।d/dθ (dy/dx) = −½ cosec²(θ/2); dx/dθ = a(1 − cos θ) = 2a sin²(θ/2)।d²y/dx² = −½ cosec²(θ/2) / [2a sin²(θ/2)] = −1 / [4a sin⁴(θ/2)]।
मध्यम उदा. 11. [1, 3] पर f(x) = x² − 4x + 3 के लिए रोले की प्रमेय सत्यापित कीजिए।
बहुपद होने से संतत और अवकलनीय। f(1) = 0 = f(3)।f′(x) = 2x − 4 = 0 ⇒ c = 2 ∈ (1, 3)। सत्यापित।
कठिन उदा. 12. [0, ½] पर f(x) = x(x−1)(x−2) के लिए LMVT सत्यापित कीजिए।
f(0) = 0; f(½) = ½ · (−½) · (−3/2) = 3/8। जीवा की प्रवणता = (3/8)/(1/2) = 3/4।f′(x) = 3x² − 6x + 2 = 3/4 ⇒ 12x² − 24x + 5 = 0 ⇒ x = (6 ± √21)/6।c = 1 − √21/6 ≈ 0.236 ∈ (0, ½)। सत्यापित।

दीर्घ उत्तरीय प्रश्न

प्र.7. सिद्ध कीजिए d/dx (tan⁻¹x) = 1/(1+x²)।y = tan⁻¹x ⇒ x = tan y ⇒ 1 = sec²y · y′ ⇒ y′ = 1/(1 + tan²y) = 1/(1 + x²)।
प्र.8. रोले की प्रमेय से LMVT सिद्ध कीजिए।खंड 11 की उपपत्ति देखिए।
