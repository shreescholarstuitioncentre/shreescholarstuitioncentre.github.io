कक्षा 12 गणित — अध्याय 24: प्रायिकता और बंटन

1. सप्रतिबंध प्रायिकता

P(A|B) = P(A∩B) / P(B), P(B) ≠ 0

यह घटना B के घट चुकने पर घटना A की प्रायिकता है। प्रतिदर्श समष्टि घटकर B रह जाती है।

2. गुणन प्रमेय और स्वतंत्र घटनाएँ

P(A∩B) = P(A)·P(B|A) = P(B)·P(A|B)
स्वतंत्र: P(A∩B) = P(A)·P(B) और P(A|B) = P(A)

घटनाएँ स्वतंत्र होती हैं जब एक का दूसरी पर प्रभाव न पड़े। यदि A, B स्वतंत्र हों तो A और B′, A′ और B, A′ और B′ भी स्वतंत्र होती हैं।

3. संपूर्ण प्रायिकता प्रमेय

P(A) = P(E₁)P(A|E₁) + P(E₂)P(A|E₂) + … + P(Eₙ)P(A|Eₙ)

E₁…Eₙ परस्पर अपवर्जी और निःशेष घटनाएँ हैं (प्रतिदर्श समष्टि का विभाजन)।

4. बेज़ प्रमेय

P(Eᵢ|A) = P(Eᵢ)P(A|Eᵢ) / Σ P(Eⱼ)P(A|Eⱼ)

परिणाम A देखने के बाद कारण Eᵢ की प्रायिकता ज्ञात करने के लिए इसका उपयोग होता है।

5. यादृच्छिक चर और प्रायिकता बंटन

X: x₁ x₂ … xₙ ; P(X): p₁ p₂ … pₙ जहाँ प्रत्येक pᵢ ≥ 0 और Σpᵢ = 1

यादृच्छिक चर प्रतिदर्श समष्टि पर परिभाषित वास्तविक मान वाला फलन है। असतत यादृच्छिक चर गणनीय मान लेता है। मानों और उनकी प्रायिकताओं की सारणी उसका प्रायिकता बंटन है।

6. माध्य, प्रसरण और मानक विचलन

माध्य E(X) = μ = Σ xᵢpᵢ
प्रसरण Var(X) = Σ xᵢ²pᵢ − μ²
मानक विचलन = √Var(X)

7. बरनौली परीक्षण

शर्तें: n परिमित; परीक्षण स्वतंत्र; दो परिणाम (सफलता, असफलता); p अचर, q = 1−p

उदाहरण: सिक्के को n बार उछालना, चित आना सफलता।

8. द्विपद बंटन

P(X = r) = ⁿCᵣ pʳ q ⁿ⁻ʳ, r = 0, 1, …, n
माध्य = np; प्रसरण = npq; मानक विचलन = √(npq)

हल किए गए उदाहरण (दिया है / ज्ञात करें / सिद्ध करें / हल)

उदाहरण 1 (सरल)। एक पासा फेंका गया। A = सम संख्या, B = संख्या ≥ 4। P(A|B) ज्ञात कीजिए।
A∩B = {4, 6} ⇒ P(A∩B) = 2/6; P(B) = 3/6।
P(A|B) = (2/6)/(3/6) = 2/3।
उदाहरण 2 (सरल)। बिना प्रतिस्थापन दो पत्ते निकाले गए। दोनों इक्के होने की प्रायिकता ज्ञात कीजिए।
P = (4/52)(3/51) = 12/2652 = 1/221।
उदाहरण 3 (सरल)। A, B स्वतंत्र हैं, P(A) = 1/2, P(B) = 1/3। P(A∩B) और P(A∪B) ज्ञात कीजिए।
P(A∩B) = 1/6।
P(A∪B) = 1/2 + 1/3 − 1/6 = 2/3।
उदाहरण 4 (मध्यम)। थैला I में 3 लाल, 4 काली; थैला II में 5 लाल, 6 काली गेंदें हैं। यादृच्छिक थैला चुनकर एक गेंद निकाली गई। लाल गेंद की प्रायिकता ज्ञात कीजिए।
P(लाल) = ½·(3/7) + ½·(5/11) = 3/14 + 5/22 = 33/154 + 35/154 = 68/154 = 34/77।
उदाहरण 5 (मध्यम, बेज़)। उदाहरण 4 में गेंद लाल निकली। उसके थैला I से होने की प्रायिकता ज्ञात कीजिए।
P(I|लाल) = (½·3/7) / (34/77) = (33/154)/(68/154) = 33/68।
उदाहरण 6 (मध्यम)। दो सिक्के उछाले गए, X = चित की संख्या। बंटन, माध्य और प्रसरण ज्ञात कीजिए।
X = 0, 1, 2 के लिए P = 1/4, 1/2, 1/4।
माध्य = 0 + 1/2 + 2/4 = 1। E(X²) = 0 + 1/2 + 4/4 = 3/2।
Var = 3/2 − 1 = 1/2; SD = 1/√2।
उदाहरण 7 (कठिन)। X के मान 0, 1, 2, 3 हैं और P = k, 2k, 3k, 4k। k, माध्य और प्रसरण ज्ञात कीजिए।
10k = 1 ⇒ k = 1/10।
माध्य = (0 + 2 + 6 + 12)/10 = 2।
E(X²) = (0 + 2 + 12 + 36)/10 = 5। Var = 5 − 4 = 1।
उदाहरण 8 (मध्यम)। एक सिक्का 6 बार उछाला गया। ठीक 4 चित आने की प्रायिकता ज्ञात कीजिए।
P = ⁶C₄ (½)⁶ = 15/64।
उदाहरण 9 (मध्यम)। पासा 4 बार फेंका गया। कम से कम एक छक्का आने की प्रायिकता ज्ञात कीजिए।
P = 1 − (5/6)⁴ = 1 − 625/1296 = 671/1296।
उदाहरण 10 (मध्यम)। n = 10, p = 0.3 वाले द्विपद बंटन का माध्य, प्रसरण और मानक विचलन।
माध्य = np = 3; Var = npq = 10(0.3)(0.7) = 2.1; SD = √2.1।
उदाहरण 11 (सिद्ध कीजिए)। यदि A और B स्वतंत्र हैं तो A और B′ स्वतंत्र हैं।
P(A∩B′) = P(A) − P(A∩B) = P(A) − P(A)P(B) = P(A)(1 − P(B)) = P(A)P(B′) ∎

लघु एवं दीर्घ प्रश्न

प्र.1 सप्रतिबंध प्रायिकता की परिभाषा दीजिए।
P(A|B) = P(A∩B)/P(B), B के घटित होने पर A की प्रायिकता।
प्र.2 स्वतंत्रता की शर्त?
P(A∩B) = P(A)P(B)।
प्र.3 संपूर्ण प्रायिकता प्रमेय लिखिए।
विभाजन E₁…Eₙ के लिए P(A) = ΣP(Eᵢ)P(A|Eᵢ)।
प्र.4 बेज़ प्रमेय लिखिए।
P(Eᵢ|A) = P(Eᵢ)P(A|Eᵢ) / ΣP(Eⱼ)P(A|Eⱼ)।
प्र.5 प्रायिकता बंटन में प्रायिकताओं का योग?
1।
प्र.6 प्रसरण का सूत्र?
Σx²p − (Σxp)²।
प्र.7 बरनौली परीक्षण क्या हैं?
स्वतंत्र परीक्षण जिनके दो परिणाम हों और सफलता की प्रायिकता अचर हो।
प्र.8 द्विपद बंटन का माध्य और प्रसरण?
np और npq।
