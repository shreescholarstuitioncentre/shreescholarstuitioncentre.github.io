Class 12 Maths — Chapter 21: Scalar Triple Product

1. Scalar Triple Product: Definition

[a b c] = a · (b × c)

First take the cross product b×c (a vector), then dot it with a. The result is a scalar. It is also written (a×b)·c, because a·(b×c) = (a×b)·c.

2. Component Form and Determinant

[a b c] = | a₁ a₂ a₃ ; b₁ b₂ b₃ ; c₁ c₂ c₃ |
= a₁(b₂c₃−b₃c₂) − a₂(b₁c₃−b₃c₁) + a₃(b₁c₂−b₂c₁)

Write the components of a, b, c as rows (in that order), then expand along the first row. Remember the sign pattern + − +.

3. Properties

Cyclic: [a b c] = [b c a] = [c a b]
Swapping two vectors changes the sign: [a c b] = −[a b c]
[a a b] = 0 (two equal vectors)
[λa b c] = λ[a b c]; [a+d b c] = [a b c]+[d b c]
[i j k] = 1

4. Coplanarity of Three Vectors

a, b, c are coplanar ⇔ [a b c] = 0

If the vectors lie in one plane, b×c is perpendicular to that plane, so a·(b×c) = 0.

5. Volume of a Parallelepiped

V = |[a b c]| = |a·(b×c)|

Base area = |b×c|; height = projection of a on b×c. So volume = base × height.

6. Volume of a Tetrahedron

V = ⅙ |[AB AC AD]|

A tetrahedron is one-sixth of the parallelepiped on the same three edges.

Solved Examples (Given / To Find / To Prove / Solution)

Ex 1 (Easy). Find [a b c] for a = 2i+j−k, b = i+3j+2k, c = i+2k.
Rows (2,1,−1), (1,3,2), (1,0,2).
= 2(6−0) − 1(2−2) + (−1)(0−3) = 12 − 0 + 3 = 15.
Ex 2 (Easy). Show [i j k] = 1 and [i k j] = −1.
[i j k] = i·(j×k) = i·i = 1.
[i k j] = i·(k×j) = i·(−i) = −1.
Ex 3 (Medium). Are a = 2i+j−k, b = i+3j+2k, c = j+k coplanar?
Rows (2,1,−1),(1,3,2),(0,1,1).
= 2(3−2) − 1(1−0) + (−1)(1−0) = 2−1−1 = 0 ⇒ coplanar.
Ex 4 (Medium). Find λ if 2i−j+k, i+2j−3k, 3i+λj+5k are coplanar.
Determinant = 2(10+3λ) + 1(5+9) + 1(λ−6) = 28+7λ.
Set = 0 ⇒ λ = −4.
Ex 5 (Medium). Volume of the parallelepiped with edges 2i−3j+4k, i+2j−k, 3i−j+2k.
[a b c] = 2(4−1) + 3(2+3) + 4(−1−6) = 6+15−28 = −7.
V = |−7| = 7 cubic units.
Ex 6 (Hard). Volume of tetrahedron with A(1,1,1), B(3,1,1), C(1,4,1), D(1,1,6).
AB = 2i, AC = 3j, AD = 5k. [AB AC AD] = 2·3·5 = 30.
V = 30/6 = 5 cubic units.
Ex 7 (Proof). Prove [a a c] = 0.
a×c is perpendicular to a, so a·(a×c) = 0 ∎
Ex 8 (Proof, Hard). Prove [a+b b+c c+a] = 2[a b c].
(b+c)×(c+a) = b×c + b×a + c×a.
Dot with (a+b): a·(b×c) = [abc]; a·(b×a) = 0; a·(c×a) = 0; b·(b×c) = 0; b·(b×a) = 0; b·(c×a) = [bca] = [abc].
Sum = 2[a b c] ∎

Short & Long Questions

Q1. Define scalar triple product.
[a b c] = a·(b×c), a scalar.
Q2. Value of [i j k]?
1.
Q3. Condition for three vectors to be coplanar?
[a b c] = 0.
Q4. What happens when two vectors are swapped?
The sign of [a b c] changes.
Q5. Volume of a parallelepiped?
|[a b c]|.
Q6. Volume of a tetrahedron?
⅙|[AB AC AD]|.
Q7. Value of [a a b]?
0.
Q8. Is a·(b×c) equal to (a×b)·c?
Yes, the dot and cross can be interchanged.
