Class 12 Maths — Chapter 20: Product of Vector Quantities

1. Dot Product: Definition

a·b = |a||b| cosθ, 0 ≤ θ ≤ π

The result is a scalar. θ is the angle between a and b when drawn tail to tail. If either vector is zero, a·b = 0.

2. Dot Product: Components and Properties

a·b = a₁b₁ + a₂b₂ + a₃b₃
i·i = j·j = k·k = 1; i·j = j·k = k·i = 0

Properties: a·b = b·a; a·(b+c) = a·b + a·c; (λa)·b = λ(a·b); a·a = |a|²; |a+b|² = |a|² + 2a·b + |b|²; |a·b| ≤ |a||b|.

3. Angle and Perpendicular Vectors

cosθ = a·b / (|a||b|)
a ⊥ b ⇔ a·b = 0 (a, b non-zero)

4. Projection and Work Done

Projection of a on b = a·b / |b|
Vector projection = (a·b/|b|²) b
Work done W = F·d

Projection is the length of the shadow of a on the line of b. Work is force times displacement along the force.

5. Cross Product: Definition

a × b = |a||b| sinθ n̂

The result is a vector perpendicular to both a and b; n̂ follows the right-hand rule. a×b = 0 if a ∥ b.

6. Cross Product: Components

a × b = | i j k ; a₁ a₂ a₃ ; b₁ b₂ b₃ | (determinant)
i×j = k, j×k = i, k×i = j

7. Properties of Cross Product

a×b = −(b×a) (not commutative)
a×(b+c) = a×b + a×c; a×a = 0
|a×b|² + (a·b)² = |a|²|b|²

8. Parallel and Collinear Vectors

a ∥ b ⇔ a × b = 0 ⇔ a₁/b₁ = a₂/b₂ = a₃/b₃

Points A, B, C are collinear if AB × AC = 0.

9. Area of Parallelogram and Triangle

Parallelogram with adjacent sides a, b: Area = |a×b|
Diagonals d₁, d₂: Area = ½|d₁×d₂|
Triangle ABC: Area = ½|AB×AC|

Solved Examples (Given / To Find / To Prove / Solution)

Ex 1 (Easy). Find a·b for a = 2i+3j−k, b = i−j+2k.
a·b = (2)(1)+(3)(−1)+(−1)(2) = 2−3−2 = −3.
Ex 2 (Easy). Angle between a = i+j and b = j+k.
a·b = 1; |a| = |b| = √2.
cosθ = 1/2 ⇒ θ = 60°.
Ex 3 (Medium). Find λ if a = 2i+λj+k and b = i−2j+3k are perpendicular.
a·b = 0 ⇒ 2 − 2λ + 3 = 0 ⇒ λ = 5/2.
Ex 4 (Medium). Projection of a = 2i+3j+2k on b = i+2j+k.
a·b = 2+6+2 = 10; |b| = √6.
Projection = 10/√6 = 5√6/3.
Ex 5 (Medium). Work done by F = 3i+2j−4k moving a particle from (1,2,3) to (5,4,1).
d = 4i+2j−2k. W = F·d = 12+4+8 = 24 units.
Ex 6 (Medium). Find a×b for a = i+2j+3k, b = 3i−j+2k.
a×b = i(4+3) − j(2−9) + k(−1−6) = 7i+7j−7k.
|a×b| = 7√3.
Ex 7 (Hard). Area of parallelogram with sides a = 3i+j+4k, b = i−j+k.
a×b = i(1+4) − j(3−4) + k(−3−1) = 5i+j−4k.
Area = √(25+1+16) = √42.
Ex 8 (Hard). Area of triangle A(1,1,1), B(1,2,3), C(2,3,1).
AB = j+2k; AC = i+2j.
AB×AC = −4i+2j−k; magnitude = √21.
Area = √21/2.
Ex 9 (Proof). Prove |a×b|² + (a·b)² = |a|²|b|².
LHS = |a|²|b|²sin²θ + |a|²|b|²cos²θ = |a|²|b|²(sin²θ+cos²θ) = |a|²|b|² ∎
Ex 10 (Proof). If |a+b| = |a−b|, prove a ⊥ b.
Squaring: |a|²+2a·b+|b|² = |a|²−2a·b+|b|².
4a·b = 0 ⇒ a·b = 0 ⇒ a ⊥ b ∎

Short & Long Questions

Q1. Define dot product.
a·b = |a||b|cosθ, a scalar.
Q2. Value of i·j?
0, since they are perpendicular.
Q3. When is a·b = 0?
When a ⊥ b, or either is a zero vector.
Q4. Is the cross product commutative?
No. a×b = −(b×a).
Q5. Value of i×j?
k.
Q6. Condition for parallel vectors?
a×b = 0.
Q7. Area of a parallelogram?
|a×b| for adjacent sides a and b.
Q8. Formula for area of a triangle?
½|AB×AC|.

MCQs

MCQ 1. i·i = ?
(a) 0 (b) 1 (c) k (d) −1 — Ans: (b) 1
MCQ 2. i×j = ?
(a) 0 (b) 1 (c) k (d) −k — Ans: (c) k
MCQ 3. If a·b = 0, vectors are:
(a) parallel (b) perpendicular (c) equal (d) unit — Ans: (b)
MCQ 4. |a×b| = 0 means:
(a) a ⊥ b (b) a ∥ b (c) a = b only (d) none — Ans: (b)
MCQ 5. Angle between i and j?
(a) 0° (b) 45° (c) 90° (d) 180° — Ans: (c) 90°
