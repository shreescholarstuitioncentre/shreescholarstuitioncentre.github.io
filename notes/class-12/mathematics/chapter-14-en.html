Integration by Parts – Class 12 Maths Notes

Unit 3: Calculus · Chapter 14 · UP Board

1. Integration by Parts Formula

It is the reverse of the product rule. Since d(uv)/dx = u·dv/dx + v·du/dx, integrating gives uv = ∫u (dv/dx) dx + ∫v (du/dx) dx. Rearranging:

∫ u·v dx = u ∫ v dx − ∫ [ (du/dx) ∫ v dx ] dx

In words: integral of (first × second) = first × integral of second − integral of (derivative of first × integral of second). Use it when the integrand is a product of two different kinds of functions that no substitution can solve.

2. Selection of First and Second Functions

A wrong choice makes the integral harder. Use the ILATE rule: I – Inverse trigonometric, L – Logarithmic, A – Algebraic, T – Trigonometric, E – Exponential. The function that comes earlier is taken as the first function u; the other is v. Reason: functions at the start become simpler on differentiation (log x → 1/x, tan⁻¹x → 1/(1+x²), xⁿ → nxⁿ⁻¹), and those at the end (e, sin, cos) are easy to integrate.

Note: when only one function is visible (∫ log x dx, ∫ tan⁻¹x dx), write the integrand as log x · 1 and take 1 as the second function.

3. Integration of Products of Functions

Steps: (1) pick u by ILATE; (2) write v; (3) find du/dx and ∫v dx (no constant needed at this stage); (4) apply the formula; (5) integrate the remaining integral; (6) add C at the end. The remaining integral must be simpler than the original; if not, swap the functions.

4. Algebraic and Trigonometric Products

∫ x sin x dx = −x cos x + sin x + C
∫ x cos x dx = x sin x + cos x + C

Here x (algebraic) comes before sin x or cos x in ILATE, so u = x. ∫ x sec²x dx = x tan x − log|sec x| + C.

5. Algebraic and Exponential Products

∫ x eˣ dx = eˣ (x − 1) + C
∫ x e^(ax) dx = e^(ax) (x/a − 1/a²) + C
∫ eˣ [f(x) + f′(x)] dx = eˣ f(x) + C
∫ e^(ax) sin bx dx = e^(ax)(a sin bx − b cos bx)/(a²+b²) + C
∫ e^(ax) cos bx dx = e^(ax)(a cos bx + b sin bx)/(a²+b²) + C

The last two are cyclic integrals: after applying parts twice the original integral reappears; move it to the left side and solve.

6. Algebraic and Logarithmic Products

∫ log x dx = x log x − x + C
∫ x log x dx = (x²/2) log x − x²/4 + C
∫ xⁿ log x dx = xⁿ⁺¹/(n+1) · log x − xⁿ⁺¹/(n+1)² + C
∫ tan⁻¹x dx = x tan⁻¹x − ½ log(1+x²) + C
∫ sin⁻¹x dx = x sin⁻¹x + √(1−x²) + C

7. Repeated Integration by Parts

When u is xⁿ with n ≥ 2, apply the formula n times; each application lowers the power by one. The tabular (DI) method in Diagram 2 does this quickly: differentiate u until zero, integrate v the same number of times, and multiply diagonally with alternating signs. Use it only when one function is a polynomial.

8. Definite Problems Based on Integration by Parts

∫ₐᵇ u v dx = [ u ∫v dx ]ₐᵇ − ∫ₐᵇ [ (du/dx) ∫v dx ] dx

Evaluate the uv-term with limits first, then integrate the rest with the same limits. No constant C appears in a definite integral.

Solved Examples (step by step)

1. Find ∫ x sin x dx
ILATE: x is algebraic, sin x is trigonometric, so u = x, v = sin x. ∫v dx = −cos x, du/dx = 1. Formula: x(−cos x) − ∫ 1·(−cos x) dx = −x cos x + sin x. Answer: −x cos x + sin x + C.
2. Find ∫ x cos x dx
u = x, v = cos x. ∫v dx = sin x. = x sin x − ∫ sin x dx = x sin x + cos x + C.
3. Find ∫ x eˣ dx
u = x, v = eˣ. = x eˣ − ∫ eˣ dx = x eˣ − eˣ. Answer: eˣ(x − 1) + C.
4. Find ∫ x log x dx
L before A, so u = log x, v = x. ∫v dx = x²/2, du/dx = 1/x. = (x²/2) log x − ∫ (1/x)(x²/2) dx = (x²/2) log x − ∫ x/2 dx. Answer: (x²/2) log x − x²/4 + C.
5. Find ∫ log x dx
Write as log x · 1. u = log x, v = 1. = x log x − ∫ (1/x)·x dx = x log x − ∫ 1 dx. Answer: x log x − x + C.
6. Find ∫ x² eˣ dx
u = x², v = eˣ. = x²eˣ − ∫ 2x eˣ dx = x²eˣ − 2∫ x eˣ dx. Using Example 3: ∫ x eˣ dx = eˣ(x−1). = x²eˣ − 2eˣ(x−1). Answer: eˣ(x² − 2x + 2) + C.
7. Find ∫ x² sin x dx
u = x², v = sin x. = −x² cos x + ∫ 2x cos x dx = −x² cos x + 2(x sin x + cos x) (Example 2). Answer: −x² cos x + 2x sin x + 2 cos x + C.
8. Find ∫ tan⁻¹x dx
Write as tan⁻¹x · 1. u = tan⁻¹x, v = 1. = x tan⁻¹x − ∫ x/(1+x²) dx. For the last integral put t = 1+x², x dx = dt/2: = ½ log(1+x²). Answer: x tan⁻¹x − ½ log(1+x²) + C.
9. Find ∫ sin⁻¹x dx
u = sin⁻¹x, v = 1. = x sin⁻¹x − ∫ x/√(1−x²) dx. Put t = 1−x², x dx = −dt/2: ∫ = −½ ∫ t^(−½) dt = −√t = −√(1−x²). Answer: x sin⁻¹x + √(1−x²) + C.
10. Find ∫ eˣ sin x dx
Let I = ∫ eˣ sin x dx. Take u = sin x, v = eˣ: I = eˣ sin x − ∫ eˣ cos x dx. Again by parts: ∫ eˣ cos x dx = eˣ cos x + ∫ eˣ sin x dx = eˣ cos x + I. So I = eˣ sin x − eˣ cos x − I ⇒ 2I = eˣ(sin x − cos x). Answer: I = eˣ(sin x − cos x)/2 + C.
11. Find ∫ eˣ (1/x − 1/x²) dx
Let f(x) = 1/x, so f′(x) = −1/x². The integrand is eˣ[f + f′]. Hence eˣ/x + C.
12. Find ∫ eˣ (sin x + cos x) dx
f = sin x, f′ = cos x. So integral = eˣ sin x + C.
13. Find ∫ x sec²x dx
u = x, v = sec²x. ∫v dx = tan x. = x tan x − ∫ tan x dx = x tan x − log|sec x| + C.
14. Find ∫ x² log x dx
u = log x, v = x². = (x³/3) log x − ∫ (1/x)(x³/3) dx = (x³/3) log x − ∫ x²/3 dx. Answer: (x³/3) log x − x³/9 + C.
15. Evaluate ∫₀¹ x eˣ dx
Indefinite: eˣ(x−1). Apply limits: [eˣ(x−1)]₀¹ = e·0 − e⁰(−1) = 0 + 1. Answer: 1.
16. Evaluate ∫₁ᵉ log x dx
Antiderivative x log x − x. At e: e·1 − e = 0. At 1: 1·0 − 1 = −1. Value = 0 − (−1) = 1.
17. Evaluate ∫₀^(π/2) x sin x dx
Antiderivative: −x cos x + sin x. At π/2: −(π/2)(0) + 1 = 1. At 0: 0 + 0 = 0. Value = 1.
18. Verify: ∫ x eˣ dx = eˣ(x − 1) + C
d/dx [eˣ(x−1)] = eˣ(x−1) + eˣ·1 = eˣ·x = x eˣ ✓. Verified.

Short & Long Q&A (tap to open)

Q1. State the formula for integration by parts.
∫ u v dx = u ∫v dx − ∫ [ (du/dx) ∫v dx ] dx.
Q2. What is ILATE?
A rule for choosing the first function: Inverse trig, Logarithmic, Algebraic, Trigonometric, Exponential; the earlier one is u.
Q3. Why is the constant not added while finding ∫v dx?
It is only a helper step; the final C is added at the end. An extra constant there would only cancel out.
Q4. How do we integrate ∫ log x dx?
Treat it as log x · 1 and apply parts: x log x − x + C.
Q5. When should integration by parts not be used?
When a simple substitution works, e.g. ∫ x eˣ² dx (put t = x²), or when the remaining integral gets harder.
Q6. What is a cyclic integral?
One where applying parts twice brings back the original integral, e.g. ∫ eˣ sin x dx; solve like an equation in I.
Q7. State the shortcut ∫ eˣ[f(x)+f′(x)] dx.
= eˣ f(x) + C.
Q8. Long: Derive the integration by parts formula.
Let u and v be differentiable. Product rule: d(uv)/dx = u (dv/dx) + v (du/dx). Integrate: uv = ∫ u (dv/dx) dx + ∫ v (du/dx) dx. Put w = dv/dx so v = ∫w dx. Then ∫ u w dx = u ∫ w dx − ∫ (du/dx)(∫ w dx) dx. Replacing w by v gives the formula.
Q9. Long: Evaluate ∫ x² e^(2x) dx.
u = x², v = e^(2x). ∫v dx = e^(2x)/2. = x² e^(2x)/2 − ∫ x e^(2x) dx. Again: ∫ x e^(2x) dx = x e^(2x)/2 − e^(2x)/4. So result = x² e^(2x)/2 − x e^(2x)/2 + e^(2x)/4 + C = e^(2x)(2x² − 2x + 1)/4 + C. Check by differentiating: e^(2x)[(2x²−2x+1)/2 + (4x−2)/4] = e^(2x)(x²) ✓.
Q10. Long: Prove ∫ x tan⁻¹x dx = ((x²+1)/2) tan⁻¹x − x/2 + C.
u = tan⁻¹x, v = x. = (x²/2) tan⁻¹x − ∫ x²/(2(1+x²)) dx. Now x²/(1+x²) = 1 − 1/(1+x²). So ∫ = ½(x − tan⁻¹x). Result = (x²/2) tan⁻¹x − x/2 + ½ tan⁻¹x = ((x²+1)/2) tan⁻¹x − x/2 + C.
