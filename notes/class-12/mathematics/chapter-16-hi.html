निश्चित समाकल – कक्षा 12 गणित नोट्स

इकाई 3: कलन · अध्याय 16 · यू.पी. बोर्ड

1. निश्चित समाकल

यदि F′(x) = f(x) हो, तो f का a से b तक निश्चित समाकल एक संख्या है:

∫ₐᵇ f(x) dx = [F(x)]ₐᵇ = F(b) − F(a)

a = निम्न सीमा, b = उच्च सीमा। इसमें अचर C नहीं लगता (F(b) − F(a) में कट जाता है) और उत्तर एक संख्या होता है। ज्यामितीय रूप से यह वक्र, x-अक्ष तथा रेखाओं x = a, x = b के बीच का चिह्नित क्षेत्रफल है: अक्ष के ऊपर का क्षेत्रफल धनात्मक, नीचे का ऋणात्मक गिना जाता है। चर एक मूक चर है: ∫ₐᵇ f(x) dx = ∫ₐᵇ f(t) dt।

2. योग की सीमा के रूप में निश्चित समाकल

[a, b] को n बराबर भागों में बाँटें, प्रत्येक की चौड़ाई h = (b − a)/n। तब

∫ₐᵇ f(x) dx = lim (n→∞) h [ f(a+h) + f(a+2h) + … + f(a+nh) ] = lim h Σ f(a+rh) (r = 1 से n)

उपयोगी योग: Σr = n(n+1)/2; Σr² = n(n+1)(2n+1)/6; Σr³ = [n(n+1)/2]²; गुणोत्तर: a + ar + … + arⁿ⁻¹ = a(rⁿ − 1)/(r − 1)। विधि: h लिखें, f(a+rh) ज्ञात करें, सूत्रों से योग करें, फिर n → ∞ लें (तब h → 0 और 1/n → 0)।

3. कलन का मूलभूत प्रमेय

प्रथम प्रमेय: यदि A(x) = ∫ₐˣ f(t) dt, तो A′(x) = f(x)।
द्वितीय प्रमेय: यदि F′ = f, तो ∫ₐᵇ f(x) dx = F(b) − F(a)।
शृंखला रूप: d/dx ∫ₐ^{g(x)} f(t) dt = f(g(x))·g′(x)।

प्रथम प्रमेय बताता है कि समाकलन और अवकलन एक-दूसरे को निरस्त करते हैं; द्वितीय प्रमेय क्षेत्रफल निकालने की व्यावहारिक विधि देता है।

4. निश्चित समाकलों का मान निकालना

(i) सीधे: अनिश्चित समाकल निकालें, b और a रखें, घटाएँ। (ii) प्रतिस्थापन से: t = g(x) रखें और सीमाएँ बदलें: g(a), g(b); तब x में वापस जाना आवश्यक नहीं। (iii) खंडशः: ∫ₐᵇ u v dx = [u∫v dx]ₐᵇ − ∫ₐᵇ (u′ ∫v dx) dx।

5. निश्चित समाकलों के गुण

P1. ∫ₐᵇ f dx = −∫ᵇₐ f dx
P2. ∫ₐᵃ f dx = 0
P3. ∫ₐᵇ f dx = ∫ₐᶜ f dx + ∫ᶜᵇ f dx (a < c < b, या कोई भी c जहाँ f परिभाषित हो)
P4. ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx
P5. ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx
P6. ∫₀^{2a} f(x) dx = 2∫₀ᵃ f(x) dx यदि f(2a−x) = f(x); = 0 यदि f(2a−x) = −f(x)
P7. ∫ₐᵇ [f ± g] dx = ∫ₐᵇ f dx ± ∫ₐᵇ g dx; ∫ₐᵇ k f dx = k∫ₐᵇ f dx

6. निश्चित समाकलों के सममिति गुण

यदि f सम है [f(−x) = f(x)]: ∫₋ₐᵃ f dx = 2 ∫₀ᵃ f dx
यदि f विषम है [f(−x) = −f(x)]: ∫₋ₐᵃ f dx = 0

सम: x², cos x, |x|। विषम: x, x³, sin x, tan x। मिश्रित समाकल्य को सम और विषम भागों में बाँटें: केवल सम भाग बचता है। साथ ही, P4 में a = 0, b = π/2 रखने पर ∫₀^{π/2} f(sin x) dx = ∫₀^{π/2} f(cos x) dx, तथा ∫₀^π x f(sin x) dx = (π/2) ∫₀^π f(sin x) dx।

7. निश्चित समाकलों का सरलीकरण एवं मान निर्धारण

(1) मापांक: |·| के भीतर का व्यंजक जहाँ चिह्न बदलता है, वहाँ अंतराल बाँटें (P3) और प्रत्येक भाग में मापांक हटाएँ। (2) त्रिकोणमितीय: समाकलन से पहले सर्वसमिकाएँ (sin²x = (1−cos 2x)/2 आदि) लगाएँ। (3) कठिन भिन्न जैसे sin x/(sin x + cos x): समाकल को I मानें, P4 से दूसरा व्यंजक पाएँ, दोनों जोड़ें ताकि समाकल्य 1 हो जाए, फिर I निकालें। (4) गणना से पहले देखें कि समाकल्य सम/विषम है या नहीं। (5) समाकलन से पहले P5 या P6 से सीमाएँ घटाएँ।

चित्र (एनिमेटेड)

चित्र 1: a = 0 और b = 3 के बीच y = x² के नीचे का क्षेत्रफल पतले आयतों से निकटतः निकाला गया है। एनिमेशन में आयत 4 से 8 और फिर 20 होते हैं, सीढ़ीनुमा आकृति वक्र के निकट आती जाती है, और n → ∞ की सीमा में योग निश्चित समाकल (यहाँ 9) बन जाता है। चित्र 2: सममिति। सम फलन x² के लिए नीला (बायाँ) और नारंगी (दायाँ) क्षेत्रफल बराबर हैं। विषम फलन x³ के लिए बायाँ भाग अक्ष के नीचे है, इसलिए उसका चिह्नित क्षेत्रफल दाएँ भाग को काट देता है।

हल किए गए उदाहरण (चरण दर चरण)

1. ∫₁² x² dx का मान ज्ञात कीजिए
प्रतिअवकलज x³/3। = (2³/3) − (1³/3) = 8/3 − 1/3 = 7/3।
2. ∫₀^(π/2) cos x dx का मान ज्ञात कीजिए
प्रतिअवकलज sin x। = sin(π/2) − sin 0 = 1 − 0 = 1।
3. ∫₀¹ (3x² + 2x + 1) dx का मान ज्ञात कीजिए
प्रतिअवकलज x³ + x² + x। 1 पर: 3। 0 पर: 0। मान = 3।
4. योग की सीमा विधि से ∫₀² x dx का मान ज्ञात कीजिए
a = 0, b = 2, h = 2/n, f(rh) = rh। योग = h Σ rh = h² · n(n+1)/2 = (4/n²) · n(n+1)/2 = 2(1 + 1/n)। n → ∞ पर: 2। (जाँच: [x²/2]₀² = 2 ✓)
5. योग की सीमा विधि से ∫₀² (x² + 1) dx का मान ज्ञात कीजिए
h = 2/n, f(rh) = r²h² + 1। योग = h[h² Σr² + n] = h³ · n(n+1)(2n+1)/6 + nh = (8/n³)·n(n+1)(2n+1)/6 + 2 = (4/3)(1 + 1/n)(2 + 1/n) + 2। n → ∞ पर: (4/3)(2) + 2 = 8/3 + 2 = 14/3।
6. d/dx ∫₀^(x²) cos t dt ज्ञात कीजिए
शृंखला रूप से: cos(x²) · d(x²)/dx। उत्तर: 2x cos x²।
7. ∫₀¹ x/(1+x²) dx का मान ज्ञात कीजिए
t = 1 + x², dt = 2x dx रखें। सीमाएँ: x = 0 → t = 1; x = 1 → t = 2। समाकल = ½ ∫₁² dt/t = ½ [log t]₁² = ½ log 2।
8. ∫₀^(π/2) sin x cos x dx का मान ज्ञात कीजिए
t = sin x, dt = cos x dx रखें। सीमाएँ 0 → 0, π/2 → 1। ∫₀¹ t dt = ½।
9. ∫₀^π x sin x dx का मान ज्ञात कीजिए
खंडशः: [−x cos x]₀^π + ∫₀^π cos x dx = (π + 0) + [sin x]₀^π = π + 0 = π।
10. ∫₀¹ dx/(1+x²) का मान ज्ञात कीजिए
प्रतिअवकलज tan⁻¹x। = tan⁻¹1 − tan⁻¹0 = π/4 − 0 = π/4।
11. ∫₀¹ dx/√(4−x²) का मान ज्ञात कीजिए
प्रतिअवकलज sin⁻¹(x/2)। = sin⁻¹(1/2) − 0 = π/6।
12. ∫₋₁² |x| dx का मान ज्ञात कीजिए
0 पर बाँटें: ∫₋₁⁰ (−x) dx + ∫₀² x dx = [−x²/2]₋₁⁰ + [x²/2]₀² = (0 + ½) + 2 = 5/2।
13. ∫₀⁴ |x − 2| dx का मान ज्ञात कीजिए
x < 2 पर |x−2| = 2−x, x > 2 पर x−2। ∫₀² (2−x) dx = [2x − x²/2]₀² = 2। ∫₂⁴ (x−2) dx = [x²/2 − 2x]₂⁴ = 0 − (−2) = 2। कुल 4।
14. −π/2 से π/2 तक sin³x का समाकल ज्ञात कीजिए
sin³x विषम है (sin(−x)³ = −sin³x)। सममिति से मान 0 है।
15. ∫₋₂² (x⁴ + x³) dx का मान ज्ञात कीजिए
x⁴ सम, x³ विषम। = 2∫₀² x⁴ dx + 0 = 2 · [x⁵/5]₀² = 2 · 32/5 = 64/5।
16. ∫₀^(π/2) sin x/(sin x + cos x) dx का मान ज्ञात कीजिए
माना I = ∫ sin x/(sin x + cos x)। P4 (x → π/2 − x) से: I = ∫ cos x/(cos x + sin x)। जोड़ने पर: 2I = ∫₀^(π/2) 1 dx = π/2। अतः I = π/4।
17. ∫₀^(π/2) √sin x /(√sin x + √cos x) dx का मान ज्ञात कीजिए
P4 से I = ∫ √cos x/(√cos x + √sin x)। जोड़ने पर 2I = π/2। I = π/4।
18. ∫₀^π x sin x/(1+cos²x) dx का मान ज्ञात कीजिए
∫₀^π x f(sin x) dx = (π/2) ∫₀^π f(sin x) dx से: I = (π/2)∫₀^π sin x/(1+cos²x) dx। t = cos x, dt = −sin x dx रखें; सीमाएँ 1 → −1: = (π/2) ∫₋₁¹ dt/(1+t²) = (π/2)[tan⁻¹t]₋₁¹ = (π/2)(π/4 + π/4) = π²/4।
19. ∫₀^(π/2) log sin x dx का मान ज्ञात कीजिए
माना I = ∫ log sin x dx = ∫ log cos x dx (P4)। 2I = ∫ log(sin x cos x) dx = ∫ log(sin 2x) dx − (π/2) log 2। 2x = u रखें: ∫₀^(π/2) log sin 2x dx = ½ ∫₀^π log sin u du = ½·2I = I। अतः 2I = I − (π/2) log 2 ⇒ I = −(π/2) log 2।
20. सत्यापित कीजिए ∫₀^(π/2) sin x dx = 1
[−cos x]₀^(π/2) = −cos(π/2) + cos 0 = 0 + 1 = 1 ✓।

लघु एवं दीर्घ प्रश्नोत्तर (खोलने के लिए छुएँ)

Q1. निश्चित समाकल की परिभाषा लिखिए।
∫ₐᵇ f dx = F(b) − F(a), जहाँ F′ = f; यह वक्र के नीचे का चिह्नित क्षेत्रफल है।
Q2. अचर C क्यों नहीं लिखा जाता?
वह F(b) − F(a) में कट जाता है।
Q3. कलन का मूलभूत प्रमेय लिखिए।
(1) d/dx ∫ₐˣ f(t) dt = f(x)। (2) ∫ₐᵇ f dx = F(b) − F(a)।
Q4. प्रतिस्थापन में सीमाओं का क्या होता है?
वे बदल जाती हैं: यदि t = g(x), तो नई सीमाएँ g(a) और g(b) होती हैं।
Q5. सम और विषम f के लिए ∫₋ₐᵃ f dx लिखिए।
सम के लिए 2∫₀ᵃ f dx; विषम के लिए 0।
Q6. ∫ₐᵃ f dx का मान क्या है?
0।
Q7. |x − c| का समाकलन कैसे करते हैं?
x = c पर अंतराल बाँटें और प्रत्येक ओर सही चिह्न के साथ मापांक हटाएँ।
Q8. दीर्घ: सिद्ध कीजिए ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx।
x = a + b − t, dx = −dt रखें। जब x = a, t = b; जब x = b, t = a। ∫ₐᵇ f(x) dx = ∫ᵇₐ f(a+b−t)(−dt) = ∫ₐᵇ f(a+b−t) dt = ∫ₐᵇ f(a+b−x) dx (मूक चर)।
Q9. दीर्घ: सिद्ध कीजिए ∫₋ₐᵃ f dx = सम f के लिए 2∫₀ᵃ f dx और विषम के लिए 0।
बाँटें: ∫₋ₐᵃ = ∫₋ₐ⁰ + ∫₀ᵃ। पहले में x = −t रखें: ∫₋ₐ⁰ f(x) dx = ∫₀ᵃ f(−t) dt। यदि f सम है, f(−t) = f(t), कुल = 2∫₀ᵃ f। यदि विषम है, f(−t) = −f(t), दोनों भाग कट जाते हैं: 0।
Q10. दीर्घ: सिद्ध कीजिए ∫₀^π x f(sin x) dx = (π/2) ∫₀^π f(sin x) dx; इससे ∫₀^π x sin x dx निकालिए।
माना I = ∫₀^π x f(sin x) dx। P5 (a = π) से: I = ∫ (π − x) f(sin(π − x)) dx = π∫ f(sin x) dx − I। अतः 2I = π ∫₀^π f(sin x) dx। f(u) = u लेने पर: I = (π/2) ∫₀^π sin x dx = (π/2)(2) = π ✓ (उदाहरण 9 से मेल)।
