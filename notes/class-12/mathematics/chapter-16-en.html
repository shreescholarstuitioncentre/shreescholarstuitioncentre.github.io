Definite Integrals – Class 12 Maths Notes

Unit 3: Calculus · Chapter 16 · UP Board

1. Definite Integrals

If F′(x) = f(x), the definite integral of f from a to b is the number

∫ₐᵇ f(x) dx = [F(x)]ₐᵇ = F(b) − F(a)

a = lower limit, b = upper limit. There is no constant C (it cancels in F(b) − F(a)) and the answer is a number. Geometrically it is the signed area between the curve, the x-axis and the lines x = a, x = b: area above the axis counts positive, below counts negative. The variable is a dummy variable: ∫ₐᵇ f(x) dx = ∫ₐᵇ f(t) dt.

2. Definite Integral as the Limit of a Sum

Divide [a, b] into n equal parts of width h = (b − a)/n. Then

∫ₐᵇ f(x) dx = lim (n→∞) h [ f(a+h) + f(a+2h) + … + f(a+nh) ] = lim h Σ f(a+rh) (r = 1 to n)

Useful sums: Σr = n(n+1)/2; Σr² = n(n+1)(2n+1)/6; Σr³ = [n(n+1)/2]²; geometric: a + ar + … + arⁿ⁻¹ = a(rⁿ − 1)/(r − 1). Method: write h, find f(a+rh), sum using the formulas, then take n → ∞ (so h → 0 and 1/n → 0).

3. Fundamental Theorem of Calculus

First theorem: if A(x) = ∫ₐˣ f(t) dt, then A′(x) = f(x).
Second theorem: if F′ = f, then ∫ₐᵇ f(x) dx = F(b) − F(a).
Chain form: d/dx ∫ₐ^{g(x)} f(t) dt = f(g(x))·g′(x).

The first theorem says integration and differentiation undo each other; the second gives the practical way of computing areas.

4. Evaluation of Definite Integrals

(i) Direct: find the indefinite integral, substitute b and a, subtract. (ii) By substitution: put t = g(x) and change the limits to g(a), g(b); then there is no need to go back to x. (iii) By parts: ∫ₐᵇ u v dx = [u∫v dx]ₐᵇ − ∫ₐᵇ (u′ ∫v dx) dx.

5. Properties of Definite Integrals

P1. ∫ₐᵇ f dx = −∫ᵇₐ f dx
P2. ∫ₐᵃ f dx = 0
P3. ∫ₐᵇ f dx = ∫ₐᶜ f dx + ∫ᶜᵇ f dx (a < c < b, or any c where f is defined)
P4. ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx
P5. ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx
P6. ∫₀^{2a} f(x) dx = 2∫₀ᵃ f(x) dx if f(2a−x) = f(x); = 0 if f(2a−x) = −f(x)
P7. ∫ₐᵇ [f ± g] dx = ∫ₐᵇ f dx ± ∫ₐᵇ g dx; ∫ₐᵇ k f dx = k∫ₐᵇ f dx

6. Symmetry Properties of Definite Integrals

If f is even [f(−x) = f(x)]: ∫₋ₐᵃ f dx = 2 ∫₀ᵃ f dx
If f is odd [f(−x) = −f(x)]: ∫₋ₐᵃ f dx = 0

Even: x², cos x, |x|. Odd: x, x³, sin x, tan x. Split a mixed integrand into even and odd parts: only the even part survives. Also, P4 with a = 0, b = π/2 shows ∫₀^{π/2} f(sin x) dx = ∫₀^{π/2} f(cos x) dx, and ∫₀^π x f(sin x) dx = (π/2) ∫₀^π f(sin x) dx.

7. Simplification and Evaluation of Definite Integrals

(1) Modulus: find where the expression inside |·| changes sign, split the interval there (P3), remove the modulus on each piece. (2) Trigonometric: use identities (sin²x = (1−cos 2x)/2 etc.) before integrating. (3) Tricky fractions like sin x/(sin x + cos x): call the integral I, apply P4 to get another expression, add the two so the integrand becomes 1, and solve for I. (4) Always check whether the integrand is even/odd before computing. (5) Reduce limits using P5 or P6 before integrating.

Solved Examples (step by step)

1. Evaluate ∫₁² x² dx
Antiderivative x³/3. = (2³/3) − (1³/3) = 8/3 − 1/3 = 7/3.
2. Evaluate ∫₀^(π/2) cos x dx
Antiderivative sin x. = sin(π/2) − sin 0 = 1 − 0 = 1.
3. Evaluate ∫₀¹ (3x² + 2x + 1) dx
Antiderivative x³ + x² + x. At 1: 3. At 0: 0. Value = 3.
4. Evaluate ∫₀² x dx as the limit of a sum
a = 0, b = 2, h = 2/n, f(rh) = rh. Sum = h Σ rh = h² · n(n+1)/2 = (4/n²) · n(n+1)/2 = 2(1 + 1/n). As n → ∞: 2. (Check: [x²/2]₀² = 2 ✓)
5. Evaluate ∫₀² (x² + 1) dx as the limit of a sum
h = 2/n, f(rh) = r²h² + 1. Sum = h[h² Σr² + n] = h³ · n(n+1)(2n+1)/6 + nh = (8/n³)·n(n+1)(2n+1)/6 + 2 = (4/3)(1 + 1/n)(2 + 1/n) + 2. As n → ∞: (4/3)(2) + 2 = 8/3 + 2 = 14/3.
6. Find d/dx ∫₀^(x²) cos t dt
By the chain form: cos(x²) · d(x²)/dx. Answer: 2x cos x².
7. Evaluate ∫₀¹ x/(1+x²) dx
Put t = 1 + x², dt = 2x dx. Limits: x = 0 → t = 1; x = 1 → t = 2. Integral = ½ ∫₁² dt/t = ½ [log t]₁² = ½ log 2.
8. Evaluate ∫₀^(π/2) sin x cos x dx
Put t = sin x, dt = cos x dx. Limits 0 → 0, π/2 → 1. ∫₀¹ t dt = ½.
9. Evaluate ∫₀^π x sin x dx
By parts: [−x cos x]₀^π + ∫₀^π cos x dx = (π + 0) + [sin x]₀^π = π + 0 = π.
10. Evaluate ∫₀¹ dx/(1+x²)
Antiderivative tan⁻¹x. = tan⁻¹1 − tan⁻¹0 = π/4 − 0 = π/4.
11. Evaluate ∫₀¹ dx/√(4−x²)
Antiderivative sin⁻¹(x/2). = sin⁻¹(1/2) − 0 = π/6.
12. Evaluate ∫₋₁² |x| dx
Split at 0: ∫₋₁⁰ (−x) dx + ∫₀² x dx = [−x²/2]₋₁⁰ + [x²/2]₀² = (0 + ½) + 2 = 5/2.
13. Evaluate ∫₀⁴ |x − 2| dx
|x−2| = 2−x for x < 2, x−2 for x > 2. ∫₀² (2−x) dx = [2x − x²/2]₀² = 2. ∫₂⁴ (x−2) dx = [x²/2 − 2x]₂⁴ = 0 − (−2) = 2. Total 4.
14. Evaluate the integral of sin³x from −π/2 to π/2
sin³x is odd (sin(−x)³ = −sin³x). By symmetry the value is 0.
15. Evaluate ∫₋₂² (x⁴ + x³) dx
x⁴ even, x³ odd. = 2∫₀² x⁴ dx + 0 = 2 · [x⁵/5]₀² = 2 · 32/5 = 64/5.
16. Evaluate ∫₀^(π/2) sin x/(sin x + cos x) dx
Let I = ∫ sin x/(sin x + cos x). By P4 (x → π/2 − x): I = ∫ cos x/(cos x + sin x). Add: 2I = ∫₀^(π/2) 1 dx = π/2. So I = π/4.
17. Evaluate ∫₀^(π/2) √sin x /(√sin x + √cos x) dx
By P4, I = ∫ √cos x/(√cos x + √sin x). Adding: 2I = π/2. I = π/4.
18. Evaluate ∫₀^π x sin x/(1+cos²x) dx
Using ∫₀^π x f(sin x) dx = (π/2) ∫₀^π f(sin x) dx: I = (π/2)∫₀^π sin x/(1+cos²x) dx. Put t = cos x, dt = −sin x dx; limits 1 → −1: = (π/2) ∫₋₁¹ dt/(1+t²) = (π/2)[tan⁻¹t]₋₁¹ = (π/2)(π/4 + π/4) = π²/4.
19. Evaluate ∫₀^(π/2) log sin x dx
Let I = ∫ log sin x dx = ∫ log cos x dx (P4). 2I = ∫ log(sin x cos x) dx = ∫ log(sin 2x) dx − (π/2) log 2. Put 2x = u: ∫₀^(π/2) log sin 2x dx = ½ ∫₀^π log sin u du = ½·2I = I. So 2I = I − (π/2) log 2 ⇒ I = −(π/2) log 2.
20. Verify ∫₀^(π/2) sin x dx = 1
[−cos x]₀^(π/2) = −cos(π/2) + cos 0 = 0 + 1 = 1 ✓.

Short & Long Q&A (tap to open)

Q1. Define a definite integral.
∫ₐᵇ f dx = F(b) − F(a), where F′ = f; it is the signed area under the curve.
Q2. Why is no constant C written?
It cancels in F(b) − F(a).
Q3. State the fundamental theorem of calculus.
(1) d/dx ∫ₐˣ f(t) dt = f(x). (2) ∫ₐᵇ f dx = F(b) − F(a).
Q4. What happens to the limits in substitution?
They are converted: if t = g(x), the new limits are g(a) and g(b).
Q5. Write ∫₋ₐᵃ f dx for even and odd f.
2∫₀ᵃ f dx for even; 0 for odd.
Q6. What is the value of ∫ₐᵃ f dx?
0.
Q7. How do we integrate |x − c|?
Split at x = c and remove the modulus on each side with correct sign.
Q8. Long: Prove ∫ₐᵇ f(x) dx = ∫ₐᵇ f(a+b−x) dx.
Put x = a + b − t, dx = −dt. When x = a, t = b; when x = b, t = a. ∫ₐᵇ f(x) dx = ∫ᵇₐ f(a+b−t)(−dt) = ∫ₐᵇ f(a+b−t) dt = ∫ₐᵇ f(a+b−x) dx (dummy variable).
Q9. Long: Prove ∫₋ₐᵃ f dx = 2∫₀ᵃ f dx for even f and 0 for odd f.
Split: ∫₋ₐᵃ = ∫₋ₐ⁰ + ∫₀ᵃ. In the first put x = −t: ∫₋ₐ⁰ f(x) dx = ∫₀ᵃ f(−t) dt. If f is even, f(−t) = f(t), so total = 2∫₀ᵃ f. If odd, f(−t) = −f(t), so the two parts cancel: 0.
Q10. Long: Evaluate ∫₀^π x f(sin x) dx = (π/2) ∫₀^π f(sin x) dx; deduce ∫₀^π x sin x dx.
Let I = ∫₀^π x f(sin x) dx. By P5 (a = π): I = ∫ (π − x) f(sin(π − x)) dx = π∫ f(sin x) dx − I. So 2I = π ∫₀^π f(sin x) dx. With f(u) = u: I = (π/2) ∫₀^π sin x dx = (π/2)(2) = π ✓ (matches Example 9).
