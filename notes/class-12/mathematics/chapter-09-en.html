1. Rate of Change of Quantities

If y = f(x), then dy/dx is the rate of change of y with respect to x. At a particular point x = x₀ it is written [dy/dx]x=x₀ = f′(x₀). If dy/dx > 0, y increases as x increases; if dy/dx < 0, y decreases. For quantities depending on time t, dx/dt is the rate of change of x with time.

Parametric form: if x = φ(t) and y = ψ(t), then dy/dx = (dy/dt)/(dx/dt).
Related rates (chain rule): if V depends on r and r depends on t, then dV/dt = (dV/dr)(dr/dt).

3. Increasing Functions & 4. Decreasing Functions

Strictly increasing on an interval I: x₁ < x₂ ⇒ f(x₁) < f(x₂).
Strictly decreasing: x₁ < x₂ ⇒ f(x₁) > f(x₂).  Constant: f(x₁) = f(x₂).
Theorem. Let f be continuous on [a, b] and differentiable on (a, b). Then
f′(x) > 0 on (a, b) ⇒ f strictly increasing; f′(x) < 0 ⇒ strictly decreasing; f′(x) = 0 ⇒ constant.

Proof (increasing case). Take a ≤ x₁ < x₂ ≤ b. By LMVT, ∃ c ∈ (x₁, x₂): f(x₂) − f(x₁) = f′(c)(x₂ − x₁). Since f′(c) > 0 and x₂ − x₁ > 0, f(x₂) > f(x₁). ∎

Method to find intervals: ① Find f′(x). ② Solve f′(x) = 0 to get critical points. ③ These split the real line into intervals. ④ Test the sign of f′ in each interval.

5. Applications in Approximation

For a small change Δx in x: Δy ≈ dy = f′(x) Δx, so f(x + Δx) ≈ f(x) + f′(x) Δx.
Absolute error = Δx; relative error = Δx/x; percentage error = (Δx/x) × 100.

Method: choose a nearby convenient value x (a perfect square/cube), take Δx as the small difference, compute f(x), f′(x), then add f′(x)Δx.

6. Maxima and Minima (Introduction)

Local maximum at c: f(c) ≥ f(x) for all x near c. Local minimum: f(c) ≤ f(x) near c.
Critical point: c where f′(c) = 0 or f′(c) does not exist. Necessary condition: at a local extremum of a differentiable function, f′(c) = 0.
Absolute max/min on [a, b]: compare f at all critical points and at the end points a and b.

7. First Derivative Test

Let f be continuous at critical point c.
① f′ changes from + to − at c ⇒ local maximum.
② f′ changes from − to + ⇒ local minimum.
③ f′ does not change sign ⇒ neither (point of inflection).

8. Second Derivative Test

Let f′(c) = 0 and f″ exist at c.
① f″(c) < 0 ⇒ local maximum. ② f″(c) > 0 ⇒ local minimum. ③ f″(c) = 0 ⇒ test fails; use the first derivative test.

9. Practical Problems Based on Derivatives

Steps: ① Identify the quantity to maximise/minimise. ② Express it in one variable using the given condition. ③ Find f′ = 0. ④ Check max/min by f″. ⑤ Verify the answer is in the allowed domain and write the final value with units.

Solved Examples (step by step)

Easy Ex 1. Radius of a circle increases at 0.7 cm/s. Find the rate of increase of its circumference.
C = 2πr ⇒ dC/dt = 2π · dr/dt = 2π(0.7) = 1.4π cm/s.
Easy Ex 2. Find the rate of change of the area of a circle w.r.t. r when r = 5 cm.
A = πr² ⇒ dA/dr = 2πr = 10π = 10π cm²/cm.
Medium Ex 3. A spherical balloon’s radius increases at 2 cm/s. Find the rate of increase of its volume when r = 10 cm.
V = (4/3)πr³ ⇒ dV/dt = 4πr² dr/dt = 4π(100)(2) = 800π cm³/s.
Medium Ex 4. A 5 m ladder slides away from a wall; its foot moves at 2 m/s. How fast is the top sliding down when the foot is 3 m from the wall?
x² + y² = 25. When x = 3, y = 4.2x dx/dt + 2y dy/dt = 0 ⇒ dy/dt = −(x/y) dx/dt = −(3/4)(2) = −3/2.The top slides down at 1.5 m/s.
Medium Ex 5. Edge of a cube increases at 3 cm/s. Find the rate of increase of volume and surface area when edge = 10 cm.
dV/dt = 3x² dx/dt = 3(100)(3) = 900 cm³/s.dS/dt = 12x dx/dt = 12(10)(3) = 360 cm²/s.
Easy Ex 6. Find intervals where f(x) = x² − 4x + 6 is increasing or decreasing.
f′ = 2x − 4 = 0 ⇒ x = 2.x > 2: f′ > 0 ⇒ increasing on (2, ∞). x < 2: f′ < 0 ⇒ decreasing on (−∞, 2).
Medium Ex 7. f(x) = 2x³ − 3x² − 36x + 7. Find monotonic intervals.
f′ = 6x² − 6x − 36 = 6(x − 3)(x + 2).f′ > 0 for x < −2 and x > 3: increasing on (−∞, −2) ∪ (3, ∞).f′ < 0 for −2 < x < 3: decreasing on (−2, 3).
Hard Ex 8. Prove f(x) = x³ − 3x² + 3x − 100 is increasing on R.
f′ = 3x² − 6x + 3 = 3(x − 1)² ≥ 0 for all x.f′ = 0 only at x = 1 (isolated point), so f′ > 0 on both sides; f is strictly increasing on R. ∎
Easy Ex 9. Approximate √25.3.
f(x) = √x, x = 25, Δx = 0.3; f(25) = 5; f′(x) = 1/(2√x) = 0.1.Δy = 0.1 × 0.3 = 0.03 ⇒ √25.3 ≈ 5.03.
Hard Ex 10. Approximate (3.968)^(3/2).
f(x) = x^(3/2), x = 4, Δx = −0.032; f(4) = 8; f′ = (3/2)√x = 3.Δy = 3 × (−0.032) = −0.096 ⇒ value ≈ 8 − 0.096 = 7.904.
Medium Ex 11. Radius of a sphere is 9 cm, with possible error 0.03 cm. Find approximate error in volume.
ΔV ≈ dV = 4πr² Δr = 4π(81)(0.03) = 9.72π cm³.
Easy Ex 12. Find local extrema of f(x) = x³ − 3x (second derivative test).
f′ = 3x² − 3 = 0 ⇒ x = ±1. f″ = 6x.f″(1) = 6 > 0 ⇒ local minimum, value f(1) = −2.f″(−1) = −6 < 0 ⇒ local maximum, value f(−1) = 2.
Medium Ex 13. Find the local max of f(x) = sin x + cos x on (0, π/2) by the first derivative test.
f′ = cos x − sin x = 0 ⇒ x = π/4.For x < π/4, f′ > 0; for x > π/4, f′ < 0: sign changes + to −.Local maximum at π/4, value √2.
Hard Ex 14. Show the second derivative test fails for f(x) = x⁴ at 0, and decide the nature of 0.
f′ = 4x³ = 0 at x = 0; f″ = 12x² = 0 at 0: test fails.First derivative test: f′ < 0 for x < 0 and f′ > 0 for x > 0 (− to +): local minimum, f(0) = 0.
Medium Ex 15. Find two positive numbers with sum 16 whose sum of cubes is minimum.
Let numbers be x and 16 − x. S = x³ + (16 − x)³.S′ = 3x² − 3(16 − x)² = 0 ⇒ x = 16 − x ⇒ x = 8.S″ = 6x + 6(16 − x) = 96 > 0 ⇒ minimum. Numbers: 8 and 8; minimum sum = 1024.
Medium Ex 16. A farmer has 200 m of fencing for a rectangular field. Find the maximum area.
2(x + y) = 200 ⇒ y = 100 − x. A = x(100 − x).A′ = 100 − 2x = 0 ⇒ x = 50; A″ = −2 < 0 ⇒ maximum.y = 50, so a square field; maximum area = 2500 m².
Hard Ex 17. An open box is made from a square sheet 18 cm by cutting equal squares of side x from the corners. Find x for maximum volume.
V = x(18 − 2x)² = 4x³ − 72x² + 324x.V′ = 12x² − 144x + 324 = 12(x − 3)(x − 9) = 0 ⇒ x = 3 (x = 9 rejected as 18 − 2x = 0).V″ = 24x − 144 = −72 < 0 at x = 3 ⇒ maximum. x = 3 cm, V = 3 × 12² = 432 cm³.

Q & A Practice (tap to open)

Short Questions

Q1. What does dy/dx represent?The rate of change of y with respect to x; geometrically the slope of the tangent.
Q2. When is f strictly increasing on an interval?When f′(x) > 0 for all x in the interval.
Q3. Define a critical point.A point c in the domain where f′(c) = 0 or f′(c) does not exist.
Q4. Write the formula for approximation.f(x + Δx) ≈ f(x) + f′(x)Δx.
Q5. Area of a circle changes at what rate w.r.t. radius at r = 3?dA/dr = 2πr = 6π.
Q6. Is f(x) = x³ having an extremum at 0?No. f′ = 3x² = 0 at 0 but f′ does not change sign; it is a point of inflection.

Long Questions

Q7. State and prove the condition for a function to be increasing.See the theorem and LMVT proof in Section 3–4.
Q8. Show that of all rectangles with given perimeter, the square has maximum area.Let perimeter 2p, sides x and p − x. A = x(p − x); A′ = p − 2x = 0 ⇒ x = p/2; A″ = −2 < 0. Both sides p/2: a square.
Q9. Show that a closed cylinder of given volume has minimum surface area when h = 2r.V = πr²h ⇒ h = V/(πr²). S = 2πr² + 2πrh = 2πr² + 2V/r. S′ = 4πr − 2V/r² = 0 ⇒ V = 2πr³ ⇒ πr²h = 2πr³ ⇒ h = 2r. S″ = 4π + 4V/r³ > 0 ⇒ minimum. ∎
