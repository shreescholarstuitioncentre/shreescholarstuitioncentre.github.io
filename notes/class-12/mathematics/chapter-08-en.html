Chapter 8: Differentiation of Composite Functions

1. Derivative of Composite Functions

A composite function is a function inside another function: (f∘g)(x) = f(g(x)). Examples: sin(x²) (outer = sin, inner = x²), e^(3x), log(sin x). To differentiate such functions we cannot use the basic table directly; we need the chain rule.

2. Chain Rule

If y = f(u) and u = g(x): dy/dx = (dy/du) · (du/dx)
In short: d/dx [f(g(x))] = f′(g(x)) · g′(x)  (derivative of outer at inner × derivative of inner).
Longer chain: y = f(u), u = g(v), v = h(x) ⇒ dy/dx = (dy/du)(du/dv)(dv/dx).

Method: ① Identify outer and inner function. ② Differentiate the outer keeping the inner unchanged. ③ Multiply by the derivative of the inner. ④ Repeat for deeper layers (work from outside to inside).

Common results: d/dx (sin f) = cos f · f′; d/dx (tan f) = sec²f · f′; d/dx (f ⁿ) = n fⁿ⁻¹ f′; d/dx (√f) = f′/(2√f).

Proof for sin⁻¹x: Let y = sin⁻¹x, so x = sin y, y ∈ (−π/2, π/2).

4. Differentiation of Implicit Functions

When y cannot be easily written as y = f(x) (e.g. x² + y² = 25), the relation is implicit.

Method: ① Differentiate every term w.r.t. x; ② treat y as a function of x, so d/dx(yⁿ) = n yⁿ⁻¹ · dy/dx and use product rule on xy; ③ collect dy/dx terms on one side and solve.

5. Exponential Functions and Derivatives

d/dx (eˣ) = eˣ; d/dx (aˣ) = aˣ log a; d/dx (e^f(x)) = e^f(x) · f′(x); d/dx (a^f(x)) = a^f(x) · log a · f′(x).

6. Logarithmic Functions and Derivatives

d/dx (log x) = 1/x; d/dx (loga x) = 1/(x log a); d/dx [log f(x)] = f′(x)/f(x).
Laws: log(mn) = log m + log n; log(m/n) = log m − log n; log mⁿ = n log m.

7. Logarithmic Differentiation

Use it when the function is of the form [f(x)]^g(x), or a long product/quotient of powers.

Steps: ① Take log of both sides. ② Simplify with log laws. ③ Differentiate both sides w.r.t. x (LHS gives (1/y) dy/dx). ④ Multiply by y and replace y by the original expression.

8. Parametric Functions

If x = φ(t), y = ψ(t): dy/dx = (dy/dt) / (dx/dt), provided dx/dt ≠ 0.

9. Second-Order Derivatives

d²y/dx² = d/dx (dy/dx), also written y″ or f″(x).
Parametric: d²y/dx² = [ d/dt (dy/dx) ] / (dx/dt).

10. Rolle’s Theorem

If f is (i) continuous on [a, b], (ii) differentiable on (a, b), (iii) f(a) = f(b), then there exists at least one c ∈ (a, b) with f′(c) = 0.

All three conditions are needed. Example of failure: f(x) = |x| on [−1, 1] is not differentiable at 0, and f′ is never 0.

11. Lagrange’s Mean Value Theorem (LMVT)

If f is continuous on [a, b] and differentiable on (a, b), there exists c ∈ (a, b) with
f′(c) = [ f(b) − f(a) ] / (b − a).

Proof (via Rolle). Define φ(x) = f(x) − f(a) − [ (f(b) − f(a))/(b − a) ] (x − a).
φ is continuous on [a, b], differentiable on (a, b).φ(a) = 0 and φ(b) = f(b) − f(a) − (f(b) − f(a)) = 0.By Rolle, ∃ c: φ′(c) = 0 ⇒ f′(c) − (f(b) − f(a))/(b − a) = 0. ∎

12. Geometrical Interpretation

Rolle: if the end points of a smooth curve are at the same height, some point has a horizontal tangent. LMVT: some point of the curve has a tangent parallel to the chord AB (slope of chord = (f(b) − f(a))/(b − a)).

Fig. 2: A line parallel to the chord slides up and touches the curve at C: f′(c) = slope of AB.

Solved Examples (step by step)

Easy Ex 1. Differentiate sin(x²).
Outer = sin u, inner u = x². dy/dx = cos(x²) · 2x = 2x cos x².
Easy Ex 2. Differentiate log(sec x).
dy/dx = (1/sec x) · sec x tan x = tan x.
Easy Ex 3. If x² + y² = 25, find dy/dx.
2x + 2y dy/dx = 0 ⇒ dy/dx = −x/y.
Easy Ex 4. If x = a cos θ, y = a sin θ, find dy/dx.
dx/dθ = −a sin θ, dy/dθ = a cos θ. dy/dx = −cot θ.
Medium Ex 5. Differentiate y = xˣ.
log y = x log x.(1/y) y′ = log x + 1.y′ = xˣ (1 + log x).
Medium Ex 6. If x³ + y³ = 3axy, find dy/dx.
3x² + 3y² y′ = 3a(y + x y′).y′(y² − ax) = ay − x².y′ = (ay − x²)/(y² − ax).
Medium Ex 7. Differentiate tan⁻¹[(√(1+x²) − 1)/x].
Put x = tan θ: (sec θ − 1)/tan θ = (1 − cos θ)/sin θ = tan(θ/2).So y = θ/2 = ½ tan⁻¹x. dy/dx = 1/[2(1+x²)].
Medium Ex 8. If y = a sin x + b cos x, show y″ + y = 0.
y′ = a cos x − b sin x; y″ = −a sin x − b cos x = −y. Hence y″ + y = 0. ∎
Hard Ex 9. Differentiate y = x^(sin x) + (sin x)^x.
Let u = x^(sin x): log u = sin x log x ⇒ u′ = x^(sin x) [ sin x/x + cos x log x ].Let v = (sin x)^x: log v = x log sin x ⇒ v′ = (sin x)^x [ log sin x + x cot x ].y′ = u′ + v′.
Hard Ex 10. If x = a(θ − sin θ), y = a(1 − cos θ), find d²y/dx².
dy/dx = a sin θ / [a(1 − cos θ)] = cot(θ/2).d/dθ (dy/dx) = −½ cosec²(θ/2); dx/dθ = a(1 − cos θ) = 2a sin²(θ/2).d²y/dx² = −½ cosec²(θ/2) / [2a sin²(θ/2)] = −1 / [4a sin⁴(θ/2)].
Medium Ex 11. Verify Rolle’s theorem for f(x) = x² − 4x + 3 on [1, 3].
Polynomial ⇒ continuous and differentiable. f(1) = 0 = f(3).f′(x) = 2x − 4 = 0 ⇒ c = 2 ∈ (1, 3). Verified.
Hard Ex 12. Verify LMVT for f(x) = x(x−1)(x−2) on [0, ½].
f(0) = 0; f(½) = ½ · (−½) · (−3/2) = 3/8. Slope of chord = (3/8)/(1/2) = 3/4.f′(x) = 3x² − 6x + 2 = 3/4 ⇒ 12x² − 24x + 5 = 0 ⇒ x = (6 ± √21)/6.c = 1 − √21/6 ≈ 0.236 ∈ (0, ½). Verified.
