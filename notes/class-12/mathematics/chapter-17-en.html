Applications of Integrals (Area) – Class 12 Maths Notes

Unit 3: Calculus · Chapter 17 · UP Board

1. Applications of Integration in Finding Areas

A definite integral is a limit of a sum of areas of very thin rectangles. So the area of a region is found by cutting it into thin elementary strips, writing the area of one strip, and integrating. A vertical strip has width dx and height y (area y dx), used when integrating along x. A horizontal strip has width dy and length x (area x dy), used when integrating along y.

2. Area Under a Curve

Area bounded by y = f(x), x-axis, x = a, x = b:   A = ∫ₐᵇ |y| dx = ∫ₐᵇ |f(x)| dx
Area bounded by x = g(y), y-axis, y = c, y = d:   A = ∫_c^d |x| dy

Area is never negative. If the curve is above the axis the integral is positive; if it is below, the integral is negative, so take the modulus. If the curve crosses the axis between a and b, split at the crossing and add the absolute values.

3. Area Under Straight Lines

For y = mx + c between x = a and x = b the area is ∫ₐᵇ (mx + c) dx = [mx²/2 + cx]ₐᵇ. It matches the geometry of a trapezium or triangle, which gives a quick check of your answer.

4. Area Under Circles and Circular Arcs

Circle x² + y² = a²: A = 4∫₀ᵃ √(a²−x²) dx = πa²
Quadrant (first): ∫₀ᵃ √(a²−x²) dx = πa²/4
Use ∫√(a²−x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a)

For a segment cut by a line, subtract the line from the circle: A = ∫ [√(a²−x²) − (line)] dx.

5. Area Under Parabolas

Parabola y² = 4ax and its latus rectum x = a: A = 8a²/3
y² = 4ax and x² = 4by: A = 16ab/3
Area from x = 0 to x = h under y² = 4ax (upper half): ∫₀ʰ 2√(ax) dx = (4/3)√a · h^{3/2}

The parabola y² = 4ax is symmetric about the x-axis, so find the upper half and double it.

6. Area Under Ellipses

x²/a² + y²/b² = 1: A = 4∫₀ᵃ (b/a)√(a²−x²) dx = πab

Because the figure is symmetric about both axes, compute the first-quadrant area (πab/4) and multiply by 4. A circle is the special case a = b.

7. Area Between Two Curves

A = ∫ₐᵇ [f(x) − g(x)] dx (f upper, g lower)
A = ∫_c^d [x_right(y) − x_left(y)] dy

Limits a and b are the x-coordinates where the curves intersect: solve f(x) = g(x). If the upper curve changes between intersections, split the integral there.

8. Area Between a Curve and the Coordinate Axes

Here one or both coordinate axes are the boundaries. Find where the curve cuts the axes (put x = 0 and y = 0). The limits are normally 0 and the intercept. In the first quadrant, A = ∫₀ᵖ y dx where p is the x-intercept.

9. Identifying the Required Region

(1) Read all the boundary conditions in the question. (2) Draw them together and shade the region that satisfies all of them. (3) Check whether the region is below or above the x-axis (sign) and which curve is on top. (4) Decide the strip direction that needs the fewest splits: if the top and bottom curves change, use a horizontal strip.

10. Sketching Curves and Finding Limits of Integration

Steps: (1) Identify the shape from the equation (line, circle, parabola, ellipse). (2) Find intercepts and the vertex or centre. (3) Check symmetry (about x-axis if y appears with even power, about y-axis if x appears with even power). (4) Plot a few points. (5) Find intersections by solving the equations together; these give the limits. (6) Decide strip, write the integral, evaluate, and put units (square units) in the answer.

Solved Examples (step by step)

1. Find the area under y = x² from x = 0 to x = 2
A = ∫₀² x² dx = [x³/3]₀² = 8/3 − 0 = 8/3 sq. units.
2. Find the area under y = 2x + 1 from x = 1 to x = 3
A = ∫₁³ (2x + 1) dx = [x² + x]₁³ = (9 + 3) − (1 + 1) = 10 sq. units. (Check: trapezium with sides 3 and 7, width 2: ½(3+7)·2 = 10 ✓)
3. Find the area bounded by y = sin x, the x-axis, x = 0 and x = π
A = ∫₀^π sin x dx = [−cos x]₀^π = 1 + 1 = 2 sq. units.
4. Find the area bounded by y = x² − 4 and the x-axis
Intercepts: x² = 4 ⇒ x = ±2. Curve is below the axis in (−2, 2). Symmetric about y-axis. A = 2∫₀² (4 − x²) dx = 2[4x − x³/3]₀² = 2(8 − 8/3) = 32/3 sq. units.
5. Find the area of the circle x² + y² = a²
By symmetry A = 4 × (first quadrant area) = 4∫₀ᵃ √(a²−x²) dx = 4[(x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a)]₀ᵃ = 4·(a²/2)(π/2) = πa² sq. units.
6. Find the area of the region x² + y² ≤ 16 in the first quadrant
a = 4. Quadrant area = π a²/4 = π·16/4 = 4π sq. units.
7. Find the area bounded by y² = 4x and the line x = 4
Symmetric about the x-axis. A = 2∫₀⁴ 2√x dx = 4 · [(2/3)x^(3/2)]₀⁴ = 4 · (2/3)(8) = 64/3 sq. units.
8. Find the area enclosed by y² = 4ax and its latus rectum
Latus rectum: x = a. A = 2∫₀ᵃ 2√a √x dx = 4√a [(2/3)x^(3/2)]₀ᵃ = 4√a · (2/3) a^(3/2) = 8a²/3 sq. units.
9. Find the area of the ellipse x²/25 + y²/9 = 1
a = 5, b = 3. y = (3/5)√(25 − x²). A = 4∫₀⁵ (3/5)√(25−x²) dx = (12/5)[(x/2)√(25−x²) + (25/2) sin⁻¹(x/5)]₀⁵ = (12/5)(25/2)(π/2) = 15π sq. units (= πab).
10. Find the area between y = x and y = x²
Solve x = x² ⇒ x = 0, 1. On (0,1), x ≥ x². A = ∫₀¹ (x − x²) dx = [x²/2 − x³/3]₀¹ = 1/2 − 1/3 = 1/6 sq. units.
11. Find the area between y² = 4x and y = 2x
4x = 4x² ⇒ x = 0 or 1. On (0,1) the parabola y = 2√x is above y = 2x. A = ∫₀¹ (2√x − 2x) dx = [(4/3)x^(3/2) − x²]₀¹ = 4/3 − 1 = 1/3 sq. units.
12. Find the area of the smaller region bounded by x² + y² = 4 and x + y = 2 (first quadrant)
They meet at (2,0) and (0,2). Circle is above the line. A = ∫₀² [√(4−x²) − (2−x)] dx. First: [(x/2)√(4−x²) + 2 sin⁻¹(x/2)]₀² = 2·π/2 = π. Second: [2x − x²/2]₀² = 2. A = π − 2 sq. units.
13. Find the area enclosed by y² = 4x and x² = 4y
Solve: x⁴/16 = 4x ⇒ x = 0 or 4. Upper curve y = 2√x, lower y = x²/4. A = ∫₀⁴ (2√x − x²/4) dx = [(4/3)x^(3/2) − x³/12]₀⁴ = 32/3 − 16/3 = 16/3 sq. units.
14. Find the area between y = x³, the x-axis, x = −1 and x = 2
The curve crosses the axis at 0, so split. ∫₋₁⁰ |x³| dx = [−x⁴/4]₋₁⁰ = 1/4. ∫₀² x³ dx = 4. Total 17/4 sq. units.
15. Find the area between y = |x| and y = 2
Meet where |x| = 2 ⇒ x = ±2. Symmetric: A = 2∫₀² (2 − x) dx = 2[2x − x²/2]₀² = 2(4 − 2) = 4 sq. units (triangle base 4, height 2 ✓).
16. Find the area between y = cos x, y = sin x, x = 0 and x = π/4
On (0, π/4), cos x ≥ sin x. A = ∫₀^(π/4) (cos x − sin x) dx = [sin x + cos x]₀^(π/4) = (√2/2 + √2/2) − (0 + 1) = √2 − 1 sq. units.
17. Find the area bounded by y = x², the y-axis and y = 4 (first quadrant)
Use a horizontal strip: x = √y. A = ∫₀⁴ √y dy = [(2/3)y^(3/2)]₀⁴ = (2/3)(8) = 16/3 sq. units.
18. Find the area of the smaller segment of x² + y² = 9 cut by x = 1
Segment lies for 1 ≤ x ≤ 3, symmetric about x-axis. A = 2∫₁³ √(9−x²) dx = 2[(x/2)√(9−x²) + (9/2) sin⁻¹(x/3)]₁³ = 2[9π/4 − √2 − (9/2) sin⁻¹(1/3)] = 9π/2 − 2√2 − 9 sin⁻¹(1/3) sq. units.

Short & Long Q&A (tap to open)

Q1. What is the area under a curve?
A = ∫ₐᵇ y dx, the sum of thin vertical strips between x = a and x = b.
Q2. Why do we take the modulus for area?
Area cannot be negative; below the x-axis the integral is negative.
Q3. What do we do if the curve crosses the x-axis in [a, b]?
Split at the crossing point and add the absolute values of the pieces.
Q4. Write the area of an ellipse.
πab.
Q5. Area between y² = 4ax and x² = 4by?
16ab/3.
Q6. How do we find the limits for the area between two curves?
Solve f(x) = g(x); the roots are the limits.
Q7. When is a horizontal strip preferred?
When the curve is given as x = f(y), or when the upper/lower curve changes along x.
Q8. Long: Prove that the area of the circle x² + y² = a² is πa².
Symmetric about both axes, so A = 4∫₀ᵃ √(a²−x²) dx. Formula: ∫√(a²−x²) dx = (x/2)√(a²−x²) + (a²/2) sin⁻¹(x/a). At a: 0 + (a²/2)(π/2). At 0: 0. So ∫₀ᵃ = πa²/4 and A = πa².
Q9. Long: Prove that the area of the ellipse x²/a² + y²/b² = 1 is πab.
y = (b/a)√(a²−x²) in the first quadrant. A = 4∫₀ᵃ (b/a)√(a²−x²) dx = (4b/a)·(πa²/4) = πab.
Q10. Long: Find the area bounded by the parabola y² = 4ax and the line y = mx (m > 0).
Intersections: m²x² = 4ax ⇒ x = 0 or 4a/m². Parabola upper: y = 2√(ax). A = ∫₀^(4a/m²) (2√a √x − mx) dx = [(4√a/3) x^(3/2) − m x²/2]. Put x = 4a/m²: x^(3/2) = 8a^(3/2)/m³. First: (4√a/3)(8a^(3/2)/m³) = 32a²/(3m³). Second: (m/2)(16a²/m⁴) = 8a²/m³. A = 32a²/(3m³) − 8a²/m³ = 8a²/(3m³). (m = 2, a = 1: 1/3 ✓ matches Example 11.)
