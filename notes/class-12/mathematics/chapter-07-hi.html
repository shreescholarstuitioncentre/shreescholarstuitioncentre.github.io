अध्याय 7: अवकलनीयता

उ.प्र. बोर्ड / एन.सी.ई.आर.टी. शैली के नोट्स · सरल, चरणबद्ध, एनिमेटेड चित्रों सहित

1. अवकलनीयता का परिचय

संतत्य (सातत्य) बताता है कि ग्राफ़ में कोई टूटन नहीं है। अवकलनीयता बताती है कि ग्राफ़ उस बिंदु पर चिकना भी है, अर्थात वहाँ कोई नुकीला कोना या ऊर्ध्वाधर स्पर्श रेखा नहीं है। ज्यामितीय रूप से, किसी बिंदु पर फलन अवकलनीय तब होता है जब वहाँ एक अद्वितीय, अऊर्ध्वाधर स्पर्श रेखा खींची जा सके। उसकी प्रवणता (ढाल) को अवकलज कहते हैं, जो y में x के सापेक्ष तात्क्षणिक परिवर्तन दर भी बताती है।

2. फलन का अवकलज एवं 3. प्रथम सिद्धांत से अवकलज

परिभाषा: f′(a) = limh→0 [ f(a+h) − f(a) ] / h, यदि यह सीमा विद्यमान और परिमित हो।
व्यापक रूप: f′(x) = limh→0 [ f(x+h) − f(x) ] / h   (इसे dy/dx, y′ भी लिखते हैं)।

प्रत्येक भाग का अर्थ: f(a+h) − f(a) = y में परिवर्तन; h = x में परिवर्तन; इनका अनुपात = बिंदुओं P(a, f(a)) और Q(a+h, f(a+h)) से जाने वाली छेदक रेखा की प्रवणता। जैसे-जैसे h → 0, बिंदु Q, बिंदु P की ओर खिसकता है और छेदक रेखा स्पर्श रेखा बन जाती है।

चित्र 1: Q के P की ओर बढ़ने पर छेदक रेखा PQ स्पर्श रेखा बन जाती है।

4. वाम पक्ष अवकलज (LHD)

Lf′(a) = limh→0⁺ [ f(a−h) − f(a) ] / (−h)  =  limx→a⁻ [ f(x) − f(a) ] / (x − a)

5. दक्षिण पक्ष अवकलज (RHD)

Rf′(a) = limh→0⁺ [ f(a+h) − f(a) ] / h  =  limx→a⁺ [ f(x) − f(a) ] / (x − a)

6. किसी बिंदु पर अवकलनीयता

f, x = a पर अवकलनीय ⇔ Lf′(a) = Rf′(a) = परिमित संख्या।
यही उभयनिष्ठ मान f′(a) है। अंतराल (a, b) में फलन अवकलनीय तब कहलाता है जब वह प्रत्येक बिंदु पर अवकलनीय हो। बंद अंतराल [a, b] में अवकलनीय होने के लिए (a, b) में अवकलनीय होना तथा a पर RHD और b पर LHD का विद्यमान होना आवश्यक है।

जाँचने के चरण: ① a के दोनों ओर f का रूप लिखिए। ② LHD निकालिए। ③ RHD निकालिए। ④ तुलना कीजिए। बराबर और परिमित हों → अवकलनीय; अन्यथा → अवकलनीय नहीं।

चित्र 2: y = |x| के लिए 0 पर LHD = −1 तथा RHD = 1 है, इसलिए वहाँ अवकलनीय नहीं।

7. संतत्य और अवकलनीयता में संबंध

प्रमेय: प्रत्येक अवकलनीय फलन संतत होता है। इसका विलोम सत्य नहीं है।

उपपत्ति। माना f, a पर अवकलनीय है, अतः f′(a) = limx→a [f(x) − f(a)]/(x − a) विद्यमान है।
x ≠ a के लिए: f(x) − f(a) = [ (f(x) − f(a)) / (x − a) ] · (x − a)। x → a पर सीमा लेने पर: lim [f(x) − f(a)] = f′(a) · 0 = 0। अतः lim f(x) = f(a), अर्थात f, a पर संतत है। ∎

विलोम का प्रति-उदाहरण: f(x) = |x|, 0 पर संतत है परंतु 0 पर अवकलनीय नहीं।
याद रखें: असंतत ⇒ अवकलनीय नहीं। संतत होने से अवकलनीय होना आवश्यक नहीं।

उपयोगी सीमाएँ: lim sin h / h = 1; lim (1 − cos h)/h = 0; lim (eʰ − 1)/h = 1; lim log(1+h)/h = 1; lim (aʰ − 1)/h = log a।

हल सहित उदाहरण (चरण-दर-चरण)

सरल उदा. 1. f(x) = x² का x = 3 पर अवकलज प्रथम सिद्धांत से ज्ञात कीजिए।
f′(3) = lim [ (3+h)² − 9 ] / h = lim [ 6h + h² ] / h= lim (6 + h) = 6।
सरल उदा. 2. सिद्ध कीजिए कि f(x) = |x|, x = 0 पर अवकलनीय नहीं है।
LHD = limh→0⁺ [ |−h| − 0 ] / (−h) = h/(−h) = −1।RHD = lim [ |h| − 0 ] / h = 1।−1 ≠ 1, अतः अवकलनीय नहीं। ∎
सरल उदा. 3. प्रथम सिद्धांत से sin x का अवकलज ज्ञात कीजिए।
= lim [ sin(x+h) − sin x ] / h = lim 2cos(x + h/2) sin(h/2) / h= lim cos(x + h/2) · [ sin(h/2) / (h/2) ] = cos x · 1 = cos x।
सरल उदा. 4. eˣ का अवकलज ज्ञात कीजिए।
= lim (eˣ⁺ʰ − eˣ)/h = eˣ · lim (eʰ − 1)/h = eˣ · 1 = eˣ।
सरल उदा. 5. log x का अवकलज ज्ञात कीजिए।
= lim [ log(x+h) − log x ] / h = lim (1/h) log(1 + h/x)= (1/x) · lim log(1 + h/x)/(h/x) = 1/x।
मध्यम उदा. 6. f(x) = x|x| की x = 0 पर अवकलनीयता जाँचिए।
x < 0 के लिए f(x) = −x²; x ≥ 0 के लिए f(x) = x²।LHD = limh→0⁺ [−h² − 0]/(−h) = lim h = 0।RHD = lim h²/h = 0।LHD = RHD = 0, अतः अवकलनीय है और f′(0) = 0।
मध्यम उदा. 7. f(x) = x² (x ≤ 1), ax + b (x > 1) यदि x = 1 पर अवकलनीय हो, तो a, b ज्ञात कीजिए।
अवकलनीय ⇒ संतत: 1 = a + b … (i)LHD = 1 पर 2x का मान = 2; RHD = a। अतः a = 2।(i) से b = −1। a = 2, b = −1।
मध्यम उदा. 8. f(x) = x sin(1/x), f(0) = 0। क्या 0 पर संतत और अवकलनीय है?
|x sin(1/x)| ≤ |x| → 0, अतः सीमा = 0 = f(0): संतत।[f(h) − f(0)]/h = sin(1/h), जो −1 और 1 के बीच दोलन करता है; सीमा विद्यमान नहीं।संतत है पर अवकलनीय नहीं।
कठिन उदा. 9. f(x) = x² sin(1/x), f(0) = 0 के लिए सिद्ध कीजिए कि f, 0 पर अवकलनीय है परंतु f′ वहाँ संतत नहीं है।
f′(0) = lim h² sin(1/h)/h = lim h sin(1/h) = 0।x ≠ 0 के लिए: f′(x) = 2x sin(1/x) − cos(1/x)।x → 0 पर 2x sin(1/x) → 0 परंतु cos(1/x) दोलन करता है; lim f′(x) विद्यमान नहीं। अतः f′ असंतत है।
कठिन उदा. 10. f(x) = |x − 1| + |x − 2| की x = 1, 2 पर अवकलनीयता की विवेचना कीजिए।
1 के पास (x<1): f = 3 − 2x, प्रवणता −2; (1<x<2): f = 1, प्रवणता 0। अतः 1 पर LHD ≠ RHD।2 के पास: बाईं ओर प्रवणता 0, दाईं ओर +2। बराबर नहीं।अतः x = 1 और x = 2 पर अवकलनीय नहीं।
