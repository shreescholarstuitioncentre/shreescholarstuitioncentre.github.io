Class 12 Maths — Chapter 23: Linear Programming

1. Introduction and Basic Terminology

Objective function Z = ax + by (to be maximised or minimised)
Constraints: linear inequalities in x, y
Non-negativity: x ≥ 0, y ≥ 0

Linear Programming finds the best (optimal) value of a linear function under linear restrictions. Decision variables (x, y) are the quantities we choose. Optimization means maximising profit or minimising cost.

2. Types of LPP

Manufacturing problem (maximise profit), diet problem (minimise cost with nutrient needs), transportation problem (minimise shipping cost).

3. Mathematical Formulation

Step 1: name the decision variables x, y. Step 2: write the objective function Z. Step 3: write each restriction as an inequality. Step 4: add x ≥ 0, y ≥ 0.

4. Linear Inequalities in Two Variables

Draw the line ax + by = c, then test the origin
If (0,0) satisfies it, shade the side containing the origin

Use a solid line for ≤ or ≥, dashed for < or >.

5. Feasible Region and Solutions

Feasible region = common region of all constraints
Feasible solution: a point in it; infeasible solution: a point outside it

Bounded region can be enclosed in a circle; otherwise it is unbounded. If constraints have no common region, the LPP has no solution (infeasible).

6. Corner Point Method

1. Find the feasible region and its corner points
2. Evaluate Z at each corner
3. Max: largest value; Min: smallest value

The optimal value always occurs at a corner point. For an unbounded region, take M = the value at corners, then check whether the open half-plane Z > M (for max) or Z < M (for min) has a common point with the region; if not, M is the optimum. If two corners give the same optimum, every point on the segment joining them is optimal.

7. Real-Life Applications

Factories choose product mix for maximum profit; hospitals plan low-cost diets; companies plan transport routes; farmers plan crop areas.

Solved Examples (Given / To Find / Solution)

Ex 1 (Easy, Formulation). A firm makes tables (profit ₹30) and chairs (profit ₹20). A table needs 3 hours and a chair 2 hours of carpentry; 120 hours available. Formulate.
Let x tables, y chairs.
Maximise Z = 30x + 20y
subject to 3x + 2y ≤ 120, x ≥ 0, y ≥ 0.
Ex 2 (Easy). Graph x + y ≤ 4.
Draw x + y = 4 through (4,0) and (0,4). Test (0,0): 0 ≤ 4 true ⇒ shade the side containing the origin.
Ex 3 (Easy). Maximise Z = 3x + 4y subject to x + y ≤ 4, x, y ≥ 0.
Corners: (0,0), (4,0), (0,4).
Z = 0, 12, 16.
Maximum Z = 16 at (0,4).
Ex 4 (Medium). Maximise Z = 5x + 4y subject to x + 2y ≤ 8, 3x + 2y ≤ 12, x, y ≥ 0.
Intersection: subtract ⇒ 2x = 4 ⇒ x = 2, y = 3.
Corners: (0,0), (4,0), (2,3), (0,4).
Z = 0, 20, 22, 16.
Maximum Z = 22 at (2,3).
Ex 5 (Medium). Minimise Z = 2x + 3y subject to x + y ≥ 4, x + 3y ≥ 6, x, y ≥ 0.
Corners: (0,4), (3,1), (6,0). Z = 12, 9, 12.
Region is unbounded, so check 2x + 3y < 9: it has no common point with the region.
Minimum Z = 9 at (3,1).
Ex 6 (Hard, Diet). Minimise Z = 4x + 3y subject to 2x + y ≥ 8, x + 2y ≥ 10, x, y ≥ 0.
Intersection: y = 8−2x; x + 16 − 4x = 10 ⇒ x = 2, y = 4.
Corners: (0,8), (2,4), (10,0). Z = 24, 20, 40.
Check 4x+3y < 20: no common point. Minimum = 20 at (2,4).
Ex 7 (Hard). Maximise Z = x + y subject to x + y ≥ 5, x + y ≤ 3.
No point can satisfy both x+y ≥ 5 and x+y ≤ 3.
Feasible region is empty ⇒ the LPP has no solution.
Ex 8 (Hard). Maximise Z = 3x + 2y with the constraints of Ex 4.
Z at (0,0), (4,0), (2,3), (0,4) = 0, 12, 12, 8.
Maximum 12 occurs at both (4,0) and (2,3), so every point on the segment joining them is optimal (infinitely many solutions).

Short & Long Questions

Q1. What is an LPP?
Optimising a linear objective function under linear constraints.
Q2. What is the objective function?
The linear function Z = ax + by to be maximised or minimised.
Q3. What are decision variables?
The unknown quantities x, y whose values we choose.
Q4. What is a feasible region?
The common region satisfying all constraints.
Q5. Bounded versus unbounded region?
A bounded region can be enclosed in a circle; an unbounded one extends indefinitely.
Q6. Where does the optimum lie?
At a corner point of the feasible region.
Q7. Why x ≥ 0, y ≥ 0?
Quantities like products or units cannot be negative.
Q8. What if the feasible region is empty?
The LPP has no solution (infeasible).
