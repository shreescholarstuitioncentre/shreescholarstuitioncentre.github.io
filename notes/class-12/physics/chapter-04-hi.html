कक्षा 12 भौतिक विज्ञान – धारिता (नोट्स)

1. संधारित्र तथा धारिता

संधारित्र दो चालकों (प्लेटों) की वह व्यवस्था है जिनके बीच विद्युतरोधी या परावैद्युत होता है; यह आवेश व ऊर्जा संचित करता है। एक प्लेट पर +Q, दूसरी पर −Q।

धारिता: किसी प्लेट के आवेश और प्लेटों के बीच विभवांतर का अनुपात।

C = Q / V

SI मात्रक: फैरड (F) = कूलॉम/वोल्ट। 1 F वह धारिता है जब 1 C आवेश देने पर विभवांतर 1 V बढ़े। 1 µF = 10⁻⁶ F, 1 nF = 10⁻⁹ F, 1 pF = 10⁻¹² F। विमा [M⁻¹ L⁻² T⁴ A²]। यह आकार, माप, दूरी व माध्यम पर निर्भर है, Q या V पर नहीं।

विलगित गोला: V = kQ/R अतः C = 4πε₀R। सिद्धांत: आवेशित चालक के पास भू-संपर्कित चालक लाने से उसका विभव घटता है और धारिता बढ़ती है, अतः अधिक आवेश संचित होता है।

2. समांतर प्लेट संधारित्र

क्षेत्रफल A की दो प्लेटें, दूरी d (d प्लेट के माप से बहुत कम), निर्वात में।

पृष्ठीय आवेश घनत्व σ = Q/A। प्लेटों के बीच क्षेत्र एकसमान: E = σ/ε₀ = Q/(ε₀A) (बाहर E = 0)। विभवांतर V = Ed = Qd/(ε₀A)।

C = Q/V = ε₀ A / d

परावैद्युत से पूर्णतः भरने पर: C = K ε₀ A / d = K C₀। अधिक C के लिए: A अधिक, d कम, K अधिक।

3. संधारित्रों का संयोजन

श्रेणी क्रम

प्रत्येक पर समान आवेश Q (भीतरी प्लेटों पर केवल प्रेरित आवेश)। विभव जुड़ते हैं: V = V₁ + V₂ + V₃ = Q/C₁ + Q/C₂ + Q/C₃। V = Q/C से:

1/C = 1/C₁ + 1/C₂ + 1/C₃

तुल्य C सबसे छोटे से भी छोटा। दो संधारित्र: C = C₁C₂/(C₁+C₂)। n समान: C/n। सबसे छोटे संधारित्र पर सबसे अधिक वोल्टता (V ∝ 1/C)।

समांतर क्रम

प्रत्येक पर समान V। आवेश बँटता है: Q = Q₁ + Q₂ + Q₃ = (C₁ + C₂ + C₃)V।

C = C₁ + C₂ + C₃

तुल्य C सबसे बड़े से भी बड़ा। सबसे बड़े संधारित्र पर सबसे अधिक आवेश (Q ∝ C)।

4. संधारित्र में संचित ऊर्जा

प्लेटों पर आवेश q होने पर विभव q/C। dq जोड़ने में कार्य: dW = (q/C)dq। Q तक आवेशित करने में कुल कार्य:

W = ∫₀^Q (q/C)dq = Q²/2C

U = ½ C V² = Q² / 2C = ½ Q V

यह ऊर्जा प्लेटों के बीच वैद्युत क्षेत्र में संचित रहती है (नष्ट नहीं होती)। V–Q ग्राफ सरल रेखा है; उसके नीचे का क्षेत्रफल ऊर्जा है।

ऊर्जा घनत्व

प्रति इकाई आयतन ऊर्जा। आयतन = Ad, V = Ed, C = ε₀A/d: U = ½(ε₀A/d)(E²d²) = ½ ε₀ E² A d।

u = U / (A d) = ½ ε₀ E²

परावैद्युत माध्यम में: u = ½ ε₀ K E² = ½ ε E²। मात्रक J/m³।

आवेश का साझाकरण

C₁ (V₁) व C₂ (V₂) को समान प्लेटें मिलाकर जोड़ने पर उभयनिष्ठ विभव V = (C₁V₁ + C₂V₂)/(C₁ + C₂)। ऊर्जा हानि (ऊष्मा/चिंगारी): ΔU = C₁C₂(V₁ − V₂)² / 2(C₁ + C₂)।

5. परावैद्युतांक तथा परावैद्युत का प्रभाव

परावैद्युतांक K = ε/ε₀ = C/C₀ = E₀/E, अर्थात परावैद्युत सहित और रहित (समान आकार) धारिताओं का अनुपात। K ≥ 1 (निर्वात 1, वायु ≈ 1.0006, अभ्रक 6, जल 80, धातु ∞)।

कारण: परावैद्युत ध्रुवित होता है और बद्ध आवेश E₀ के विपरीत E_p बनाते हैं, अतः E = E₀ − E_p = E₀/K, V = Ed घटता है, इसलिए C = Q/V, K गुना बढ़ जाता है।

6. आंशिक रूप से परावैद्युत भरा संधारित्र

(a) मोटाई t की पट्टिका, पूरा प्लेट क्षेत्रफल

वायु अंतराल (d − t) में क्षेत्र E₀ = σ/ε₀; पट्टिका में E = E₀/K। V = E₀(d − t) + E₀t/K = (σ/ε₀)[d − t + t/K]।

C = ε₀A / (d − t + t/K)

चालक पट्टिका (K → ∞): C = ε₀A/(d − t)। t = d होने पर: C = Kε₀A/d।

(b) पट्टिका क्षेत्रफल के एक भाग को ढके

दो संधारित्र समांतर: C = ε₀(KA₁ + A₂)/d, A₁ पर पट्टिका, A₂ पर वायु।

(c) दो परावैद्युत परतों में (मोटाई d₁, d₂)

श्रेणी: C = ε₀A / (d₁/K₁ + d₂/K₂)।

प्रश्न एवं उत्तर (सैद्धांतिक व बहुविकल्पीय)

प्र.1 संधारित्र क्या है? धारिता व उसका SI मात्रक परिभाषित कीजिए। (2)

परावैद्युत से पृथक दो चालक जो आवेश/ऊर्जा संचित करते हैं। C = Q/V; मात्रक फैरड = कूलॉम/वोल्ट।

प्र.2 समांतर प्लेट संधारित्र की धारिता व्युत्पन्न कीजिए। (5)

E = σ/ε₀ = Q/ε₀A, V = Ed = Qd/ε₀A, C = Q/V = ε₀A/d।

प्र.3 श्रेणी क्रम की तुल्य धारिता व्युत्पन्न कीजिए। (3)

समान Q। V = V₁ + V₂ + V₃ = Q(1/C₁ + 1/C₂ + 1/C₃) = Q/C, अतः 1/C = Σ1/Cᵢ।

प्र.4 समांतर क्रम की तुल्य धारिता व्युत्पन्न कीजिए। (3)

समान V। Q = Q₁ + Q₂ + Q₃ = (C₁ + C₂ + C₃)V = CV, अतः C = ΣCᵢ।

प्र.5 संधारित्र में संचित ऊर्जा व्युत्पन्न कीजिए। (3)

dW = (q/C)dq, W = ∫₀^Q q dq/C = Q²/2C = ½CV² = ½QV।

प्र.6 वैद्युत क्षेत्र का ऊर्जा घनत्व व्युत्पन्न कीजिए। (3)

U = ½CV² = ½(ε₀A/d)(Ed)² = ½ε₀E²(Ad)। u = U/Ad = ½ε₀E²।

प्र.7 बैटरी हटाने पर परावैद्युत पट्टिका का C, V, E, U पर प्रभाव समझाइए। (5)

Q नियत। C′ = KC₀। V′ = Q/C′ = V₀/K। E′ = E₀/K। U′ = Q²/2C′ = U₀/K (घटती है)।

प्र.8 संधारित्र में मोटाई t की पट्टिका रखने पर C व्युत्पन्न कीजिए। (5)

खंड 6(a) देखें: V = E₀(d − t) + E₀t/K, C = ε₀A/(d − t + t/K)।

प्र.9 दो आवेशित संधारित्र जोड़ने पर ऊर्जा हानि क्यों होती है? (2)

विभव बराबर करने के लिए आवेश बहता है; धारा तारों को गर्म करती है व चिंगारी बनती है, अतः ΔU = C₁C₂(V₁ − V₂)²/2(C₁+C₂) > 0।

प्र.10 संधारित्र DC को रोकता व AC को पार क्यों होने देता है? (2)

DC में आवेशित होने के बाद धारा नहीं बहती (अंतराल विद्युतरोधी)। AC में यह लगातार आवेशित-विसर्जित होता है, अतः धारा बहती है।

हल सहित संख्यात्मक प्रश्न (सरल → कठिन)

सरल 1. संधारित्र 12 V पर 6 µC आवेश रखता है। C ज्ञात कीजिए।
C = Q/V = 6×10⁻⁶/12 = 0.5×10⁻⁶ F = 0.5 µF।
सरल 2. प्लेट क्षेत्रफल 0.01 m², अंतराल 1 mm, वायु। C ज्ञात कीजिए।
C = ε₀A/d = 8.85×10⁻¹² × 0.01 / 10⁻³ = 8.85×10⁻¹¹ F = 88.5 pF।
मध्यम 1. 2 µF, 3 µF, 6 µF (i) श्रेणी (ii) समांतर में।
(i) 1/C = 1/2 + 1/3 + 1/6 = (3+2+1)/6 = 1, अतः C = 1 µF। (ii) C = 2 + 3 + 6 = 11 µF।
मध्यम 2. 100 V पर 10 µF में संचित ऊर्जा।
U = ½CV² = ½ × 10×10⁻⁶ × 10⁴ = 0.05 J।
मध्यम 3. 200 V पर आवेशित 4 µF को अनावेशित 6 µF से जोड़ा। उभयनिष्ठ V व ऊर्जा हानि।
V = C₁V₁/(C₁+C₂) = 4×200/10 = 80 V। U_i = ½×4×10⁻⁶×4×10⁴ = 0.08 J। U_f = ½×10×10⁻⁶×6400 = 0.032 J। हानि = 0.048 J।
कठिन 1. C₀ = 10 pF। K = 5, t = d/2 की पट्टिका रखी। नई C ज्ञात कीजिए।
d − t + t/K = d/2 + d/10 = 0.6d। C = ε₀A/0.6d = C₀/0.6 = 16.7 pF।
कठिन 2. 100 V पर आवेशित 5 µF, बैटरी हटाकर K = 4 परावैद्युत पूरा भरा। V व ऊर्जा परिवर्तन।
C′ = 20 µF। Q = 500 µC नियत, V′ = 500/20 = 25 V। U₀ = ½×5×10⁻⁶×10⁴ = 0.025 J। U′ = ½×20×10⁻⁶×625 = 0.00625 J। कमी 0.01875 J (पट्टिका खिंचती है)।
कठिन 3. 2 µF, 3 µF व 6 µF की श्रेणी जोड़ी के समांतर है। 12 V से जुड़ा। प्रत्येक पर आवेश ज्ञात कीजिए।
श्रेणी जोड़ी: 3×6/9 = 2 µF। कुल = 2 + 2 = 4 µF। Q_कुल = 4×12 = 48 µC। शाखा 1 (2 µF): 24 µC। शाखा 2: 2×12 = 24 µC, 3 µF व 6 µF दोनों पर। V(3 µF) = 24/3 = 8 V; V(6 µF) = 24/6 = 4 V (कुल 12 V)।
कठिन 4. E = 10⁵ N/C पर ऊर्जा घनत्व।
u = ½ε₀E² = 0.5 × 8.85×10⁻¹² × 10¹⁰ = 4.4×10⁻² J/m³।
