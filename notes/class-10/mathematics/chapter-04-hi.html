कक्षा 10 गणित – अध्याय 4: द्विघात समीकरण

1. द्विघात समीकरण

मानक रूप: ax² + bx + c = 0, जहाँ a, b, c वास्तविक संख्याएँ हैं और a ≠ 0। घात 2 है, इसलिए अधिकतम 2 मूल होते हैं।
जैसे 2x² − 3x + 1 = 0। द्विघात नहीं: x³ + 2x = 5 (घात 3), 3x + 2 = 0 (घात 1)।
कुछ समीकरण सरल करने पर द्विघात बनते हैं: (x+1)² = 2(x−3) ⇒ x² + 7 = 0।
मूल: α समीकरण ax² + bx + c = 0 का मूल है यदि aα² + bα + c = 0। जैसे x² − 5x + 6 में x = 2: 4 − 10 + 6 = 0 ✓।

2. गुणनखंड विधि से हल

चरण: (1) मानक रूप में लिखें। (2) मध्य पद b को दो संख्याओं में तोड़ें जिनका योग = b और गुणनफल = ac। (3) गुणनखंड करें। (4) प्रत्येक गुणनखंड = 0 रखें।
उदाहरण: 6x² − x − 2 = 0। ac = −12; −x = 3x − 4x। 6x² + 3x − 4x − 2 = 3x(2x + 1) − 2(2x + 1) = (3x − 2)(2x + 1)। x = 2/3 या x = −1/2।

y = x² − 5x + 6 का परवलय x-अक्ष को x = 2 और x = 3 पर काटता है। यही x² − 5x + 6 = 0 के मूल हैं। निम्नतम बिंदु (शीर्ष) दोनों मूलों के बीच x = 2.5 पर है।

3. पूर्ण वर्ग बनाने की विधि

चित्र देखिए: x² + 6x एक वर्ग और 3×x की दो पट्टियाँ है। खाली कोना 3×3 = 9 का है। 9 जोड़ने पर पूर्ण वर्ग (x + 3)² बन जाता है। यही इस विधि का आधार है।

चरण: a से भाग दें; अचर पद दाएँ पक्ष में ले जाएँ; दोनों ओर (x के गुणांक का आधा)² जोड़ें; बाएँ पक्ष को वर्ग लिखें; वर्गमूल लें।
उदाहरण: 2x² − 7x + 3 = 0 ⇒ x² − (7/2)x = −3/2 ⇒ (x − 7/4)² = −3/2 + 49/16 = 25/16 ⇒ x − 7/4 = ± 5/4 ⇒ x = 3 या 1/2।

4. द्विघाती सूत्र

x = (−b ± √(b² − 4ac)) / 2a, जब b² − 4ac ≥ 0।
विविक्तकर D = b² − 4ac।
मूलों का योग = −b/a; मूलों का गुणनफल = c/a।

उदाहरण: 2x² − 7x + 3 = 0: D = 49 − 24 = 25, x = (7 ± 5)/4 = 3 या 1/2 ✓।

मूलों की प्रकृति

विविक्तकरमूल
D > 0दो भिन्न वास्तविक मूल
D = 0दो समान वास्तविक मूल, x = −b/2a
D < 0कोई वास्तविक मूल नहीं

5. शाब्दिक प्रश्न

  • अज्ञात को x मानें; कथन से द्विघात समीकरण बनाएँ।
  • हल करें; लंबाई, आयु, चाल, वस्तुओं की संख्या के लिए ऋणात्मक या असंभव मान अस्वीकार करें।
  • प्रकार: क्रमागत पूर्णांक (x, x+1), दिए योग/गुणनफल वाली संख्याएँ, क्षेत्रफल व पाइथागोरस, चाल–समय (समय = दूरी/चाल), कार्य, आयु।

प्रश्नोत्तर – अभ्यास

बहुविकल्पीय प्रश्न (NCERT / बालाजी / राजीव / यूपी बोर्ड शैली)

द्विघात समीकरण कौन-सा है? (a) x³ + 2x = 5 (b) x² − 3x + 1 = 0 (c) 3x + 2 = 0 (d) 2x = 5
(b)। सबसे बड़ी घात 2 है।
x² − 5x + 6 = 0 के मूल हैं (a) 1, 6 (b) −2, −3 (c) 2, 3 (d) −1, −6
(c) 2, 3: (x−2)(x−3) = 0।
2x² − 4x + 3 = 0 का विविक्तकर है (a) 8 (b) −8 (c) 40 (d) −40
(b) −8: 16 − 24।
x² + 4 = 0 के (a) दो वास्तविक मूल (b) एक वास्तविक मूल (c) कोई वास्तविक मूल नहीं (d) अनंत मूल
(c) कोई वास्तविक मूल नहीं; D = −16 < 0।
यदि 2, x² − 5x + k = 0 का मूल है तो k = (a) 3 (b) 4 (c) 6 (d) 10
(c) 6: 4 − 10 + k = 0।
2x² − 7x + 3 = 0 के मूलों का योग है (a) 7/2 (b) −7/2 (c) 3/2 (d) −3/2
(a) 7/2 = −b/a।
x² − kx + 9 = 0 के मूल समान होंगे यदि k = (a) 3 (b) ±3 (c) 6 (d) ±6
(d) ±6: k² − 36 = 0।

लघु उत्तरीय प्रश्न

x² − 3x − 10 = 0 हल कीजिए।
(x − 5)(x + 2) = 0 ⇒ x = 5, −2।
2x² − 6x + 3 = 0 के मूलों की प्रकृति ज्ञात कीजिए और मूल निकालिए।
D = 36 − 24 = 12 > 0 ⇒ दो भिन्न वास्तविक मूल। x = (6 ± √12)/4 = (3 ± √3)/2।
k का मान ज्ञात कीजिए ताकि kx(x − 2) + 6 = 0 के मूल समान हों।
kx² − 2kx + 6 = 0; D = 4k² − 24k = 0 ⇒ 4k(k − 6) = 0। k ≠ 0, अतः k = 6।
दो क्रमागत धनात्मक पूर्णांकों का गुणनफल 306 है। उन्हें ज्ञात कीजिए।
x(x+1) = 306 ⇒ x² + x − 306 = 0 ⇒ (x + 18)(x − 17) = 0 ⇒ x = 17 (−18 अस्वीकार)। 17 और 18।
द्विघाती सूत्र से 3x² − 5x + 2 = 0 हल कीजिए।
D = 25 − 24 = 1; x = (5 ± 1)/6 ⇒ x = 1 या 2/3।

दीर्घ उत्तरीय प्रश्न

पूर्ण वर्ग विधि से 2x² − 7x + 3 = 0 हल कीजिए।
2 से भाग: x² − (7/2)x + 3/2 = 0। अचर पद दाएँ: x² − (7/2)x = −3/2। (7/4)² = 49/16 जोड़ने पर: (x − 7/4)² = 49/16 − 24/16 = 25/16। वर्गमूल: x − 7/4 = ±5/4। x = 3 या x = 1/2।
दो संख्याएँ ज्ञात कीजिए जिनका योग 27 और गुणनफल 182 है।
संख्याएँ x और 27 − x: x(27 − x) = 182 ⇒ x² − 27x + 182 = 0। D = 729 − 728 = 1; x = (27 ± 1)/2 = 14 या 13। संख्याएँ: 13 और 14।
एक रेलगाड़ी 360 km एकसमान चाल से चलती है। यदि चाल 5 km/h अधिक होती तो उसे 1 घंटा कम लगता। चाल ज्ञात कीजिए।
चाल x: 360/x − 360/(x+5) = 1 ⇒ 1800 = x(x + 5) ⇒ x² + 5x − 1800 = 0। D = 7225 = 85²; x = (−5 + 85)/2 = 40 (ऋणात्मक अस्वीकार)। चाल = 40 km/h। जाँच: 9 घंटे बनाम 8 घंटे ✓।
समकोण त्रिभुज का शीर्षलंब उसके आधार से 7 cm कम है। यदि कर्ण 13 cm है तो अन्य दो भुजाएँ ज्ञात कीजिए।
आधार x, शीर्षलंब x − 7: x² + (x − 7)² = 169 ⇒ x² − 7x − 60 = 0 ⇒ (x − 12)(x + 5) = 0 ⇒ x = 12। आधार 12 cm, शीर्षलंब 5 cm (5-12-13 ✓)।
k का मान ज्ञात कीजिए जिसके लिए kx² + kx + 1 = 0 के मूल समान हों।
D = k² − 4k = 0 ⇒ k(k − 4) = 0। k = 0 पर 1 = 0, द्विघात नहीं रहता, अतः k = 4।
