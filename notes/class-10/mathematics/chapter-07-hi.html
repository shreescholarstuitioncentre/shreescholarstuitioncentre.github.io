कक्षा 10 गणित – अध्याय 7: निर्देशांक ज्यामिति

1. कार्तीय तल – पुनरावृत्ति

दो लंबवत संख्या रेखाएँ मूलबिंदु O(0, 0) पर मिलती हैं: क्षैतिज x-अक्ष, ऊर्ध्वाधर y-अक्ष। बिंदु P(x, y): x = भुज (y-अक्ष से दूरी), y = कोटि (x-अक्ष से दूरी)।
चतुर्थांश: I (+,+), II (−,+), III (−,−), IV (+,−)। x-अक्ष पर बिंदु (x, 0); y-अक्ष पर (0, y)।

2. दूरी सूत्र

d = √[(x₂ − x₁)² + (y₂ − y₁)²]
P(x, y) की मूलबिंदु से दूरी = √(x² + y²)।

देखिए: रेखाखंड AB एक समकोण त्रिभुज का कर्ण है जिसकी भुजाएँ 4 (क्षैतिज) और 3 (ऊर्ध्वाधर) हैं। पाइथागोरस से AB = √(16 + 9) = 5। दूरी सूत्र ग्राफ पर पाइथागोरस ही है।

दूरी सूत्र के उपयोग

  • संरेख: तीन बिंदु संरेख हैं यदि दो दूरियों का योग तीसरी के बराबर हो।
  • समद्विबाहु: दो भुजाएँ बराबर। समबाहु: तीनों भुजाएँ बराबर। समकोण: दो भुजाओं के वर्गों का योग तीसरी के वर्ग के बराबर।
  • वर्ग: चारों भुजाएँ और विकर्ण बराबर। समचतुर्भुज: चारों भुजाएँ बराबर, विकर्ण असमान। आयत: सम्मुख भुजाएँ और विकर्ण बराबर। समांतर चतुर्भुज: सम्मुख भुजाएँ बराबर (विकर्ण एक-दूसरे को समद्विभाजित करते हैं)।
  • समदूरस्थ बिंदु: P, A और B से समदूरस्थ हो तो PA² = PB² रखें (वर्गमूल की ज़रूरत नहीं)।

3. विभाजन सूत्र

A(x₁, y₁) और B(x₂, y₂) को m : n में अंतःविभाजित करने वाला बिंदु P (AP : PB = m : n):
P = ( (mx₂ + nx₁)/(m + n) , (my₂ + ny₁)/(m + n) )
मध्य-बिंदु (m = n): ( (x₁ + x₂)/2 , (y₁ + y₂)/2 )
केंद्रक (त्रिभुज का): ( (x₁ + x₂ + x₃)/3 , (y₁ + y₂ + y₃)/3 )

A(1,1) और B(7,4) में AP : PB = 1 : 2 लेने पर P = ((7 + 2)/3, (4 + 2)/3) = (3, 2)। मध्य-बिंदु M = (4, 2.5) AB पर और आगे है।

अनुपात ज्ञात करना: अनुपात k : 1 मानें, विभाजन सूत्र लगाएँ और निर्देशांक बराबर रखें (y-अक्ष के लिए x = 0, x-अक्ष के लिए y = 0)। k ऋणात्मक हो तो बहिर्विभाजन।

4. त्रिभुज का क्षेत्रफल

क्षेत्रफल = ½ |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)|
तीन बिंदु संरेख हैं यदि यह क्षेत्रफल = 0।

A(2,1), B(6,1), C(4,5) के लिए आधार AB = 4, ऊँचाई 4, अतः क्षेत्रफल = ½ × 4 × 4 = 8। सूत्र से: ½|2(1−5) + 6(5−1) + 4(1−1)| = ½ × 16 = 8 ✓। (त्रिभुज का क्षेत्रफल यूपी बोर्ड और पुराने NCERT पाठ्यक्रम में है; CBSE में यह हटा दिया गया है, अपना पाठ्यक्रम देख लें।)

लघु उत्तरीय प्रश्न

क्या (1, 5), (2, 3), (−2, −11) संरेख हैं?
AB = √5, BC = √212, AC = √265। √5 + √212 ≠ √265 ⇒ संरेख नहीं।
यदि (2, −3) और (10, y) के बीच की दूरी 10 है तो y ज्ञात कीजिए।
64 + (y + 3)² = 100 ⇒ (y + 3)² = 36 ⇒ y + 3 = ±6 ⇒ y = 3 या −9।
(−1, 7) और (4, −3) को 2 : 3 में विभाजित करने वाला बिंदु ज्ञात कीजिए।
x = (2·4 + 3·(−1))/5 = 1; y = (2·(−3) + 3·7)/5 = 3 ⇒ (1, 3)।
(−4, −6) और (10, 8) को y-अक्ष किस अनुपात में बाँटता है?
x = 0: (10m − 4n)/(m + n) = 0 ⇒ m : n = 2 : 5। बिंदु: y = (16 − 30)/7 = −2 ⇒ (0, −2)।
दिखाइए कि (0, 0), (4, 0), (2, 2√3) समबाहु त्रिभुज बनाते हैं।

दीर्घ उत्तरीय प्रश्न

दिखाइए कि (1, 7), (4, 2), (−1, −1), (−4, 4) एक वर्ग के शीर्ष हैं।
AB = √(9 + 25) = √34; BC = √(25 + 9) = √34; CD = √(9 + 25) = √34; DA = √(25 + 9) = √34। विकर्ण AC = √(4 + 64) = √68, BD = √(64 + 4) = √68। चारों भुजाएँ बराबर और विकर्ण बराबर ⇒ वर्ग।
x-अक्ष पर वह बिंदु ज्ञात कीजिए जो (2, −5) और (−2, 9) से समदूरस्थ हो।
मानो P(x, 0)। PA² = PB²: (x − 2)² + 25 = (x + 2)² + 81 ⇒ −4x + 29 = 4x + 85 ⇒ −8x = 56 ⇒ x = −7। P = (−7, 0)।
A(1, −5), B(−4, 5) को x-अक्ष किस अनुपात में बाँटता है? बिंदु भी ज्ञात कीजिए।
अनुपात k : 1, y = 0: (5k − 5)/(k + 1) = 0 ⇒ k = 1। अनुपात 1 : 1; बिंदु = (−3/2, 0) (मध्य-बिंदु)।
शीर्षों (1, −1), (−4, 6), (−3, −5) वाले त्रिभुज का क्षेत्रफल ज्ञात कीजिए।
½|1(6 + 5) + (−4)(−5 + 1) + (−3)(−1 − 6)| = ½|11 + 16 + 21| = 24 वर्ग इकाई।
k के किस मान के लिए (7, −2), (5, 1), (3, k) संरेख हैं?
क्षेत्रफल = 0: 7(1 − k) + 5(k + 2) + 3(−2 − 1) = 0 ⇒ 8 − 2k = 0 ⇒ k = 4।
