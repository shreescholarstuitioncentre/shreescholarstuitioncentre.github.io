Class 10 Maths – Ch 5: Arithmetic Progressions

1. What is an Arithmetic Progression (AP)?

A list of numbers in which each term is obtained by adding a fixed number d (common difference) to the previous term.
General form: a, a + d, a + 2d, a + 3d, …
a = first term, d = common difference = a₂ − a₁ = a₃ − a₂ …

See the bars grow by +3 each time: 2, 5, 8, 11, 14. So a = 2 and d = 3.

  • d > 0: terms increase (2, 5, 8 …). d < 0: terms decrease (10, 7, 4 …). d = 0: all terms equal (5, 5, 5 …).
  • Finite AP has last term; infinite AP goes on forever.
  • Test: a list is an AP if aₖ₊₁ − aₖ is the same for all k. Eg 1, 4, 9, 16 is NOT an AP (differences 3, 5, 7).

2. nth Term of an AP

aₙ = a + (n − 1)d
nth term from the end: l − (n − 1)d, where l is the last term.
Number of terms: n = (l − a)/d + 1.

The points (1,2), (2,5), (3,8) … lie on one straight line. Its slope is d. That is why the nth term is a linear expression in n.

Example 1: 10th term of 2, 7, 12, …: a = 2, d = 5, a₁₀ = 2 + 9×5 = 47.
Example 2: Which term of 3, 8, 13, … is 78? 3 + (n − 1)5 = 78 ⇒ n = 16.

3. Sum of First n Terms

Sₙ = (n/2)[2a + (n − 1)d]
If last term l is known: Sₙ = (n/2)(a + l)
aₙ = Sₙ − Sₙ₋₁
Sum of first n natural numbers = n(n + 1)/2; sum of first n odd numbers = n².

Gauss's trick: write 1 to 10 and join the first with the last, the second with the second-last … Every pair sums to 11 and there are 5 pairs, so the sum is 55. This is exactly (n/2)(a + l).

Example: Sum of first 22 terms of 8, 3, −2, …: a = 8, d = −5. S₂₂ = 11[16 + 21(−5)] = 11(−89) = −979.

4. Handy Tricks

  • Three terms in AP: a − d, a, a + d (sum = 3a).
  • Four terms: a − 3d, a − d, a + d, a + 3d.
  • Three numbers a, b, c are in AP ⇔ 2b = a + c (b is the arithmetic mean).

Q & A – Practice

MCQs (NCERT / Balaji / Rajeev / UP Board style)

Common difference of 2, 5, 8, 11 … is (a) 2 (b) 3 (c) −3 (d) 5
(b) 3.
The 10th term of an AP with a = 5, d = 3 is (a) 30 (b) 32 (c) 35 (d) 38
(b) 32: 5 + 9×3.
30th term of 10, 7, 4, … is (a) 97 (b) 77 (c) −77 (d) −87
(c) −77: 10 + 29(−3).
Sum of first 10 natural numbers is (a) 45 (b) 50 (c) 55 (d) 100
(c) 55: 10×11/2.
If k, 2k − 1, 2k + 1 are in AP then k = (a) 2 (b) 3 (c) 4 (d) 5
(b) 3: (2k − 1) − k = 2 ⇒ k − 1 = 2.
Number of terms in 7, 13, 19, …, 205 is (a) 33 (b) 34 (c) 35 (d) 36
(b) 34: (205 − 7)/6 + 1.
If aₙ = 3n + 7, common difference is (a) 7 (b) 3 (c) 10 (d) 4
(b) 3: coefficient of n.

Short Answer

Is 3, 6, 12, 24 an AP?
a₂ − a₁ = 3, a₃ − a₂ = 6, not equal ⇒ not an AP (it is a GP).
Find the 11th term of 3, 8, 13, 18, …
a = 3, d = 5: 3 + 10×5 = 53.
Find the sum of first 20 terms of 7, 10, 13, …
S₂₀ = 10[14 + 19×3] = 10×71 = 710.
In an AP a₃ = 16 and a₇ − a₅ = 12. Find the AP.
a₇ − a₅ = 2d = 12 ⇒ d = 6; a + 2d = 16 ⇒ a = 4. AP: 4, 10, 16, 22, …
Find the sum of first 15 multiples of 8.
8, 16, …, 120: S = (15/2)(8 + 120) = 15×64 = 960.

Long Answer

Find the sum of first 22 terms of the AP 8, 3, −2, …
a = 8, d = −5, n = 22. S = (22/2)[2(8) + 21(−5)] = 11(16 − 105) = −979.
The sum of first 14 terms of an AP is 1050 and its first term is 10. Find the 20th term.
S₁₄ = 7[20 + 13d] = 1050 ⇒ 20 + 13d = 150 ⇒ d = 10. a₂₀ = 10 + 19×10 = 200.
Find the sum of all 3-digit natural numbers divisible by 7.
105, 112, …, 994. n = (994 − 105)/7 + 1 = 128. S = (128/2)(105 + 994) = 64×1099 = 70336.
How many terms of 9, 17, 25, … must be taken to give a sum of 636?
(n/2)[18 + 8(n − 1)] = 636 ⇒ n(4n + 5) = 636 ⇒ 4n² + 5n − 636 = 0 ⇒ n = (−5 + 101)/8 = 12 (reject negative).
Three numbers in AP have sum 15 and product 80. Find them.
Let a − d, a, a + d: 3a = 15 ⇒ a = 5. (5 − d)(5)(5 + d) = 80 ⇒ 25 − d² = 16 ⇒ d = ±3. Numbers: 2, 5, 8 (or 8, 5, 2).
