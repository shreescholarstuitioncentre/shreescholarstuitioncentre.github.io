अध्याय 4: स्ट्रक्चर और यूनियन

यूज़र-डिफ़ाइंड डेटा टाइप  |  कंप्यूटर एप्लीकेशन, कक्षा 10

1. स्ट्रक्चर क्यों?

ऐरे में कई मान एक ही टाइप के होते हैं। पर असली चीज़ (जैसे छात्र) में अलग-अलग टाइप का डेटा होता है: roll (int), name (char), marks (float)।

स्ट्रक्चर: एक यूज़र-डिफ़ाइंड डेटा टाइप जो अलग-अलग डेटा टाइप के वेरिएबल को एक नाम के नीचे समूहित करता है। अंदर के हर वेरिएबल को सदस्य (member) कहते हैं।

2. स्ट्रक्चर बनाना और प्रयोग करना

  • कीवर्ड: struct। घोषणा के अंत में semicolon ज़रूरी है।
  • वेरिएबल बनाना: struct student s1, s2;
  • सदस्य तक पहुँचने के लिए डॉट (.) ऑपरेटर: s1.roll
  • मान देते समय braces में सदस्यों के क्रम में ही लिखें।
  • स्ट्रक्चर की मेमोरी = सभी सदस्यों का योग (हर सदस्य की अपनी अलग जगह)।
struct student {
    int roll;
    char name[10];
    float marks;
};                       // semicolon is a must

int main() {
    struct student s1 = {1, "Amit", 85.5};
    printf("%d %s %.1f", s1.roll, s1.name, s1.marks);
    s1.marks = 90.0;      // dot operator
    return 0;
}
चित्र 1: struct student का मेमोरी लेआउट (एनिमेशन) – संख्याएँ byte offset हैं

कुल = 4 + 10 + 4 = 18 बाइट (कंपाइलर अतिरिक्त padding बाइट जोड़ सकता है)। सदस्य एक के बाद एक रखे जाते हैं।

3. ऐरे, नेस्टेड स्ट्रक्चर और पॉइंटर

क. स्ट्रक्चर का ऐरे

कई छात्रों का रिकॉर्ड रखने के लिए। s[i].marks = i-वें छात्र के अंक।

struct student s[3];
for (i = 0; i < 3; i++)
    scanf("%d %s %f", &s[i].roll, s[i].name, &s[i].marks);

ख. नेस्टेड स्ट्रक्चर

एक स्ट्रक्चर के अंदर दूसरा स्ट्रक्चर; हर स्तर के लिए एक डॉट।

struct date { int d, m, y; };
struct emp { int id; struct date dob; } e;
e.dob.y = 2008;   // two dots

ग. स्ट्रक्चर का पॉइंटर

पॉइंटर के साथ एरो (->) ऑपरेटर प्रयोग होता है।

struct student *p = &s1;
printf("%d", p->roll);   // same as (*p).roll

4. यूनियन

यूनियन: स्ट्रक्चर जैसा ही, पर इसके सभी सदस्य एक ही मेमोरी साझा करते हैं। कीवर्ड: union।
  • यूनियन का आकार = सबसे बड़े सदस्य का आकार।
  • एक समय में केवल एक सदस्य में सही मान होता है।
  • नया मान रखने पर पुराना मान मिट जाता है।
  • मेमोरी बचाने के लिए प्रयोग होता है।
union data {
    int i;
    float f;
    char c;
};
union data u;
u.i = 10;
u.f = 5.5;                // overwrites u.i
printf("%d", sizeof(u)); // 4 (largest member)
000बाइट 0
100बाइट 1
200बाइट 2
300बाइट 3
चित्र 2: union data {int i; float f; char c;} – 4 बाइट का एक ही ब्लॉक (एनिमेशन)। बटन दबाकर बाइट (hex) देखें।

f = 5.5 रखने के बाद i पढ़ने पर बेकार संख्या मिलती है, क्योंकि वही बाइट int की तरह पढ़े जाते हैं। इसीलिए केवल आख़िरी रखा गया सदस्य ही सही होता है।

6. याद रखें

  • स्ट्रक्चर = अलग डेटा टाइप एक नाम में; पहुँच . से (पॉइंटर में ->)।
  • बंद braces के बाद ; न भूलें।
  • struct का आकार = योग; union का आकार = सबसे बड़ा सदस्य।
  • यूनियन में नया मान पुराने को मिटा देता है।
