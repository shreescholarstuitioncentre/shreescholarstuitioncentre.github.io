1Function क्या है?

Function statements का एक नाम वाला, अपने-आप में पूरा block है जो एक खास काम करता है। इसे हम एक बार लिखते हैं और program में कहीं से भी, जितनी बार चाहें call (बुला) सकते हैं।

रोज़ का उदाहरण: मिक्सर-ग्राइंडर। आप फल डालते हैं (input), वह अंदर काम करता है (process) और जूस देता है (output)। हर बार जूस के लिए नया मिक्सर नहीं बनाना पड़ता।

C program कई functions का समूह होता है। main() पहला function है और हर C program का execution हमेशा main() से ही शुरू होता है।

याद रखो!Function = Input + Process + Output। कोई function बिना input या बिना output का भी हो सकता है।

2Functions क्यों use करते हैं?

  • Modularity: बड़े program को छोटे, आसान हिस्सों में बाँटना।
  • Reusability: एक बार लिखो, कई बार use करो। copy-paste नहीं।
  • कम code: बार-बार आने वाले statements सिर्फ़ एक बार लिखने पड़ते हैं।
  • आसान debugging: error पूरे program में नहीं, एक छोटे function में ढूँढनी पड़ती है।
  • पढ़ने में आसान और teamwork: अलग-अलग programmers अलग-अलग functions लिख सकते हैं।

4User-defined function के हिस्से

User-defined function के तीन हिस्से होते हैं:

हिस्सामतलबउदाहरण
Declaration (prototype)Compiler को नाम, return type और parameters बताता है। अंत में ; आता हैint add(int, int);
DefinitionFunction का असली code (header + body)। Header के बाद ; नहीं लगता।int add(int a, int b){...}
Callmain() या किसी दूसरे function से function को use करना।add(x, y);

सामान्य syntax

return_type function_name(parameter_list)
{
    // statements (body)
    return value;
}

पूरा program

#include <stdio.h>
int add(int a, int b);        // 1. Declaration (prototype)

int main()
{
    int x = 5, y = 3, result;
    result = add(x, y);       // 3. Function call (बुलाना)
    printf("Sum = %d", result);
    return 0;
}

int add(int a, int b)         // 2. Definition (परिभाषा)
{
    int sum = a + b;
    return sum;
}
Output:Sum = 8
Prototype क्यों?Compiler ऊपर से नीचे पढ़ता है। अगर main() में add() को call किया गया है और add() बाद में define हुआ है, तो compiler को पहले से add() के बारे में पता होना चाहिए। यही prototype का काम है। अगर function main() के ऊपर define हो तो prototype ज़रूरी नहीं।

6return statement

  • return एक value को call करने वाले function में वापस भेजता है और function को तुरंत खत्म कर देता है।
  • एक function सिर्फ़ एक value return कर सकता है।
  • Return की गई value, function के return type (int, float, char ...) से मेल खानी चाहिए।
  • अगर function कुछ return नहीं करता तो return type void होता है और हम सिर्फ़ return; लिख सकते हैं या कुछ नहीं।
  • return के बाद लिखे statements कभी नहीं चलते।
  • main(), operating system को 0 return करता है, मतलब "program सफलतापूर्वक खत्म हुआ"।

8Call by value और Call by reference

Function को values भेजने के दो तरीके हैं।

(a) Call by value

Actual value की copy भेजी जाती है। Formal parameters में किए गए बदलाव original variables पर असर नहीं डालते। C में यही default तरीका है।

#include <stdio.h>
void swap(int a, int b)      // a, b सिर्फ़ COPY हैं
{
    int t = a;
    a = b;
    b = t;
}
int main()
{
    int x = 10, y = 20;
    swap(x, y);
    printf("%d %d", x, y);
    return 0;
}
Output:10 20

(b) Call by reference (जानकारी के लिए)

Variable का address (& से) भेजा जाता है और function उसे pointer (* से) में लेता है। इसलिए function original variable को बदल सकता है।

void swap(int *a, int *b)    // a, b में ADDRESS आते हैं
{
    int t = *a;
    *a = *b;
    *b = t;
}
// call: swap(&x, &y);   -> x = 20, y = 10
Call by valueCall by reference
Value की copy जाती हैAddress जाता है
Original नहीं बदलताOriginal बदल सकता है
सामान्य variablesPointers (* और &)

9Recursion

Recursion वह technique है जिसमें function खुद को ही call करता है और बड़ी problem को उसी तरह की छोटी problems में तोड़कर हल करता है।

हर recursive function में दो चीज़ें ज़रूरी हैं:

  • Base case: वह शर्त जहाँ function खुद को call करना बंद कर देता है।
  • Recursive case: वह हिस्सा जहाँ function छोटी value के साथ खुद को call करता है।

Recursion से factorial

n! = n x (n-1)! और 1! = 1

#include <stdio.h>
int fact(int n)
{
    if (n <= 1)                   // base case (रुकने की शर्त)
        return 1;
    else
        return n * fact(n - 1);   // recursive call (खुद को call)
}
int main()
{
    printf("%d", fact(3));
    return 0;
}
Output:6
फ़ायदेनुकसान
Code छोटा और साफ़ज़्यादा memory (stack) लगती है
factorial, Fibonacci जैसी problems के लिए स्वाभाविकLoops से धीमा
Base case न हो तो अनंत calls और stack overflow

10Variables का scope

Scope का मतलब है program का वह हिस्सा जहाँ variable को use किया जा सकता है।

Local variableGlobal variable
Function के अंदर declare होता हैसभी functions के बाहर declare होता है
सिर्फ़ उसी function में use होता हैहर function में use होता है
Function शुरू होने पर बनता है, खत्म होने पर नष्टProgram खत्म होने तक रहता है
#include <stdio.h>
int g = 100;                // global variable
void show(void)
{
    int y = 9;              // show() का local
    printf("%d %d", g, y);
}
int main()
{
    int x = 5;              // main() का local
    show();
    printf(" %d %d", g, x); // OK
    // printf("%d", y);     // ERROR: y यहाँ नहीं दिखता
    return 0;
}
Output:100 9 100 5
याद रखो!दो अलग functions में एक ही variable नाम हो सकता है, क्योंकि हर local variable अलग होता है।

12आम गलतियाँ

  • Prototype के बाद ; भूल जाना।
  • Definition में function header के बाद ; लगा देना।
  • गलत संख्या या गलत type के arguments भेजना।
  • जिस function को value देनी है उसमें return न लिखना।
  • एक function को दूसरे function के अंदर define करना (C में allowed नहीं)।
  • Base case के बिना recursion।
  • Local variable को उसके function के बाहर use करना।
  • Call by value से original variable बदलने की उम्मीद करना।

14ज़रूरी प्रश्न और उत्तर

Q1. Function की परिभाषा लिखो।

Function statements का नाम वाला block है जो कोई खास काम करता है और जिसे कई बार call किया जा सकता है।

Q2. Functions के कोई दो फ़ायदे लिखो।

Code की reusability, और program modular तथा debug करने में आसान बन जाता है।

Q3. Actual और formal parameters में अंतर लिखो।

Actual parameters function call में होते हैं और असली values रखते हैं; formal parameters function definition में होते हैं और उन values की copy पाते हैं।

Q4. Function prototype का क्या उपयोग है?

यह function के call होने से पहले compiler को उसका नाम, return type और parameters बताता है।

Q5. Recursion क्या है? Base case क्या है?

Recursion यानी function का खुद को call करना। Base case वह शर्त है जो recursive calls को रोकती है।

Q6. void का क्या मतलब है?

इसका मतलब है "कुछ नहीं": function कोई value return नहीं करता (या brackets में लिखा हो तो कोई parameter नहीं लेता)।

Q7. Output बताओ।
int f(int x)
{
    return x * 2;
}
// printf("%d", f(f(3)));

Output 12 है। f(3) = 6, फिर f(6) = 12।

Q8. Call by value वाला swap(), x और y को क्यों नहीं बदलता?

क्योंकि a और b सिर्फ़ copies हैं। Function खत्म होते ही वे नष्ट हो जाते हैं, इसलिए x और y वैसे ही रहते हैं।
