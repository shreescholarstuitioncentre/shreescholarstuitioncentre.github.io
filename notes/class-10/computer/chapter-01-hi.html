C भाषा में फ़ंक्शन (Functions in C)

कक्षा 10 · कंप्यूटर विज्ञान · अध्याय 1 · हस्तलिखित शैली के पूरे नोट्स, एनिमेटेड चित्रों सहित

ध्यान दें: ये नोट्स कक्षा 10 की कंप्यूटर पुस्तकों में पढ़ाए जाने वाले C भाषा के “फ़ंक्शन” के सामान्य पाठ्यक्रम पर आधारित हैं। नीचे दिए गए प्रश्न बोर्ड परीक्षा के सामान्य पैटर्न पर बनाए गए अभ्यास प्रश्न हैं (ये NCERT, किसी प्रकाशक या UP Board के प्रश्न-पत्र से शब्दशः नहीं लिए गए हैं)। अपने उत्तर की शैली अपनी पाठ्य-पुस्तक और शिक्षक के अनुसार मिला लें।

1. परिचय: फ़ंक्शन क्या है?

परिभाषा: फ़ंक्शन स्टेटमेंट्स का एक नामयुक्त, स्वतंत्र समूह है जिसे एक विशेष कार्य करने के लिए लिखा जाता है। यह तभी चलता है जब इसे कॉल किया जाए, और इसे जितनी बार चाहें कॉल कर सकते हैं।

रोज़मर्रा के उदाहरण

  • मिक्सर-ग्राइंडर: आप फल डालते हैं (इनपुट), स्विच दबाते हैं (कॉल) और जूस मिलता है (आउटपुट)। हर बार मशीन नहीं बनानी पड़ती।
  • ATM: कार्ड और PIN अंदर जाते हैं (आर्गुमेंट), नकद बाहर आता है (return value)।
  • रेसिपी: एक बार लिखी जाती है और बार-बार इस्तेमाल होती है।

C प्रोग्राम में फ़ंक्शन

C प्रोग्राम फ़ंक्शनों का समूह होता है। हर प्रोग्राम में कम से कम एक फ़ंक्शन main() होता है। प्रोग्राम हमेशा main() से शुरू होता है और वहीं समाप्त होता है। बाकी फ़ंक्शन तभी चलते हैं जब उन्हें main() या किसी अन्य फ़ंक्शन से कॉल किया जाए।

फ़ंक्शन की आवश्यकता क्यों? (लाभ)

  1. मॉड्यूलैरिटी: बड़ी समस्या छोटे भागों में बँट जाती है। हर भाग एक फ़ंक्शन होता है।
  2. पुनः उपयोग (Reusability): एक बार लिखो, कई बार चलाओ। इससे प्रोग्राम का आकार घटता है।
  3. आसान डिबगिंग: त्रुटि हज़ारों लाइनों में नहीं, एक छोटे फ़ंक्शन में खोजनी पड़ती है।
  4. पठनीयता: प्रोग्राम पढ़ना और समझना आसान होता है।
  5. टीम वर्क: अलग-अलग प्रोग्रामर अलग-अलग फ़ंक्शन लिख सकते हैं।
  6. आसान रखरखाव: तर्क बदलना हो तो केवल एक जगह बदलना पड़ता है।
उदाहरण: मान लीजिए दो संख्याओं में बड़ी संख्या 5 अलग जगहों पर निकालनी है। फ़ंक्शन के बिना वही if-else 5 बार लिखना पड़ेगा। max() फ़ंक्शन बनाकर एक बार लिखें और 5 बार कॉल करें।

2. फ़ंक्शन के प्रकार: Library और User-defined

(अ) Library (बिल्ट-इन / पूर्व-परिभाषित) फ़ंक्शन

इन्हें C कंपाइलर बनाने वालों ने पहले से लिखकर हेडर फ़ाइलों में रखा होता है। इन्हें उपयोग करने के लिए प्रोग्राम के शुरू में #include <header-file> लिखते हैं। हमें केवल इन्हें कॉल करना होता है, इनका कोड नहीं लिखना पड़ता।

हेडर फ़ाइलफ़ंक्शनउपयोगउदाहरण → परिणाम

#include <stdio.h>
#include <math.h>
#include <string.h>
#include <ctype.h>

int main()
{
    printf("%.1f\n", sqrt(25));          // square root
    printf("%.0f\n", pow(2, 3));         // 2 raised to 3
    printf("%d\n", (int)strlen("India")); // length of string
    printf("%c\n", toupper('a'));        // lower to upper
    return 0;
}
5.0 8 5 A

(ब) User-defined फ़ंक्शन

ये वे फ़ंक्शन हैं जिन्हें प्रोग्रामर किसी विशेष समस्या को हल करने के लिए खुद लिखता है, जैसे add(), max(), factorial()। नाम, पैरामीटर और तर्क प्रोग्रामर तय करता है। इस अध्याय का अधिकांश भाग इन्हीं पर है।

याद रखें: main() भी एक फ़ंक्शन है, पर उसे प्रोग्रामर नहीं बल्कि ऑपरेटिंग सिस्टम कॉल करता है।

3. फ़ंक्शन के भाग: Declaration, Definition और Call

यूज़र-डिफ़ाइंड फ़ंक्शन उपयोग करने के लिए तीन चीज़ें चाहिए:

// Declaration (prototype) - ends with semicolon
return_type function_name(type param1, type param2);

// Definition
return_type function_name(type param1, type param2)
{
    // body: statements
    return value;      // if return_type is not void
}

// Call
variable = function_name(arg1, arg2);
भागक्या करता हैअंत में ;
Declaration (Prototype)फ़ंक्शन के प्रयोग से पहले कंपाइलर को नाम, return type और पैरामीटर के प्रकार बताता हैहाँ
Definitionफ़ंक्शन की असली बॉडी (कोड) होती हैनहीं (हेडर के बाद ; नहीं)
Callफ़ंक्शन को चलाने के लिए कहता हैहाँ (यह एक स्टेटमेंट है)

फ़ंक्शन लिखने के नियम

  • फ़ंक्शन का नाम identifier के नियमों से बनता है: अक्षर, अंक और underscore; अंक से शुरू नहीं हो सकता, keyword नहीं हो सकता, और C में बड़े-छोटे अक्षर अलग माने जाते हैं।
  • Prototype में पैरामीटर के नाम लिखना ज़रूरी नहीं: int add(int, int); सही है।
  • यदि फ़ंक्शन main() के ऊपर परिभाषित है तो अलग prototype अनिवार्य नहीं (पर लिखना अच्छी आदत है)।
  • कॉल में आर्गुमेंट की संख्या, क्रम और प्रकार परिभाषा के पैरामीटर से मेल खाने चाहिए।
  • C में एक फ़ंक्शन के अंदर दूसरा फ़ंक्शन परिभाषित नहीं किया जा सकता।

पूरा उदाहरण: दो संख्याओं का जोड़

#include <stdio.h>

int add(int a, int b);       // 1. declaration (prototype)

int main()
{
    int x = 5, y = 3, r;
    r = add(x, y);           // 2. function call
    printf("Sum = %d", r);
    return 0;
}

int add(int a, int b)        // 3. function definition
{
    int s = a + b;
    return s;
}
Sum = 8

पंक्ति-दर-पंक्ति व्याख्या

  1. int add(int a, int b); prototype: add दो int लेता है और एक int लौटाता है।
  2. r = add(x, y); आर्गुमेंट 5 और 3 के साथ फ़ंक्शन कॉल हुआ। लौटा हुआ मान 8, r में रखा गया।
  3. int add(int a, int b) { ... } परिभाषा: a को 5 और b को 3 मिला।
  4. return s; 8 को कॉल वाली जगह लौटा देता है।
सावधान: definition के हेडर के बाद semicolon न लगाएँ: int add(int a, int b); { ... } गलत है।

4. फ़ंक्शन कॉल कैसे काम करता है (चरण-दर-चरण)

  1. कॉल करने वाले फ़ंक्शन में function call स्टेटमेंट तक प्रोग्राम पहुँचता है।
  2. कंट्रोल बुलाए गए फ़ंक्शन में चला जाता है। आर्गुमेंट के मान formal parameters में कॉपी हो जाते हैं।
  3. फ़ंक्शन की बॉडी के स्टेटमेंट एक-एक करके चलते हैं।
  4. return स्टेटमेंट (या बंद होने वाला ब्रेस) आने पर कंट्रोल वापस कॉल करने वाले के पास जाता है। लौटा हुआ मान कॉल की जगह ले लेता है।
  5. कॉल करने वाला फ़ंक्शन कॉल के अगले स्टेटमेंट से आगे चलता है।
सुझाव: जब फ़ंक्शन कोई मान लौटाता है तो उसकी कॉल एक expression होती है। इसलिए r = add(x, y);, printf("%d", add(2, 3)); और add(add(1, 2), 3) सब सही हैं।

5. return स्टेटमेंट और रिटर्न टाइप

return: return स्टेटमेंट फ़ंक्शन का निष्पादन तुरंत रोक देता है और कंट्रोल (तथा चाहें तो एक मान) कॉल करने वाले फ़ंक्शन को लौटा देता है।
Return typeअर्थउदाहरण
intपूर्ण संख्या लौटाता हैint add(int a, int b)
float / doubleदशमलव संख्या लौटाता हैfloat area(float r)
charकैरेक्टर लौटाता हैchar grade(int m)
voidकुछ नहीं लौटाताvoid greet()

महत्वपूर्ण बातें

  • return द्वारा फ़ंक्शन केवल एक मान लौटा सकता है।
  • return के बाद लिखे स्टेटमेंट कभी नहीं चलते।
  • void फ़ंक्शन जल्दी बाहर निकलने के लिए return; (बिना मान) लिख सकता है, या return बिल्कुल न भी लिखे।
  • लौटाया गया मान return type के अनुसार होना चाहिए; नहीं तो वह उसी प्रकार में बदल जाता है (जैसे int फ़ंक्शन से 3.9 लौटाने पर 3 मिलता है)।
  • फ़ंक्शन में एक से अधिक return हो सकते हैं (जैसे if-else में), पर एक कॉल में उनमें से केवल एक चलता है।
  • main() में return 0; ऑपरेटिंग सिस्टम को बताता है कि प्रोग्राम सफलतापूर्वक समाप्त हुआ।

8. आर्गुमेंट भेजने की विधियाँ: Call by Value और Call by Reference

Call by Value

आर्गुमेंट की कॉपी फ़ंक्शन को दी जाती है। फ़ंक्शन कॉपी पर काम करता है, इसलिए मूल वेरिएबल कभी नहीं बदलता। C में यही सामान्य तरीका है।

#include <stdio.h>

void swap(int a, int b)        // a, b are COPIES
{
    int t = a;
    a = b;
    b = t;
}

int main()
{
    int x = 10, y = 20;
    swap(x, y);
    printf("x = %d, y = %d", x, y);
    return 0;
}
x = 10, y = 20

अदला-बदली केवल फ़ंक्शन के अंदर कॉपी a और b पर हुई। x और y नहीं बदले।

Call by Reference (पॉइंटर द्वारा)

वेरिएबल का पता (address) & द्वारा भेजा जाता है। फ़ंक्शन उसे पॉइंटर में लेता है और * ऑपरेटर से मूल वेरिएबल तक पहुँचता है। इसलिए मूल मान बदल सकता है।

#include <stdio.h>

void swap(int *a, int *b)      // a, b hold ADDRESSES
{
    int t = *a;
    *a = *b;
    *b = t;
}

int main()
{
    int x = 10, y = 20;
    swap(&x, &y);              // send addresses
    printf("x = %d, y = %d", x, y);
    return 0;
}
x = 20, y = 10

तकनीकी बात: सख़्ती से देखें तो C में केवल call by value होता है। “Call by reference” में address का मान भेजा जाता है। पुस्तकों में फिर भी यही नाम चलता है।
चिह्न: &x = x का पता। *p = p में रखे पते पर संग्रहित मान।

9. रिकर्शन (Recursion)

Recursion: जब कोई फ़ंक्शन स्वयं को कॉल करता है, सीधे या परोक्ष रूप से, तो उसे recursive function और इस प्रक्रिया को recursion कहते हैं।

हर सही recursive फ़ंक्शन के दो भाग होते हैं:

  • Base case: वह शर्त जहाँ फ़ंक्शन रुक जाता है और स्वयं को दोबारा कॉल नहीं करता।
  • Recursive case: वह भाग जहाँ फ़ंक्शन छोटी समस्या के साथ स्वयं को कॉल करता है।
#include <stdio.h>

int fact(int n)
{
    if (n <= 1)              // base case
        return 1;
    return n * fact(n - 1);  // recursive case
}

int main()
{
    printf("Factorial of 3 = %d", fact(3));
    return 0;
}
Factorial of 3 = 6

याद रखें: n! = n × (n−1)! और 0! = 1! = 1।

11. फ़ंक्शन को Array भेजना

Array भेजने के लिए कॉल में केवल उसका नाम लिखते हैं। Array का नाम उसके पहले तत्व का address होता है, इसलिए फ़ंक्शन मूल array पर काम करता है (कॉपी पर नहीं)। फ़ंक्शन में किए गए बदलाव कॉल करने वाले में भी दिखते हैं। आमतौर पर आकार (size) भी भेजते हैं।

#include <stdio.h>

int sum(int arr[], int n)      // array + its size
{
    int i, s = 0;
    for (i = 0; i < n; i++)
        s = s + arr[i];
    return s;
}

int main()
{
    int marks[5] = {1, 2, 3, 4, 5};
    printf("Total = %d", sum(marks, 5));
    return 0;
}
Total = 15
  • हेडर का रूप: int sum(int arr[], int n) (या int *arr)।
  • कॉल का रूप: sum(marks, 5) (ब्रैकेट नहीं)।
  • Array के तत्व अलग-अलग भेजें, जैसे show(marks[2]), तो वे value द्वारा जाते हैं।

12. फ़ंक्शन द्वारा दूसरे फ़ंक्शन को कॉल और महत्वपूर्ण नियम

कार्यप्रणाली: square(3) = 9 और square(4) = 16, इसलिए 9 + 16 = 25।

  • अलग-अलग फ़ंक्शन में एक ही नाम के वेरिएबल हो सकते हैं; वे अलग-अलग वेरिएबल होते हैं।
  • एक प्रोग्राम में दो फ़ंक्शन का नाम एक नहीं हो सकता (C में function overloading नहीं है)।

15. त्वरित दोहराव पत्रक (Quick Revision)

  • फ़ंक्शन = एक कार्य के लिए नामयुक्त कोड-ब्लॉक; नाम से कॉल होता है।

    printf("x = %d, y = %d", x, y);
    return 0;
}

#include <stdio.h>

int fact(int n)
{
    if (n <= 1)              // base case
        return 1;
    return n * fact(n - 1);  // recursive case
}

int main()
{
    printf("Factorial of 3 = %d", fact(3));
    return 0;
}
Factorial of 3 = 6

कार्यप्रणाली: fact(3) = 3 × fact(2); fact(2) = 2 × fact(1); fact(1) base case है और 1 लौटाता है। लौटते समय fact(2) = 2 × 1 = 2, fact(3) = 3 × 2 = 6।

Q1. यह जाँचने के लिए फ़ंक्शन लिखिए कि कोई संख्या अभाज्य (prime) है या नहीं।
#include <stdio.h>

int isPrime(int n)
{
    int i;
    if (n < 2)
        return 0;
    for (i = 2; i * i <= n; i++)
        if (n % i == 0)
            return 0;          // found a divisor
    return 1;
}

int main()
{
    if (isPrime(17))
        printf("17 is prime");
    else
        printf("17 is not prime");
    return 0;
}
17 is prime

फ़ंक्शन विभाजक मिलते ही 0 लौटा देता है और कोई विभाजक न मिलने पर 1। हमें केवल तब तक जाँच करनी है जब तक i * i <= n।

Q3. base की घात exp निकालने के लिए फ़ंक्शन power(base, exp) लिखिए।
#include <stdio.h>

long power(int base, int exp)
{
    long r = 1;
    int i;
    for (i = 1; i <= exp; i++)

    return r;
}

int main()
{
    printf("2 ^ 5 = %ld", power(2, 5));
    return 0;
}
2 ^ 5 = 32

Q8. दो संख्याओं का GCD निकालने का recursive फ़ंक्शन लिखिए।
#include <stdio.h>

int gcd(int a, int b)
{
    if (b == 0)
        return a;            // base case
    return gcd(b, a % b);    // recursive case
}

int main()
{
    printf("GCD = %d", gcd(48, 18));
    return 0;
}
GCD = 6

gcd(48,18) → gcd(18,12) → gcd(12,6) → gcd(6,0) = 6।

आउटपुट पर आधारित प्रश्न

पहले प्रोग्राम को कॉपी में हल कीजिए, फिर आउटपुट और कारण मिलाइए।

Q1. इस प्रोग्राम का आउटपुट लिखिए।
int f(int x)
{
    return x * 2;
}
int main()
{
    printf("%d", f(f(3)));
    return 0;
}
12

f(3) = 6, फिर f(6) = 12। Nested कॉल अंदर से बाहर की ओर हल होती हैं।

Q2. इस प्रोग्राम का आउटपुट लिखिए।
void show(int n)
{
    if (n == 0)
        return;
    printf("%d ", n);
    show(n - 1);
}
int main()
{
    show(3);
    return 0;
}
3 2 1

show(3) 3 छापकर show(2) बुलाता है जो 2 छापता है, फिर show(1) 1 छापता है, फिर show(0) लौट जाता है। आउटपुट 3 2 1 है।

Q3. इस प्रोग्राम का आउटपुट लिखिए।
int x = 5;
void change()
{
    x = 10;
}
int main()
{
    change();
    printf("%d", x);
    return 0;
}
10

x ग्लोबल वेरिएबल है। change() उसे 10 कर देता है, इसलिए main() 10 छापता है।

Q4. इस प्रोग्राम का आउटपुट लिखिए।
void fun()
{
    int c = 0;
    c++;
    printf("%d ", c);
}
int main()
{
    fun(); fun(); fun();
    return 0;
}
1 1 1

c सामान्य लोकल वेरिएबल है और हर कॉल में 0 से शुरू होता है, इसलिए हर कॉल 1 छापती है।

Q5. इस प्रोग्राम का आउटपुट लिखिए।
int sum(int n)
{
    if (n == 0)
        return 0;
    return n + sum(n - 1);
}
int main()
{
    printf("%d", sum(4));
    return 0;
}
10

sum(4) = 4 + 3 + 2 + 1 + 0 = 10।

Q6. इस प्रोग्राम का आउटपुट लिखिए।
int test(int a)
{
    a = a + 5;
    return a;
}
int main()
{
    int x = 2, y;
    y = test(x);
    printf("%d %d", x, y);
    return 0;
}
2 7

फ़ंक्शन केवल अपनी कॉपी a बदलता है (2 + 5 = 7) और उसे लौटाता है। x = 2 ही रहता है; y = 7 हो जाता है।

Q7. इस प्रोग्राम का आउटपुट लिखिए।
#include <stdio.h>

void swap(int a, int b)        // a, b are COPIES
{
    int t = a;
    a = b;
    b = t;
}

int main()
{
    int x = 10, y = 20;
    swap(x, y);
    printf("x = %d, y = %d", x, y);
    return 0;
}
x = 10, y = 20

अदला-बदली कॉपी पर होती है, इसलिए x और y नहीं बदलते।

Q8. इस प्रोग्राम का आउटपुट लिखिए।
#include <stdio.h>

void counter()
{
    static int c = 0;     // created once, remembers value
    c++;
    printf("%d ", c);
}

int main()
{
    counter();
    counter();
    counter();
    return 0;
}
1 2 3

static वेरिएबल अपना मान याद रखता है, इसलिए तीन कॉल 1, 2 और 3 छापती हैं।
