1. Function (Subroutine)

Definition: A function is a named block of statements that performs one specific task. It runs only when it is called, and it can be reused many times.

Why use functions?

  • Big program splits into small parts (modular programming).
  • Reusability – write once, call many times.
  • Easy to debug and understand.
  • Saves memory and time.

Types

  • Library (built-in) functions: printf(), scanf(), sqrt(), strlen().
  • User-defined functions: written by the programmer, e.g. add().

Syntax

return_type function_name(parameter list) { body }

Prototype (declaration before main): int add(int, int);

int add(int a, int b)      // function header
{
    int s = a + b;          // function body
    return s;               // return value
}
int main()
{
    int r = add(5, 3);      // function call
    printf("%d", r);        // output: 8
    return 0;
}

2. Searching

Searching means finding the position of a given element (key) in an array.

A. Linear (Sequential) Search

  • Compare key with each element from first to last.
  • If equal: print position and stop. Otherwise go to next.
  • If the end is reached: not found.
  • Array need not be sorted. Slow for big data (n comparisons).
int linear(int a[], int n, int key)
{
    for (int i = 0; i < n; i++)
        if (a[i] == key) return i;   // found
    return -1;                       // not found
}

B. Binary Search

  • Array must be sorted.
  • Find mid = (low + high) / 2.
  • key == a[mid] → found.
  • key > a[mid] → search right half (low = mid+1).
  • key < a[mid] → search left half (high = mid-1).
  • Repeat until low > high. Very fast (about log₂n steps).
int binary(int a[], int n, int key)
{
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (a[mid] == key) return mid;
        else if (key > a[mid]) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

3. Sorting

Sorting means arranging elements in ascending or descending order.

A. Bubble Sort

  • Compare two adjacent elements; swap if left is greater.
  • After pass 1 the largest goes to the last place (like a bubble rising).
  • Repeat n-1 passes; each pass needs one comparison less.
for (i = 0; i < n-1; i++)
  for (j = 0; j < n-i-1; j++)
    if (a[j] > a[j+1]) {
      t = a[j]; a[j] = a[j+1]; a[j+1] = t;
    }
Fig 4: Bubble sort – orange = comparing, green = sorted (animated)

B. Selection Sort

  • Find the smallest element in the unsorted part.
  • Swap it with the first element of that part.
  • Repeat for the rest. Example: 29 10 14 → 10 29 14 → 10 14 29.
for (i = 0; i < n-1; i++) {
  min = i;
  for (j = i+1; j < n; j++)
    if (a[j] < a[min]) min = j;
  t = a[i]; a[i] = a[min]; a[min] = t;
}

5. Remember

  • Function = reusable named block; call it to run it.
  • Binary search works only on a sorted array.
  • Bubble sort swaps neighbours; selection sort swaps the minimum.
  • Return value of search: index, or -1 if not found.
