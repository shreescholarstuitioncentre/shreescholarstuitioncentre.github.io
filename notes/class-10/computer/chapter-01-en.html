C Functions (Subroutines): Searching and Sorting Techniques

Class 10 · Computer Science · Chapter 3 · Complete Handwritten-Style Notes with Animated Diagrams

Note: These notes cover functions (subroutines) in C and their use for the standard searching techniques (linear and binary search) and sorting techniques (bubble, selection and insertion sort) taught in Class 10 computer books. The questions are practice questions written in the usual board-exam pattern, not copied word-for-word from any NCERT, publisher or UP Board paper. Check with your teacher which sorting methods your syllabus asks for.

1. Introduction: Functions (Subroutines) and Modular Programming

Function / Subroutine: A function (also called a subroutine or sub-program) is a named block of statements that performs one specific task. It is written once and can be called whenever that task is needed.

In C every program is made of functions. main() is the starting function; it calls other functions to do smaller jobs. Dividing a big program into small functions is called modular programming.

Why use functions in searching and sorting programs?

  • Searching and sorting are needed again and again, so we write them once as functions and reuse them for any array.
  • Each function can be tested separately, so errors are found easily.
  • main() stays short and readable: read the data → display → sort → search.
  • Different programmers can write display(), sort() and search() separately.

Example: a program with two functions

#include <stdio.h>

void display(int a[], int n);        // prototypes
int  findMax(int a[], int n);

int main()
{
    int a[5] = {4, 9, 2, 7, 5};
    display(a, 5);                   // call 1
    printf("\nLargest = %d", findMax(a, 5));   // call 2
    return 0;
}

void display(int a[], int n)         // prints the array
{
    int i;
    for (i = 0; i < n; i++)
        printf("%d ", a[i]);
}

int findMax(int a[], int n)          // returns the biggest element
{
    int i, m = a[0];
    for (i = 1; i < n; i++)
        if (a[i] > m)
            m = a[i];
    return m;
}

2. Passing an Array to a Function

Searching and sorting functions work on arrays. To pass an array we write only its name in the call and, normally, its size as a second argument.

  • Call: bubbleSort(a, 5); (no square brackets in the call).
  • Header: void bubbleSort(int a[], int n) (or int *a).
  • The array name is the address of the first element, so the function works on the original array. Changes made inside the function remain after it returns.
  • The function cannot find the array size by itself, so the size n is passed separately.
#include <stdio.h>

void doubleAll(int a[], int n)       // changes the ORIGINAL array
{
    int i;
    for (i = 0; i < n; i++)
        a[i] = a[i] * 2;
}

int main()
{
    int a[3] = {1, 2, 3}, i;
    doubleAll(a, 3);
    for (i = 0; i < 3; i++)
        printf("%d ", a[i]);
    return 0;
}
2 4 6
Result: A sorting function can be a void function because the array is sorted in place. A searching function normally returns an int: the index of the key, or −1 if it is not found.

Swap as a separate function

If we write swap(int a, int b) (call by value) only copies are exchanged and the array does not change. We must send the addresses with & and receive them in pointers:

#include <stdio.h>

void swap(int *x, int *y)            // receives ADDRESSES
{
    int t = *x;
    *x = *y;
    *y = t;
}

int main()
{
    int a[2] = {10, 20};
    swap(&a[0], &a[1]);              // swap two array elements
    printf("%d %d", a[0], a[1]);
    return 0;
}
20 10
Careful: A swap function that receives plain int parameters has no effect on the caller’s variables, because call by value works on copies.

4. Searching: Basic Idea and Linear Search

Searching: Finding whether a given value (called the key) is present in a list or array, and, if present, at which position.

Two common techniques are linear (sequential) search and binary search.

Linear search: The key is compared with the elements one by one from the beginning until it is found or the array ends.

Algorithm

  1. Start from the first element (i = 0).
  2. If a[i] equals the key, return i (found) and stop.
  3. Otherwise increase i by 1 and repeat.
  4. If the end is reached without a match, return −1 (not found).
#include <stdio.h>

int linearSearch(int a[], int n, int key)
{
    int i;
    for (i = 0; i < n; i++)
        if (a[i] == key)
            return i;               // found: send back the index
    return -1;                      // not found
}

int main()
{
    int a[6] = {12, 45, 30, 8, 19, 27};
    int pos;

    pos = linearSearch(a, 6, 30);
    if (pos != -1)
        printf("Found at index %d\n", pos);
    else
        printf("Not found\n");

    pos = linearSearch(a, 6, 99);
    if (pos != -1)
        printf("Found at index %d", pos);
    else
        printf("Not found");
    return 0;
}

5. Binary Search

Binary search: A fast method that works only on a sorted array. It compares the key with the middle element and, depending on the result, throws away one half of the array each time.

Condition

The array must be sorted (ascending in our programs). On unsorted data binary search gives wrong answers.

Algorithm

  1. Set low = 0 and high = n − 1.
  2. While low <= high: find mid = (low + high) / 2.
  3. If a[mid] == key → found, return mid.
  4. If key > a[mid] → search the right half: low = mid + 1.
  5. If key < a[mid] → search the left half: high = mid − 1.
  6. If the loop ends (low > high) → not found, return −1.
#include <stdio.h>

int binarySearch(int a[], int n, int key)
{
    int low = 0, high = n - 1, mid;
    while (low <= high)
    {
        mid = (low + high) / 2;         // middle position
        if (a[mid] == key)
            return mid;                 // found
        else if (key > a[mid])
            low = mid + 1;              // search right half
        else
            high = mid - 1;             // search left half
    }
    return -1;                          // not found
}

int main()
{
    int a[7] = {10, 20, 30, 40, 50, 60, 70};   // must be sorted
    int pos = binarySearch(a, 7, 70);
    if (pos != -1)
        printf("Found at index %d", pos);
    else
        printf("Not found");
    return 0;
}

Binary search using recursion

The same idea can be written as a recursive function: the function calls itself on the smaller half.

#include <stdio.h>

int binSearch(int a[], int low, int high, int key)
{
    int mid;
    if (low > high)
        return -1;                      // base case: not found
    mid = (low + high) / 2;
    if (a[mid] == key)
        return mid;                     // base case: found
    if (key > a[mid])
        return binSearch(a, mid + 1, high, key);
    return binSearch(a, low, mid - 1, key);
}

int main()
{
    int a[5] = {5, 15, 25, 35, 45};
    int pos = binSearch(a, 0, 4, 25);
    printf("Found at index %d", pos);
    return 0;
}
Found at index 2

Analysis

  • Every step halves the part still to be searched, so the maximum number of comparisons is about log₂ n + 1 (for 1024 elements only 11).
  • Best case: key is the middle element (1 comparison).
  • Advantage: very fast for large arrays. Disadvantage: array must be sorted first.
Careful: Use mid + 1 and mid - 1 when moving low and high. Writing only mid can make the loop run forever.

7. Sorting: Basic Ideas

Sorting: Arranging the elements of an array in a particular order: ascending (small to big) or descending (big to small).

Why sort?

  • Sorted data is easier to read (marks list, telephone directory, dictionary).
  • Binary search and many other methods need sorted data.

Terms

PassOne complete round over the (remaining) array
ComparisonChecking which of two elements is bigger
SwapExchanging the positions of two elements
In-place sortingSorting inside the same array without another array

In this chapter we study three simple sorting techniques: bubble sort, selection sort and insertion sort. All three are written as functions that take the array and its size, e.g. void bubbleSort(int a[], int n).

8. Bubble Sort

Bubble sort: Repeatedly compares neighbouring elements and swaps them if they are in the wrong order. After each pass the largest remaining element “bubbles” to the end.

Algorithm (ascending)

  1. For each pass i from 0 to n − 2:
  2. Compare a[j] and a[j+1] for j = 0 to n − 2 − i.
  3. If a[j] > a[j+1], swap them.
  4. If no swap happened in a pass, the array is already sorted: stop early (this is the swapped flag).
#include <stdio.h>

void display(int a[], int n)
{
    int i;
    for (i = 0; i < n; i++)
        printf("%d ", a[i]);
    printf("\n");
}

void bubbleSort(int a[], int n)
{
    int i, j, t, swapped;
    for (i = 0; i < n - 1; i++)             // passes
    {
        swapped = 0;
        for (j = 0; j < n - 1 - i; j++)     // compare neighbours
        {
            if (a[j] > a[j + 1])
            {
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
                swapped = 1;
            }
        }
        if (swapped == 0)                   // no swap: already sorted
            break;
    }
}

int main()
{
    int a[5] = {5, 1, 4, 2, 8};
    printf("Before: ");
    display(a, 5);
    bubbleSort(a, 5);
    printf("After : ");
    display(a, 5);
    return 0;
}

Points to remember

  • For n elements without the flag, comparisons = (n−1) + (n−2) + … + 1 = n(n−1)/2 (for n = 5 that is 10).
  • With the flag, an already sorted array needs only one pass (n − 1 comparisons).
  • Simple, but slow for big arrays because it may make many swaps.
// Only the comparison changes for DESCENDING order:
if (a[j] < a[j + 1])        // was: a[j] > a[j + 1]
{
    t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
}

9. Selection Sort

Selection sort: In each pass the smallest element of the unsorted part is selected and swapped with the first element of that part.

Algorithm (ascending)

  1. For i from 0 to n − 2: assume a[i] is the smallest (min = i).
  2. Compare with every element after it; whenever a[j] < a[min], set min = j.
  3. After the inner loop, swap a[i] and a[min].
#include <stdio.h>

void selectionSort(int a[], int n)
{
    int i, j, min, t;
    for (i = 0; i < n - 1; i++)
    {
        min = i;                            // assume a[i] is smallest
        for (j = i + 1; j < n; j++)
            if (a[j] < a[min])
                min = j;                    // remember smaller one
        if (min != i)
        {
            t = a[i];                       // put smallest at position i
            a[i] = a[min];
            a[min] = t;
        }
    }
}

int main()
{
    int a[5] = {64, 25, 12, 22, 11}, i;
    selectionSort(a, 5);
    for (i = 0; i < 5; i++)
        printf("%d ", a[i]);
    return 0;
}

  • Makes at most n − 1 swaps, fewer than bubble sort, so it is good when swapping is costly.

10. Insertion Sort

Insertion sort: The array is divided into a sorted left part and an unsorted right part. Each time the next element (the key) is inserted at its correct place in the sorted part, like arranging playing cards in the hand.

Algorithm (ascending)

  1. Treat a[0] as sorted. For i from 1 to n − 1: set key = a[i] and j = i − 1.
  2. While j >= 0 and a[j] > key: shift a[j] one place right and decrease j.
  3. Place the key at a[j + 1].
#include <stdio.h>

void insertionSort(int a[], int n)
{
    int i, j, key;
    for (i = 1; i < n; i++)
    {
        key = a[i];                         // element to insert
        j = i - 1;
        while (j >= 0 && a[j] > key)        // shift bigger ones right
        {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;                     // insert at the gap
    }
}

int main()
{
    int a[4] = {7, 4, 5, 2}, i;
    insertionSort(a, 4);
    for (i = 0; i < 4; i++)
        printf("%d ", a[i]);
    return 0;
}

  • Very fast on an almost sorted array (best case n − 1 comparisons); worst case n(n−1)/2.
  • Uses shifting instead of repeated swapping.

12. A Complete Program: Sort, Display and Search with Functions

This program uses three functions together. Notice that the array is sorted first and only then searched with binary search.

#include <stdio.h>

void display(int a[], int n);
void bubbleSort(int a[], int n);
int  binarySearch(int a[], int n, int key);

int main()
{
    int a[5] = {64, 25, 12, 22, 11};
    int pos;

    printf("Original: ");
    display(a, 5);

    bubbleSort(a, 5);                       // sort first
    printf("Sorted  : ");
    display(a, 5);

    pos = binarySearch(a, 5, 22);           // binary search needs sorted data
    if (pos != -1)
        printf("22 found at index %d (position %d)", pos, pos + 1);
    else
        printf("22 not found");
    return 0;
}

void display(int a[], int n)
{
    int i;
    for (i = 0; i < n; i++)
        printf("%d ", a[i]);
    printf("\n");
}

void bubbleSort(int a[], int n)
{
    int i, j, t;
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - 1 - i; j++)
            if (a[j] > a[j + 1])
            {
                t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            }
}

int binarySearch(int a[], int n, int key)
{
    int low = 0, high = n - 1, mid;
    while (low <= high)
    {
        mid = (low + high) / 2;
        if (a[mid] == key) return mid;
        else if (key > a[mid]) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
Original: 64 25 12 22 11 Sorted : 11 12 22 25 64 22 found at index 2 (position 3)
  • display() and bubbleSort() are void functions; binarySearch() returns the index.
  • Position = index + 1, so index 2 is the 3rd element.

14. Quick Revision Sheet

  • Function (subroutine) = named block for one task; modular programming = program built from functions.
  • Array name passed to a function passes its address; the function changes the original array; size is passed separately.
  • Swap needs a temporary variable (or pointers when written as a function).
  • Linear search: check one by one; works on any array; worst case n comparisons; return index or −1.
  • Binary search: sorted array only; mid = (low + high) / 2; halves the range; worst case ≈ log₂ n + 1.
  • Bubble sort: compare neighbours, swap; largest goes to the end each pass; n(n−1)/2 comparisons.
  • Selection sort: select the smallest and swap it to the front; at most n − 1 swaps.
  • Insertion sort: insert each element into the sorted part by shifting; good for nearly sorted data.
  • For descending order change only the comparison operator.

Short Answer Questions (2–3 Marks)

Q1. What is a subroutine? Write any three advantages of using functions.
A subroutine (function) is a named block of statements that performs a specific task. Advantages: (1) reusability: written once, called many times; (2) easier debugging and testing of small parts; (3) program becomes shorter, readable and easy to maintain.
Q2. Why is the size of the array passed to a function along with the array?
The array name gives only the address of the first element; the function cannot know how many elements the array has. So the number of elements is passed as another argument and used in loops.
Q3. Why does a sorting function not need to return the array?
The array is passed by address, so the function sorts the original array in place. The changes are visible in the calling function, so nothing needs to be returned and the function can be void.
Q4. Explain the swapping of two elements with the help of a temporary variable.
Statements: t = a[j]; a[j] = a[j+1]; a[j+1] = t;. First a[j] is saved in t, then a[j+1] is copied into a[j], and finally the saved value in t is copied into a[j+1]. Without t, the first value would be overwritten.
Q5. Explain linear search with its algorithm.
Linear search compares the key with every element one by one from the first. Algorithm: start with i = 0; if a[i] equals the key, return i; otherwise increase i; if the end is reached, return −1. It works on unsorted data too.
Q6. Explain binary search in brief.
Binary search works on a sorted array. It finds mid = (low + high) / 2 and compares the key with a[mid]. If equal, the search ends; if the key is bigger, low = mid + 1; if smaller, high = mid − 1. The process repeats until the key is found or low > high.
Q7. Differentiate between linear search and binary search.
LinearBinary
Works on any arrayNeeds a sorted array
One by one comparisonHalves the range each time
Worst case n comparisonsAbout log₂ n + 1
Slow for large dataFast for large data
Q8. Why must the array be sorted before applying binary search?
Binary search decides to discard the left or right half by comparing the key with the middle element. This decision is correct only if the elements are in order. In an unsorted array the key may lie in the discarded half.
Q9. Explain bubble sort in brief.
Bubble sort compares neighbouring elements and swaps them if the left one is greater (ascending order). After the first pass the largest element is at the end, after the second pass the second largest is in place, and so on. At most n − 1 passes sort the array.
Q10. Explain selection sort in brief.
In each pass the smallest element of the unsorted part is found and swapped with the first element of that part. After pass 1 the smallest is at index 0, after pass 2 the next smallest is at index 1, and so on.
Q11. Explain insertion sort in brief.
The left part of the array is kept sorted. The next element (key) is taken and the bigger elements before it are shifted one place right; then the key is placed in the gap. This is repeated for all elements.
Q12. How many comparisons does bubble sort make for 5 elements (without the flag)?
(5−1) + (5−2) + (5−3) + (5−4) = 4 + 3 + 2 + 1 = 10 comparisons, i.e. n(n−1)/2.
Q13. What is the advantage of the swapped flag in bubble sort?
If a complete pass makes no swap, the array is already sorted, so the loop stops. For a sorted or almost sorted array this saves many unnecessary passes.
Q14. Why should a search function return −1 and not 0 when the key is not found?
Because 0 is a valid index (the first element). Returning 0 would wrongly suggest that the key was found at the first position, so a value that can never be an index, such as −1, is used.
Q15. Differentiate between bubble sort and selection sort.
Bubble sort compares neighbours and may swap many times in each pass; the largest element moves to the end. Selection sort finds the smallest element in each pass and makes only one swap per pass (at most n − 1 swaps in all).

Long Answer Questions (4–5 Marks)

Q1. What is a function? Explain how an array is passed to a function with an example. (5 marks)

A function is a named block of statements that performs a particular task and can be called many times. To pass an array only its name is written in the call, together with its size. The function receives the address of the first element and works on the original array.

#include <stdio.h>

void doubleAll(int a[], int n)       // changes the ORIGINAL array

Q3. Explain binary search with an algorithm and a program. (5 marks)

Condition: sorted array. Algorithm: low = 0, high = n − 1; while low ≤ high find mid = (low + high)/2; if a[mid] = key return mid; if key is bigger low = mid + 1; else high = mid − 1; if the loop ends return −1.

#include <stdio.h>

int binarySearch(int a[], int n, int key)
{
    int low = 0, high = n - 1, mid;
    while (low <= high)
    {
        mid = (low + high) / 2;         // middle position
        if (a[mid] == key)
            return mid;                 // found
        else if (key > a[mid])
            low = mid + 1;              // search right half
        else
            high = mid - 1;             // search left half
    }
    return -1;                          // not found
}

int main()
{
    int a[7] = {10, 20, 30, 40, 50, 60, 70};   // must be sorted
    int pos = binarySearch(a, 7, 70);
    if (pos != -1)
        printf("Found at index %d", pos);
    else
        printf("Not found");
    return 0;
}

{
    int i, j, t, swapped;
    for (i = 0; i < n - 1; i++)             // passes
    {

{

Q10. Explain how two elements are swapped, and why a swap function needs pointers. (3 marks)

Swap uses a temporary variable: t = a[j]; a[j] = a[j+1]; a[j+1] = t;. If a swap function receives ordinary parameters, only copies are exchanged. Passing addresses (&a[0], &a[1]) and using pointers lets the function change the original elements.

#include <stdio.h>

void swap(int *x, int *y)            // receives ADDRESSES
{
    int t = *x;
    *x = *y;
    *y = t;
}

int main()
{
    int a[2] = {10, 20};
    swap(&a[0], &a[1]);              // swap two array elements
    printf("%d %d", a[0], a[1]);
    return 0;
}
