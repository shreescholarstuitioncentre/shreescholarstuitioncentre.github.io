1What is a function?

A function is a named, self-contained block of statements that performs one specific task. We write it once and can call it as many times as we want, from anywhere in the program.

Real-life example: a mixer-grinder. You put in fruits (input), it works inside (process) and gives juice (output). You do not rebuild the mixer every time you want juice.

A C program is a collection of functions. main() is the first function and the execution of every C program always starts from main().

Remember!Function = Input + Process + Output. A function may also take no input or give no output.

2Why do we use functions?

  • Modularity: a big program is divided into small, easy parts.
  • Reusability: write once, use many times. No copy-paste.
  • Less code: repeated statements are written only once.
  • Easy debugging: an error is searched in one small function, not in the whole program.
  • Readability and teamwork: different programmers can write different functions.

4Parts of a user-defined function

A user-defined function has three parts:

PartMeaningExample
Declaration (prototype)Tells the compiler the name, return type and parameters. Ends with ;int add(int, int);
DefinitionThe actual code of the function (header + body). NO semicolon after the header.int add(int a, int b){...}
CallUsing the function from main() or another function.add(x, y);

General syntax

return_type function_name(parameter_list)
{
    // statements (body)
    return value;
}

Complete program

#include <stdio.h>
int add(int a, int b);        // 1. Declaration (prototype)

int main()
{
    int x = 5, y = 3, result;
    result = add(x, y);       // 3. Function call
    printf("Sum = %d", result);
    return 0;
}

int add(int a, int b)         // 2. Definition
{
    int sum = a + b;
    return sum;
}
Output:Sum = 8
Why a prototype?The compiler reads top to bottom. If main() calls add() before add() is defined, the compiler must already know about add(). That is the job of the prototype. If the function is defined above main(), the prototype is not needed.

5Actual and formal parameters

Actual parameters (arguments)Formal parameters
Written in the function callWritten in the function definition
Hold the real values: x, y or even 5, 3Receive copies of the values: a, b
Can be constants, variables or expressionsMust be variables with data types

In add(x, y), x, y are actual parameters. In int add(int a, int b), a, b are formal parameters.

RuleNumber, order and data type of actual parameters must match the formal parameters.

6The return statement

  • return sends a value back to the calling function and ends the function immediately.
  • A function can return only one value.
  • The returned value must match the function's return type (int, float, char ...).
  • If the function returns nothing, the return type is void and we may write just return; or nothing.
  • Statements written after a return are never executed.
  • main() returns 0 to the operating system to say "program ended successfully".

8Call by value and call by reference

There are two ways of passing values to a function.

(a) Call by value

The copy of the actual value is sent. Changes made to the formal parameters do not affect the original variables. This is the default way in C.

#include <stdio.h>
void swap(int a, int b)      // a, b are COPIES
{
    int t = a;
    a = b;
    b = t;
}
int main()
{
    int x = 10, y = 20;
    swap(x, y);
    printf("%d %d", x, y);
    return 0;
}
Output:10 20

(b) Call by reference (for knowledge)

The address of the variable (using &) is sent and the function receives it in a pointer (using *). So the function changes the original variable.

void swap(int *a, int *b)    // a, b hold ADDRESSES
{
    int t = *a;
    *a = *b;
    *b = t;
}
// call: swap(&x, &y);   -> x = 20, y = 10
Call by valueCall by reference
Copy of value is passedAddress is passed
Original does NOT changeOriginal CAN change
Uses normal variablesUses pointers (* and &)

9Recursion

Recursion is a technique in which a function calls itself to solve a problem by breaking it into smaller problems of the same kind.

Every recursive function needs two things:

  • Base case: the condition where the function stops calling itself.
  • Recursive case: the part where the function calls itself with a smaller value.

Factorial using recursion

n! = n x (n-1)! and 1! = 1

#include <stdio.h>
int fact(int n)
{
    if (n <= 1)                   // base case
        return 1;
    else
        return n * fact(n - 1);   // recursive call
}
int main()
{
    printf("%d", fact(3));
    return 0;
}
Output:6
AdvantagesDisadvantages
Code is short and cleanUses more memory (stack)
Natural for problems like factorial, FibonacciSlower than loops
Without base case: infinite calls and stack overflow

10Scope of variables

Scope means the part of the program where a variable can be used.

Local variableGlobal variable
Declared inside a functionDeclared outside all functions
Usable only in that functionUsable in every function
Created when function starts, destroyed when it endsLives until the program ends
#include <stdio.h>
int g = 100;                // global variable
void show(void)
{
    int y = 9;              // local to show()
    printf("%d %d", g, y);
}
int main()
{
    int x = 5;              // local to main()
    show();
    printf(" %d %d", g, x); // OK
    // printf("%d", y);     // ERROR: y not visible here
    return 0;
}
Output:100 9 100 5
Remember!Two different functions can use the same variable name, because each local variable is separate.

11More example programs

Program 1: check even or odd using a function

#include <stdio.h>
int isEven(int n)
{
    if (n % 2 == 0)
        return 1;
    else
        return 0;
}
int main()
{
    int num = 7;
    if (isEven(num))
        printf("Even");
    else
        printf("Odd");
    return 0;
}
Output:Odd

Program 2: largest of two numbers

int largest(int a, int b)
{
    return (a > b) ? a : b;
}
// printf("%d", largest(12, 30));
Output:30

12Common mistakes

  • Forgetting ; after the prototype.
  • Putting ; after the function header in the definition.
  • Passing the wrong number or type of arguments.
  • Not writing return in a function that must return a value.
  • Defining one function inside another function (not allowed in C).
  • Recursion without a base case.
  • Using a local variable outside its function.
  • Expecting call by value to change the original variable.

14Important questions and answers

Q1. Define a function.

A function is a named block of statements that performs a specific task and can be called many times.

Q2. Write any two advantages of functions.

Reusability of code, and the program becomes modular and easy to debug.

Q3. Differentiate between actual and formal parameters.

Actual parameters are in the function call and carry real values; formal parameters are in the function definition and receive copies of those values.

Q4. What is the use of a function prototype?

It tells the compiler the name, return type and parameters of a function before it is called.

Q5. What is recursion? What is a base case?

Recursion is a function calling itself. The base case is the condition that stops the recursive calls.

Q6. What does void mean?

It means "nothing": the function returns no value (or takes no parameters when written inside the brackets).

Q7. Find the output.
int f(int x)
{
    return x * 2;
}
// printf("%d", f(f(3)));

Output is 12. f(3) = 6, then f(6) = 12.

Q8. Why does the swap() with call by value not swap x and y?

Because a and b are only copies. They are destroyed when the function ends, so x and y stay the same.
