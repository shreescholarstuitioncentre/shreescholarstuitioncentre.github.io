1. पॉइंटर

पॉइंटर: ऐसा वेरिएबल जो किसी दूसरे वेरिएबल का मेमोरी पता (address) रखता है।

हर वेरिएबल मेमोरी में किसी पते पर रहता है (मकान नंबर की तरह)। पॉइंटर वही पता रखता है, इसलिए वह वेरिएबल तक अप्रत्यक्ष रूप से पहुँच सकता है।

  • & = address-of ऑपरेटर: &x से x का पता मिलता है।
  • * = dereference (value-at) ऑपरेटर: *p से p में रखे पते पर संग्रहित मान मिलता है।
  • घोषणा: int *p; (int का पॉइंटर); float *q;
  • पॉइंटर को हमेशा initialise करें; कहीं इशारा न करता हो तो NULL रखें।
int x = 10;
int *p = &x;          // p stores the address of x
printf("%d", x);      // 10
printf("%p", &x);     // address of x
printf("%d", *p);     // 10  (value at address)
*p = 20;              // x becomes 20

चित्र 1: पॉइंटर p में x का पता रखा है (एनिमेशन)

यहाँ p = 1000 x का पता है, इसलिए *p का अर्थ x का मान है। *p बदलने पर x बदल जाता है।

2. पॉइंटर और ऐरे

  • ऐरे का नाम उसके पहले तत्व का पता होता है: a = &a[0]।
  • p++ पॉइंटर को sizeof(type) जितना आगे बढ़ाता है (int में 4 बाइट), 1 बाइट नहीं।
  • *(a+i) और a[i] एक ही हैं।
int a[3] = {10, 20, 30};
int *p = a;           // same as &a[0]
printf("%d", *p);     // 10
p++;                  // moves 4 bytes (size of int)
printf("%d", *p);     // 20
printf("%d", *(a+2)); // 30

3. कॉल बाय रेफ़रेंस

फ़ंक्शन को पते भेजने से वह मूल वेरिएबल बदल सकता है (call by value में केवल कॉपी बदलती है)।

void swap(int *a, int *b) {
    int t = *a; *a = *b; *b = t;
}
int main() {
    int x = 5, y = 9;
    swap(&x, &y);     // x = 9, y = 5
    return 0;
}

4. फ़ाइल हैंडलिंग

फ़ाइल: डिस्क पर नाम वाली जगह जहाँ डेटा स्थायी रूप से रखा जाता है। RAM के वेरिएबल प्रोग्राम खत्म होते ही मिट जाते हैं; फ़ाइल नहीं मिटती।
  • टेक्स्ट फ़ाइल: पढ़ने योग्य अक्षर (.txt)। बाइनरी फ़ाइल: कच्चे बाइट (.dat)।
  • फ़ाइल फ़ाइल पॉइंटर से प्रयोग होती है: FILE *fp;
  • चरण: 1. खोलना (fopen) → 2. पढ़ना/लिखना → 3. बंद करना (fclose)।
  • फ़ाइल न खुल सके तो fopen NULL लौटाता है।
#include <stdio.h>
int main() {
    FILE *fp;
    char buf[20];
    fp = fopen("data.txt", "w");
    if (fp == NULL) { printf("Error"); return 1; }
    fprintf(fp, "Hello");
    fclose(fp);

    fp = fopen("data.txt", "r");
    fgets(buf, 20, fp);
    printf("%s", buf);    // Hello
    fclose(fp);
    return 0;
}

5. याद रखें

  • & से पता मिलता है; * से उस पते का मान।
  • पॉइंटर में पता होता है, सामान्य मान नहीं।
  • p++ डेटा टाइप के आकार जितना आगे जाता है।
  • fopen का परिणाम NULL के लिए जाँचें, और fclose() ज़रूर करें।
  • w पुराना डेटा मिटाता है; a अंत में जोड़ता है।
