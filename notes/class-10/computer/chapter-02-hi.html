C भाषा में ऐरे (Arrays in C)

कक्षा 10 · कंप्यूटर विज्ञान · अध्याय 2 · हस्तलिखित शैली के पूरे नोट्स, एनिमेटेड चित्रों सहित

ध्यान दें: ये नोट्स कक्षा 10 की कंप्यूटर पुस्तकों में पढ़ाए जाने वाले C भाषा के “ऐरे” के सामान्य पाठ्यक्रम (1-D ऐरे, 2-D ऐरे और कैरेक्टर ऐरे/स्ट्रिंग) पर आधारित हैं। प्रश्न बोर्ड परीक्षा के सामान्य पैटर्न पर बनाए गए अभ्यास प्रश्न हैं, NCERT, किसी प्रकाशक या UP Board के प्रश्न-पत्र से शब्दशः नहीं लिए गए। यहाँ मेमोरी का आकार (int = 4 बाइट) आधुनिक कंपाइलर के अनुसार है; Turbo C जैसे पुराने कंपाइलर में int 2 बाइट का होता है।

1. परिचय: ऐरे (Array) क्या है?

परिभाषा: ऐरे एक ही डेटा टाइप के निश्चित संख्या के तत्वों का समूह है, जो लगातार मेमोरी स्थानों में रखा जाता है और एक सामान्य नाम से पहचाना जाता है।

ऐरे की आवश्यकता क्यों?

मान लीजिए 50 विद्यार्थियों के अंक रखने हैं। ऐरे के बिना 50 वेरिएबल m1, m2, m3 … m50 बनाने पड़ेंगे। इन्हें लिखना, पढ़ना और जोड़ना बहुत लंबा होगा। ऐरे में केवल int marks[50]; काफ़ी है और एक लूप सबको सँभाल लेता है।

रोज़मर्रा के उदाहरण

  • अंडे की ट्रे: एक जैसे कई खाने, एक ट्रे, हर खाने की अपनी स्थिति।
  • इमारत के फ़्लैट: इमारत का एक नाम, हर फ़्लैट का एक नंबर (index)।
  • बस की सीटें: एक बस, एक कतार में कई सीटें, हर सीट का नंबर।

ऐरे की विशेषताएँ

  • सभी तत्व एक ही डेटा टाइप के होते हैं (सब int, सब float या सब char)।
  • तत्व लगातार (पास-पास) मेमोरी में रखे जाते हैं।
  • हर तत्व index (subscript) से मिलता है। पहले तत्व का index 0 होता है।
  • घोषणा के समय आकार तय हो जाता है और प्रोग्राम चलते समय बदला नहीं जा सकता।
  • index से किसी भी तत्व को सीधे पढ़ा या बदला जा सकता है (random access)।
लाभहानि
एक नाम के नीचे कई मानआकार निश्चित; बढ़ या घट नहीं सकता
लूप से सभी तत्व आसानी से संभाले जाते हैंसभी तत्व एक ही प्रकार के होने चाहिए
index द्वारा तेज़ पहुँचकम तत्व रखने पर मेमोरी बेकार जाती है
खोजना और क्रमबद्ध करना आसानबीच में जोड़ने/हटाने पर तत्वों को खिसकाना पड़ता है

ऐरे के प्रकार

  • एक-आयामी (1-D) ऐरे: तत्वों की एक ही पंक्ति, जैसे int a[5]।
  • द्वि-आयामी (2-D) ऐरे: पंक्तियों और स्तंभों की तालिका, जैसे int m[3][3]।
  • बहु-आयामी ऐरे: तीन या अधिक आयाम (इस स्तर पर केवल विचार जानना काफ़ी है)।

2. एक-आयामी ऐरे की घोषणा (Declaration)

Syntax: data_type array_name[size];
int marks[5];          // 5 integers
float price[10];       // 10 decimal numbers
char name[20];         // 20 characters (a string)
double temp[7];        // 7 double values

नियम

  • ऐरे का नाम identifier के नियमों से बनता है (अक्षर, अंक, underscore; अंक से शुरू नहीं; keyword नहीं)।
  • आकार धनात्मक पूर्ण संख्या का अचर (जैसे 5 या 100) होना चाहिए और वर्गाकार कोष्ठक में लिखा जाता है।
  • ऐरे का प्रयोग करने से पहले उसकी घोषणा ज़रूरी है।
  • अंतिम वैध index = आकार − 1। int a[5] में वैध index 0, 1, 2, 3, 4 हैं।

ऐरे द्वारा ली गई मेमोरी

सूत्र: कुल बाइट = तत्वों की संख्या × एक तत्व का आकार
घोषणागणना (आधुनिक कंपाइलर)कुल
int a[5]5 × 420 बाइट
float f[10]10 × 440 बाइट
double d[3]3 × 824 बाइट
char c[20]20 × 120 बाइट

sizeof ऑपरेटर से ये मान देखे जा सकते हैं:

#include <stdio.h>

int main()
{
    int a[5];
    printf("Size = %d bytes\n", (int)sizeof(a));
    printf("Elements = %d", (int)(sizeof(a) / sizeof(a[0])));
    return 0;
}
Size = 20 bytes Elements = 5
यदि आपकी पुस्तक Turbo C (int = 2 बाइट) पर आधारित है तो int a[5] में 5 × 2 = 10 बाइट लगेंगे। प्रश्न में जो आकार दिया हो वही प्रयोग करें।

3. मेमोरी में ऐरे: Index, Value और Address

  • Index (subscript) तत्व की स्थिति बताता है। पहला तत्व a[0], दूसरा a[1] और अंतिम a[size-1] होता है।
  • पहले तत्व का पता base address कहलाता है। ऐरे का नाम a स्वयं इसी पते को दर्शाता है।
  • तत्व पास-पास होने से किसी भी तत्व का पता base + index × तत्व का आकार होता है। इसी कारण index से पहुँच बहुत तेज़ होती है।
उदाहरण: यदि base address = 1000 और int 4 बाइट का है तो marks[0] = 1000, marks[1] = 1004, marks[2] = 1008, marks[3] = 1012, marks[4] = 1016।
सावधान: तीसरा तत्व a[2] है, a[3] नहीं। स्थिति = index + 1।

4. ऐरे को मान देना (Initialisation)

Initialisation का अर्थ है तत्वों को मान देना।

int a[5] = {10, 20, 30, 40, 50};   // full initialisation
int b[5] = {1, 2};                 // rest become 0
int c[] = {5, 6, 7};               // size 3 decided by compiler
int d[5] = {0};                    // all five elements are 0

मान देने के तरीके

  1. घोषणा के समय: घुंघराले कोष्ठक में मान, अल्पविराम से अलग।
  2. आकार से कम मान: शेष तत्व 0 हो जाते हैं (संख्याओं के लिए)।
  3. बिना आकार लिखे: int c[] = {5, 6, 7}; कंपाइलर मान गिन लेता है।
  4. एक-एक तत्व करके: a[0] = 10; a[1] = 20;
  5. कीबोर्ड से लूप में scanf() द्वारा (नीचे दिखाया गया है)।
सावधान: आकार से अधिक मान, जैसे int a[3] = {1, 2, 3, 4};, error/warning देता है। साथ ही, बिना मान दिया लोकल ऐरे में garbage मान होते हैं। ग्लोबल ऐरे अपने आप 0 से भर जाता है।
ऐरे को b = a; से कॉपी नहीं किया जा सकता। लूप से तत्व-दर-तत्व कॉपी करें।

5. तत्वों तक पहुँच: Input, Output और Traversal

एक तत्व के लिए array_name[index] लिखते हैं, जैसे a[2] = 50; या printf("%d", a[2]);। सभी तत्वों के लिए लूप लेते हैं जिसका वेरिएबल index का काम करता है। हर तत्व को एक बार देखना traversal कहलाता है।

प्रोग्राम 1: 5 संख्याएँ पढ़ना और दिखाना

#include <stdio.h>

int main()
{
    int a[5], i;
    printf("Enter 5 numbers: ");
    for (i = 0; i < 5; i++)
        scanf("%d", &a[i]);          // note the & sign

    printf("You entered: ");
    for (i = 0; i < 5; i++)
        printf("%d ", a[i]);
    return 0;
}
Enter 5 numbers: 4 8 2 6 10 You entered: 4 8 2 6 10

scanf("%d", &a[i]); में & पर ध्यान दें। हर तत्व एक अलग पूर्णांक वेरिएबल है, इसलिए उसका address चाहिए।

प्रोग्राम 2: योग और औसत

#include <stdio.h>

int main()
{
    int a[5] = {4, 8, 2, 6, 10};
    int i, sum = 0;
    float avg;

    for (i = 0; i < 5; i++)
        sum = sum + a[i];
    avg = (float)sum / 5;

    printf("Sum = %d\n", sum);
    printf("Average = %.2f", avg);
    return 0;
}
Sum = 30 Average = 6.00

(float)sum / 5 पहले योग को float में बदलता है ताकि औसत का दशमलव भाग बना रहे।

6. ऐरे Index सीमा से बाहर (Out of Bounds)

int a[5] = {1, 2, 3, 4, 5};
a[5] = 99;      // WRONG: valid indexes are 0 to 4
a[-1] = 7;      // WRONG: negative index
  • C सीमा की जाँच नहीं करता। कोई अपने-आप error संदेश नहीं आता।
  • गलत index से दूसरे वेरिएबल बदल सकते हैं, garbage आउटपुट आ सकता है या प्रोग्राम क्रैश हो सकता है।
  • लूप की शर्त हमेशा i < size रखें (i <= size नहीं)।

7. एक-आयामी ऐरे के सामान्य प्रोग्राम

प्रोग्राम 3: सबसे बड़ा और सबसे छोटा तत्व

#include <stdio.h>

int main()
{
    int a[5] = {12, 45, 7, 30, 22};
    int i, max, min;

    max = min = a[0];                // assume first is both
    for (i = 1; i < 5; i++)
    {
        if (a[i] > max) max = a[i];
        if (a[i] < min) min = a[i];
    }
    printf("Largest = %d\n", max);
    printf("Smallest = %d", min);
    return 0;
}
Largest = 45 Smallest = 7

विचार: पहले तत्व को ही सबसे बड़ा और सबसे छोटा मान लें, फिर बाकी सभी तत्वों से तुलना करें।

प्रोग्राम 4: ऐरे को उल्टे क्रम में छापना

#include <stdio.h>

int main()
{
    int a[5] = {1, 2, 3, 4, 5};
    int i;
    for (i = 4; i >= 0; i--)         // last index to first index
        printf("%d ", a[i]);
    return 0;
}
5 4 3 2 1

प्रोग्राम 5: सम (even) और विषम (odd) संख्याएँ गिनना

#include <stdio.h>

int main()
{
    int a[7] = {1, 2, 3, 4, 5, 6, 7};
    int i, even = 0, odd = 0;

    for (i = 0; i < 7; i++)
    {
        if (a[i] % 2 == 0)
            even++;
        else
            odd++;
    }
    printf("Even = %d, Odd = %d", even, odd);
    return 0;
}
Even = 3, Odd = 4

प्रोग्राम 6: एक ऐरे को दूसरे में कॉपी करना

#include <stdio.h>

int main()
{
    int a[3] = {3, 6, 9}, b[3], i;
    for (i = 0; i < 3; i++)
        b[i] = a[i];                 // element-by-element copy
    for (i = 0; i < 3; i++)
        printf("%d ", b[i]);
    return 0;
}
3 6 9

8. ऐरे में खोज: Linear Search

Linear search: key (खोजा जाने वाला मान) की तुलना शुरू से एक-एक तत्व से तब तक की जाती है जब तक वह मिल न जाए या ऐरे समाप्त न हो जाए।
#include <stdio.h>

int main()
{
    int a[5] = {7, 3, 9, 5, 1};
    int i, key = 5, found = 0;

    for (i = 0; i < 5; i++)
    {
        if (a[i] == key)
        {
            printf("Found at index %d", i);
            found = 1;
            break;                   // stop searching
        }
    }
    if (found == 0)
        printf("Not found");
    return 0;
}
Found at index 3
  • किसी भी ऐरे (क्रमबद्ध या अक्रमबद्ध) पर काम करता है।
  • सबसे अच्छी स्थिति: key पहला तत्व है (1 तुलना)। सबसे बुरी स्थिति: key अंतिम है या नहीं है (n तुलनाएँ)।
  • break key मिलते ही लूप रोक देता है।
  • क्रमबद्ध ऐरे के लिए तेज़ विधि binary search होती है: वह key की तुलना बीच के तत्व से करती है और हर बार आधा ऐरे छोड़ देती है।

9. ऐरे को क्रमबद्ध करना: Bubble Sort

Sorting: तत्वों को बढ़ते (छोटे से बड़े) या घटते (बड़े से छोटे) क्रम में लगाना। Bubble sort बार-बार पास-पास के तत्वों की तुलना करके गलत क्रम होने पर उनकी अदला-बदली करता है।
#include <stdio.h>

int main()
{
    int a[5] = {5, 1, 4, 2, 3};
    int i, j, t;

    for (i = 0; i < 4; i++)              // number of passes
        for (j = 0; j < 4 - i; j++)      // compare neighbours
            if (a[j] > a[j + 1])
            {
                t = a[j];                // swap
                a[j] = a[j + 1];
                a[j + 1] = t;
            }

    for (i = 0; i < 5; i++)
        printf("%d ", a[i]);
    return 0;
}
1 2 3 4 5

कार्यप्रणाली

  • पास 1 के बाद सबसे बड़ा तत्व अंतिम स्थान पर पहुँचता है; पास 2 के बाद दूसरा सबसे बड़ा अपनी जगह पर, और इसी तरह आगे।
  • n तत्वों के लिए अधिकतम n − 1 पास चाहिए।
  • अदला-बदली के लिए तीसरा वेरिएबल t चाहिए: t = a[j]; a[j] = a[j+1]; a[j+1] = t;
सुझाव: घटते क्रम के लिए शर्त a[j] < a[j+1] कर दें।

10. फ़ंक्शन को ऐरे भेजना

फ़ंक्शन की कॉल में ऐरे का नाम लिखा जाता है, जो पहले तत्व का address होता है। इसलिए फ़ंक्शन मूल ऐरे पर काम करता है और उसमें किए गए बदलाव main() में भी दिखते हैं। आकार आमतौर पर दूसरे आर्गुमेंट के रूप में भेजा जाता है।

#include <stdio.h>

int sum(int arr[], int n)      // array + its size
{
    int i, s = 0;
    for (i = 0; i < n; i++)
        s = s + arr[i];
    return s;
}

int main()
{
    int marks[5] = {1, 2, 3, 4, 5};
    printf("Total = %d", sum(marks, 5));
    return 0;
}
Total = 15
  • हेडर: int sum(int arr[], int n)। कॉल: sum(marks, 5) (कॉल में कोष्ठक नहीं)।
  • एकल तत्व, जैसे marks[2], value द्वारा (कॉपी) जाता है।

11. द्वि-आयामी ऐरे (Matrix)

Syntax: data_type array_name[rows][columns]; उदाहरण: int m[3][3]; में 3 पंक्तियाँ और 3 स्तंभ हैं, इसलिए 3 × 3 = 9 तत्व।

पंक्ति i और स्तंभ j का तत्व m[i][j] है। कुल तत्व = पंक्तियाँ × स्तंभ। मेमोरी = पंक्तियाँ × स्तंभ × तत्व का आकार (int के लिए 3 × 3 × 4 = 36 बाइट)।

Initialisation

int m[2][3] = {{1, 2, 3}, {4, 5, 6}};   // 2 rows, 3 columns
int n[2][3] = {1, 2, 3, 4, 5, 6};       // same result
int p[][3]  = {{1, 2, 3}, {4, 5, 6}};   // rows may be omitted, columns must be given

प्रोग्राम 7: Matrix दिखाना (nested loops)

बाहरी लूप पंक्तियाँ और भीतरी लूप स्तंभ नियंत्रित करता है।

#include <stdio.h>

int main()
{
    int m[3][3] = {{1, 2, 3},
                   {4, 5, 6},
                   {7, 8, 9}};
    int i, j;

    for (i = 0; i < 3; i++)          // rows
    {
        for (j = 0; j < 3; j++)      // columns
            printf("%d ", m[i][j]);
        printf("\n");                // new line after every row
    }
    return 0;
}

प्रोग्राम 8: दो matrix का जोड़

Matrix का क्रम (order) समान होना चाहिए। एक ही स्थान के तत्व जोड़े जाते हैं।

#include <stdio.h>

int main()
{
    int A[2][2] = {{1, 2}, {3, 4}};
    int B[2][2] = {{5, 6}, {7, 8}};
    int S[2][2], i, j;

    for (i = 0; i < 2; i++)
        for (j = 0; j < 2; j++)
            S[i][j] = A[i][j] + B[i][j];

    for (i = 0; i < 2; i++)
    {
        for (j = 0; j < 2; j++)
            printf("%d ", S[i][j]);
        printf("\n");
    }
    return 0;
}

प्रोग्राम 9: Matrix का transpose

Transpose का अर्थ है पंक्तियों और स्तंभों की अदला-बदली, इसलिए 2×3 matrix 3×2 बन जाता है।

#include <stdio.h>

int main()
{
    int A[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int T[3][2], i, j;

    for (i = 0; i < 2; i++)
        for (j = 0; j < 3; j++)
            T[j][i] = A[i][j];           // rows become columns

    for (i = 0; i < 3; i++)
    {
        for (j = 0; j < 2; j++)
            printf("%d ", T[i][j]);
        printf("\n");
    }
    return 0;
}

Q5. ऐरे का index 0 से क्यों शुरू होता है?
Index बताता है कि तत्व पहले तत्व से कितनी दूरी पर है। पहला तत्व base address पर ही है यानी दूरी 0, इसलिए उसका index 0 है। पता base + index × आकार से निकाला जाता है।
Q6. “Array index out of bounds” का क्या अर्थ है? यह खतरनाक क्यों है?
इसका अर्थ है 0 से छोटा या आकार के बराबर/अधिक index प्रयोग करना, जैसे int a[5] में a[5]। C इसकी जाँच नहीं करता, इसलिए दूसरे वेरिएबल बदल सकते हैं, गलत परिणाम आ सकते हैं या प्रोग्राम क्रैश हो सकता है।
Q7. ऐरे द्वारा घेरी गई मेमोरी कैसे निकालते हैं? उदाहरण दीजिए।
मेमोरी = तत्वों की संख्या × एक तत्व का आकार। float f[10] में, float 4 बाइट का मानें तो 10 × 4 = 40 बाइट।
Q8. Linear search संक्षेप में समझाइए।
Linear search में खोजा जाने वाला मान (key) पहले तत्व से शुरू करके एक-एक तत्व से मिलाया जाता है। मेल मिलने पर उसका index बताया जाता है; मेल मिले बिना ऐरे समाप्त हो जाए तो key मौजूद नहीं है। यह क्रमबद्ध और अक्रमबद्ध दोनों ऐरे पर काम करता है।
Q9. Bubble sort संक्षेप में समझाइए।
Bubble sort पास-पास के हर जोड़े की तुलना करता है और बायाँ तत्व बड़ा हो तो (बढ़ते क्रम के लिए) अदला-बदली कर देता है। पहले पास के बाद सबसे बड़ा तत्व अंत में पहुँचता है; पास दोहराने (अधिकतम n−1) पर ऐरे क्रमबद्ध हो जाता है।

Q5. Bubble sort को प्रोग्राम और चित्र सहित समझाइए। (5 अंक)
#include <stdio.h>

int main()
{
    int a[5] = {5, 1, 4, 2, 3};
    int i, j, t;

    for (i = 0; i < 4; i++)              // number of passes
        for (j = 0; j < 4 - i; j++)      // compare neighbours
            if (a[j] > a[j + 1])
            {
                t = a[j];                // swap
                a[j] = a[j + 1];
                a[j + 1] = t;
            }

    for (i = 0; i < 5; i++)
        printf("%d ", a[i]);
    return 0;
}
1 2 3 4 5

हर पास में पास-पास के तत्वों की तुलना होती है और बायाँ तत्व बड़ा हो तो अदला-बदली होती है। पास 1 के बाद सबसे बड़ा मान अंत में पहुँचता है। अधिकतम n − 1 पास में ऐरे क्रमबद्ध हो जाता है।
