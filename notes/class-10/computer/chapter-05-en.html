1. Pointers

Pointer: a variable that stores the memory address of another variable.

Every variable lives at an address in memory (like a house number). A pointer holds that address, so it can reach the variable indirectly.

  • & = address-of operator: &x gives the address of x.
  • * = dereference (value-at) operator: *p gives the value stored at the address in p.
  • Declaration: int *p; (pointer to int); float *q;
  • Always initialise a pointer; use NULL if it points to nothing.
int x = 10;
int *p = &x;          // p stores the address of x
printf("%d", x);      // 10
printf("%p", &x);     // address of x
printf("%d", *p);     // 10  (value at address)
*p = 20;              // x becomes 20

2. Pointers and Arrays

  • An array name is the address of its first element: a = &a[0].
  • p++ moves the pointer by sizeof(type) (4 bytes for int), not by 1 byte.
  • *(a+i) is the same as a[i].
int a[3] = {10, 20, 30};
int *p = a;           // same as &a[0]
printf("%d", *p);     // 10
p++;                  // moves 4 bytes (size of int)
printf("%d", *p);     // 20
printf("%d", *(a+2)); // 30

3. Call by Reference

Passing addresses to a function lets it change the original variables (in call by value only a copy changes).

void swap(int *a, int *b) {
    int t = *a; *a = *b; *b = t;
}
int main() {
    int x = 5, y = 9;
    swap(&x, &y);     // x = 9, y = 5
    return 0;
}

4. File Handling

File: a named place on disk to store data permanently. Variables in RAM are lost when the program ends; files are not.
  • Text file: readable characters (.txt). Binary file: raw bytes (.dat).
  • A file is accessed through a file pointer: FILE *fp;
  • Steps: 1. Open (fopen) → 2. Read/Write → 3. Close (fclose).
  • fopen returns NULL if the file cannot be opened.
#include <stdio.h>
int main() {
    FILE *fp;
    char buf[20];
    fp = fopen("data.txt", "w");
    if (fp == NULL) { printf("Error"); return 1; }
    fprintf(fp, "Hello");
    fclose(fp);

    fp = fopen("data.txt", "r");
    fgets(buf, 20, fp);
    printf("%s", buf);    // Hello
    fclose(fp);
    return 0;
}

5. Remember

  • & gives address; * gives value at address.
  • Pointer holds an address, not a normal value.
  • p++ jumps by the size of the data type.
  • Always check fopen result for NULL, and always fclose().
  • w erases old data; a adds at the end.
