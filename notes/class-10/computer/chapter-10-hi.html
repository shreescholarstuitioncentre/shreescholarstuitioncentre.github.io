अध्याय 10: C भाषा पर आधारित प्रोग्राम

1. C भाषा क्या है?

C एक सामान्य-उद्देश्य वाली, संरचित, उच्च-स्तरीय भाषा है जिसे 1972 में बेल लैब्स में डेनिस रिची ने बनाया। यह तेज़ और पोर्टेबल है तथा C++ और Java का आधार है। C प्रोग्राम निर्देशों का समूह होता है जिसे कंप्यूटर एक-एक करके चलाता है।

2. C प्रोग्राम की संरचना

हर C प्रोग्राम में हैडर सेक्शन, main() फ़ंक्शन और कर्ली ब्रैकेट { } के अंदर स्टेटमेंट होते हैं। हर स्टेटमेंट सेमीकोलन (;) पर समाप्त होता है। एनिमेटेड चित्र में हर भाग बारी-बारी से चमकता है।

चित्र 1: C प्रोग्राम की संरचना

3. C प्रोग्राम कैसे चलता है?

आप सोर्स कोड लिखते हैं; कंपाइलर उसे ऑब्जेक्ट कोड में बदलता है (और गलतियाँ बताता है); लिंकर लाइब्रेरी कोड जोड़कर एक्ज़ीक्यूटेबल फ़ाइल बनाता है; अंत में CPU उसे चलाकर आउटपुट दिखाता है।

चित्र 2: C प्रोग्राम का निष्पादन

4. मूल निर्माण खंड

डेटा टाइप बताता है कि वेरिएबल में किस प्रकार का मान रहेगा। scanf() में वेरिएबल के नाम से पहले हमेशा & लगाएँ।

टाइपअर्थफ़ॉर्मेटआकार
intपूर्ण संख्या%d4 बाइट
floatदशमलव संख्या%f4 बाइट
doubleबड़ी दशमलव संख्या%lf8 बाइट
charएक अक्षर%c1 बाइट
अंकगणितीय+ - * / %
तुलनात्मक> < >= <= == !=
तार्किक&& || !
असाइनमेंट / वृद्धि / कमी= += ++ --

5. निर्णय लेना (if, if-else, switch)

if शर्त सही होने पर कोड चलाता है; if-else दो रास्ते देता है; else-if सीढ़ी में कई शर्तें जाँची जाती हैं; switch मान के अनुसार कई विकल्पों में से एक चुनता है (हर case के बाद break लगाएँ)।

6. लूप (दोहराव)

for तब प्रयोग होता है जब दोहराव की संख्या पता हो; while पहले शर्त जाँचता है; do-while कम से कम एक बार चलता है। नीचे for लूप का एनिमेटेड फ़्लोचार्ट है: बिंदु रास्ते पर चलता है।

चित्र 3: for लूप का फ़्लोचार्ट

7. ऐरे, स्ट्रिंग, फ़ंक्शन, पॉइंटर, स्ट्रक्चर

ऐरे एक ही प्रकार के कई मान लगातार मेमोरी में रखता है; इंडेक्स 0 से शुरू होता है। स्ट्रिंग null अक्षर पर समाप्त होने वाला char ऐरे है। फ़ंक्शन दोबारा प्रयोग होने वाला कोड-ब्लॉक है। पॉइंटर वेरिएबल का पता (address) रखता है। स्ट्रक्चर अलग-अलग प्रकार के डेटा को एक नाम से जोड़ता है।

प्रोग्राम 46: फ़ंक्शन: संख्या का वर्ग

int sq(int n){
 return n*n;
}

 printf("Square = %d",sq(6));
 return 0;
}

प्रोग्राम 47: रिकर्शन: फ़िबोनाची
कोड
#include <stdio.h>
int fib(int n){
 if(n<=1) return n;
 return fib(n-1)+fib(n-2);
}
int main(){
 printf("fib(7) = %d",fib(7));
 return 0;
}
आउटपुट
fib(7) = 13
प्रोग्राम 48: पॉइंटर की मूल बातें
कोड
#include <stdio.h>
int main(){
 int x=25,*p=&x;
 printf("x = %d\n",x);
 printf("*p = %d",*p);
 return 0;
}
आउटपुट
x = 25
*p = 25
प्रोग्राम 49: स्ट्रक्चर: विद्यार्थी रिकॉर्ड
कोड
#include <stdio.h>
struct student{ int roll; char name[20]; int marks; };
int main(){
 struct student s={1,"Ravi",85};
 printf("Roll: %d\nName: %s\nMarks: %d",s.roll,s.name,s.marks);
 return 0;
}
आउटपुट
Roll: 1
Name: Ravi
Marks: 85
प्रोग्राम 50: दो संख्याओं का महत्तम (HCF)
कोड
#include <stdio.h>
int main(){
 int a=12,b=18,t;
 while(b!=0){ t=b; b=a%b; a=t; }
 printf("GCD = %d",a);
 return 0;
}
आउटपुट
GCD = 6
प्रोग्राम 51: लूप से घात (power)
कोड
#include <stdio.h>
int main(){
 int i,p=1;
 for(i=1;i<=5;i++) p=p*2;
 printf("2^5 = %d",p);
 return 0;
}
आउटपुट
2^5 = 32
प्रोग्राम 52: दशमलव से बाइनरी
कोड
#include <stdio.h>
int main(){
 int n=10,b[8],i=0;
 while(n>0){ b[i++]=n%2; n=n/2; }
 for(i--;i>=0;i--) printf("%d",b[i]);
 return 0;
}
