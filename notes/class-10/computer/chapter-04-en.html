Chapter 4: Structures and Union

User-defined data types  |  Computer Applications, Class 10

1. Why Structure?

An array stores many values of the same type. But real things (a student) have different types of data: roll (int), name (char), marks (float).

Structure: a user-defined data type that groups variables of different data types under one name. Each variable inside is called a member (or field).

2. Defining and Using a Structure

  • Keyword: struct. Declaration ends with a semicolon.
  • Declaring variable: struct student s1, s2;
  • Access a member with the dot (.) operator: s1.roll
  • Initialise with braces in the same order as the members.
  • Memory of a structure = sum of all members (every member has its own space).
struct student {
    int roll;
    char name[10];
    float marks;
};                       // semicolon is a must

int main() {
    struct student s1 = {1, "Amit", 85.5};
    printf("%d %s %.1f", s1.roll, s1.name, s1.marks);
    s1.marks = 90.0;      // dot operator
    return 0;
}
Fig 1: Memory layout of struct student (animated) – numbers are byte offsets

Total = 4 + 10 + 4 = 18 bytes (the compiler may add extra padding bytes). Members sit one after another.

3. Array, Nested Structure and Pointer

A. Array of structures

Stores records of many students. s[i].marks = marks of the i-th student.

struct student s[3];
for (i = 0; i < 3; i++)
    scanf("%d %s %f", &s[i].roll, s[i].name, &s[i].marks);

B. Nested structure

A structure inside another structure; use one dot per level.

struct date { int d, m, y; };
struct emp { int id; struct date dob; } e;
e.dob.y = 2008;   // two dots

C. Pointer to structure

With a pointer use the arrow (->) operator.

struct student *p = &s1;
printf("%d", p->roll);   // same as (*p).roll

4. Union

Union: like a structure, but all members share the same memory. Keyword: union.
  • Size of union = size of its largest member.
  • Only one member holds a valid value at a time.
  • Storing a new value overwrites the old one.
  • Used to save memory.
union data {
    int i;
    float f;
    char c;
};
union data u;
u.i = 10;
u.f = 5.5;                // overwrites u.i
printf("%d", sizeof(u)); // 4 (largest member)

After f = 5.5, reading i gives a garbage number: the same bytes are read as an int. This is why only the last stored member is valid.

6. Remember

  • Structure = different data types under one name; access with . (or -> for pointers).
  • Don’t forget the ; after the closing brace.
  • struct size = sum; union size = largest member.
  • Union: new value overwrites the old.
