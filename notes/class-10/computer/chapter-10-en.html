Chapter 10: Programs Based on C Language

1. What is C Language?

C is a general-purpose, structured, high-level language created by Dennis Ritchie at Bell Labs in 1972. It is fast and portable, and it is the base of C++ and Java. A C program is a set of instructions that the computer executes one by one.

2. Structure of a C Program

Every C program has a header section, a main() function and statements inside curly braces { }. Each statement ends with a semicolon (;). In the animated diagram each part glows in turn.

Fig. 1: Structure of a C program

3. How a C Program Runs

You write the source code; the compiler converts it into object code (and reports errors); the linker joins library code and builds an executable file; finally the CPU runs it and shows the output.

Fig. 2: Execution of a C program

5. Decision Making (if, if-else, switch)

if runs code when a condition is true; if-else gives two paths; an else-if ladder checks many conditions; switch picks one of many cases by value (put break after each case).

6. Loops (Repetition)

for is used when the number of repetitions is known; while checks the condition first; do-while runs at least once. Below is the animated flowchart of a for loop: the dot follows the path.

Fig. 3: Flowchart of for loop

7. Arrays, Strings, Functions, Pointers, Structures

An array stores many values of the same type in continuous memory; the index starts at 0. A string is a char array ending with a null character. A function is a reusable block of code. A pointer stores the address of a variable. A structure groups different data types under one name.

Fig. 4: Array in memory
