1. फ़ंक्शन (सबरूटीन)

परिभाषा: फ़ंक्शन कथनों (statements) का एक नाम वाला ब्लॉक है जो कोई एक विशेष कार्य करता है। यह तभी चलता है जब इसे call किया जाए, और इसे बार-बार प्रयोग किया जा सकता है।

फ़ंक्शन क्यों?

  • बड़ा प्रोग्राम छोटे भागों में बँट जाता है (मॉड्यूलर प्रोग्रामिंग)।
  • पुनः उपयोग – एक बार लिखो, कई बार call करो।
  • त्रुटि ढूँढना (debug) और समझना आसान।
  • समय और मेमोरी की बचत।

प्रकार

  • लाइब्रेरी (built-in) फ़ंक्शन: printf(), scanf(), sqrt(), strlen()।
  • यूज़र-डिफ़ाइंड फ़ंक्शन: प्रोग्रामर द्वारा लिखे गए, जैसे add()।

सिंटैक्स

return_type function_name(parameter list) { body }

प्रोटोटाइप (main से पहले घोषणा): int add(int, int);

int add(int a, int b)      // function header
{
    int s = a + b;          // function body
    return s;               // return value
}
int main()
{
    int r = add(5, 3);      // function call
    printf("%d", r);        // output: 8
    return 0;
}

चित्र 1: फ़ंक्शन call और return (डेटा का प्रवाह)

भाग: return type (int), नाम (add), फ़ॉर्मल पैरामीटर (int a, int b), बॉडी, return कथन। Call by value: वास्तविक मान की कॉपी फ़ॉर्मल पैरामीटर में जाती है, इसलिए मूल मान नहीं बदलता।

2. सर्चिंग (खोज)

सर्चिंग का अर्थ है किसी ऐरे (array) में दिए गए तत्व (key) की स्थिति ढूँढना।

क. लीनियर (क्रमिक) सर्च

  • key की तुलना पहले से अंतिम तत्व तक एक-एक से करें।
  • बराबर मिले तो स्थिति बताएँ और रुक जाएँ, वरना अगले पर जाएँ।
  • अंत तक न मिले तो नहीं मिला।
  • ऐरे का क्रमबद्ध होना ज़रूरी नहीं। बड़े डेटा में धीमी (n तुलनाएँ)।
int linear(int a[], int n, int key)
{
    for (int i = 0; i < n; i++)
        if (a[i] == key) return i;   // found
    return -1;                       // not found
}

ख. बाइनरी सर्च

  • ऐरे क्रमबद्ध (sorted) होना चाहिए।
  • mid = (low + high) / 2 निकालें।
  • key == a[mid] → मिल गया।
  • key > a[mid] → दायाँ आधा भाग खोजें (low = mid+1)।
  • key < a[mid] → बायाँ आधा भाग खोजें (high = mid-1)।
  • low > high होने तक दोहराएँ। बहुत तेज़ (लगभग log₂n चरण)।
int binary(int a[], int n, int key)
{
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (a[mid] == key) return mid;
        else if (key > a[mid]) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

3. सॉर्टिंग (क्रमबद्ध करना)

सॉर्टिंग का अर्थ है तत्वों को आरोही (ascending) या अवरोही (descending) क्रम में लगाना।

क. बबल सॉर्ट

  • दो आसन्न तत्वों की तुलना करें; बायाँ बड़ा हो तो अदला-बदली (swap) करें।
  • पहले पास के बाद सबसे बड़ा तत्व अंत में पहुँच जाता है (बुलबुले की तरह)।
  • n-1 पास दोहराएँ; हर पास में एक तुलना कम होती है।
for (i = 0; i < n-1; i++)
  for (j = 0; j < n-i-1; j++)
    if (a[j] > a[j+1]) {
      t = a[j]; a[j] = a[j+1]; a[j+1] = t;
    }
चित्र 4: बबल सॉर्ट – नारंगी = तुलना, हरा = क्रमबद्ध (एनिमेशन)

ख. सेलेक्शन सॉर्ट

  • अक्रमबद्ध भाग में सबसे छोटा तत्व ढूँढें।
  • उसे उस भाग के पहले तत्व से swap करें।
  • बाकी भाग के लिए दोहराएँ। उदाहरण: 29 10 14 → 10 29 14 → 10 14 29।
for (i = 0; i < n-1; i++) {
  min = i;
  for (j = i+1; j < n; j++)
    if (a[j] < a[min]) min = j;
  t = a[i]; a[i] = a[min]; a[min] = t;
}

5. याद रखें

  • फ़ंक्शन = दोबारा प्रयोग होने वाला नामित ब्लॉक; call करने पर चलता है।
  • बाइनरी सर्च केवल sorted ऐरे पर चलती है।
  • बबल सॉर्ट पड़ोसियों को swap करता है; सेलेक्शन सॉर्ट न्यूनतम को।
  • सर्च का परिणाम: index, या नहीं मिला तो -1।
