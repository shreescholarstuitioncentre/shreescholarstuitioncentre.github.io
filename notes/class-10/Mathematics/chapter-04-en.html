Class 10 Maths – Ch 4: Quadratic Equations

1. Quadratic Equation

Standard form: ax² + bx + c = 0, where a, b, c are real numbers and a ≠ 0. Degree is 2, so it has at most 2 roots.
Eg 2x² − 3x + 1 = 0. Not quadratic: x³ + 2x = 5 (degree 3), 3x + 2 = 0 (degree 1).
Some equations become quadratic after simplifying: (x+1)² = 2(x−3) ⇒ x² + 7 = 0.
Root: α is a root (zero) of ax² + bx + c = 0 if aα² + bα + c = 0. Eg x = 2 in x² − 5x + 6: 4 − 10 + 6 = 0 ✓.

2. Solving by Factorisation

Steps: (1) Write in standard form. (2) Split the middle term b into two numbers whose sum = b and product = ac. (3) Factorise. (4) Put each factor = 0.
Example: 6x² − x − 2 = 0. ac = −12; split −x = 3x − 4x. 6x² + 3x − 4x − 2 = 3x(2x + 1) − 2(2x + 1) = (3x − 2)(2x + 1). x = 2/3 or x = −1/2.

The parabola of y = x² − 5x + 6 crosses the x-axis at x = 2 and x = 3. These are exactly the roots of x² − 5x + 6 = 0. The lowest point (vertex) lies midway between the roots at x = 2.5.

3. Completing the Square

Watch the picture: x² + 6x is a square with two 3×x strips. The missing corner is 3×3 = 9. Adding 9 gives the perfect square (x + 3)². This is the idea behind the method.

Steps: divide by a; move constant to RHS; add (½ × coefficient of x)² to both sides; write LHS as a square; take square root.
Example: 2x² − 7x + 3 = 0 ⇒ x² − (7/2)x = −3/2 ⇒ (x − 7/4)² = −3/2 + 49/16 = 25/16 ⇒ x − 7/4 = ± 5/4 ⇒ x = 3 or 1/2.

4. Quadratic Formula

x = (−b ± √(b² − 4ac)) / 2a, provided b² − 4ac ≥ 0.
Discriminant D = b² − 4ac.
Sum of roots = −b/a; Product of roots = c/a.

Example: 2x² − 7x + 3 = 0: D = 49 − 24 = 25, x = (7 ± 5)/4 = 3 or 1/2 ✓.

Nature of roots

DiscriminantRoots
D > 0Two distinct real roots
D = 0Two equal real roots, x = −b/2a
D < 0No real roots

5. Word Problems

  • Assume the unknown as x; form a quadratic equation from the statement.
  • Solve it; reject negative or impossible values for length, age, speed, number of objects.
  • Types: consecutive integers (x, x+1), numbers with given sum/product, area and Pythagoras, speed–time (time = distance/speed), work, ages.

Q & A – Practice

MCQs (NCERT / Balaji / Rajeev / UP Board style)

Which is a quadratic equation? (a) x³ + 2x = 5 (b) x² − 3x + 1 = 0 (c) 3x + 2 = 0 (d) 2x = 5
(b). Highest power is 2.
Roots of x² − 5x + 6 = 0 are (a) 1, 6 (b) −2, −3 (c) 2, 3 (d) −1, −6
(c) 2, 3: (x−2)(x−3) = 0.
Discriminant of 2x² − 4x + 3 = 0 is (a) 8 (b) −8 (c) 40 (d) −40
(b) −8: 16 − 24.
x² + 4 = 0 has (a) two real roots (b) one real root (c) no real roots (d) infinite roots
(c) no real roots; D = −16 < 0.
If 2 is a root of x² − 5x + k = 0, k = (a) 3 (b) 4 (c) 6 (d) 10
(c) 6: 4 − 10 + k = 0.
Sum of roots of 2x² − 7x + 3 = 0 is (a) 7/2 (b) −7/2 (c) 3/2 (d) −3/2
(a) 7/2 = −b/a.
x² − kx + 9 = 0 has equal roots if k = (a) 3 (b) ±3 (c) 6 (d) ±6
(d) ±6: k² − 36 = 0.

Short Answer

Solve x² − 3x − 10 = 0.
(x − 5)(x + 2) = 0 ⇒ x = 5, −2.
Find the nature of roots of 2x² − 6x + 3 = 0 and find them.
D = 36 − 24 = 12 > 0 ⇒ two distinct real roots. x = (6 ± √12)/4 = (3 ± √3)/2.
Find k so that kx(x − 2) + 6 = 0 has equal roots.
kx² − 2kx + 6 = 0; D = 4k² − 24k = 0 ⇒ 4k(k − 6) = 0. k ≠ 0, so k = 6.
Product of two consecutive positive integers is 306. Find them.
x(x+1) = 306 ⇒ x² + x − 306 = 0 ⇒ (x + 18)(x − 17) = 0 ⇒ x = 17 (reject −18). 17 and 18.
Solve 3x² − 5x + 2 = 0 by the quadratic formula.
D = 25 − 24 = 1; x = (5 ± 1)/6 ⇒ x = 1 or 2/3.

Long Answer

Solve 2x² − 7x + 3 = 0 by completing the square.
Divide by 2: x² − (7/2)x + 3/2 = 0. Move constant: x² − (7/2)x = −3/2. Add (7/4)² = 49/16: (x − 7/4)² = 49/16 − 24/16 = 25/16. Square root: x − 7/4 = ±5/4. x = 3 or x = 1/2.
Find two numbers whose sum is 27 and product is 182.
Numbers x and 27 − x: x(27 − x) = 182 ⇒ x² − 27x + 182 = 0. D = 729 − 728 = 1; x = (27 ± 1)/2 = 14 or 13. Numbers: 13 and 14.
A train travels 360 km at a uniform speed. If the speed were 5 km/h more, it would take 1 hour less. Find the speed.
Speed x: 360/x − 360/(x+5) = 1 ⇒ 1800 = x(x + 5) ⇒ x² + 5x − 1800 = 0. D = 7225 = 85²; x = (−5 + 85)/2 = 40 (reject negative). Speed = 40 km/h. Check: 9 h vs 8 h ✓.
The altitude of a right triangle is 7 cm less than its base. If the hypotenuse is 13 cm, find the other two sides.
Base x, altitude x − 7: x² + (x − 7)² = 169 ⇒ x² − 7x − 60 = 0 ⇒ (x − 12)(x + 5) = 0 ⇒ x = 12. Base 12 cm, altitude 5 cm (5-12-13 ✓).
Find k for which kx² + kx + 1 = 0 has equal roots.
D = k² − 4k = 0 ⇒ k(k − 4) = 0. k = 0 gives 1 = 0, not quadratic, so k = 4.
