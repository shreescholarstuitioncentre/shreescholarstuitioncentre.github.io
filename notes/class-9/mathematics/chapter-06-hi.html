📌 भूमिका: बहुपद को लंबा भाग किए बिना शेषफल निकालना और यह जाँचना कि कोई रैखिक व्यंजक गुणनखंड है या नहीं, इन्हीं दो प्रमेयों से संभव है।

1. शेषफल प्रमेय

कथन: यदि p(x) घात ≥ 1 का बहुपद है और इसे (x − a) से भाग दिया जाए, तो शेषफल = p(a)।
रूपांतर:
• (x + a) से भाग: शेषफल p(−a)
• (ax + b) से भाग: शेषफल p(−b/a)
• (b − ax) से भाग: शेषफल p(b/a)

प्रमाण

भाग एल्गोरिथ्म से p(x) = (x − a)·q(x) + r (r अचर)। दोनों ओर x = a रखें: p(a) = 0·q(a) + r = r। अतः शेषफल r = p(a)। ∎

एनिमेटेड चित्र 1: प्रमाण का प्रवाह

एनिमेटेड चित्र 2: लंबा भाग (x³ − 3x² + 2x + 4) ÷ (x − 2)

भाग से शेषफल 4 मिलता है, और p(2) = 8 − 12 + 4 + 4 = 4 भी वही है। दोनों विधियाँ मेल खाती हैं।

2. गुणनखंड प्रमेय

कथन: (x − a), p(x) का गुणनखंड है ⇔ p(a) = 0।
अर्थ: शेषफल 0 आए तो भाग पूरा-पूरा जाता है।

उपयोग: (i) गुणनखंड की जाँच, (ii) अज्ञात k ज्ञात करना, (iii) त्रिघात बहुपद का गुणनखंडन। परीक्षण के लिए अचर पद के गुणनखंड (±1, ±2, ±3, …) आज़माएँ।

3. हल किए गए उदाहरण

शेषफल: x³ + 3x² + 3x + 1 को (x + 1) से भाग।
पद 1: x + 1 = x − (−1) ⇒ a = −1
पद 2: p(−1) = −1 + 3 − 3 + 1 = 0
शेषफल = 0।
शेषफल: 2x³ − 5x² + x − 3 को (2x − 1) से भाग।
पद 1: 2x − 1 = 0 ⇒ x = 1/2
पद 2: p(1/2) = 2/8 − 5/4 + 1/2 − 3 = 1/4 − 5/4 + 1/2 − 3
पद 3: = −1 + 1/2 − 3 = −7/2
शेषफल = −7/2।
जाँचिए: क्या (x − 3), x³ − 4x² + x + 6 का गुणनखंड है?
पद 1: p(3) = 27 − 36 + 3 + 6
पद 2: = 0
हाँ, गुणनखंड है।
k ज्ञात कीजिए: (x + 2), 2x³ + kx² − 5x − 6 का गुणनखंड हो।
पद 1: p(−2) = 0
पद 2: 2(−8) + 4k + 10 − 6 = 0 ⇒ 4k − 12 = 0
k = 3।
गुणनखंड कीजिए: x³ − 7x + 6
पद 1: p(1) = 1 − 7 + 6 = 0 ⇒ (x−1) गुणनखंड।
पद 2: भाग देने पर x² + x − 6।
पद 3: x² + x − 6 = (x+3)(x−2)।
(x−1)(x+3)(x−2)।
सिद्ध कीजिए: (x − a), xⁿ − aⁿ का गुणनखंड है।
पद 1: p(x) = xⁿ − aⁿ।
पद 2: p(a) = aⁿ − aⁿ = 0।
पद 3: गुणनखंड प्रमेय से (x − a) गुणनखंड है। ∎
कठिन: x³ + ax² + 3x − 5 तथा x² + ax + 3 को (x − 2) से भाग देने पर समान शेषफल मिलता है। a ज्ञात कीजिए।
पद 1: p(2) = 8 + 4a + 6 − 5 = 4a + 9
पद 2: q(2) = 4 + 2a + 3 = 2a + 7
पद 3: 4a + 9 = 2a + 7 ⇒ 2a = −2
a = −1।
कठिन: x³ + ax² + bx + 6 का एक गुणनखंड (x − 2) है और (x − 3) से भाग देने पर शेषफल 3 मिलता है। a, b ज्ञात कीजिए।
पद 1: p(2) = 0 ⇒ 8 + 4a + 2b + 6 = 0 ⇒ 2a + b = −7 …(i)
पद 2: p(3) = 3 ⇒ 27 + 9a + 3b + 6 = 3 ⇒ 3a + b = −10 …(ii)
पद 3: (ii) − (i): a = −3, फिर b = −7 + 6 = −1।
a = −3, b = −1।

4. प्रश्नोत्तर (क्लिक करके उत्तर देखें)

लघु उत्तरीय

Q. (x + a) से भाग देने पर शेषफल?

उत्तर: p(−a)।

Q. (ax + b) से भाग देने पर शेषफल?

उत्तर: p(−b/a)।

Q. x² − 3x + 2 को (x − 1) से भाग देने पर शेषफल?

उत्तर: 1 − 3 + 2 = 0।

Q. क्या (x − 1), xⁿ − 1 का गुणनखंड है?

उत्तर: हाँ, p(1) = 1 − 1 = 0।

Q. x⁵ + 1 को (x + 1) से भाग देने पर शेषफल?

उत्तर: p(−1) = −1 + 1 = 0।

Q. क्या (x − 2), x³ − 8 का गुणनखंड है?

उत्तर: हाँ, p(2) = 0।

Q. 2x² − 3 को (x − 2) से भाग देने पर शेषफल?

उत्तर: 8 − 3 = 5।

Q. क्या (x + 1), x² + 1 का गुणनखंड है?

उत्तर: नहीं, p(−1) = 2 ≠ 0।

Q. x³ + x² + x + 1 को (x − 1) से भाग देने पर शेषफल?

उत्तर: 1+1+1+1 = 4।

Q. 3x + 7 को (x + 1) से भाग देने पर शेषफल?

उत्तर: p(−1) = 4।

Q. रैखिक भाजक से भाग देने पर शेषफल की घात?

उत्तर: 0 (शेषफल अचर होता है)।

Q. गुणनखंड प्रमेय का विलोम क्या है?

उत्तर: यदि p(a) = 0 तो (x − a) गुणनखंड है।

बहुविकल्पीय (MCQ)

Q. x² + x + 1 को (x − 1) से भाग देने पर शेषफल?
(a) 1 (b) 2 (c) 3 (d) 0

उत्तर: (c) p(1) = 3।

Q. (x − 2) किसका गुणनखंड है?
(a) x²+4 (b) x²−4 (c) x²−2x+1 (d) x²+2

उत्तर: (b) 4 − 4 = 0।

Q. 2x³ − x को (2x + 1) से भाग देने पर शेषफल?
(a) 1/4 (b) −1/4 (c) 0 (d) 1/2

उत्तर: (a) p(−1/2) = −1/4 + 1/2 = 1/4।

Q. (x − a), p(x) का गुणनखंड हो तो?
(a) p(a) = 0 (b) p(a) = 1 (c) p(−a) = 0 (d) p(0) = a

उत्तर: (a) p(a) = 0।

Q. x³ − 3x² + 5 को (x + 1) से भाग देने पर शेषफल?
(a) 1 (b) −1 (c) 5 (d) 0

उत्तर: (a) −1 − 3 + 5 = 1।

दीर्घ उत्तरीय

Q. शेषफल प्रमेय सिद्ध कीजिए।

उत्तर: देखें: प्रमेय 1 का प्रमाण — p(x) = (x−a)q(x) + r में x = a रखने पर p(a) = r। ∎

Q. गुणनखंड कीजिए: 2x³ + x² − 13x + 6।

उत्तर: p(2) = 16 + 4 − 26 + 6 = 0 ⇒ (x−2)। भाग: 2x² + 5x − 3 = (2x−1)(x+3)। उत्तर: (x−2)(2x−1)(x+3)।

Q. a ज्ञात कीजिए: ax³ + 3x² − 3 तथा 2x³ − 5x + a को (x − 4) से भाग देने पर समान शेषफल मिलता है।

उत्तर: p(4) = 64a + 48 − 3 = 64a + 45; q(4) = 128 − 20 + a = 108 + a। समान: 63a = 63 ⇒ a = 1।

Q. गुणनखंड कीजिए: x³ + x² − 4x − 4।

उत्तर: p(2) = 8+4−8−4 = 0 ⇒ (x−2)। भाग: x² + 3x + 2 = (x+1)(x+2)। उत्तर: (x−2)(x+1)(x+2)।
