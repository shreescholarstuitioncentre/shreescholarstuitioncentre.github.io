Operating System

Class 9 · Computer Science · UP Board

1. Introduction

An Operating System (OS) is system software that manages the hardware and software of a computer and works as an interface between the user and the hardware. It is the first program loaded at boot. It consists of the kernel (core, always in RAM) and the shell (outer part that takes commands). Examples: Windows, Linux, macOS, Android, iOS.

2. Functions of an Operating System

  • Process management: creates, schedules, ends processes.
  • Memory management: gives RAM to programs and takes it back.
  • File management: create, copy, move, delete, protect files.
  • Device management: controls printer, keyboard, disk via drivers.
  • Security: passwords, user accounts, permissions.
  • User interface: GUI / CLI.

6. CPU Scheduling

Several ready processes compete for one CPU. FCFS (first come first served), SJF (shortest job first), Round Robin (fixed time quantum in turn). Formulas: TAT = completion − arrival; WT = TAT − burst.

7. File and Folder Management

A file holds data; a folder holds files. The location is the path. The extension tells the type (.docx, .txt, .jpg, .mp3, .exe). Shortcuts: Ctrl+C copy, Ctrl+X cut, Ctrl+V paste, Ctrl+Z undo, F2 rename, Del delete, Shift+Del permanent delete.

9. Solved Examples (step by step)

Easy 1: Classify: Windows, MS-DOS, Linux, Android – GUI or CLI?

Windows → GUI; MS-DOS → CLI; Android → GUI (touch); Linux → both (desktop GUI and terminal CLI).

Easy 2: A computer completes 12 jobs in 3 minutes. Find throughput.

Throughput = jobs ÷ time = 12 ÷ 3 = 4 jobs per minute.

Easy 3: Write the path and extension of the file in the diagram.

Path: C:\Users\Rahul\Documents\notes.docx. Extension: .docx (Word document).

Intermediate 1: 8 users share a CPU in time-sharing with 25 ms slice. Find the time before a user gets the CPU again.

One round = 8 × 25 = 200 ms (ignoring switch time). Each user waits the other 7 × 25 = 175 ms.

Intermediate 2: A user stores 250 photos of 3.2 MB each on a 1 GB pen drive. Find free space and how many more photos fit.

Used = 250 × 3.2 = 800 MB. Drive = 1 × 1024 = 1024 MB. Free = 1024 − 800 = 224 MB. More photos = 224 ÷ 3.2 = 70 photos (70 × 3.2 = 224 ✓).

Hard 3: Prove that running the shorter job first reduces total waiting time (two jobs, bursts a > b).

Order 1 (long first): first job waits 0, second waits a → total = a.
Order 2 (short first): first job waits 0, second waits b → total = b.
Difference = a − b > 0 since a > b, so Order 2 gives smaller total waiting time. Hence shortest-job-first minimises average waiting. Verified with the example: 4.33 → 3.67. Proved.

Hard 4: In Round Robin the quantum is 10 ms and a context switch costs 2 ms. Find CPU efficiency. What if quantum = 2 ms?

Efficiency = useful time ÷ (useful + switch).
q = 10: 10 ÷ 12 = 0.833 = 83.3%.
q = 2: 2 ÷ 4 = 0.5 = 50%.
A very small quantum wastes half the time in switching, so the quantum must be chosen carefully.

10. Short Q & A (tap for answer)

Q1. What is an operating system?

System software that manages hardware and software resources and works as an interface between user and computer.

Q2. Why is an OS needed?

Without it the user would have to give machine-level instructions; the OS makes the computer easy and efficient to use.

Q3. Name five operating systems.

Windows, Linux, macOS, Android, iOS (UNIX, MS-DOS).

Q4. What is the kernel?

The core part of the OS that always stays in RAM and controls CPU, memory and devices.

Q5. What is the shell?

The outer part of the OS that takes user commands and passes them to the kernel.

Q6. What is a process?

A program in execution.

Q7. Program vs process?

A program is a passive set of instructions on disk; a process is that program loaded in RAM and running.

Q8. What is multitasking?

Running several tasks at the same time by switching the CPU quickly among them.

Q9. What is multiprogramming?

Keeping several programs in memory so the CPU never sits idle while one waits for I/O.

Q10. What is a real-time OS?

An OS that must respond within a guaranteed time limit, e.g. in flight control.

Q11. What is a GUI?

Graphical user interface with windows, icons, menus and pointer.

Q12. What is a CLI? Example.

Command line interface; user types commands, e.g. MS-DOS.

Q13. What is a file?

A named collection of related data stored on a disk.

Q14. What is a folder (directory)?

A container used to organise files and other folders.

Q15. What is a file extension? Examples.

The suffix after the dot that shows file type: .docx (Word), .txt (text), .jpg (image), .mp3 (audio), .exe (program).

Q16. What is a path?

The address of a file, e.g. C:\Users\Rahul\Documents\notes.docx.

Q17. What is the desktop?

The main screen shown after login holding icons, taskbar and wallpaper.

Q18. What is the taskbar?

The bar at the bottom with the Start button, running programs and system tray.

Q19. What is the Recycle Bin?

A temporary place for deleted files from which they can be restored.

Q20. What is the Control Panel / Settings?

The place to change system settings like display, sound, users and programs.

Q21. What is CPU scheduling?

Deciding which ready process gets the CPU next.

Q22. What is turnaround time?

Completion time − arrival time.

Q23. What is waiting time?

Turnaround time − burst time (time spent in the ready queue).

Q24. What is a device driver?

Software that lets the OS control a hardware device.

Q25. What is a deadlock?

A situation in which processes wait for each other's resources forever.

11. Long Q & A

Q1. Explain the functions of an operating system.

1) Process management: create, schedule and end processes. 2) Memory management: allocate RAM and free it. 3) File management: create, name, copy, move, delete, protect files. 4) Device management: control I/O devices using drivers. 5) Security: passwords and access rights. 6) User interface: GUI/CLI. 7) Error detection and resource accounting.

Q2. Describe the types of operating systems.

Single-user, multi-user, batch, multiprogramming, multitasking/time-sharing, multiprocessing, real-time and distributed. See the table for meaning and example of each.

Q3. Differentiate GUI and CLI.

GUI uses icons and mouse, is easy and friendly but needs more resources. CLI needs typed commands, is harder to learn but fast and light for experts.

Q4. Explain process states with diagram.

A process moves New → Ready → Running → Terminated. From Running it may go to Waiting for I/O and then back to Ready, or go back to Ready when its time slice ends (see the animated diagram).

Q5. Explain file and folder management in Windows.

Using File Explorer one can create (New), rename (F2), copy (Ctrl+C), cut (Ctrl+X), paste (Ctrl+V), delete (Del; goes to Recycle Bin; Shift+Del deletes permanently), search and set properties. Files are arranged in a tree of folders.

Q6. Compare FCFS, SJF and Round Robin scheduling.

FCFS: first come first served, simple but long jobs delay short ones. SJF: shortest job first, gives minimum average waiting time but long jobs may starve. Round Robin: each process gets a fixed quantum in turn, fair and best for time-sharing (worked examples below).
