1. What is Software?

Software is a set of programs and instructions that tells the hardware what to do. A program is a sequence of instructions to solve a problem. Software cannot be touched; hardware can.

2. System Software

It manages the computer and runs the application software. It includes the operating system, language translators, utility programs, device drivers and firmware.

2.1 Operating System (OS)

The OS is the interface between the user and hardware. Functions: process, memory, file, device management, security and user interface.

2.4 Utility programs and device drivers

Utilities: antivirus, backup, disk cleanup, defragmenter, file compression. Drivers let the OS operate printers, scanners, graphics cards.

3. Application Software

General purpose: word processor (Word), spreadsheet (Excel), presentation (PowerPoint), database (Access), browser, media player. Specific purpose: payroll, accounting (Tally), railway reservation, hospital management. Customised: made to order for one organisation.

5. Solved Examples (step by step)

Easy 1: Classify: MS Word, Windows, Tally, Linux, Paint, Compiler

System: Windows, Linux (OS), Compiler (translator). Application: MS Word, Tally, Paint. Reason: the first group manages the computer; the second helps a user task.

Easy 2: Which translator is needed for (a) C program (b) Python script (c) ADD AX, BX?

(a) C → compiler. (b) Python → interpreter. (c) ADD AX, BX is assembly → assembler.

Intermediate 1: A 100-line program has an error on line 40. What happens with (a) interpreter (b) compiler?

(a) Interpreter runs lines 1–39 (39 lines executed), stops at line 40 and shows the error. (b) Compiler scans all 100 lines first, reports the error (and any others), and no executable is produced, so 0 lines run until corrected.

Intermediate 2: Time-sharing: 10 users, each gets a 20 ms slice. After how long does a user get the CPU again?

One full round = 10 × 20 ms = 200 ms (ignoring switching time). 200 ms = 0.2 s, so each user feels continuous service.

Intermediate 3: A school buys software for 25 PCs: proprietary ₹1,200/PC; open source free but ₹300/PC support. Find the saving.

Proprietary = 25 × 1200 = ₹30,000. Open source = 25 × 300 = ₹7,500. Saving = 30,000 − 7,500 = ₹22,500.

Hard 1: A program takes 10 s to compile once and 2 s per run. Interpreting takes 5 s per run. Find the minimum runs after which compiling is faster.

Let n = number of runs.
Compiler total = 10 + 2n. Interpreter total = 5n.
Compiler faster when 10 + 2n < 5n ⇒ 10 < 3n ⇒ n > 3.33.
So n = 4 runs.
Check: n=3 → 16 s vs 15 s (interpreter wins); n=4 → 18 s vs 20 s (compiler wins) ✓.

Hard 2: In multiprogramming each program waits for I/O 80% of the time. Find CPU utilisation for 3 and 5 programs (assume independence). Show that more programs help.

CPU is idle only if all n programs wait: probability = 0.8ⁿ. Utilisation = 1 − 0.8ⁿ.
n = 3: 0.8³ = 0.512 ⇒ 1 − 0.512 = 0.488 = 48.8%.
n = 5: 0.8⁵ = 0.32768 ⇒ 1 − 0.32768 = 0.672 ≈ 67.2%.
Since 0.8ⁿ decreases as n grows, 1 − 0.8ⁿ increases: proved (n=1 gives only 20%).

Hard 3: Arrange the events in correct booting order: OS shows desktop, POST, BIOS finds disk, power on, kernel loaded to RAM. Justify.

Power on → POST → BIOS finds disk → kernel loaded to RAM → desktop.
Why: hardware must be tested before use (POST); BIOS is in ROM so it runs first; the OS can only run from RAM, so it must be loaded before it can show the desktop.

6. Short Q & A (tap for answer)

Q1. What is software?

A set of programs and instructions that makes hardware work and perform tasks.

Q2. Hardware vs software?

Hardware is the physical, touchable part; software is the set of instructions you cannot touch. Both are needed together.

Q3. Main types of software?

System software and application software.

Q4. What is system software?

Software that controls and manages hardware and provides a platform for applications, e.g. OS.

Q5. What is application software?

Software made for a specific user task such as typing, calculating, drawing or playing.

Q6. What is an operating system?

The main system software that acts as an interface between user and hardware and manages resources.

Q7. Name four operating systems.

Windows, Linux, macOS, Android (also iOS, UNIX).

Q8. What is GUI?

Graphical User Interface: icons, windows, menus and mouse used to operate the computer.

Q9. What is CLI?

Command Line Interface: user types text commands, e.g. MS-DOS.

Q10. What is booting?

The process of starting the computer and loading the OS into RAM.

Q11. Cold boot vs warm boot?

Cold boot: starting from power off. Warm boot: restarting with power on (Restart / Ctrl+Alt+Del).

Q12. What is a language translator?

A program that converts source code into machine language: assembler, compiler, interpreter.

Q13. What is source code and object code?

Source code is the program written by the programmer; object code is the machine-language output of the translator.

Q14. What is machine language?

The only language the CPU understands directly, written in 0s and 1s.

Q15. What is assembly language?

Low-level language using mnemonics such as ADD, SUB, MOV; translated by an assembler.

Q16. Name some high-level languages.

C, C++, Java, Python, BASIC, COBOL.

Q17. What is a utility program? Examples.

Helper software for maintenance: antivirus, backup, disk cleanup, defragmenter, file compressor.

Q18. What is a device driver?

Program that lets the OS talk to a hardware device (printer, scanner).

Q19. What is firmware?

Permanent software stored in ROM/flash of a device, e.g. BIOS, remote-control chip.

Q20. What is a word processor? Example.

Application to create, edit, format and print text documents: MS Word, LibreOffice Writer.

Q21. What is a spreadsheet?

Application that works on rows and columns of data with formulas: MS Excel.

Q22. What is open source software?

Software whose source code is freely available to view, modify and share, e.g. Linux.

Q23. What is a software license?

Legal permission that states how a user may use, copy or share the software.

Q24. What is piracy?

Illegal copying or use of software without a licence; it is a punishable crime.

Q25. What is a computer virus?

A harmful program that copies itself and damages files; removed by antivirus software.

7. Long Q & A

Q1. Explain the functions of an operating system.

1) Process management: decides which program gets the CPU. 2) Memory management: allots and frees RAM. 3) File management: create, copy, delete, organise files. 4) Device management: controls I/O devices via drivers. 5) Security: login, passwords, permissions. 6) User interface: GUI or CLI. 7) Error handling and booting.

Q2. Differentiate compiler and interpreter. Which is better?

See the table and animated flows above. Compiler is better for finished programs run many times; interpreter is better while learning and debugging because it shows errors line by line.

Q3. Describe the booting process.

Power on → POST tests hardware → BIOS in ROM locates the boot device → bootstrap loader copies the OS kernel into RAM → OS takes control and shows the desktop. Needed because RAM is empty at power on.

Q4. Differentiate system software and application software.

System software manages the machine, starts at boot and works without the user's task in mind (OS, drivers). Application software is installed for a user task and needs the OS (Word, Tally). System software is written in low/high-level languages by specialists; applications are often general or custom.

Q5. Explain generations of programming languages.

Machine language (1st): binary, machine dependent, fastest. Assembly (2nd): mnemonics, assembler. High-level (3rd): English-like, portable, needs compiler/interpreter. Higher generations make programming easier but need more translation.

Q6. Explain types of operating systems.

Single-user, multi-user, batch, multitasking/time-sharing and real-time (see table above with meaning and examples).
