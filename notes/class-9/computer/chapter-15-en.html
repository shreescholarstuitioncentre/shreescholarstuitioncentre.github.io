Class 9 Computer – Ch.12: Flowcharts and Algorithms

1. Algorithm

Algorithm = a finite, step-by-step list of instructions, in simple language, to solve a problem.

Characteristics: finite steps; clear and unambiguous; has input; gives output; every step is simple and effective.

Example 1 (Easy) – Add two numbers.
Step 1: Start. Step 2: Read A, B. Step 3: Sum = A + B. Step 4: Print Sum. Step 5: Stop.

Example 2 (Intermediate) – Largest of two numbers.
1: Start. 2: Read A, B. 3: If A > B print A, else print B. 4: Stop.

Example 3 (Hard) – Factorial of N.
1: Start. 2: Read N. 3: F = 1, I = 1. 4: Repeat F = F × I, I = I + 1 while I ≤ N. 5: Print F. 6: Stop.
Check N = 4: F = 1×1×2×3×4 = 24.

2. Flowchart

Flowchart = pictorial representation of an algorithm using standard symbols joined by arrows.
SymbolNameUse
OvalTerminalStart / Stop
ParallelogramInput/OutputRead / Print
RectangleProcessCalculation
DiamondDecisionYes/No question
ArrowFlow lineDirection of flow
CircleConnectorJoins parts of chart

Advantages: easy to understand, helps find errors, good documentation. Limits: hard to draw for big programs, difficult to modify.

3. Animated flowchart – Sum of two numbers

Watch the shapes appear one by one: Oval → Parallelogram → Rectangle → Diamond (only when a decision is needed) → Parallelogram → Oval.

4. Types of structures

Sequence – steps one after another. Selection – decision (IF-ELSE). Iteration – repeating steps (loop).

Questions and Answers

Q1. Define algorithm.
A finite step-by-step procedure to solve a problem.

Q2. Define flowchart.
A diagram showing an algorithm with standard symbols and arrows.

Q3. Which symbol is used for decision?
Diamond.

Q4. Which symbol is used for Start/Stop?
Oval (terminal).

Q5. Which symbol is used for input/output?
Parallelogram.

Q6. Name the three control structures.
Sequence, selection, iteration.

Q7. Write an algorithm to find the area of a rectangle.
1 Start. 2 Read L, B. 3 Area = L × B. 4 Print Area. 5 Stop.

Q8. Write an algorithm to check even or odd.
1 Start. 2 Read N. 3 If N mod 2 = 0 print Even, else print Odd. 4 Stop.

Q9. Write an algorithm for the average of 3 numbers.
1 Start. 2 Read A, B, C. 3 Avg = (A+B+C)/3. 4 Print Avg. 5 Stop.

Q10. Write advantages of flowcharts.
Easy to understand, easy debugging, good documentation, helps in planning.

Q11. MCQ: Rectangle in a flowchart shows – (a) Input (b) Process (c) Decision (d) Stop
(b) Process.

Q12. MCQ: An algorithm must be – (a) infinite (b) ambiguous (c) finite (d) none
(c) finite.
