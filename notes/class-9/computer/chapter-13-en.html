Class 9 Computer – Ch.13: Computer Virus and Security

1. Computer Virus

Computer virus = a harmful program that copies itself, attaches to other files/programs and damages data or slows the computer.

Spreads through: email attachments, pen drives, downloads from unsafe sites, pirated software, networks.

Symptoms: slow computer, strange messages, files missing or corrupted, programs not opening, frequent crashes.

2. Types of malware

TypeMeaning
Boot sector virusInfects the boot area of disk; runs when computer starts
File infectorAttaches to .exe/.com files
Macro virusInfects Word/Excel documents
WormSpreads by itself over a network, no host file needed
Trojan horseLooks useful but hides harmful code; does not copy itself
SpywareSecretly collects your information

3. Animated diagram – how a virus spreads

The red virus moves from the infected computer through a pen drive or email to the clean computer, which then gets infected.

4. Computer Security

Security = protecting computer, data and network from virus, hackers and unauthorized access.

Prevention: install antivirus and update it; scan pen drives; do not open unknown email attachments; use a firewall; take regular backups; use strong passwords (letters + digits + symbols); avoid pirated software.

Antivirus = software that detects, blocks and removes viruses (e.g. Quick Heal, Norton, McAfee). Firewall = filters network traffic and blocks unauthorized access. Backup = extra copy of data kept safely.

5. Solved example – strong password

To find: which is strong: "ram123" or "R@m#7Kx9"?
Step 1: Check length: 6 vs 8. Step 2: Check variety: first has letters+digits only; second has capital, small, digit, symbols. Step 3: First contains a common name. Answer: "R@m#7Kx9" is strong.

Questions and Answers

Q1. Define computer virus.
A harmful self-copying program that damages files and slows the computer.

Q2. Full form of VIRUS (popular)?
Vital Information Resources Under Siege.

Q3. Name any three ways a virus spreads.
Email attachments, pen drives, unsafe downloads.

Q4. Write any three symptoms of a virus.
Slow speed, missing files, frequent crashes.

Q5. What is a worm?
A malware that spreads by itself over a network without a host file.

Q6. What is a Trojan horse?
A program that looks useful but hides harmful code.

Q7. What is antivirus?
Software that detects and removes viruses.

Q8. What is a firewall?
A security system that filters network traffic and blocks unauthorized access.

Q9. Why is backup important?
If data is lost or damaged by a virus, it can be restored from the backup copy.

Q10. Write four preventive measures.
Use updated antivirus, scan pen drives, avoid unknown attachments, take backups.

Q11. Difference between virus and worm?
A virus needs a host file and a user action; a worm spreads by itself through networks.

Q12. MCQ: Which is an antivirus? (a) Quick Heal (b) Word (c) Paint (d) Excel
(a) Quick Heal.

Q13. MCQ: Strong password should have – (a) only letters (b) only digits (c) mix of letters, digits, symbols (d) name
(c) mix of letters, digits, symbols.
