1. Introduction

A computer network is a group of two or more computers and devices (nodes) joined by cables or wireless links to share data, files, printers and the Internet.

  • Advantages: resource sharing, fast communication, central backup, cost saving.
  • Disadvantages: setup cost, security risk (virus, hacking), server dependence.

6. Protocols, IP Address and DNS

Protocol: rules of communication – TCP/IP (Internet), HTTP (web), FTP (file transfer), SMTP (send email), POP/IMAP (receive email). IP address: unique address of a device, IPv4 = four numbers 0–255 (32 bits). DNS turns names into IP addresses. Bandwidth = data per second (bps, Kbps, Mbps, Gbps); 1 byte = 8 bits.

8. Solved Examples (step by step)

Easy 1: Convert the IP address 192.168.1.10 to binary.

Convert each octet:
192 = 128+64 → 11000000
168 = 128+32+8 → 10101000
1 → 00000001
10 = 8+2 → 00001010
Answer: 11000000.10101000.00000001.00001010 (4 × 8 = 32 bits ✓).

Easy 2: Which of these is an invalid IPv4 address: 10.0.0.5, 172.16.300.1, 8.8.8.8?

Each octet must be 0–255 (8 bits give 2⁸ = 256 values). In 172.16.300.1, 300 > 255, so 172.16.300.1 is invalid.

Intermediate 1: A 100 MB file is sent over an 8 Mbps link. Find the time.

1 byte = 8 bits, so size = 100 × 8 = 800 Mb (megabits).
Time = size ÷ speed = 800 ÷ 8 = 100 seconds (1 min 40 s).

Intermediate 2: Find the number of cables needed to connect 6 computers in (a) star (b) ring (c) mesh.

(a) Star: one cable per computer to the hub = 6.
(b) Ring: each computer to the next, last to first = 6.
(c) Mesh: n(n−1)/2 = 6×5/2 = 15.

Intermediate 3: A cable costs ₹50 per link. Find the extra cost of mesh over star for 6 computers.

Star = 6 × 50 = ₹300. Mesh = 15 × 50 = ₹750. Extra = 750 − 300 = ₹450.

Hard 1: Download 1.5 GB at 50 Mbps. Find the time (1 GB = 1024 MB).

Step 1: 1.5 GB = 1.5 × 1024 = 1536 MB.
Step 2: bits = 1536 × 8 = 12,288 Mb.
Step 3: time = 12,288 ÷ 50 = 245.76 s.
Step 4: 245.76 s = 4 min + 5.76 s ≈ 4 min 6 s.
Check: 50 Mbps = 6.25 MB/s; 1536 ÷ 6.25 = 245.76 ✓.

Hard 2: Prove that a full mesh of n nodes needs n(n−1)/2 links. Find the ports per node for n = 8.

Proof: each node connects to the other (n−1) nodes, so counting node-by-node gives n(n−1) connections. But every link is counted twice (once from each end), so links = n(n−1)/2. Hence proved.
For n = 8: ports per node = n−1 = 7; links = 8×7/2 = 28.

Hard 3: How many different IPv4 addresses are possible? How many usable hosts in a network with 8 host bits?

IPv4 has 32 bits, each 0 or 1, so total = 2³² = 4,294,967,296.
With 8 host bits: 2⁸ = 256 addresses. All-0s is the network address and all-1s is the broadcast address, so usable hosts = 256 − 2 = 254.

Hard 4: In a bus network a cable breaks between nodes 3 and 4 of 6 nodes (no terminators issue). In a star network the cable of node 3 breaks. How many nodes can still communicate with each other in each?

Bus: the backbone splits into two parts {1,2,3} and {4,5,6}. Nodes can talk only inside their part (practically the signal reflects without terminators, so the network usually fails entirely). Star: only node 3 is cut off; the other 5 nodes still communicate through the hub. This shows why star is more fault-tolerant.

9. Short Q & A (tap for answer)

Q1. What is a computer network?

Two or more computers and devices connected to share data, files and resources.

Q2. Why do we use networks?

Resource sharing (printer, internet), file sharing, communication (email, chat), centralised backup, saving cost.

Q3. What is a node?

Any device (computer, printer) connected to a network.

Q4. What is LAN?

Local Area Network: covers a small area such as a lab or building; high speed, low cost.

Q5. What is MAN?

Metropolitan Area Network: covers a city.

Q6. What is WAN? Example.

Wide Area Network covering countries/world; the Internet is the biggest WAN.

Q7. What is PAN?

Personal Area Network around one person, e.g. Bluetooth between phone and earphones.

Q8. What is topology?

The physical or logical arrangement of nodes and links in a network.

Q9. Name the common topologies.

Bus, star, ring, mesh, tree.

Q10. Which topology is most commonly used in schools/offices?

Star topology with a switch.

Q11. What is a protocol?

A set of rules for communication between devices, e.g. TCP/IP, HTTP, FTP, SMTP.

Q12. Full form of TCP/IP.

Transmission Control Protocol / Internet Protocol.

Q13. What is an IP address?

A unique number identifying a device on a network, e.g. 192.168.1.10 (IPv4, 32 bits).

Q14. What is a MAC address?

A unique hardware address burned into the NIC by the maker.

Q15. What is DNS?

Domain Name System: converts website names into IP addresses.

Q16. What is bandwidth?

The maximum amount of data that can be transferred per second, measured in bps, Kbps, Mbps, Gbps.

Q17. What is a client and a server?

Client requests services; server provides them (web server, file server).

Q18. What is a NIC?

Network Interface Card: hardware that connects a computer to a network.

Q19. What is a modem?

Device that converts digital data to analog for transmission and back (modulator-demodulator).

Q20. Hub vs switch?

Hub sends data to all ports; switch sends it only to the destination port.

Q21. What is a router?

Device that connects networks and chooses the best path for data packets.

Q22. What is Wi-Fi?

Wireless networking using radio waves to connect devices without cables.

Q23. What is the Internet?

A worldwide network of networks using TCP/IP.

Q24. What is a firewall?

Security system that filters incoming and outgoing network traffic.

10. Long Q & A

Q1. Explain types of networks (PAN, LAN, MAN, WAN).

PAN: around one person (Bluetooth). LAN: building/campus, high speed, privately owned. MAN: whole city, cable TV or bank networks. WAN: countries and world, uses telephone/satellite links, the Internet. Coverage grows PAN < LAN < MAN < WAN, while speed and ownership control generally fall (see animated coverage chart).

Q2. Explain any three network topologies with diagram.

Bus: all nodes on one backbone cable with terminators. Star: every node linked to a central hub/switch. Ring: each node linked to two neighbours forming a circle, data moves one way. Mesh: every node linked to every other node. Tree: star groups arranged in a hierarchy (see animated diagrams and the advantages table).

Q3. Describe networking devices.

NIC, modem, hub, switch, repeater, bridge, router and gateway; each has a specific function as given in the device table above.

Q4. Compare wired and wireless transmission media.

Wired (twisted pair, coaxial, fibre): stable, secure, faster (fibre), but fixed and costly to lay. Wireless (Wi-Fi, microwave, satellite): mobile and easy to set up but weaker, less secure and affected by obstacles.

Q5. Explain how a web page reaches your browser.

The browser (client) asks DNS for the IP address, sends an HTTP request to the web server, the server returns the page, and the browser displays it (see animated steps).

Q6. What are the advantages and disadvantages of networking?

Advantages: sharing of hardware, software and data, fast communication, central control, cost saving. Disadvantages: setup cost, security risks (hacking, virus), dependence on the server, need for administrator.
