Number System & Conversion

Class 9 · Computer Science · UP Board (notes in the style of Avtaar / Rajeev / Vidya / Sumita Arora)

1. What is a Number System?

A number system is a way of writing numbers using a fixed set of digits/symbols. The count of digits is called the base (radix). Computers store everything as electrical ON/OFF signals, so they use binary.

SystemBaseDigitsExample
Decimal100–9(45)10
Binary20, 1(1011)2
Octal80–7(157)8
Hexadecimal160–9, A–F(2AF)16
Remember: A=10, B=11, C=12, D=13, E=14, F=15.   1 nibble = 4 bits, 1 byte = 8 bits. MSB = leftmost bit, LSB = rightmost bit.

2. Positional Value

Each digit has a place value = digit × baseposition (position starts from 0 at the right). Example: (345)10 = 3×10² + 4×10¹ + 5×10⁰ = 300+40+5.

3. Decimal → Binary (Division method)

Rule: divide by 2 again and again, write remainders, read them bottom to top.

Animated diagram: (25)10 → ( ? )2

2 | 25   1 ↑
2 | 12   0
2 | 6   0
2 | 3   1
2 | 1   1
    0  

Read remainders upward: 11001 ⇒ (25)10 = (11001)2

4. Binary → Decimal

Multiply each bit by 2position and add. Weights: 128 64 32 16 8 4 2 1.

5. Decimal → Octal / Hexadecimal

6. Binary ⇄ Octal ⇄ Hex (Shortcut)

Binary → Octal: group bits in 3s from the right. Binary → Hex: group in 4s. For the reverse, write 3-bit (octal) or 4-bit (hex) code for each digit.

7. Solved Examples (step by step)

Easy 1: Convert (1011)2 to decimal

Solution: 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11.

Easy 2: Convert (13)10 to binary

13÷2=6 r1; 6÷2=3 r0; 3÷2=1 r1; 1÷2=0 r1. Upward: 1101.

Intermediate 1: Convert (234)8 to decimal

2×8² + 3×8¹ + 4×8⁰ = 128 + 24 + 4 = 156.

Intermediate 2: Convert (1101101)2 to octal

Group in 3s from right: 001 | 101 | 101 → 1, 5, 5 ⇒ (155)8. Check: 64+40+5 = 109 ✓.

Hard 1: Convert (2AF)16 to decimal

2×16² + 10×16¹ + 15×16⁰ = 512 + 160 + 15 = 687.

Hard 2: Convert (1101101)2 to hexadecimal

Group in 4s: 0110 | 1101 → 6, D ⇒ (6D)16 (=96+13=109 ✓).

Hard 3: Convert (0.625)10 to binary

Multiply fraction by 2: 0.625×2=1.25 → 1; 0.25×2=0.5 → 0; 0.5×2=1.0 → 1. Read downward: (0.101)2.

9. Long Q & A

Q1. Why do computers use the binary system?

Electronic circuits have two stable states (ON/OFF, high/low voltage) which map to 1 and 0. This is simple, cheap, fast and less prone to error than a 10-level circuit.

Q2. Explain the steps to convert decimal to binary.

(1) Divide the number by 2. (2) Write the remainder. (3) Divide the quotient again by 2. (4) Repeat until quotient is 0. (5) Read remainders from bottom to top.

Q3. Differentiate between bit, nibble and byte.

Bit = one binary digit (0/1). Nibble = 4 bits. Byte = 8 bits (stores one character).
