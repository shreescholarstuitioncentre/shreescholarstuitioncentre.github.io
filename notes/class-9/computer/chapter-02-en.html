Computer Fundamentals, Parts & Types

Class 9 · Computer Science · UP Board

1. Computer System

A computer system = Hardware (physical parts) + Software (programs) + Users (peopleware). Work cycle: Input → Process → Output, with storage.

2. Parts of a Computer

(a) Input devices

Keyboard, mouse, scanner, mic, webcam, joystick, barcode reader, touch screen.

(b) CPU

Control Unit (directs), ALU (calculates), registers (fast tiny memory). Speed is measured in Hz (GHz).

(c) Memory

TypePropertyUse
RAMVolatile, read/writeRunning programs
ROMNon-volatile, read-onlyBoot (BIOS)
CacheVery fast, smallBetween CPU and RAM
HDD/SSD/Pen drivePermanentSaving files

(d) Output devices

Soft copy: monitor, speaker, projector. Hard copy: printer, plotter.

(e) Other parts

Motherboard joins everything; SMPS gives power; Ports (USB, HDMI) connect devices.

4. Memory Units

8 bits = 1 Byte · 1 KB = 1024 B · 1 MB = 1024 KB · 1 GB = 1024 MB · 1 TB = 1024 GB

5. Worked Examples

Ex.1 (Easy): How many bits are in 5 bytes?
1 byte = 8 bits → 5 × 8 = 40 bits.
Ex.2 (Medium): Convert 3 GB into MB.
1 GB = 1024 MB → 3 × 1024 = 3072 MB.
Ex.3 (Hard): A pen drive has 16 GB. Each photo is 4 MB. How many photos fit?
Step 1: 16 GB = 16 × 1024 = 16384 MB.
Step 2: 16384 ÷ 4 = 4096 photos.
Ex.4 (Hard): How many characters can 2 KB store (1 char = 1 byte)?
2 × 1024 = 2048 characters.

6. Short Questions

What are the main parts of a computer system?

Input unit, CPU (CU + ALU + memory), output unit and storage unit. Together with software they form a complete system.

What is an input device? Give examples.

A device that sends data/instructions to the computer: keyboard, mouse, scanner, microphone, webcam, light pen.

What is an output device? Give examples.

A device that shows the results: monitor (soft copy), printer (hard copy), speaker, projector, plotter.

Difference between RAM and ROM?

RAM: read/write, volatile (data lost on power off), temporary workspace. ROM: read-only, non-volatile, stores start-up (BIOS) instructions.

What is a motherboard?

The main circuit board that holds the CPU, RAM and connectors, and joins all components together.

Which is the fastest and costliest computer?

Supercomputer (e.g., PARAM by C-DAC, India). Used in weather forecasting and space research.

What is a microcomputer?

A small computer built around a microprocessor, meant for one user: desktop, laptop, tablet, smartphone.

What is an analog computer?

It works on continuous physical quantities such as temperature, speed or pressure (e.g., thermometer, speedometer).

What is a hybrid computer?

Combines features of analog and digital; analog part measures, digital part calculates. Used in hospitals (ECG) and petrol pumps.

What is a bit and a byte?

Bit = smallest unit (0 or 1). Byte = 8 bits = one character.

7. Long Questions

Classify computers on the basis of size and describe each.

Super: fastest, thousands of processors; weather, defence (PARAM, Cray). Mainframe: large, serves hundreds of users together; banks, railways. Mini: mid-size, serves 4–200 users; small companies. Micro: single-user PCs; desktop, laptop, tablet, smartphone.

Explain the types of computers on the basis of working (data handled).

Analog: measures continuous values (speedometer). Digital: works on binary 0/1, counts discrete data; accurate and fast (PC). Hybrid: mix of both; used in ICU machines and industrial control.

Describe memory units with their conversion.

1 Byte = 8 bits; 1 KB = 1024 B; 1 MB = 1024 KB; 1 GB = 1024 MB; 1 TB = 1024 GB; 1 PB = 1024 TB. Memory is of two kinds: primary (RAM, ROM, cache) and secondary (HDD, SSD, pen drive, CD/DVD).
