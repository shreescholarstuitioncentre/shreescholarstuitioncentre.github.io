Computer Memory & Computer Software

Class 9 · Computer Science · UP Board

1. Computer Memory

Memory stores data, instructions and results. It is made of storage cells; every cell has an address. Memory is measured in bits and bytes.

2. Types of Memory

A. Primary memory (main memory)

CPU accesses it directly. It is fast but limited. It includes RAM, ROM and cache.

PointRAMROM
Full formRandom Access MemoryRead Only Memory
NatureVolatileNon-volatile
UseRunning programsBoot / BIOS
TypesSRAM, DRAMPROM, EPROM, EEPROM
SRAM: flip-flops, fast, no refresh, costly (cache). DRAM: capacitors, needs refresh, cheap (main RAM). PROM / EPROM / EEPROM: once programmable / UV erasable / electrically erasable.

B. Secondary memory (auxiliary / storage)

Permanent, large and cheap but slower. Types: magnetic (hard disk, tape), optical (CD, DVD, Blu-ray), flash/solid state (SSD, pen drive, memory card).

3. Computer Software

Software is a set of programs that instructs hardware. Without software, hardware is useless.

System software

  • Operating system: manages processes, memory, files, devices, security (Windows, Linux, Android).
  • Language translators: assembler (assembly → machine), compiler (whole program), interpreter (line by line).
  • Utility programs: antivirus, backup, disk defragmenter, compression.
  • Device drivers: let the OS control hardware such as printers.

Application software

General purpose (word processor, spreadsheet, browser) and specific purpose (payroll, railway reservation, Tally).

Other terms

Firmware (software in ROM), freeware (free), shareware (trial), open source (free + source code), proprietary (paid, owned by company).

4. Solved Examples (step by step)

Easy 1: Convert 2 KB into bytes

1 KB = 1024 bytes ⇒ 2 × 1024 = 2048 bytes.

Easy 2: Convert 3 MB into KB

1 MB = 1024 KB ⇒ 3 × 1024 = 3072 KB.

Intermediate 1: A CD holds 700 MB. How many 3.5 MB songs fit?

Songs = total ÷ size of one = 700 ÷ 3.5 = 200 songs. Check: 200 × 3.5 = 700 ✓.

Intermediate 2: Convert 4 GB to KB

GB → MB: 4 × 1024 = 4096 MB. MB → KB: 4096 × 1024 = 4,194,304 KB.

Intermediate 3: How many 1.44 MB floppies are needed for a 20 MB file?

20 ÷ 1.44 = 13.89. Whole disks only, so round up: 14 floppies (13 disks hold only 18.72 MB).

Hard 1: A document has 200 pages, 50 lines per page, 60 characters per line (1 char = 1 byte). Find its size in KB. How many such documents fit in an 8 GB pen drive?

Step 1: bytes = 200 × 50 × 60 = 600,000 bytes.
Step 2: KB = 600000 ÷ 1024 = ≈ 585.94 KB.
Step 3: 8 GB = 8 × 1024³ = 8,589,934,592 bytes.
Step 4: 8,589,934,592 ÷ 600,000 = 14,316.56 → 14,316 documents.
Check: 600,000 × 14,316 = 8,589,600,000 ≤ 8,589,934,592 ✓.

Hard 2: How many address lines are needed for a 64 KB byte-addressable memory?

64 KB = 64 × 1024 = 65,536 locations = 2⁶ × 2¹⁰ = 2¹⁶. With n lines we can address 2ⁿ locations, so n = 16 lines.

Hard 3: Prove that 1 TB = 2⁴⁰ bytes.

1 KB = 2¹⁰ B; 1 MB = 2¹⁰ KB = 2²⁰ B; 1 GB = 2¹⁰ MB = 2³⁰ B; 1 TB = 2¹⁰ GB = 2⁴⁰ B = 1,099,511,627,776 bytes. Hence proved.

5. Short Q & A (tap for answer)

Q1. What is computer memory?

The place where a computer stores data, instructions and results, temporarily or permanently.

Q2. What is the smallest unit of memory?

Bit (binary digit, 0 or 1).

Q3. How many bytes are in 1 KB?

1024 bytes (2¹⁰).

Q4. What is RAM?

Random Access Memory: main working memory, read/write, volatile. Holds running programs and data.

Q5. What is ROM?

Read Only Memory: non-volatile, stores permanent instructions like BIOS/boot program.

Q6. What is volatile memory?

Memory that loses its contents when power is switched off (RAM).

Q7. Expand PROM, EPROM, EEPROM.

Programmable ROM (written once by user); Erasable PROM (erased by UV light); Electrically Erasable PROM (erased by electric signal).

Q8. Differentiate SRAM and DRAM.

SRAM uses flip-flops, is faster, costlier, needs no refresh (cache). DRAM uses capacitors, is slower, cheaper, needs periodic refresh (main RAM).

Q9. What is cache memory?

A small, very fast memory between CPU and RAM that keeps frequently used data to speed up processing.

Q10. What are registers?

Tiny, fastest storage cells inside the CPU holding the data being processed right now.

Q11. Give examples of secondary memory.

Hard disk, SSD, CD/DVD, pen drive, memory card, magnetic tape.

Q12. Why is secondary memory needed?

RAM is volatile and small; secondary memory stores large data permanently at low cost.

Q13. What is software?

A set of programs/instructions that tells hardware what to do.

Q14. Name the two main types of software.

System software and application software.

Q15. What is an operating system? Give examples.

System software that manages hardware and resources and gives an interface to users: Windows, Linux, Android, macOS.

Q16. Compiler vs interpreter?

Compiler translates the whole program at once and lists all errors; interpreter translates and runs line by line, stopping at the first error.

Q17. What is an assembler?

Translator that converts assembly language into machine language.

Q18. What is utility software?

Programs that maintain the computer: antivirus, disk cleanup, backup, file compression.

Q19. What is a device driver?

Software that lets the OS communicate with a hardware device such as a printer.

Q20. What is firmware?

Software permanently stored in ROM/flash inside hardware, e.g. BIOS.

Q21. Differentiate freeware, shareware and open source.

Freeware: free to use, source hidden. Shareware: free trial, then pay. Open source: free and source code available to modify (Linux).

6. Long Q & A

Q1. Differentiate between RAM and ROM.

RAM: volatile; read and write; temporary storage of running programs; larger (GB); types SRAM/DRAM. ROM: non-volatile; mostly read only; permanent storage of boot instructions; smaller; types PROM/EPROM/EEPROM. Both are primary memory and directly accessed by the CPU.

Q2. Explain the memory hierarchy.

Memory is arranged by speed, cost and size. Top: registers, then cache, RAM, secondary storage, backup. Going down, capacity increases and cost per byte falls, but speed falls. This lets the computer keep hot data close to the CPU and bulk data cheaply (see animated diagram).

Q3. Differentiate primary and secondary memory.

Primary (RAM, ROM, cache): directly accessed by CPU, fast, costly per byte, small, mostly volatile. Secondary (HDD, SSD, pen drive): accessed through I/O, slower, cheap, large, permanent.

Q4. Differentiate system software and application software.

System software runs and manages the computer (OS, drivers, translators) and starts at boot. Application software helps users do tasks (Word, games, Tally) and runs on top of the OS.

Q5. Explain functions of an operating system.

Process management, memory management, file management, device management, security (passwords) and providing a user interface (GUI/CLI).
