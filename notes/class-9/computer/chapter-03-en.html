6. Worked Examples

Ex.1 (Easy): A printer prints 20 pages per minute (ppm). Pages in 5 minutes?
20 × 5 = 100 pages.
Ex.2 (Medium): Time to print 150 pages at 20 ppm?
Time = 150 ÷ 20 = 7.5 minutes.
Ex.3 (Hard): Screen resolution 1920 × 1080. Total pixels?
Step 1: pixels = width × height.
Step 2: 1920 × 1080 = 20,73,600 pixels (about 2 megapixels).
Ex.4 (Hard): A scanned photo of 3 MB. How many fit in 1 GB?
1 GB = 1024 MB → 1024 ÷ 3 = 341.3 → 341 photos.

7. Short Questions

What is hardware?

The physical, touchable parts of a computer such as keyboard, monitor, CPU, RAM and printer.

What is software?

A set of programs/instructions that tells the hardware what to do. It cannot be touched.

Name any four input devices.

Keyboard, mouse, scanner, microphone (also webcam, joystick, barcode reader).

What is OCR? What is OMR?

OCR (Optical Character Recognition) reads printed/typed text. OMR (Optical Mark Recognition) reads marks, e.g., on exam answer sheets.

What is a touch screen?

A device that works as both input and output – you touch the display to give commands.

Difference between soft copy and hard copy?

Soft copy: output on screen/speaker, not on paper (monitor). Hard copy: printed output on paper (printer, plotter).

Types of printers?

Impact (dot-matrix: hits ribbon) and Non-impact (inkjet, laser: no hitting, quieter, faster).

What is an operating system?

System software that manages hardware and runs other programs: Windows, Linux, Android, macOS.

What is a compiler?

Translator that converts the whole high-level program into machine code at once. (Interpreter translates line by line; Assembler converts assembly code.)

What is freeware, shareware, open-source?

Freeware: free to use. Shareware: free trial, then pay. Open-source: source code is open to modify (Linux).

8. Long Questions

Describe input devices with their uses.

Keyboard types text/numbers. Mouse points and clicks. Scanner converts paper to digital image. Microphone inputs sound. Webcam captures video. Barcode reader reads product codes at shops. Light pen/Joystick for drawing and games. Biometric reads fingerprint/face for security.

Explain output devices: monitor, printer, speaker, projector.

Monitor (CRT, LCD, LED) shows soft copy; quality measured by resolution (pixels). Printer gives hard copy (dot-matrix, inkjet, laser); measured in dpi and ppm. Speaker outputs sound. Projector enlarges the screen for a class or meeting. Plotter prints large drawings and maps.

What is software? Explain its types.

System software runs the computer: operating system, utility programs (antivirus, disk cleaner), language translators, device drivers. Application software does user tasks: general-purpose (MS Word, Excel, browser), and customised/special-purpose (railway reservation, payroll). Hardware without software is useless, like a body without life.

9. MCQs

1. Which is an output device?
A) Mouse B) Scanner C) Monitor D) Mic

Answer: Monitor

2. Windows is:
A) Hardware B) System software C) Application D) Utility

Answer: System software

3. OMR is used for:
A) Typing B) Checking answer sheets C) Printing D) Sound

Answer: Checking answer sheets

4. A dot-matrix printer is:
A) Laser B) Inkjet C) Impact D) Thermal

Answer: Impact printer

5. Antivirus is a ___ software.
A) Utility B) Game C) Hardware D) Output

Answer: Utility

6. Which converts whole program at once?
A) Interpreter B) Compiler C) Editor D) Driver

Answer: Compiler

7. Touch screen is:
A) Input only B) Output only C) Both D) Neither

Answer: Input and output

8. MS Word is:
A) System B) Application C) Hardware D) Firmware

Answer: Application software
