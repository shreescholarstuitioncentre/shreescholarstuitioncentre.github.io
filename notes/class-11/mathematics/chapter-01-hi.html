कक्षा 11 गणित - अध्याय 1: समुच्चय (Sets)

1. समुच्चय और उसका निरूपण

समुच्चय वस्तुओं का सुपरिभाषित संग्रह है। वस्तुओं को अवयव (element) कहते हैं; x ∈ A का अर्थ "x, A का सदस्य है" और x ∉ A का अर्थ "सदस्य नहीं है"। समुच्चय को A, B, C जैसे बड़े अक्षरों से लिखते हैं।

सुपरिभाषित = स्पष्ट रूप से कहा जा सके कि वस्तु समुच्चय में है या नहीं। "कक्षा के अच्छे विद्यार्थी" समुच्चय नहीं है; "अंग्रेज़ी के स्वर" समुच्चय है।

निरूपण

रोस्टर (सारणीबद्ध) रूप: अवयव { } में अल्पविराम से लिखें, दोहराव नहीं। A = {a, e, i, o, u}।
समुच्चय-निर्माण रूप: A = {x : x एक स्वर है}। उदा. B = {x : x ∈ N, x < 5} = {1,2,3,4}।

मानक समुच्चय: N = प्राकृत, W = पूर्ण, Z = पूर्णांक, Q = परिमेय, R = वास्तविक संख्याएँ।

2. समुच्चयों के प्रकार

रिक्त (शून्य) समुच्चय: कोई अवयव नहीं, ∅ या { }। उदा. {x : x ∈ N, 1 < x < 2} = ∅। ध्यान दें: {0} और {∅} रिक्त नहीं हैं।

परिमित समुच्चय: अवयव गिने जा सकें; n(A) = अवयवों की संख्या। अपरिमित समुच्चय: अवयव कभी समाप्त न हों, जैसे N, Z, R। (∅ परिमित है, n(∅)=0।)

समान समुच्चय: A = B यदि दोनों के अवयव बिल्कुल वही हों; क्रम व दोहराव मायने नहीं रखते। {1,2,3} = {3,1,2,2}।

3. उपसमुच्चय

A ⊆ B यदि A का प्रत्येक अवयव B में हो। प्रत्येक समुच्चय स्वयं का उपसमुच्चय है और ∅ ⊆ A। यदि A ⊆ B और A ≠ B तो A उचित उपसमुच्चय (A ⊂ B) है। यदि A ⊆ B और B ⊆ A तो A = B।

N ⊂ W ⊂ Z ⊂ Q ⊂ R। n अवयवों वाले समुच्चय के 2n उपसमुच्चय और 2n − 1 उचित उपसमुच्चय होते हैं।

4. अंतराल (R के उपसमुच्चय)

विवृत (a,b) = {x : a < x < b}। संवृत [a,b] = {x : a ≤ x ≤ b}। अर्ध-विवृत [a,b) या (a,b]। प्रत्येक अंतराल की लंबाई = b − a। गोल कोष्ठक = सिरा शामिल नहीं (खाली बिंदु); चौकोर कोष्ठक = शामिल (भरा बिंदु)।

5. घात समुच्चय

P(A) = A के सभी उपसमुच्चयों का समुच्चय। n(P(A)) = 2n। उदा. A = {1,2}: P(A) = {∅, {1}, {2}, {1,2}} (4 = 2² अवयव)।

6. सार्वत्रिक समुच्चय और वेन आरेख

सार्वत्रिक समुच्चय U वह बड़ा समुच्चय है जिसमें चर्चा के सभी समुच्चय हों। वेन आरेख में U आयत और समुच्चय उसके भीतर वृत्त होते हैं। (एनिमेशन में आरेख बनते देखें; गुलाबी = अभीष्ट क्षेत्र।)

7. समुच्चयों पर संक्रियाएँ

संघ: A ∪ B = {x : x ∈ A या x ∈ B}। सर्वनिष्ठ: A ∩ B = {x : x ∈ A और x ∈ B}; यदि A ∩ B = ∅ तो समुच्चय असंयुक्त (disjoint) हैं।

A ∪ B (संघ)
A ∩ B (सर्वनिष्ठ)

अंतर: A − B = {x : x ∈ A और x ∉ B}। पूरक: A′ = U − A = {x : x ∈ U, x ∉ A}।

A − B (अंतर)
A′ (पूरक)
मुख्य नियम: A ∪ A′ = U, A ∩ A′ = ∅, (A′)′ = A, ∅′ = U, U′ = ∅।
डी-मॉर्गन: (A ∪ B)′ = A′ ∩ B′ और (A ∩ B)′ = A′ ∪ B′।
n(A ∪ B) = n(A) + n(B) − n(A ∩ B)।
वितरण: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)।

हल किए गए उदाहरण (चरणबद्ध)

सरल A = {x : x ∈ N, x² < 30} को रोस्टर रूप में लिखिए।
हल. 1²=1, 2²=4, 3²=9, 4²=16, 5²=25 < 30; 6²=36 > 30। अतः A = {1,2,3,4,5}।
सरल A = {1,2,3}, B = {3,4}। A ∪ B, A ∩ B, A − B ज्ञात कीजिए।
हल. A ∪ B = {1,2,3,4}; A ∩ B = {3}; A − B = {1,2}।
मध्यम {a,b,c} के सभी उपसमुच्चय लिखिए।
हल. n = 3, अतः 2³ = 8: ∅, {a}, {b}, {c}, {a,b}, {b,c}, {a,c}, {a,b,c}।
मध्यम सिद्ध कीजिए A − B = A ∩ B′।
उपपत्ति. x ∈ A − B ⇔ x ∈ A और x ∉ B ⇔ x ∈ A और x ∈ B′ ⇔ x ∈ A ∩ B′। इति सिद्धम्।
कठिन 60 विद्यार्थियों की कक्षा में 40 चाय, 30 कॉफी और 15 दोनों पसंद करते हैं। कितने किसी को भी पसंद नहीं करते?
हल. n(T ∪ C) = 40 + 30 − 15 = 55। कोई नहीं = 60 − 55 = 5।
कठिन सिद्ध कीजिए (A ∪ B)′ = A′ ∩ B′।
उपपत्ति. x ∈ (A ∪ B)′ ⇔ x ∉ A ∪ B ⇔ x ∉ A और x ∉ B ⇔ x ∈ A′ और x ∈ B′ ⇔ x ∈ A′ ∩ B′। इति सिद्धम्।
