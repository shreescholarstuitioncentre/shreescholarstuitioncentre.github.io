Class 11 Maths - Chapter 2: Relations and Functions

PART A: RELATIONS

1. Ordered Pair

A pair (a, b) in which the order matters is an ordered pair; a is the first and b the second component. (a,b) = (c,d) iff a = c and b = d. So (2,3) ≠ (3,2); (a,b) = (b,a) only if a = b.

2. Cartesian Product

A × B = {(a,b) : a ∈ A, b ∈ B}. Eg. A={1,2}, B={x,y}: A×B = {(1,x),(1,y),(2,x),(2,y)}.

If n(A)=p, n(B)=q then n(A×B) = pq. A × A has p² elements. A × B ≠ B × A (unless A = B). A × ∅ = ∅. R × R = the whole coordinate plane.

3. Relation

A relation R from A to B is any subset of A × B. If (a,b) ∈ R we write a R b; b is the image of a.

Domain = set of all first components. Co-domain = the set B. Range = set of all second components (range ⊆ co-domain). If n(A)=p, n(B)=q, total relations = 2pq.

Representation

Roster: R = {(1,2),(2,4),(3,6)}. Set-builder: R = {(x,y) : y = 2x, x ∈ A}. Pictorial (arrow diagram): draw A and B as ovals and an arrow for each pair.

R = {(1,2),(2,4),(3,6)}; 8 is not related

Here domain = {1,2,3}, co-domain = {2,4,6,8}, range = {2,4,6}.

PART B: FUNCTIONS

4. Definition

A relation f from A to B is a function if every element of A has exactly one image in B. Write f : A → B, y = f(x). A function is a special relation: no element of A is left out, and none has two images.

Function: one arrow from each x
NOT a function: 1 has two arrows, 3 has none
Domain = set of inputs (all of A). Co-domain = B. Range = set of actual outputs ⊆ B. Real valued function: range ⊆ R. Vertical line test: a graph is a function if every vertical line cuts it at most once.

5. Types of Functions

Constant: f(x) = c. Domain R, range {c}. Graph: horizontal line.

f(x)=3 (constant), range {3}

Identity: f(x) = x. Domain R, range R. Graph: line through origin at 45°.

f(x)=x (identity), line at 45°

Polynomial: f(x) = a₀ + a₁x + … + aₙxⁿ (n whole number). Domain R. Eg. x² − 3x + 2.
Rational: f(x) = p(x)/q(x), q(x) ≠ 0. Eg. 1/(x−2): domain R − {2}.

Modulus: f(x) = |x| = x if x ≥ 0, −x if x < 0. Domain R, range [0,∞).

f(x)=|x|, range [0,∞)

Signum: f(x) = 1 (x>0), 0 (x=0), −1 (x<0). Domain R, range {−1,0,1}.

signum: −1, 0, 1

Greatest integer: f(x) = [x] = greatest integer ≤ x. [2.7]=2, [−1.3]=−2. Domain R, range Z.

f(x)=[x] steps; ● included, ○ not

Exponential: f(x) = aˣ (a>0, a≠1). Domain R, range (0,∞).

f(x)=2ˣ, passes (0,1), y>0

Logarithmic: f(x) = logₐx (a>0, a≠1). Domain (0,∞), range R. It is the inverse of aˣ.

f(x)=log₂x, passes (1,0), x>0

6. Algebra of Functions

(f+g)(x) = f(x)+g(x); (f−g)(x) = f(x)−g(x); (fg)(x) = f(x)·g(x); (f/g)(x) = f(x)/g(x), g(x) ≠ 0. Domain = Df ∩ Dg (for f/g remove points where g = 0).

Solved Examples (step by step)

Easy A={1,2,3}, B={4,5}. Find A×B and n(A×B).
Sol. A×B = {(1,4),(1,5),(2,4),(2,5),(3,4),(3,5)}; n = 3×2 = 6.
Easy If (x+1, 3) = (2, y−2), find x, y.
Sol. x+1 = 2 ⇒ x = 1; y−2 = 3 ⇒ y = 5.
Medium R = {(x,y) : x+y = 5, x,y ∈ N}. Write in roster form, find domain and range.
Sol. x=1,y=4; 2,3; 3,2; 4,1. R = {(1,4),(2,3),(3,2),(4,1)}. Domain = {1,2,3,4}, range = {1,2,3,4}.
Medium Find domain of f(x) = √(x−2)/(x−5).
Sol. Need x−2 ≥ 0 ⇒ x ≥ 2, and x−5 ≠ 0 ⇒ x ≠ 5. Domain = [2,∞) − {5}.
Hard If n(A)=3, n(B)=2, how many relations from A to B? How many are functions?
Sol. n(A×B) = 6, relations = 2⁶ = 64. A function gives each of 3 elements one of 2 images: 2×2×2 = 8 functions.
Hard f(x) = x², g(x) = 2x+1. Find (f+g)(x), (fg)(x), (f/g)(x) with domain.
Sol. (f+g) = x²+2x+1; (fg) = x²(2x+1) = 2x³+x²; (f/g) = x²/(2x+1). Domain of f, g is R; for f/g exclude 2x+1 = 0, so x ≠ −1/2.

Questions & Answers (tap to open)

Q1. What is an ordered pair?
A pair (a,b) where order matters; (a,b) = (b,a) only if a = b.
Q2. A={1,2}, B={3}. Find A×B and B×A.
A×B={(1,3),(2,3)}; B×A={(3,1),(3,2)}. They are different.
Q3. If n(A)=4, n(B)=5, find n(A×B).
4×5 = 20.
Q4. If (a,b)∈A×B..., find x if (x,2)=(5,2).
x = 5.
Q5. Define relation, domain, range.
Relation: subset of A×B. Domain: first components. Range: second components.
Q6. A={1,2,3}, R={(x,y): y=x+1}. Write R.
R = {(1,2),(2,3)} if B contains 2,3; (3,4) needs 4 ∈ B.
Q7. Number of relations from a 2-element set to a 3-element set?
2^(2×3) = 64.
Q8. Is every relation a function?
No. A function needs exactly one image for each element of the domain.
Q9. Is {(1,2),(1,3)} a function?
No, 1 has two images.
Q10. Find domain of 1/(x−3).
R − {3}.
Q11. Find domain of √(4−x).
4−x ≥ 0 ⇒ x ≤ 4, so (−∞,4].
Q12. Find range of f(x)=x², x∈R.
[0,∞).
Q13. Find [3.9], [−0.5], [5].
3, −1, 5.
Q14. Find |−7| and sgn(−7).
7 and −1.
Q15. What is the domain and range of log x?
Domain (0,∞), range R.
Q16. Range of f(x)=2ˣ?
(0,∞) since 2ˣ is always positive.
Q17. f(x)=x+1, g(x)=2x. Find (f+g)(3) and (fg)(3).
f(3)=4, g(3)=6: sum 10, product 24.
Q18. Find f(2) if f(x)=x²−3x+1.
4−6+1 = −1.
Q19. Prove: if A⊆B then A×C ⊆ B×C.
Take (a,c)∈A×C: a∈A⊆B so a∈B, c∈C ⇒ (a,c)∈B×C. Hence proved.
