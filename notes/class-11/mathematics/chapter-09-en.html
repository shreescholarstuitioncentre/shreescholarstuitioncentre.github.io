Straight Lines

Class 11 • Chapter 11 • Handwritten-style notes
Based on NCERT with practice in the style of Avtaar, Rajeev, Vidya & Sumitra Arora (UP Board).

1. Recall of Coordinate Geometry

Distance: √[(x₂−x₁)²+(y₂−y₁)²]. Midpoint: ((x₁+x₂)/2, (y₁+y₂)/2). Section (internal m:n): ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n)).

Area of triangle = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|. Three points are collinear if this area is 0.

2. Shifting of Origin

Shift the origin to O′(h, k) keeping axes parallel. If P(x, y) becomes P(X, Y):

x = X + h,   y = Y + k  (X = x − h, Y = y − k)

Use: to simplify an equation, choose (h, k) so that terms vanish; substitute x = X+h, y = Y+k and write the new equation in X, Y.

3. Slope of a Line

Inclination θ = angle (0° ≤ θ < 180°) a line makes with the +x-axis, measured anticlockwise. Slope m = tan θ.

m = (y₂ − y₁)/(x₂ − x₁)

x-axis (or ∥) → m = 0; y-axis (or ∥) → slope undefined (θ = 90°). Line Ax+By+C=0 → m = −A/B.

Parallel: m₁ = m₂. Perpendicular: m₁·m₂ = −1. Three points are collinear if slopes AB = BC.

4. Angle between Two Lines

If lines have slopes m₁, m₂, the acute angle θ between them is:

tan θ = | (m₁ − m₂)/(1 + m₁m₂) |

If m₁m₂ = −1 → θ = 90°. If m₁ = m₂ → θ = 0° (parallel). Obtuse angle = 180° − θ.

5. Forms of Equation of a Line

(a) Parallel to axes: parallel to y-axis at distance a: x = a; parallel to x-axis: y = b. (x-axis: y = 0, y-axis: x = 0.)

(b) Point-slope:

y − y₁ = m(x − x₁)

(c) Slope-intercept:

y = mx + c
c = y-intercept.

(d) Two-point:

y − y₁ = [(y₂−y₁)/(x₂−x₁)] (x − x₁)

(e) Intercept form:

x/a + y/b = 1
a = x-intercept, b = y-intercept (see diagram).

General form: Ax + By + C = 0; slope −A/B, x-intercept −C/A, y-intercept −C/B.

6. Distance of a Point from a Line

Perpendicular distance of P(x₁, y₁) from Ax + By + C = 0:

d = |Ax₁ + By₁ + C| / √(A² + B²)

From the origin: |C|/√(A²+B²). Between parallel lines Ax+By+C₁=0 and Ax+By+C₂=0: |C₁ − C₂| / √(A²+B²).

7. Solved Examples (Easy → Hard)

Example 1 EASY Find the slope of the line through (2, 3) and (6, 11).
  1. Step 1: m = (y₂−y₁)/(x₂−x₁) = (11−3)/(6−2)
  2. Step 2: = 8/4
  3. Step 3: = 2
Example 2 EASY Find the equation of the line through (1, 2) with slope 3.
  1. Step 1: Point-slope: y − y₁ = m(x − x₁)
  2. Step 2: y − 2 = 3(x − 1) = 3x − 3
  3. Step 3: 3x − y − 1 = 0
Example 3 EASY Find the equation of the line with slope 2 and y-intercept −3.
  1. Step 1: Slope-intercept: y = mx + c
  2. Step 2: m = 2, c = −3
  3. Step 3: y = 2x − 3, i.e. 2x − y − 3 = 0
Example 4 MEDIUM Find the equation of the line through (−1, 4) and (3, −2).
  1. Step 1: Slope = (−2−4)/(3+1) = −6/4 = −3/2
  2. Step 2: y − 4 = −(3/2)(x + 1)
  3. Step 3: 2y − 8 = −3x − 3
  4. Step 4: 3x + 2y − 5 = 0 (check (3,−2): 9−4−5 = 0 ✔)
Example 5 MEDIUM Find the equation of the line with x-intercept 3 and y-intercept −4.
  1. Step 1: Intercept form: x/a + y/b = 1, a = 3, b = −4
  2. Step 2: x/3 − y/4 = 1
  3. Step 3: Multiply by 12: 4x − 3y = 12
  4. Step 4: 4x − 3y − 12 = 0
Example 6 MEDIUM Find the acute angle between lines of slopes 2 and 1/3.
  1. Step 1: tan θ = |(m₁ − m₂)/(1 + m₁m₂)|
  2. Step 2: = |(2 − 1/3)/(1 + 2/3)| = (5/3)/(5/3)
  3. Step 3: tan θ = 1
  4. Step 4: θ = 45°
Example 7 HARD Find k so that 3x + ky = 5 and 2x − 3y = 7 are perpendicular.
  1. Step 1: Slope₁ = −3/k, Slope₂ = 2/3
  2. Step 2: Perpendicular: (−3/k)(2/3) = −1
  3. Step 3: −2/k = −1
  4. Step 4: k = 2
Example 8 HARD Find the line through (2, 3) which has equal intercepts on the axes.
  1. Step 1: Equal intercepts a: x/a + y/a = 1 → x + y = a
  2. Step 2: Passes through (2, 3): 2 + 3 = a → a = 5
  3. Step 3: Line: x + y = 5, i.e. x + y − 5 = 0
Example 9 HARD Shift the origin to (2, −3) and transform x² + y² − 4x + 6y − 12 = 0.
  1. Step 1: Put x = X + 2, y = Y − 3
  2. Step 2: (X+2)² + (Y−3)² − 4(X+2) + 6(Y−3) − 12 = 0
  3. Step 3: X²+4X+4 + Y²−6Y+9 − 4X−8 + 6Y−18 − 12 = 0
  4. Step 4: X² + Y² − 25 = 0 → X² + Y² = 25
Example 10 HARD Find the distance between parallel lines 3x + 4y − 10 = 0 and 3x + 4y + 5 = 0.
  1. Step 1: Take a point on line 1: (2, 1) (6+4−10 = 0 ✔)
  2. Step 2: d = |3(2) + 4(1) + 5| / √(3²+4²)
  3. Step 3: = 15/5
  4. Step 4: d = 3 (formula |C₁−C₂|/√(A²+B²) = 15/5 ✔)

8. Short Q&A

Q1. Define slope of a line.

Ans m = tan θ, where θ is the inclination; m = (y₂−y₁)/(x₂−x₁).

Q2. Condition for parallel and perpendicular lines?

Ans Parallel: m₁ = m₂. Perpendicular: m₁m₂ = −1.

Q3. Write the intercept form.

Ans x/a + y/b = 1.

Q4. Write the distance of a point from a line.

Ans |Ax₁+By₁+C| / √(A²+B²).

Q5. What are the formulas for shifting the origin?

Ans x = X + h, y = Y + k.
