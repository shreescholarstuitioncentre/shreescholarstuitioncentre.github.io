आयताकार कार्तीय निर्देशांक पद्धति

कक्षा 11 • अध्याय 10 • हस्तलिखित शैली नोट्स
NCERT पर आधारित; अवतार, राजीव, विद्या व सुमित्रा अरोड़ा (यूपी बोर्ड) शैली का अभ्यास।

1. कार्तीय निर्देशांक पद्धति

रेने डेकार्ट द्वारा दी गई। दो लंबवत संख्या-रेखाएँ एक बिंदु पर मिलती हैं; ये मिलकर तल के प्रत्येक बिंदु की स्थिति निर्धारित करती हैं। इस तल को कार्तीय (निर्देशांक) तल कहते हैं।

2. निर्देशांक अक्ष

क्षैतिज रेखा XOX′ = x-अक्ष; ऊर्ध्वाधर रेखा YOY′ = y-अक्ष। ये मूलबिंदु O(0,0) पर मिलती हैं।

O के दाईं और ऊपर धनात्मक; O के बाईं और नीचे ऋणात्मक दिशा है।

x-अक्ष पर कोई भी बिंदु (a, 0); y-अक्ष पर (0, b)।

3. चतुर्थांश

अक्ष तल को 4 चतुर्थांशों में बाँटते हैं: I (+,+), II (−,+), III (−,−), IV (+,−), वामावर्त गिनती।

अक्षों पर स्थित बिंदु किसी चतुर्थांश में नहीं होते।

4. बिंदु के निर्देशांक

बिंदु को क्रमित युग्म (x, y) से लिखते हैं: x = भुज (y-अक्ष से चिह्नित दूरी), y = कोटि (x-अक्ष से चिह्नित दूरी)।

(a, b) ≠ (b, a) जब तक a = b न हो। x-अक्ष से दूरी = |y|, y-अक्ष से = |x|, मूलबिंदु से = √(x²+y²)।

(x, y) का प्रतिबिंब: x-अक्ष में → (x, −y); y-अक्ष में → (−x, y); मूलबिंदु में → (−x, −y)।

5. दूरी सूत्र

A(x₁, y₁) और B(x₂, y₂) के बीच दूरी:

AB = √[(x₂−x₁)² + (y₂−y₁)²]

उपपत्ति: AC ∥ x-अक्ष और BC उस पर लंब खींचें; समकोण त्रिभुज ACB में AB² = AC² + BC² (पाइथागोरस) = (x₂−x₁)² + (y₂−y₁)²। चित्र को बनते देखें।

उपयोग: AB + BC = AC हो तो संरेख; भुजाओं की तुलना से समद्विबाहु/समबाहु/समकोण त्रिभुज; समांतर चतुर्भुज, समचतुर्भुज, आयत, वर्ग की जाँच।

6. विभाजन सूत्र

P, AB को m : n में अंतः विभाजित करे:

P = ( (mx₂ + nx₁)/(m+n) , (my₂ + ny₁)/(m+n) )

बाह्य विभाजन m : n में:

P = ( (mx₂ − nx₁)/(m−n) , (my₂ − ny₁)/(m−n) )

x-अक्ष, AB को −y₁ : y₂ में बाँटता है; y-अक्ष −x₁ : x₂ में (ऋणात्मक ⇒ बाह्य)।

7. मध्य-बिंदु सूत्र

विभाजन सूत्र में m = n = 1 रखने पर:

M = ( (x₁+x₂)/2 , (y₁+y₂)/2 )

त्रिभुज का केंद्रक: ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)। समांतर चतुर्भुज के विकर्ण एक-दूसरे को समद्विभाजित करते हैं (मध्य-बिंदु समान)।

8. हल किए गए उदाहरण (सरल → कठिन)

उदाहरण 1 सरल (2, 3) और (5, 7) के बीच दूरी ज्ञात कीजिए।
  1. चरण 1: x₂−x₁ = 3, y₂−y₁ = 4
  2. चरण 2: d = √(3² + 4²) = √(9+16)
  3. चरण 3: = √25 = 5
उदाहरण 2 सरल (−2, 4) और (6, −8) का मध्य-बिंदु ज्ञात कीजिए।
  1. चरण 1: x = (−2+6)/2 = 2
  2. चरण 2: y = (4+(−8))/2 = −2
  3. चरण 3: मध्य-बिंदु = (2, −2)
उदाहरण 3 सरल (−3, 5) किस चतुर्थांश में है? x-अक्ष में इसका प्रतिबिंब ज्ञात कीजिए।
  1. चरण 1: x < 0, y > 0 → द्वितीय चतुर्थांश
  2. चरण 2: x-अक्ष में प्रतिबिंब: (x, −y)
  3. चरण 3: = (−3, −5)
उदाहरण 4 मध्यम x-अक्ष पर वह बिंदु ज्ञात कीजिए जो (2, −5) और (−2, 9) से समदूरस्थ हो।
  1. चरण 1: बिंदु P(x, 0) मानें
  2. चरण 2: PA² = PB²: (x−2)² + 25 = (x+2)² + 81
  3. चरण 3: x² − 4x + 29 = x² + 4x + 85
  4. चरण 4: −8x = 56 → x = −7; P = (−7, 0)
उदाहरण 5 मध्यम (1, −3) और (−3, 9) को 1 : 3 में अंतः विभाजित करने वाला बिंदु ज्ञात कीजिए।
  1. चरण 1: m = 1, n = 3, (x₁,y₁) = (1,−3), (x₂,y₂) = (−3,9)
  2. चरण 2: x = (1·(−3) + 3·1)/4 = 0
  3. चरण 3: y = (1·9 + 3·(−3))/4 = 0
  4. चरण 4: बिंदु = (0, 0)
उदाहरण 6 मध्यम x-अक्ष (2, −3) और (5, 6) को मिलाने वाली रेखा को किस अनुपात में बाँटता है?
  1. चरण 1: अनुपात = −y₁ : y₂ = 3 : 6 = 1 : 2 (धनात्मक → अंतः)
  2. चरण 2: x = (1·5 + 2·2)/3 = 3
  3. चरण 3: बिंदु = (3, 0), अनुपात 1 : 2
उदाहरण 7 कठिन दर्शाइए कि A(−4,−1), B(−2,−4), C(4,0), D(2,3) एक आयत के शीर्ष हैं।
  1. चरण 1: AB = √(4+9) = √13, CD = √(4+9) = √13
  2. चरण 2: BC = √(36+16) = √52, DA = √(36+16) = √52 (सम्मुख भुजाएँ बराबर)
  3. चरण 3: AC = √(64+1) = √65, BD = √(16+49) = √65 (विकर्ण बराबर)
  4. चरण 4: बराबर विकर्णों वाला समांतर चतुर्भुज ⟹ आयत ∎
उदाहरण 8 कठिन दर्शाइए कि (0,0), (3,√3), (0,2√3) एक समबाहु त्रिभुज के शीर्ष हैं।
  1. चरण 1: OA = √(9+3) = 2√3
  2. चरण 2: AB = √(9+3) = 2√3
  3. चरण 3: OB = 2√3
  4. चरण 4: तीनों भुजाएँ बराबर ⟹ समबाहु ∎
उदाहरण 9 कठिन x ज्ञात कीजिए यदि (x, 2) और (3, −6) के बीच दूरी 10 है।
  1. चरण 1: √[(x−3)² + (2+6)²] = 10
  2. चरण 2: (x−3)² + 64 = 100 → (x−3)² = 36
  3. चरण 3: x − 3 = ±6
  4. चरण 4: x = 9 या x = −3
उदाहरण 10 कठिन दर्शाइए कि (1,−1), (2,1), (4,5) संरेख हैं।
  1. चरण 1: AB = √(1+4) = √5
  2. चरण 2: BC = √(4+16) = √20 = 2√5
  3. चरण 3: AC = √(9+36) = √45 = 3√5
  4. चरण 4: AB + BC = √5 + 2√5 = 3√5 = AC ⟹ संरेख ∎

9. लघु प्रश्नोत्तर

प्र.1. दूरी सूत्र लिखिए।

उ. AB = √[(x₂−x₁)² + (y₂−y₁)²]।

प्र.2. भुज और कोटि क्या हैं?

उ. x-निर्देशांक भुज और y-निर्देशांक कोटि कहलाता है।

प्र.3. अंतः विभाजन सूत्र लिखिए।

उ. P = ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n))।

प्र.4. (−,+) कौन-सा चतुर्थांश है?

उ. द्वितीय चतुर्थांश।

प्र.5. मध्य-बिंदु सूत्र लिखिए।

उ. ((x₁+x₂)/2, (y₁+y₂)/2)।
