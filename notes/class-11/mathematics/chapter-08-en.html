Sequences & Series

Class 11 • Chapter 9 • Handwritten-style notes
Based on NCERT with practice in the style of Avtaar, Rajeev, Vidya & Sumitra Arora (UP Board).

1. Sequence

A sequence is a list of numbers arranged in a definite order by some rule: a₁, a₂, a₃, … Example: 2, 4, 6, 8, … (aₙ = 2n).

Finite sequence has last term; infinite sequence goes on forever. Its n-th term aₙ is a function of n.

2. Series

If a₁, a₂, …, aₙ is a sequence, then a₁ + a₂ + … + aₙ is the corresponding series. Sum of n terms is written Sₙ and aₙ = Sₙ − Sₙ₋₁.

Sequence = list; Series = sum of that list.

3. Arithmetic Progression (Basics)

AP: each term = previous + constant d (common difference).

aₙ = a + (n−1)d    Sₙ = n/2 [2a + (n−1)d]

Arithmetic Mean of a, b: A = (a+b)/2. Three terms in AP: a−d, a, a+d.

4. Geometric Progression (GP)

GP: each term = previous × constant r (common ratio), r = a₂/a₁ ≠ 0. Example: 3, 6, 12, 24 (r = 2); 8, 4, 2, 1 (r = ½).

Three terms in GP: a/r, a, ar. Test: b² = ac.

5. General Term of GP

aₙ = a rⁿ⁻¹

From the end of a finite GP with l as last term: n-th from end = l / rⁿ⁻¹.

6. Sum of n terms of GP

Sₙ = a(rⁿ − 1)/(r − 1), r > 1    Sₙ = a(1 − rⁿ)/(1 − r), r < 1

If r = 1, then Sₙ = na.

Proof idea: Sₙ = a + ar + … + arⁿ⁻¹; r·Sₙ = ar + … + arⁿ; subtract: (1−r)Sₙ = a(1−rⁿ).

7. Infinite GP & its Sum

A GP that never ends. If |r| < 1, rⁿ → 0, so the sum is finite:

S∞ = a / (1 − r),  |r| < 1

If |r| ≥ 1 the sum does not exist (it is not finite). Diagram: 1 + ½ + ¼ + … fills a length of 2.

Recurring decimal: 0.3̄ = 0.3 + 0.03 + … = 0.3/(1−0.1) = 1/3.

8. Geometric Mean (GM)

GM of a and b (positive) is G = √(ab) (a, G, b are in GP).

n GMs between a and b: r = (b/a)^(1/(n+1)); terms are ar, ar², …, arⁿ. Product of the n GMs = Gⁿ where G = √(ab).

9. AM–GM Relation

For positive a, b:

AM ≥ GM, i.e. (a+b)/2 ≥ √(ab)

Equality holds only when a = b. Also AM·HM = GM².

Diagram: in a semicircle of diameter a+b, radius = AM and the perpendicular CD at the join = GM. Radius is never shorter than the perpendicular.

Use: if sum x+y is fixed, product xy is maximum when x = y; if product is fixed, sum is minimum when x = y.

10. Solved Examples (Easy → Hard)

Example 1 EASY Find the 10th term of the GP 2, 6, 18, …
  1. Step 1: a = 2, r = 6/2 = 3, n = 10
  2. Step 2: aₙ = a rⁿ⁻¹ = 2 × 3⁹
  3. Step 3: 3⁹ = 19683, so a₁₀ = 39366
Example 2 EASY Find the sum of first 6 terms of 3, 6, 12, …
  1. Step 1: a = 3, r = 2 (r > 1), n = 6
  2. Step 2: S₆ = 3(2⁶ − 1)/(2 − 1) = 3 × 63
  3. Step 3: = 189
Example 3 EASY Find the sum of 1 + ½ + ¼ + … to ∞.
  1. Step 1: a = 1, r = ½, |r| < 1 ✔
  2. Step 2: S∞ = a/(1−r) = 1/(1−½)
  3. Step 3: = 2
Example 4 MEDIUM The 3rd term of a GP is 12 and the 6th term is 96. Find a and r.
  1. Step 1: ar² = 12 … (1), ar⁵ = 96 … (2)
  2. Step 2: (2)÷(1): r³ = 8 → r = 2
  3. Step 3: From (1): a × 4 = 12 → a = 3
Example 5 MEDIUM Insert 3 GMs between 1 and 81.
  1. Step 1: a = 1, b = 81, n = 3; b = ar⁴ → r⁴ = 81
  2. Step 2: r = 3
  3. Step 3: GMs: 3, 9, 27 (sequence 1, 3, 9, 27, 81)
Example 6 MEDIUM Express 0.777… as a fraction.
  1. Step 1: 0.777… = 0.7 + 0.07 + 0.007 + …, a = 0.7, r = 0.1
  2. Step 2: S∞ = 0.7/(1 − 0.1) = 0.7/0.9
  3. Step 3: = 7/9
Example 7 HARD Prove AM ≥ GM for two positive numbers a, b.
  1. Step 1: AM − GM = (a+b)/2 − √(ab) = (a + b − 2√(ab))/2
  2. Step 2: = (√a − √b)²/2
  3. Step 3: A square is ≥ 0, so AM − GM ≥ 0
  4. Step 4: Equal only when √a = √b i.e. a = b ∎
Example 8 HARD Find the sum of n terms of 7 + 77 + 777 + …
  1. Step 1: Sₙ = 7(1 + 11 + 111 + …) = (7/9)(9 + 99 + 999 + …)
  2. Step 2: = (7/9)[(10−1) + (10²−1) + … + (10ⁿ−1)]
  3. Step 3: = (7/9)[10(10ⁿ − 1)/9 − n]
  4. Step 4: = (70/81)(10ⁿ − 1) − 7n/9
Example 9 HARD If a, b, c are in GP and a^(1/x) = b^(1/y) = c^(1/z), prove x, y, z are in AP.
  1. Step 1: Let each = k: a = kˣ, b = kʸ, c = kᶻ
  2. Step 2: GP ⟹ b² = ac → k²ʸ = kˣ⁺ᶻ
  3. Step 3: So 2y = x + z
  4. Step 4: Hence x, y, z are in AP ∎
Example 10 HARD If x > 0, find the minimum value of x + 1/x.
  1. Step 1: AM of x and 1/x ≥ GM: (x + 1/x)/2 ≥ √(x · 1/x) = 1
  2. Step 2: So x + 1/x ≥ 2
  3. Step 3: Equality when x = 1/x → x = 1
  4. Step 4: Minimum value = 2

11. Short Q&A

Q1. Define a sequence and a series.

Ans A sequence is an ordered list of numbers by a rule; a series is the sum of its terms.

Q2. State the general term and sum of a GP.

Ans aₙ = arⁿ⁻¹; Sₙ = a(rⁿ−1)/(r−1) for r≠1.

Q3. When does an infinite GP have a sum?

Ans Only when |r| < 1; then S∞ = a/(1−r).

Q4. Define geometric mean.

Ans For positive a, b, GM = √(ab); a, G, b are in GP.

Q5. State the AM–GM inequality.

Ans For positive reals, (a+b)/2 ≥ √(ab), equality iff a = b.
