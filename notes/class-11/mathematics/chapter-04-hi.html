कक्षा 11 गणित - अध्याय 5: सम्मिश्र संख्याएँ और द्विघात समीकरण

भाग A: सम्मिश्र संख्याएँ

1. सम्मिश्र संख्याओं की आवश्यकता

समीकरण x² + 1 = 0 का कोई वास्तविक हल नहीं है क्योंकि कोई वास्तविक संख्या ऐसी नहीं जिसका वर्ग −1 हो। ऐसे समीकरण हल करने के लिए संख्या पद्धति का विस्तार किया गया।

2. काल्पनिक इकाई i

i = √−1, अतः i² = −1, i³ = −i, i⁴ = 1।
सामान्यतः iⁿ का मान n mod 4 पर निर्भर है: i4k = 1, i4k+1 = i, i4k+2 = −1, i4k+3 = −i।
Powers of i repeat every 4 steps; multiplying by i rotates by 90°

सम्मिश्र संख्या z = a + ib (a, b वास्तविक)। a = Re(z) वास्तविक भाग, b = Im(z) काल्पनिक भाग। यदि b = 0 तो z वास्तविक; यदि a = 0 (b≠0) तो z शुद्ध काल्पनिक है। दो सम्मिश्र संख्याएँ समान तब जब उनके वास्तविक भाग और काल्पनिक भाग दोनों समान हों।

3. सम्मिश्र संख्याओं का बीजगणित

(a+ib) + (c+id) = (a+c) + i(b+d)
(a+ib) − (c+id) = (a−c) + i(b−d)
(a+ib)(c+id) = (ac − bd) + i(ad + bc)
(a+ib)/(c+id) = [(ac + bd) + i(bc − ad)]/(c² + d²) (अंश और हर को संयुग्मी c − id से गुणा करें)

जोड़ और गुणा क्रमविनिमेय, साहचर्य और वितरण नियम का पालन करते हैं। योज्य तत्समक 0, योज्य प्रतिलोम −z। गुणात्मक तत्समक 1, गुणात्मक प्रतिलोम 1/z = z̄/|z|² (z≠0)।

4. आर्गन्ड तल (Argand Plane)

संख्या a + ib को बिंदु (a, b) से दर्शाते हैं। x-अक्ष वास्तविक अक्ष और y-अक्ष काल्पनिक अक्ष है।

Argand plane: z, its conjugate z̄ (mirror in real axis) and modulus |z|

5. मापांक और संयुग्मी

मापांक: |z| = √(a² + b²) = z की मूलबिंदु से दूरी।
संयुग्मी: z̄ = a − ib (वास्तविक अक्ष में दर्पण-प्रतिबिंब)।
z z̄ = |z|², z + z̄ = 2a, z − z̄ = 2ib, |z̄| = |z|, conj(z̄) = z।
|z₁z₂| = |z₁||z₂|, |z₁/z₂| = |z₁|/|z₂|, conj(z₁ ± z₂) = z̄₁ ± z̄₂, conj(z₁z₂) = z̄₁z̄₂।

z वास्तविक ⇔ z = z̄; z शुद्ध काल्पनिक ⇔ z = −z̄।

6. सम्मिश्र संख्या का वर्गमूल

√(a+ib) = ± [ √((|z|+a)/2) + i·sgn(b)·√((|z|−a)/2) ], जहाँ |z| = √(a²+b²) और sgn(b) = +1 यदि b > 0, −1 यदि b < 0।

विधि 2: √(a+ib) = x + iy रखें, वर्ग करें, वास्तविक और काल्पनिक भाग बराबर करें: x² − y² = a, 2xy = b, और हल करें।

भाग B: द्विघात समीकरण

7. बीजगणित का मूल प्रमेय

n ≥ 1 घात के प्रत्येक बहुपद समीकरण का सम्मिश्र संख्याओं में कम से कम एक मूल होता है, अतः कुल n मूल होते हैं (दोहराए मूल गिनकर)। इसलिए द्विघात समीकरण के C में सदैव 2 मूल होते हैं।

8. ax² + bx + c = 0 (a ≠ 0) का हल

x = [−b ± √(b² − 4ac)]/(2a)। विविक्तकर D = b² − 4ac।
मूलों का योग = −b/a। मूलों का गुणनफल = c/a।

वास्तविक मूल

D > 0: दो भिन्न वास्तविक मूल। D = 0: दो समान वास्तविक मूल x = −b/2a।

D > 0: parabola cuts x-axis at 2 points (two real roots)
D = 0: touches x-axis (equal real roots)

सम्मिश्र मूल

D < 0: मूल x = [−b ± i√(4ac − b²)]/(2a), जो एक-दूसरे के संयुग्मी हैं (वास्तविक a, b, c के लिए)।

D < 0: no contact (two complex roots)

हल किए गए उदाहरण (चरणबद्ध)

सरल i⁵⁷ + i⁷⁰ ज्ञात कीजिए।
हल. 57 = 4×14 + 1 ⇒ i⁵⁷ = i। 70 = 4×17 + 2 ⇒ i⁷⁰ = −1। योग = i − 1।
सरल (2+3i)(4−5i) ज्ञात कीजिए।
हल. = 8 − 10i + 12i − 15i² = 8 + 2i + 15 = 23 + 2i।
मध्यम (1+2i)/(3−4i) को a + ib रूप में लिखिए।
हल. (3+4i)/(3+4i) से गुणा करें: अंश = (1+2i)(3+4i) = 3 + 4i + 6i + 8i² = −5 + 10i। हर = 9 + 16 = 25। परिणाम = −1/5 + (2/5)i।
मध्यम x² + 2x + 5 = 0 हल कीजिए।
हल. D = 4 − 20 = −16 < 0। x = (−2 ± √−16)/2 = (−2 ± 4i)/2 = −1 ± 2i।
कठिन 3 + 4i का वर्गमूल ज्ञात कीजिए।
हल. माना (x+iy)² = 3+4i। तब x² − y² = 3 और 2xy = 4। |z| = 5, अतः x² + y² = 5। जोड़ने पर 2x² = 8, x = ±2। घटाने पर 2y² = 2, y = ±1। 2xy = 4 > 0 अतः x, y समान चिह्न के हैं। मूल: ±(2 + i)।
कठिन वास्तविक x, y ज्ञात कीजिए यदि (x + iy)(2 − 3i) = 4 + i।
हल. x + iy = (4+i)/(2−3i) = (4+i)(2+3i)/13 = (8 + 12i + 2i + 3i²)/13 = (5 + 14i)/13। अतः x = 5/13, y = 14/13।
कठिन सिद्ध कीजिए |z₁+z₂|² + |z₁−z₂|² = 2(|z₁|² + |z₂|²)।
उपपत्ति. |z₁+z₂|² = (z₁+z₂)(z̄₁+z̄₂) = |z₁|² + z₁z̄₂ + z̄₁z₂ + |z₂|²। |z₁−z₂|² = |z₁|² − z₁z̄₂ − z̄₁z₂ + |z₂|²। जोड़ने पर बीच के पद कट जाते हैं: 2|z₁|² + 2|z₂|²।
