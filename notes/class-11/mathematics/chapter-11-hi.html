शांकव – वृत्त

कक्षा 11 • अध्याय 12 • हस्तलिखित शैली नोट्स
NCERT पर आधारित; अवतार, राजीव, विद्या व सुमित्रा अरोड़ा (यूपी बोर्ड) शैली का अभ्यास।

1. वृत्त

वृत्त उस बिंदु का बिंदुपथ है जो तल में इस प्रकार चलता है कि एक निश्चित बिंदु (केंद्र) से उसकी दूरी अचर (त्रिज्या) रहे।

यह एक शांकव है: शंकु को उसकी अक्ष के लंबवत तल से काटने पर वृत्त मिलता है।

शब्द: व्यास = 2r (सबसे लंबी जीवा); जीवा दो बिंदुओं को जोड़ती है; छेदक रेखा 2 बिंदुओं पर काटती है; स्पर्श रेखा 1 बिंदु पर छूती है; चाप = वृत्त का भाग।

2. मानक समीकरण

केंद्र C(h, k), त्रिज्या r। वृत्त पर किसी बिंदु P(x, y) के लिए CP = r। दूरी सूत्र से (चित्र देखें):

(x − h)² + (y − k)² = r²

केंद्र मूलबिंदु पर:

x² + y² = r²

व्यास रूप: सिरे (x₁,y₁), (x₂,y₂): (x−x₁)(x−x₂) + (y−y₁)(y−y₂) = 0।

वृत्त केंद्र और त्रिज्या (या तीन असंरेख बिंदुओं) से निर्धारित होता है।

3. केंद्र एवं त्रिज्या (व्यापक समीकरण)

व्यापक रूप:

x² + y² + 2gx + 2fy + c = 0

केंद्र = (−g, −f), त्रिज्या = √(g² + f² − c)। (पूर्ण वर्ग बनाकर मानक रूप पाएँ।)

g²+f²−c > 0 वास्तविक वृत्त; = 0 बिंदु वृत्त; < 0 काल्पनिक वृत्त।

द्विघात समीकरण वृत्त है यदि x² व y² के गुणांक बराबर हों और xy पद न हो। ax² + ay² + … हो तो पहले a से भाग दें।

4. सरल गुणधर्म

बिंदु P(x₁, y₁) की स्थिति: S₁ = x₁² + y₁² + 2gx₁ + 2fy₁ + c; S₁ > 0 बाहर, = 0 पर, < 0 अंदर।

केंद्र से जीवा पर डाला लंब जीवा को समद्विभाजित करता है; केंद्र से जीवा के मध्य-बिंदु को मिलाने वाली रेखा जीवा पर लंब होती है।

बराबर जीवाएँ केंद्र से समान दूरी पर होती हैं। अर्धवृत्त में कोण = 90°।

तीन असंरेख बिंदुओं से एक ही वृत्त जाता है: बिंदु x²+y²+2gx+2fy+c=0 में रखकर g, f, c ज्ञात करें।

5. स्पर्श रेखा (मूल)

स्पर्श रेखा वृत्त को ठीक एक बिंदु (स्पर्श बिंदु) पर छूती है। स्पर्श बिंदु पर स्पर्श रेखा ⟂ त्रिज्या (चित्र देखें)। बाह्य बिंदु से बराबर लंबाई की 2 स्पर्श रेखाएँ खिंचती हैं।

x² + y² = r² के (x₁, y₁) पर स्पर्श रेखा:

x x₁ + y y₁ = r²

x²+y²+2gx+2fy+c=0 के लिए: x x₁ + y y₁ + g(x+x₁) + f(y+y₁) + c = 0।

रेखा y = mx + c, वृत्त x² + y² = r² को छूती है यदि

c² = r²(1 + m²)

रेखा स्पर्शी है यदि (केंद्र से रेखा की दूरी) = r। (x₁, y₁) से स्पर्श रेखा की लंबाई = √S₁।

6. हल किए गए उदाहरण (सरल → कठिन)

उदाहरण 1 सरल केंद्र (2, −3) और त्रिज्या 5 वाले वृत्त का समीकरण ज्ञात कीजिए।
  1. चरण 1: सूत्र (x−h)² + (y−k)² = r²
  2. चरण 2: h = 2, k = −3, r = 5
  3. चरण 3: (x−2)² + (y+3)² = 25
उदाहरण 2 सरल x² + y² − 6x + 4y − 12 = 0 का केंद्र और त्रिज्या ज्ञात कीजिए।
  1. चरण 1: x²+y²+2gx+2fy+c = 0 से तुलना: 2g = −6, 2f = 4, c = −12
  2. चरण 2: g = −3, f = 2 → केंद्र (−g, −f) = (3, −2)
  3. चरण 3: r = √(9 + 4 + 12) = √25 = 5
उदाहरण 3 सरल मूलबिंदु केंद्र और त्रिज्या 7 वाले वृत्त का समीकरण लिखिए।
  1. चरण 1: केंद्र (0,0) → x² + y² = r²
  2. चरण 2: r = 7
  3. चरण 3: x² + y² = 49
उदाहरण 4 मध्यम केंद्र (1, 2) वाला वह वृत्त ज्ञात कीजिए जो (4, 6) से गुज़रता है।
  1. चरण 1: r = (1,2) से (4,6) की दूरी = √(9 + 16)
  2. चरण 2: r = 5
  3. चरण 3: (x−1)² + (y−2)² = 25
उदाहरण 5 मध्यम (2, 3) और (−2, −1) को व्यास के सिरे मानकर वृत्त का समीकरण ज्ञात कीजिए।
  1. चरण 1: व्यास रूप: (x−2)(x+2) + (y−3)(y+1) = 0
  2. चरण 2: x² − 4 + y² − 2y − 3 = 0
  3. चरण 3: x² + y² − 2y − 7 = 0
  4. चरण 4: जाँच: केंद्र (0,1), r = √8 = (2,3) से दूरी ✔
उदाहरण 6 मध्यम x² + y² = 16 के सापेक्ष (3, 4) की स्थिति ज्ञात कीजिए।
  1. चरण 1: S₁ = 3² + 4² − 16
  2. चरण 2: = 25 − 16 = 9
  3. चरण 3: S₁ > 0 → बिंदु वृत्त के बाहर है
उदाहरण 7 कठिन (0,0), (4,0) और (0,6) से जाने वाला वृत्त ज्ञात कीजिए।
  1. चरण 1: x²+y²+2gx+2fy+c = 0 मानें। (0,0): c = 0
  2. चरण 2: (4,0): 16 + 8g = 0 → g = −2
  3. चरण 3: (0,6): 36 + 12f = 0 → f = −3
  4. चरण 4: x² + y² − 4x − 6y = 0; केंद्र (2,3), r = √13
उदाहरण 8 कठिन सिद्ध कीजिए कि x² + y² = r² के (x₁, y₁) पर स्पर्श रेखा x x₁ + y y₁ = r² है।
  1. चरण 1: (x₁,y₁) तक त्रिज्या की प्रवणता y₁/x₁; स्पर्श रेखा ⟂ त्रिज्या → प्रवणता = −x₁/y₁
  2. चरण 2: y − y₁ = −(x₁/y₁)(x − x₁)
  3. चरण 3: y y₁ − y₁² = −x x₁ + x₁² → x x₁ + y y₁ = x₁² + y₁²
  4. चरण 4: (x₁,y₁) वृत्त पर: x₁²+y₁² = r² → x x₁ + y y₁ = r² ∎
उदाहरण 9 कठिन c का मान ज्ञात कीजिए जिसके लिए y = x + c, x² + y² = 25 की स्पर्श रेखा हो।
  1. चरण 1: m = 1, r² = 25; शर्त c² = r²(1 + m²)
  2. चरण 2: c² = 25 × 2 = 50
  3. चरण 3: c = ±5√2
  4. चरण 4: जाँच: x − y + c = 0 की मूलबिंदु से दूरी |c|/√2 = 5 ✔
उदाहरण 10 कठिन (6, 5) से x² + y² − 2x − 4y − 4 = 0 पर स्पर्श रेखा की लंबाई ज्ञात कीजिए।
  1. चरण 1: लंबाई = √S₁
  2. चरण 2: S₁ = 36 + 25 − 12 − 20 − 4 = 25
  3. चरण 3: लंबाई = √25 = 5
  4. चरण 4: जाँच: केंद्र (1,2), r = 3, d² = 34; √(34 − 9) = 5 ✔

7. लघु प्रश्नोत्तर

प्र.1. वृत्त को परिभाषित कीजिए।

उ. एक निश्चित बिंदु (केंद्र) से अचर दूरी (त्रिज्या) पर स्थित बिंदुओं का बिंदुपथ।

प्र.2. मानक समीकरण लिखिए।

उ. (x−h)² + (y−k)² = r²।

प्र.3. x²+y²+2gx+2fy+c=0 का केंद्र और त्रिज्या?

उ. केंद्र (−g, −f), त्रिज्या √(g²+f²−c)।

प्र.4. स्पर्श रेखा क्या है?

उ. वह रेखा जो वृत्त को ठीक एक बिंदु पर छूती है; वहाँ त्रिज्या पर लंब होती है।

प्र.5. y=mx+c के x²+y²=r² को छूने की शर्त लिखिए।

उ. c² = r²(1+m²)।
