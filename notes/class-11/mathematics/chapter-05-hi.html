कक्षा 11 गणित - अध्याय 6: रैखिक असमिकाएँ

1. रैखिक असमिकाएँ

जिस कथन में दो व्यंजक <, >, ≤ या ≥ से जुड़े हों उसे असमिका कहते हैं। यदि चर की घात 1 हो तो वह रैखिक असमिका है। उदा. 3x + 5 < 14 (एक चर), 2x + 3y ≥ 6 (दो चर)।

निरपेक्ष (Strict) असमिका: < या > (अंत मान शामिल नहीं)। शिथिल (Slack) असमिका: ≤ या ≥ (अंत मान शामिल)। हल समुच्चय = चर के वे सभी मान जो असमिका को सत्य करें; यह प्रांत (N, Z या R) पर निर्भर करता है।

2. बीजीय हल: नियम

1. दोनों पक्षों में एक ही संख्या जोड़ें या घटाएँ: चिह्न वही रहता है।
2. दोनों पक्षों को एक ही धनात्मक संख्या से गुणा या भाग दें: चिह्न वही रहता है।
3. दोनों पक्षों को ऋणात्मक संख्या से गुणा या भाग दें: चिह्न उलट जाता है (< से >)।
4. पद को दूसरी ओर ले जाने पर उसका चिह्न बदलें (पक्षांतरण)।

नियम 3 का उदाहरण: −2x < 6। −2 से भाग दें और चिह्न उलटें: x > −3।

3. एक चर वाली असमिका का हल

चरण: (i) कोष्ठक और भिन्न हटाएँ (हरों के LCM से गुणा, जो धनात्मक है), (ii) x वाले पद एक ओर और संख्याएँ दूसरी ओर, (iii) x के गुणांक से भाग दें (ऋणात्मक हो तो चिह्न उलटें), (iv) हल समुच्चय लिखें, (v) संख्या रेखा पर दर्शाएँ। a < f(x) ≤ b जैसी दोहरी असमिका में तीनों भागों पर एक साथ संक्रिया करें।

4. संख्या रेखा पर निरूपण

< या > के लिए अंत बिंदु पर खाली वृत्त ○ (शामिल नहीं); ≤ या ≥ के लिए भरा वृत्त ● (शामिल)। असमिका को संतुष्ट करने वाले भाग को रंगें; तीर बताता है कि यह अनंत तक जाता है।

x > 2 : open circle, arrow to right
x ≥ 2 : filled circle, arrow to right
x < −1 : open circle, arrow to left
x ≤ −1 : filled circle, arrow to left
−1 ≤ x < 2 : interval [−1, 2)

अंतराल रूप: x > 2 है (2, ∞); x ≥ 2 है [2, ∞); x < −1 है (−∞, −1); −1 ≤ x < 2 है [−1, 2)। अनंत पर सदैव गोल कोष्ठक लगता है।

5. ग्राफीय निरूपण (दो चर)

ax + by ≥ c (या >, ≤, <) के चरण: (i) रेखा ax + by = c खींचें (दो बिंदु, जैसे अंतःखंड); (ii) ≤ या ≥ के लिए रेखा ठोस, < या > के लिए बिंदुकित; (iii) परीक्षण बिंदु लें, प्रायः O(0,0) (यदि रेखा पर हो तो दूसरा लें); (iv) यदि वह असमिका को संतुष्ट करे तो उसी ओर का भाग रंगें, अन्यथा दूसरी ओर।

x + y ≥ 3: solid line, shade side not containing O
x + y > 3: dashed line (line itself not included)

असमिका निकाय: प्रत्येक को खींचें; उभयनिष्ठ रंगीन क्षेत्र ही हल है।

x ≥ 0, y ≥ 0, x + y ≤ 4: common region (triangle)

हल किए गए उदाहरण (चरणबद्ध)

सरल 3x + 5 < 14, x ∈ R हल कीजिए।
हल. 3x < 14 − 5 = 9 ⇒ x < 3। हल समुच्चय (−∞, 3)।
सरल −2x ≤ 6 हल कीजिए।
हल. −2 से भाग देकर चिह्न उलटें: x ≥ −3। हल [−3, ∞)।
मध्यम 3(2 − x) ≥ 2(1 − x) हल कीजिए।
हल. 6 − 3x ≥ 2 − 2x ⇒ 6 − 2 ≥ 3x − 2x ⇒ 4 ≥ x, अर्थात् x ≤ 4। हल (−∞, 4]।
मध्यम −8 ≤ 5x − 3 < 7 हल कीजिए।
हल. सभी भागों में 3 जोड़ें: −5 ≤ 5x < 10। 5 से भाग दें: −1 ≤ x < 2। हल [−1, 2)।
कठिन क्रमागत विषम धन पूर्णांकों के वे युग्म ज्ञात कीजिए जो दोनों 10 से छोटे हों और जिनका योग 11 से अधिक हो।
हल. संख्याएँ x और x + 2 (x विषम)। x + 2 < 10 ⇒ x < 8। x + (x+2) > 11 ⇒ 2x > 9 ⇒ x > 4.5। अतः 4.5 < x < 8, x विषम: x = 5, 7। युग्म: (5,7) और (7,9)।
कठिन एक घोल का ताप 68°F और 77°F के बीच रखना है। C = (5/9)(F − 32) से °C में परिसर ज्ञात कीजिए।
हल. 68 < F < 77 ⇒ 36 < F − 32 < 45 ⇒ 5/9 से गुणा: 20 < C < 25। अतः ताप 20°C और 25°C के बीच है।
कठिन x ≥ 0, y ≥ 0, x + y ≤ 4 को ग्राफ से हल कीजिए।
हल. x ≥ 0: y-अक्ष के दाएँ। y ≥ 0: x-अक्ष के ऊपर। x + y = 4 बिंदु (4,0) और (0,4) से जाती है; O की जाँच: 0 ≤ 4 सत्य, O की ओर रंगें। उभयनिष्ठ क्षेत्र = शीर्ष (0,0), (4,0), (0,4) वाला त्रिभुज, सीमा सहित।

प्रश्न-उत्तर (खोलने के लिए टैप करें)

Q1. रैखिक असमिका की परिभाषा दीजिए।
ऐसी असमिका जिसमें चर की घात 1 हो, जैसे 2x + 3 < 9।
Q2. निरपेक्ष और शिथिल असमिका में अंतर?
निरपेक्ष में < या > (अंत मान शामिल नहीं); शिथिल में ≤ या ≥ (शामिल)।
Q3. असमिका का चिह्न कब उलटता है?
जब दोनों पक्षों को ऋणात्मक संख्या से गुणा या भाग दें।
Q4. x + 5 > 8 हल कीजिए।
x > 3, अर्थात् (3, ∞)।
Q5. 4x − 3 ≤ 9 हल कीजिए।
4x ≤ 12 ⇒ x ≤ 3।
Q6. −3x > 12 हल कीजिए।
−3 से भाग दें, चिह्न उलटें: x < −4।
Q7. 5x − 3 < 3x + 1, x ∈ R हल कीजिए।
2x < 4 ⇒ x < 2।
Q8. 2x + 1 > 9, x ∈ N हल कीजिए।
x > 4 ⇒ x = 5, 6, 7, …
Q9. 3x − 1 < 8, x धन पूर्णांक हल कीजिए।
x < 3 ⇒ x = 1, 2।
Q10. (x/2) + 3 ≥ 5 हल कीजिए।
x/2 ≥ 2 ⇒ x ≥ 4।
Q11. (x − 1)/3 < 2 हल कीजिए।
x − 1 < 6 ⇒ x < 7।
Q12. 1 ≤ 2x + 3 ≤ 7 हल कीजिए।
3 घटाएँ: −2 ≤ 2x ≤ 4 ⇒ −1 ≤ x ≤ 2।
Q13. x ≥ −2 को अंतराल रूप में लिखिए।
[−2, ∞)।
Q14. x < 3 को संख्या रेखा पर दर्शाइए।
3 पर खाली वृत्त, तीर बाईं ओर।
Q15. x ≤ 1 को संख्या रेखा पर दर्शाइए।
1 पर भरा वृत्त, तीर बाईं ओर।
Q16. 6 − 3x ≥ 12 हल कीजिए।
−3x ≥ 6 ⇒ x ≤ −2।
Q17. क्या x = 2, 3x − 5 > 0 का हल है?
6 − 5 = 1 > 0 सत्य, अतः हाँ।
Q18. x + y ≤ 5 को ग्राफ से हल कीजिए।
ठोस रेखा x + y = 5 बिंदु (5,0), (0,5) से खींचें। O: 0 ≤ 5 सत्य, O वाली ओर रंगें।
Q19. 2x + y > 4 को ग्राफ से हल कीजिए।
बिंदुकित रेखा 2x + y = 4 बिंदु (2,0), (0,4) से। O: 0 > 4 असत्य, O वाली ओर का भाग न रंगें, दूसरी ओर रंगें।
Q20. निरपेक्ष असमिका में बिंदुकित रेखा क्यों?
रेखा पर बिंदु < या > को संतुष्ट नहीं करते, अतः सीमा शामिल नहीं।
Q21. MCQ: −2x < 4 का हल? (a)x<−2 (b)x>−2 (c)x<2 (d)x>2
(b) x > −2 (चिह्न उलटा)।
Q22. MCQ: −1 < x ≤ 3 का अंतराल? (a)[−1,3] (b)(−1,3] (c)(−1,3) (d)[−1,3)
(b) (−1, 3]।
Q23. MCQ: x ≥ 4 के लिए कौन सा वृत्त? (a)खाली (b)भरा (c)कोई नहीं (d)आधा
(b) भरा।
Q24. MCQ: सामान्यतः परीक्षण बिंदु? (a)(1,1) (b)(0,0) (c)(2,2) (d)(3,0)
(b) (0, 0), यदि वह रेखा पर न हो।
