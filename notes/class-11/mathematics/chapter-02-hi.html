कक्षा 11 गणित - अध्याय 2: संबंध एवं फलन

भाग A: संबंध (Relations)

1. क्रमित युग्म

वह युग्म (a, b) जिसमें क्रम महत्त्वपूर्ण हो, क्रमित युग्म कहलाता है; a प्रथम और b द्वितीय घटक है। (a,b) = (c,d) तभी जब a = c और b = d। अतः (2,3) ≠ (3,2); (a,b) = (b,a) केवल तब जब a = b।

2. कार्तीय गुणन

A × B = {(a,b) : a ∈ A, b ∈ B}। उदा. A={1,2}, B={x,y}: A×B = {(1,x),(1,y),(2,x),(2,y)}।

यदि n(A)=p, n(B)=q तो n(A×B) = pq। A × A में p² अवयव। A × B ≠ B × A (जब तक A = B न हो)। A × ∅ = ∅। R × R = पूरा निर्देशांक तल।

3. संबंध

A से B में संबंध R, A × B का कोई भी उपसमुच्चय है। यदि (a,b) ∈ R तो a R b लिखते हैं; b, a का प्रतिबिंब (image) है।

प्रांत (Domain) = सभी प्रथम घटकों का समुच्चय। सहप्रांत (Co-domain) = समुच्चय B। परिसर (Range) = सभी द्वितीय घटकों का समुच्चय (परिसर ⊆ सहप्रांत)। यदि n(A)=p, n(B)=q तो कुल संबंध = 2pq।

निरूपण

रोस्टर: R = {(1,2),(2,4),(3,6)}। समुच्चय-निर्माण: R = {(x,y) : y = 2x, x ∈ A}। चित्रीय (तीर आरेख): A और B को अंडाकार बनाकर प्रत्येक युग्म के लिए तीर खींचें।

R = {(1,2),(2,4),(3,6)}; 8 is not related

यहाँ प्रांत = {1,2,3}, सहप्रांत = {2,4,6,8}, परिसर = {2,4,6}।

भाग B: फलन (Functions)

4. परिभाषा

A से B में संबंध f फलन है यदि A के प्रत्येक अवयव का B में ठीक एक प्रतिबिंब हो। f : A → B, y = f(x)। फलन एक विशेष संबंध है: A का कोई अवयव छूटता नहीं और किसी के दो प्रतिबिंब नहीं होते।

Function: one arrow from each x
NOT a function: 1 has two arrows, 3 has none
प्रांत = निवेश (input) का समुच्चय (पूरा A)। सहप्रांत = B। परिसर = वास्तविक निर्गत का समुच्चय ⊆ B। वास्तविक मान फलन: परिसर ⊆ R। ऊर्ध्वाधर रेखा परीक्षण: यदि प्रत्येक ऊर्ध्वाधर रेखा ग्राफ को अधिकतम एक बार काटे तो वह फलन है।

5. फलनों के प्रकार

अचर फलन: f(x) = c। प्रांत R, परिसर {c}। ग्राफ: क्षैतिज रेखा।

f(x)=3 (constant), range {3}

तत्समक फलन: f(x) = x। प्रांत R, परिसर R। ग्राफ: मूलबिंदु से 45° पर रेखा।

f(x)=x (identity), line at 45°

बहुपद फलन: f(x) = a₀ + a₁x + … + aₙxⁿ (n पूर्ण संख्या)। प्रांत R। उदा. x² − 3x + 2।
परिमेय फलन: f(x) = p(x)/q(x), q(x) ≠ 0। उदा. 1/(x−2): प्रांत R − {2}।

मापांक फलन: f(x) = |x| = x यदि x ≥ 0, −x यदि x < 0। प्रांत R, परिसर [0,∞)।

f(x)=|x|, range [0,∞)

चिह्न (Signum) फलन: f(x) = 1 (x>0), 0 (x=0), −1 (x<0)। प्रांत R, परिसर {−1,0,1}।

signum: −1, 0, 1

महत्तम पूर्णांक फलन: f(x) = [x] = x से छोटा या बराबर सबसे बड़ा पूर्णांक। [2.7]=2, [−1.3]=−2। प्रांत R, परिसर Z।

f(x)=[x] steps; ● included, ○ not

चरघातांकी फलन: f(x) = aˣ (a>0, a≠1)। प्रांत R, परिसर (0,∞)।

f(x)=2ˣ, passes (0,1), y>0

लघुगणकीय फलन: f(x) = logₐx (a>0, a≠1)। प्रांत (0,∞), परिसर R। यह aˣ का प्रतिलोम है।

f(x)=log₂x, passes (1,0), x>0

6. फलनों का बीजगणित

(f+g)(x) = f(x)+g(x); (f−g)(x) = f(x)−g(x); (fg)(x) = f(x)·g(x); (f/g)(x) = f(x)/g(x), g(x) ≠ 0। प्रांत = Df ∩ Dg (f/g में g = 0 वाले बिंदु हटाएँ)।

हल किए गए उदाहरण (चरणबद्ध)

सरल A={1,2,3}, B={4,5}। A×B और n(A×B) ज्ञात कीजिए।
हल. A×B = {(1,4),(1,5),(2,4),(2,5),(3,4),(3,5)}; n = 3×2 = 6।
सरल यदि (x+1, 3) = (2, y−2) तो x, y ज्ञात कीजिए।
हल. x+1 = 2 ⇒ x = 1; y−2 = 3 ⇒ y = 5।
मध्यम R = {(x,y) : x+y = 5, x,y ∈ N} को रोस्टर रूप में लिखिए, प्रांत व परिसर ज्ञात कीजिए।
हल. x=1,y=4; 2,3; 3,2; 4,1। R = {(1,4),(2,3),(3,2),(4,1)}। प्रांत = {1,2,3,4}, परिसर = {1,2,3,4}।
मध्यम f(x) = √(x−2)/(x−5) का प्रांत ज्ञात कीजिए।
हल. x−2 ≥ 0 ⇒ x ≥ 2 और x−5 ≠ 0 ⇒ x ≠ 5। प्रांत = [2,∞) − {5}।
कठिन यदि n(A)=3, n(B)=2 तो A से B में कितने संबंध हैं? कितने फलन हैं?
हल. n(A×B) = 6, संबंध = 2⁶ = 64। फलन में 3 अवयवों में प्रत्येक के 2 में से एक प्रतिबिंब: 2×2×2 = 8 फलन।
कठिन f(x) = x², g(x) = 2x+1। (f+g)(x), (fg)(x), (f/g)(x) प्रांत सहित ज्ञात कीजिए।
हल. (f+g) = x²+2x+1; (fg) = x²(2x+1) = 2x³+x²; (f/g) = x²/(2x+1)। f, g का प्रांत R है; f/g के लिए 2x+1 = 0 हटाएँ, अतः x ≠ −1/2।

प्रश्न-उत्तर (खोलने के लिए टैप करें)

Q1. क्रमित युग्म क्या है?
ऐसा युग्म (a,b) जिसमें क्रम महत्त्वपूर्ण है; (a,b) = (b,a) केवल तब जब a = b।
Q2. A={1,2}, B={3}। A×B और B×A ज्ञात कीजिए।
A×B={(1,3),(2,3)}; B×A={(3,1),(3,2)}। दोनों भिन्न हैं।
Q3. n(A)=4, n(B)=5 हो तो n(A×B) ज्ञात कीजिए।
4×5 = 20।
Q4. यदि (x,2)=(5,2) तो x ज्ञात कीजिए।
x = 5।
Q5. संबंध, प्रांत, परिसर की परिभाषा दीजिए।
संबंध: A×B का उपसमुच्चय। प्रांत: प्रथम घटक। परिसर: द्वितीय घटक।
Q6. A={1,2,3}, R={(x,y): y=x+1} लिखिए।
R = {(1,2),(2,3)} यदि B में 2,3 हों; (3,4) के लिए 4 ∈ B चाहिए।
Q7. 2 अवयव वाले समुच्चय से 3 अवयव वाले समुच्चय में कितने संबंध?
2^(2×3) = 64।
Q8. क्या प्रत्येक संबंध फलन है?
नहीं। फलन में प्रांत के प्रत्येक अवयव का ठीक एक प्रतिबिंब होना चाहिए।
Q9. क्या {(1,2),(1,3)} फलन है?
नहीं, 1 के दो प्रतिबिंब हैं।
Q10. 1/(x−3) का प्रांत ज्ञात कीजिए।
R − {3}।
Q11. √(4−x) का प्रांत ज्ञात कीजिए।
4−x ≥ 0 ⇒ x ≤ 4, अतः (−∞,4]।
Q12. f(x)=x², x∈R का परिसर ज्ञात कीजिए।
[0,∞)।
Q13. [3.9], [−0.5], [5] ज्ञात कीजिए।
3, −1, 5।
Q14. |−7| और sgn(−7) ज्ञात कीजिए।
7 और −1।
Q15. log x का प्रांत व परिसर लिखिए।
प्रांत (0,∞), परिसर R।
Q16. f(x)=2ˣ का परिसर?
(0,∞), क्योंकि 2ˣ सदैव धनात्मक है।
Q17. f(x)=x+1, g(x)=2x। (f+g)(3) और (fg)(3) ज्ञात कीजिए।
f(3)=4, g(3)=6: योग 10, गुणनफल 24।
Q18. f(x)=x²−3x+1 हो तो f(2) ज्ञात कीजिए।
4−6+1 = −1।
Q19. सिद्ध कीजिए: यदि A⊆B तो A×C ⊆ B×C।
(a,c)∈A×C लें: a∈A⊆B अतः a∈B, c∈C ⇒ (a,c)∈B×C। इति सिद्धम्।
