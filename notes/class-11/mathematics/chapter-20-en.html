Class 11 Maths - Chapter 4: Sine and Cosine Formulae

0. Notation

In triangle ABC, sides opposite to angles A, B, C are a, b, c. Semi-perimeter s = (a+b+c)/2, area = Δ, circumradius = R.

Triangle ABC with sides a, b, c

1. Sine Rule

a/sin A = b/sin B = c/sin C = 2R

Proof. Draw the circumcircle (centre O, radius R) of triangle ABC. Draw diameter BD and join CD. Angle BCD = 90° (angle in a semicircle) and angle BDC = A (same arc BC). In right triangle BCD, sin A = BC/BD = a/2R. So a/sin A = 2R. In the same way b/sin B = c/sin C = 2R.

Circumcircle: a/sin A = b/sin B = c/sin C = 2R

Useful forms: a = 2R sin A, b = 2R sin B, c = 2R sin C; also a : b : c = sin A : sin B : sin C.

2. Cosine Rule

a² = b² + c² − 2bc cos A
b² = c² + a² − 2ca cos B
c² = a² + b² − 2ab cos C
cos A = (b² + c² − a²)/(2bc), cos B = (c² + a² − b²)/(2ca), cos C = (a² + b² − c²)/(2ab)
Cosine rule: c² = a² + b² − 2ab cos C

Proof (coordinates). Put C at origin, B = (a, 0), A = (b cos C, b sin C). Then c² = AB² = (b cos C − a)² + (b sin C)² = b²cos²C − 2ab cos C + a² + b²sin²C = a² + b² − 2ab cos C.

Nature of triangle: if a² > b² + c² angle A is obtuse; if a² = b² + c², A = 90° (Pythagoras); if a² < b² + c², A is acute.

3. Projection Formula

a = b cos C + c cos B
b = c cos A + a cos C
c = a cos B + b cos A
CD ⟂ AB: c = b cos A + a cos B (projection)

Proof. Draw CD ⟂ AB. AD = b cos A and DB = a cos B. So AB = AD + DB gives c = b cos A + a cos B. (If D falls outside, the cosine becomes negative and the formula still holds.)

4. Area of a Triangle

Δ = ½ ab sin C = ½ bc sin A = ½ ca sin B
Δ = abc/(4R)
Heron: Δ = √[s(s−a)(s−b)(s−c)]
Area = ½ × base × height = ½ c h = ½ bc sin A

Reason: height h = b sin A, so Δ = ½ × c × h = ½ bc sin A. Using a = 2R sin A: Δ = ½ bc (a/2R) = abc/4R.

5. Applications

Sine rule is used when: two angles and one side are given (ASA, AAS), or two sides and an angle opposite one of them (SSA, ambiguous case, can give 0, 1 or 2 triangles).
Cosine rule is used when: two sides and the included angle (SAS) or all three sides (SSS) are given.
Heights and distances: make a triangle from the figure, mark known angles, and apply sine rule or cosine rule.

Solved Examples (step by step)

Easy In ABC, a = 10, A = 30°, B = 45°. Find b.
Sol. b/sin B = a/sin A ⇒ b = 10 × sin45°/sin30° = 10 × (1/√2)/(1/2) = 10√2.
Easy Find the area if a = 6, b = 8, C = 30°.
Sol. Δ = ½ ab sin C = ½ × 6 × 8 × ½ = 12 square units.
Medium Sides of a triangle are 3, 5, 7. Find its largest angle.
Sol. The largest angle is opposite 7. cos C = (3² + 5² − 7²)/(2×3×5) = (9 + 25 − 49)/30 = −15/30 = −1/2. So C = 120°.
Medium In ABC, a = 2, b = 2, C = 90°. Find c and A.
Sol. c² = 4 + 4 − 0 = 8 ⇒ c = 2√2. a = b so A = B = 45°.
Hard Prove a(b cos C − c cos B) = b² − c².
Proof. ab cos C = (a² + b² − c²)/2 and ac cos B = (a² + c² − b²)/2. Subtract: (2b² − 2c²)/2 = b² − c². Hence proved.
Hard Prove (b² − c²)/a² = sin(B−C)/sin(B+C).
Proof. By sine rule b = 2R sin B, c = 2R sin C, a = 2R sin A. So (b²−c²)/a² = (sin²B − sin²C)/sin²A. Now sin²B − sin²C = (sin B + sin C)(sin B − sin C) = 2 sin((B+C)/2)cos((B−C)/2) × 2 cos((B+C)/2) sin((B−C)/2) = sin(B+C) sin(B−C). Since A = 180° − (B+C), sin A = sin(B+C). So result = sin(B+C) sin(B−C)/sin²(B+C) = sin(B−C)/sin(B+C).

Questions & Answers (tap to open)

Q1. State the sine rule.
a/sin A = b/sin B = c/sin C = 2R.
Q2. State the cosine rule.
a² = b² + c² − 2bc cos A (and similarly for b, c).
Q3. State the projection formula.
a = b cos C + c cos B (and cyclic).
Q4. Write the area formula using two sides and the included angle.
Δ = ½ ab sin C.
Q5. In ABC, A = 60°, B = 45°, a = 6. Find b.
b = a sin B/sin A = 6 × (1/√2)/(√3/2) = 6√2/√3 = 2√6.
Q6. Find c if a = 5, b = 7, C = 60°.
c² = 25 + 49 − 2×5×7×½ = 39, so c = √39.
Q7. Find angle A if a = 7, b = 8, c = 9? (cos A)
cos A = (64+81−49)/(2×8×9) = 96/144 = 2/3.
Q8. Find the area if a = 5, b = 12, C = 90°.
½ × 5 × 12 = 30.
Q9. Is a triangle with sides 4, 5, 7 acute or obtuse?
7² = 49 > 16 + 25 = 41, so the largest angle is obtuse.
Q10. If a = 2R sin A, find sin A when a = 3, R = 3.
sin A = a/2R = 3/6 = 1/2.
Q11. Find the circumradius of a triangle with a = 6, A = 30°.
2R = a/sin A = 12, so R = 6.
Q12. In ABC, if A = 90°, deduce Pythagoras from cosine rule.
cos 90° = 0, so a² = b² + c².
Q13. Show a : b : c = sin A : sin B : sin C.
Since a = 2R sin A, b = 2R sin B, c = 2R sin C, dividing by 2R gives the ratio.
Q14. In an equilateral triangle of side 2, find area using ½ ab sin C.
½ × 2 × 2 × sin60° = √3.
Q15. Find the angles if a = 1, b = 1, c = √2.
cos C = (1+1−2)/2 = 0, so C = 90°, A = B = 45°.
Q16. Prove a = b cos C + c cos B.
Draw AD ⟂ BC: BD = c cos B, DC = b cos C, a = BD + DC.
Q17. Prove (a² + b² − c²) = 2ab cos C.
This is the cosine rule c² = a² + b² − 2ab cos C rearranged.
Q18. Prove a sin(B − C) + b sin(C − A) + c sin(A − B) = 0.
Put a = 2R sin A etc. Using sin(B−C) sin(B+C) = sin²B − sin²C, the sum becomes 2R × [(sin²B − sin²C) + (sin²C − sin²A) + (sin²A − sin²B)] = 0.
Q19. Prove Δ = abc/4R.
Δ = ½ bc sin A and sin A = a/2R, so Δ = abc/4R.
Q20. MCQ: If a² + b² = c², angle C = ? (a)30° (b)60° (c)90° (d)120°
(c) 90°.
Q21. MCQ: Δ = ? (a)½ ab cos C (b)½ ab sin C (c)ab sin C (d)½ a sin C
(b).
Q22. MCQ: a/sin A = ? (a)R (b)2R (c)R/2 (d)4R
(b) 2R.
