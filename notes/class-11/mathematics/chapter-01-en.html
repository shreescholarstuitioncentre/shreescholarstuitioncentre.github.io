Class 11 Maths - Chapter 1: Sets

1. Set and its Representation

A set is a well-defined collection of distinct objects. Objects are called elements; x ∈ A means "x belongs to A", x ∉ A means "does not belong". Sets are named with capital letters: A, B, C.

Well-defined = we can say clearly whether an object is in the set or not. "Good students of class" is NOT a set; "vowels of English" IS a set.

Representation

Roster (Tabular) form: list elements in { } separated by commas, no repetition. A = {a, e, i, o, u}.
Set-builder form: A = {x : x is a vowel}. Example: B = {x : x ∈ N, x < 5} = {1,2,3,4}.

Standard sets: N = natural, W = whole, Z = integers, Q = rational, R = real numbers.

2. Types of Sets

Empty (Null) set: no element, written ∅ or { }. Eg. {x : x ∈ N, 1 < x < 2} = ∅. Note: {0} and {∅} are NOT empty.

Finite set: number of elements is countable; n(A) = number of elements. Infinite set: elements never end, eg. N, Z, R. (∅ is finite, n(∅)=0.)

Equal sets: A = B if both have exactly the same elements; order/repetition do not matter. {1,2,3} = {3,1,2,2}.

3. Subsets

A ⊆ B if every element of A is in B. Every set is a subset of itself, and ∅ ⊆ A for every A. If A ⊆ B and A ≠ B then A is a proper subset (A ⊂ B). If A ⊆ B and B ⊆ A then A = B.

N ⊂ W ⊂ Z ⊂ Q ⊂ R. A set with n elements has 2n subsets and 2n − 1 proper subsets.

4. Intervals (Subsets of R)

Open (a,b) = {x : a < x < b}. Closed [a,b] = {x : a ≤ x ≤ b}. Semi-open [a,b) or (a,b]. Length of each interval = b − a. Round bracket = end not included (empty dot); square bracket = included (filled dot).

5. Power Set

P(A) = set of all subsets of A. n(P(A)) = 2n. Eg. A = {1,2}: P(A) = {∅, {1}, {2}, {1,2}} (4 = 2² elements).

6. Universal Set and Venn Diagrams

The universal set U is the big set that contains all sets under discussion. In a Venn diagram U is a rectangle and sets are circles inside. (Watch the animation draw each diagram; pink = required region.)

7. Operations on Sets

Union: A ∪ B = {x : x ∈ A or x ∈ B}. Intersection: A ∩ B = {x : x ∈ A and x ∈ B}; if A ∩ B = ∅ the sets are disjoint.

A ∩ B (Intersection)

Difference: A − B = {x : x ∈ A and x ∉ B}. Complement: A′ = U − A = {x : x ∈ U, x ∉ A}.

A′ (Complement)
Key laws: A ∪ A′ = U, A ∩ A′ = ∅, (A′)′ = A, ∅′ = U, U′ = ∅.
De Morgan: (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′.
n(A ∪ B) = n(A) + n(B) − n(A ∩ B).
Distributive: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C).

Solved Examples (step by step)

Easy Write A = {x : x ∈ N, x² < 30} in roster form.
Sol. 1²=1, 2²=4, 3²=9, 4²=16, 5²=25 < 30; 6²=36 > 30. So A = {1,2,3,4,5}.
Easy A = {1,2,3}, B = {3,4}. Find A ∪ B, A ∩ B, A − B.
Sol. A ∪ B = {1,2,3,4}; A ∩ B = {3}; A − B = {1,2}.
Medium Find all subsets of {a,b,c}.
Sol. n = 3, so 2³ = 8 subsets: ∅, {a}, {b}, {c}, {a,b}, {b,c}, {a,c}, {a,b,c}.
Medium Prove A − B = A ∩ B′.
Proof. x ∈ A − B ⇔ x ∈ A and x ∉ B ⇔ x ∈ A and x ∈ B′ ⇔ x ∈ A ∩ B′. Hence proved.
Hard In a class of 60, 40 like tea, 30 like coffee, 15 like both. How many like neither?
Sol. n(T ∪ C) = 40 + 30 − 15 = 55. Neither = 60 − 55 = 5.
Hard Prove (A ∪ B)′ = A′ ∩ B′.
Proof. x ∈ (A ∪ B)′ ⇔ x ∉ A ∪ B ⇔ x ∉ A and x ∉ B ⇔ x ∈ A′ and x ∈ B′ ⇔ x ∈ A′ ∩ B′. Hence proved.

Questions & Answers (tap to open)

Q1. Define a set. Give an example.
A well-defined collection of distinct objects, eg. the set of vowels {a,e,i,o,u}.
Q2. Write {x : x is a prime less than 12} in roster form.
{2,3,5,7,11}.
Q3. Is {x : x is a tall boy} a set?
No, 'tall' is not well-defined.
Q4. Is {0} an empty set?
No, it has one element 0.
Q5. Write the set of letters of the word MATHEMATICS.
{M,A,T,H,E,I,C,S} (repeats not written).
Q6. Are A = {1,2,3} and B = {x : x ∈ N, x < 4} equal?
B = {1,2,3} = A, so yes.
Q7. How many subsets does {1,2,3,4} have?
2⁴ = 16 subsets; 15 proper subsets.
Q8. Write the interval notation of −2 < x ≤ 5.
(−2, 5].
Q9. Write the power set of {a,b,c}. How many elements?
8 elements: ∅,{a},{b},{c},{a,b},{b,c},{a,c},{a,b,c}.
Q10. If n(A)=20, n(B)=15, n(A ∩ B)=5, find n(A ∪ B).
20+15−5 = 30.
Q11. If U = {1..10}, A = {2,4,6,8}, find A′.
{1,3,5,7,9,10}.
Q12. Find A − B if A = {1,2,3,4}, B = {3,4,5}.
{1,2}.
Q13. Is ∅ a subset of every set?
Yes, ∅ has no element that could fail to be in A.
Q14. Is A ⊂ A?
No (proper subset needs A ≠ A), but A ⊆ A is true.
Q15. Find (A′)′.
A, because complement of complement returns the set.
Q16. Prove A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C).
Take x ∈ A ∩ (B ∪ C): x ∈ A and (x ∈ B or x ∈ C) ⇒ (x ∈ A and B) or (x ∈ A and C) ⇒ x ∈ RHS. Reverse steps give RHS ⊆ LHS, so equal.
Q17. In a group of 100, 60 read Hindi, 45 read English, 20 read both. How many read only Hindi?
Only Hindi = 60 − 20 = 40.
Q18. If A ⊆ B, show A ∪ B = B.
Every element of A is already in B, so union adds nothing new: A ∪ B = B.
Q19. MCQ: Number of elements in P(A) if n(A)=5? (a)10 (b)25 (c)32 (d)5
(c) 32 = 2⁵.
Q20. MCQ: Which is an infinite set? (a){x:x∈N, x<5} (b)∅ (c)Z (d){0}
(c) Z.
Q21. MCQ: A ∩ A′ = ? (a)U (b)A (c)∅ (d)A′
(c) ∅.
Q22. MCQ: Length of interval [3,9) = ? (a)6 (b)12 (c)3 (d)9
(a) 6 = 9 − 3.
Q23. MCQ: (A ∩ B)′ = ? (a)A′ ∩ B′ (b)A′ ∪ B′ (c)A ∪ B (d)U
(b) A′ ∪ B′ (De Morgan).
Q24. MCQ: Number of proper subsets of a 4-element set? (a)16 (b)15 (c)14 (d)8
(b) 15.
Q25. MCQ: Which is a null set? (a){0} (b){∅} (c){x:x∈N, x<1} (d){1}
(c); no natural number is less than 1.
