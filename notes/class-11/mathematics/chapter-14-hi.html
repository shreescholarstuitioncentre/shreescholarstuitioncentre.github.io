शांकव – अतिपरवलय

कक्षा 11 • अध्याय 15 • हस्तलिखित शैली नोट्स
NCERT पर आधारित; अवतार, राजीव, विद्या व सुमित्रा अरोड़ा (यूपी बोर्ड) शैली का अभ्यास।

1. परिभाषा

अतिपरवलय उस बिंदु P का बिंदुपथ है जो इस प्रकार चलता है कि दो निश्चित बिंदुओं (नाभियों F₁, F₂) से उसकी दूरियों का अंतर अचर रहे: |PF₁ − PF₂| = 2a, जहाँ 2a < F₁F₂ = 2c।

यह e > 1 वाला शांकव है, जो द्विशंकु को उसकी अक्ष के समांतर तल से काटने पर मिलता है। इसकी दो अलग शाखाएँ होती हैं।

2. पद: नाभियाँ, अनुप्रस्थ व संयुग्मी अक्ष

नाभियाँ: (±c, 0)। केंद्र C: F₁F₂ का मध्य-बिंदु। शीर्ष: A, A′ = (±a, 0)।

अनुप्रस्थ अक्ष: नाभियों से जाने वाला रेखाखंड A′A, लंबाई 2a।

संयुग्मी अक्ष: केंद्र से जाने वाला अनुप्रस्थ अक्ष पर लंब रेखाखंड B′B, लंबाई 2b, B, B′ = (0, ±b) (ये बिंदु वक्र पर नहीं होते)।

सहायक आयत: भुजाएँ x = ±a, y = ±b; इसके विकर्ण अनंतस्पर्शी हैं। नियताएँ: x = ±a/e।

3. मानक समीकरण (व्युत्पत्ति)

F₁(−c, 0), F₂(c, 0), |PF₁ − PF₂| = 2a लें (चित्र देखें):

√[(x+c)² + y²] − √[(x−c)² + y²] = ±2a

दो बार वर्ग कर सरल करें: (c² − a²)x² − a²y² = a²(c² − a²)

b² = c² − a² रखें (अतः c² = a² + b², दीर्घवृत्त से भिन्न) और a²b² से भाग दें:

x²/a² − y²/b² = 1

4. अनंतस्पर्शी

अनंतस्पर्शी वे रेखाएँ हैं जिनके वक्र x → ∞ पर निकट आता है पर कभी मिलता नहीं। x²/a² − y²/b² = 1 के लिए:

y = ± (b/a) x    (अर्थात् x²/a² − y²/b² = 0)

y²/a² − x²/b² = 1 के लिए: y = ± (a/b) x। ये सहायक आयत के विकर्ण हैं।

आयताकार अतिपरवलय: a = b, अनंतस्पर्शी लंबवत, समीकरण x² − y² = a², e = √2।

5. उत्केंद्रता एवं नाभिलंब

e = c/a > 1

b² = c² − a² ⟹ b² = a²(e² − 1)। नाभियाँ (±ae, 0)।

नाभिलंब = 2b²/a, सिरे (±c, ±b²/a)।

दाईं शाखा पर P(x₁, y₁) की नाभीय दूरियाँ: PF₁ = ex₁ + a, PF₂ = ex₁ − a; अंतर 2a।

6. दो मानक रूप

x²/a² − y²/b² = 1y²/a² − x²/b² = 1
अनुप्रस्थ अक्षx-अक्ष, 2ay-अक्ष, 2a
संयुग्मी अक्षy-अक्ष, 2bx-अक्ष, 2b
शीर्ष(±a, 0)(0, ±a)
नाभियाँ(±c, 0)(0, ±c)
अनंतस्पर्शीy = ±(b/a)xy = ±(a/b)x
नियताएँx = ±a/ey = ±a/e
नाभिलंब2b²/a2b²/a

सुझाव: जिस चर के आगे धनात्मक चिह्न हो, वही अनुप्रस्थ अक्ष की दिशा है।

7. गुणधर्म

दोनों अक्षों के सापेक्ष सममित; x = −a और x = a के बीच वक्र का कोई भाग नहीं।

प्राचलिक रूप: (a sec θ, b tan θ)। सहायक वृत्त: x² + y² = a²।

x²/a² − y²/b² = 1 का संयुग्मी अतिपरवलय −x²/a² + y²/b² = 1; दोनों के अनंतस्पर्शी समान।

बिंदु (x₁, y₁): x₁²/a² − y₁²/b² − 1 > 0 अंदर (शाखा के), < 0 बाहर।

वास्तविक जीवन: कूलिंग टावर, LORAN नेविगेशन, सोनिक बूम, टेलीस्कोप दर्पण।

8. हल किए गए उदाहरण (सरल → कठिन)

उदाहरण 1 सरल x²/16 − y²/9 = 1 की नाभियाँ, शीर्ष, अक्ष, e, नाभिलंब और अनंतस्पर्शी ज्ञात कीजिए।
  1. चरण 1: a² = 16 → a = 4; b² = 9 → b = 3
  2. चरण 2: c = √(a²+b²) = √25 = 5 → नाभियाँ (±5, 0); शीर्ष (±4, 0)
  3. चरण 3: अनुप्रस्थ अक्ष 2a = 8, संयुग्मी अक्ष 2b = 6; e = c/a = 5/4
  4. चरण 4: नाभिलंब = 2b²/a = 18/4 = 9/2; अनंतस्पर्शी y = ±(3/4)x
उदाहरण 2 सरल 16x² − 9y² = 144 की नाभियाँ और e ज्ञात कीजिए।
  1. चरण 1: 144 से भाग: x²/9 − y²/16 = 1
  2. चरण 2: a = 3, b = 4, c = √(9+16) = 5
  3. चरण 3: नाभियाँ (±5, 0)
  4. चरण 4: e = 5/3
उदाहरण 3 सरल y²/16 − x²/9 = 1 की नाभियाँ, शीर्ष, e और अनंतस्पर्शी ज्ञात कीजिए।
  1. चरण 1: धनात्मक पद y² → अनुप्रस्थ अक्ष y पर: a² = 16, b² = 9
  2. चरण 2: c = √25 = 5 → नाभियाँ (0, ±5); शीर्ष (0, ±4)
  3. चरण 3: e = 5/4
  4. चरण 4: अनंतस्पर्शी y = ±(a/b)x = ±(4/3)x
उदाहरण 4 मध्यम शीर्ष (±2, 0) और नाभियाँ (±3, 0) वाला अतिपरवलय ज्ञात कीजिए।
  1. चरण 1: a = 2, c = 3
  2. चरण 2: b² = c² − a² = 9 − 4 = 5
  3. चरण 3: x²/4 − y²/5 = 1
उदाहरण 5 मध्यम नाभियाँ (0, ±√10) वाला वह अतिपरवलय ज्ञात कीजिए जो (2, 3) से जाता है।
  1. चरण 1: नाभियाँ y-अक्ष पर: y²/a² − x²/b² = 1, a² + b² = 10
  2. चरण 2: (2,3): 9/a² − 4/b² = 1; b² = 10 − a² → a⁴ − 23a² + 90 = 0
  3. चरण 3: a² = 5 या 18; a² = 18 से b² < 0 ✘ → a² = 5, b² = 5
  4. चरण 4: y²/5 − x²/5 = 1, अर्थात् y² − x² = 5 (जाँच: 9 − 4 = 5 ✔)
उदाहरण 6 मध्यम आयताकार अतिपरवलय x² − y² = a² की e और नाभियाँ ज्ञात कीजिए।
  1. चरण 1: x²/a² − y²/a² = 1 → b = a
  2. चरण 2: c² = a² + b² = 2a² → c = a√2
  3. चरण 3: e = c/a = √2
  4. चरण 4: नाभियाँ (±a√2, 0)
उदाहरण 7 कठिन सिद्ध कीजिए कि x²/a² − y²/b² = 1 का नाभिलंब 2b²/a है और b² = a²(e² − 1)।
  1. चरण 1: b² = c² − a² = a²e² − a² = a²(e² − 1) ✔
  2. चरण 2: नाभिलंब (c, 0) से: c²/a² − y²/b² = 1
  3. चरण 3: y² = b²(c²/a² − 1) = b²·b²/a² → y = ±b²/a
  4. चरण 4: लंबाई = 2b²/a ∎
उदाहरण 8 कठिन सिद्ध कीजिए कि दाईं शाखा पर P(x₁, y₁) के लिए PF₁ − PF₂ = 2a।
  1. चरण 1: PF₁² = (x₁+c)² + y₁², y₁² = b²(x₁²/a² − 1)
  2. चरण 2: = x₁²(1 + b²/a²) + 2cx₁ + c² − b² = e²x₁² + 2aex₁ + a²
  3. चरण 3: = (ex₁ + a)²; इसी प्रकार PF₂² = (ex₁ − a)² (ex₁ > a)
  4. चरण 4: PF₁ − PF₂ = (ex₁ + a) − (ex₁ − a) = 2a ∎
उदाहरण 9 कठिन दर्शाइए कि y = ±(b/a)x, x²/a² − y²/b² = 1 के अनंतस्पर्शी हैं।
  1. चरण 1: बड़े x के लिए: y = (b/a)√(x² − a²) = (b/a) x √(1 − a²/x²)
  2. चरण 2: ≈ (b/a) x (1 − a²/2x²) = (b/a)x − ab/(2x)
  3. चरण 3: रेखा y = (b/a)x से अंतर −ab/(2x) → 0 जब x → ∞
  4. चरण 4: अतः वक्र y = (b/a)x (इसी प्रकार y = −(b/a)x) के निकट आता है ∎
उदाहरण 10 कठिन उस अतिपरवलय की e ज्ञात कीजिए जिसके अनंतस्पर्शी y = ±(4/3)x हैं (अनुप्रस्थ अक्ष x पर)।
  1. चरण 1: b/a = 4/3
  2. चरण 2: e² = 1 + b²/a² = 1 + 16/9 = 25/9
  3. चरण 3: e = 5/3
  4. चरण 4: (जैसे a = 3, b = 4, c = 5)

9. लघु प्रश्नोत्तर

प्र.1. अतिपरवलय को परिभाषित कीजिए।

उ. वह बिंदुपथ जिसकी दो निश्चित बिंदुओं (नाभियों) से दूरियों का अंतर अचर 2a (< नाभियों के बीच दूरी) हो; e > 1।

प्र.2. c, a, b का संबंध लिखिए।

उ. c² = a² + b² (दीर्घवृत्त में c² = a² − b²)।

प्र.3. x²/a² − y²/b² = 1 के अनंतस्पर्शी क्या हैं?

उ. y = ±(b/a)x।

प्र.4. आयताकार अतिपरवलय परिभाषित कीजिए।

उ. a = b वाला अतिपरवलय; अनंतस्पर्शी लंबवत; e = √2।

प्र.5. नाभिलंब लिखिए।

उ. 2b²/a।
