द्विपद प्रमेय

कक्षा 11 • अध्याय 8 • हस्तलिखित शैली नोट्स
NCERT पर आधारित; अवतार, राजीव, विद्या व सुमित्रा अरोड़ा (यूपी बोर्ड) शैली का अभ्यास।

1. इतिहास

  • पिंगल (भारत, लगभग 200 ई.पू.) ने इस त्रिभुज को मेरु प्रस्तार कहा; बाद में हलायुध ने इसे समझाया।
  • उमर खय्याम (फ़ारस) और यांग हुई (चीन) ने इसका उपयोग मूल व प्रसार में किया।
  • ब्लेज़ पास्कल (1654) ने इसका गहन अध्ययन किया, इसलिए यूरोप में यह पास्कल त्रिभुज कहलाता है।
  • आइज़क न्यूटन ने प्रमेय को भिन्नात्मक/ऋणात्मक घात तक बढ़ाया।

2. कथन

किसी भी प्राकृत संख्या n के लिए:

(a+b)ⁿ = nC0 aⁿ + nC1 aⁿ⁻¹b + nC2 aⁿ⁻²b² + … + nCn bⁿ

अर्थात् (a+b)ⁿ = Σ nCr aⁿ⁻ʳ bʳ, r = 0 से n तक।

3. उपपत्ति (आगमन विधि)

चरण 1 (n=1): (a+b)¹ = a+b = 1C0 a + 1C1 b ✔ सत्य।

चरण 2: मानें n = k के लिए सत्य: (a+b)ᵏ = Σ kCr aᵏ⁻ʳbʳ।

चरण 3: (a+b) से गुणा कर समान घातें इकट्ठी करें; aᵏ⁺¹⁻ʳ bʳ का गुणांक kCr + kC(r−1) आता है।

चरण 4: kCr + kC(r−1) = (k+1)Cr से (a+b)ᵏ⁺¹ = Σ (k+1)Cr aᵏ⁺¹⁻ʳ bʳ, अतः n = k+1 के लिए सत्य। आगमन से सभी n के लिए सत्य ∎

4. द्विपद का प्रसार

पदों की संख्या = n+1। a की घात n→0 घटती, b की 0→n बढ़ती है; प्रत्येक पद में घातों का योग = n।

दोनों सिरों से समान दूरी के गुणांक बराबर: nCr = nC(n−r)।

(a−b)ⁿ: चिह्न एकांतर (+ − + − …)।

(1+x)ⁿ = 1 + nx + n(n−1)/2!·x² + … + xⁿ

सभी गुणांकों का योग: a=b=1 रखने पर 2ⁿ। विषम स्थान योग = सम स्थान योग = 2ⁿ⁻¹।

5. पास्कल त्रिभुज

पंक्ति n, (a+b)ⁿ के गुणांक देती है। प्रत्येक संख्या = ठीक ऊपर की दो संख्याओं का योग (nCr = (n−1)C(r−1) + (n−1)Cr)। त्रिभुज को पंक्ति-दर-पंक्ति बनते देखें।

पंक्तियाँ: (a+b)² → 1 2 1; (a+b)³ → 1 3 3 1; (a+b)⁴ → 1 4 6 4 1; (a+b)⁵ → 1 5 10 10 5 1।

6. व्यापक पद एवं मध्य पद

T(r+1) = nCr aⁿ⁻ʳ bʳ

मध्य पद: n सम → एक पद T(n/2 + 1)। n विषम → दो पद T((n+1)/2) और T((n+3)/2)।

x से स्वतंत्र पद: व्यापक पद लिखें, x की घात = 0 रखें, r ज्ञात करें।

xᵏ का गुणांक: x की घात = k रखें, r निकालें, फिर गुणांक लें।

7. अनुप्रयोग

  • विशिष्ट पद, गुणांक, मध्य पद ज्ञात करना
  • (1.01)⁵, 99⁵, (√2+1)⁵+(√2−1)⁵ जैसे मान निकालना
  • विभाज्यता / शेषफल, जैसे 9ⁿ⁺¹ − 8n − 9, 64 से विभाज्य
  • ΣnCr = 2ⁿ जैसे सर्वसमिकाएँ सिद्ध करना

8. हल किए गए उदाहरण (सरल → कठिन)

उदाहरण 1 सरल (x+y)⁴ का प्रसार कीजिए।
  1. चरण 1: n=4, पास्कल की पंक्ति 4: 1 4 6 4 1
  2. चरण 2: x की घात 4→0 घटती, y की 0→4 बढ़ती
  3. चरण 3: = x⁴ + 4x³y + 6x²y² + 4xy³ + y⁴
उदाहरण 2 सरल (2+x)³ का प्रसार कीजिए।
  1. चरण 1: = 3C0·2³ + 3C1·2²·x + 3C2·2·x² + 3C3·x³
  2. चरण 2: = 8 + 3·4x + 3·2x² + x³
  3. चरण 3: = 8 + 12x + 6x² + x³
उदाहरण 3 सरल (x+2)⁷ का 5वाँ पद ज्ञात कीजिए।
  1. चरण 1: T(r+1) = 7Cr x⁷⁻ʳ 2ʳ; 5वाँ पद → r = 4
  2. चरण 2: T5 = 7C4 x³ 2⁴ = 35 × 16 x³
  3. चरण 3: = 560x³
उदाहरण 4 मध्यम (√2+1)⁵ + (√2−1)⁵ का मान ज्ञात कीजिए।
  1. चरण 1: विषम स्थान के पद दुगुने, सम स्थान के कट जाते हैं: = 2[5C0(√2)⁵ + 5C2(√2)³ + 5C4(√2)]
  2. चरण 2: (√2)⁵ = 4√2, 5C2(√2)³ = 10·2√2 = 20√2, 5C4√2 = 5√2
  3. चरण 3: = 2[4√2+20√2+5√2] = 2 × 29√2
  4. चरण 4: = 58√2
उदाहरण 5 मध्यम (x + 1/x)¹⁰ का मध्य पद ज्ञात कीजिए।
  1. चरण 1: n = 10 सम → मध्य पद T(6)
  2. चरण 2: T6 = 10C5 x⁵ (1/x)⁵ = 10C5 x⁰
  3. चरण 3: 10C5 = 252, अतः मध्य पद = 252
उदाहरण 6 मध्यम (x+3)⁸ में x⁵ का गुणांक ज्ञात कीजिए।
  1. चरण 1: T(r+1) = 8Cr x⁸⁻ʳ 3ʳ
  2. चरण 2: 8−r = 5 → r = 3
  3. चरण 3: गुणांक = 8C3 × 3³ = 56 × 27 = 1512
उदाहरण 7 कठिन (2x² − 1/x)⁹ में x से स्वतंत्र पद ज्ञात कीजिए।
  1. चरण 1: T(r+1) = 9Cr (2x²)⁹⁻ʳ (−1/x)ʳ = 9Cr 2⁹⁻ʳ (−1)ʳ x¹⁸⁻³ʳ
  2. चरण 2: x से स्वतंत्र → 18 − 3r = 0 → r = 6
  3. चरण 3: T7 = 9C6 · 2³ · (−1)⁶ = 84 × 8
  4. चरण 4: = 672
उदाहरण 8 कठिन सिद्ध कीजिए कि 9ⁿ⁺¹ − 8n − 9, 64 से विभाज्य है (n ∈ N)।
  1. चरण 1: 9ⁿ⁺¹ = (1+8)ⁿ⁺¹ = 1 + (n+1)·8 + (n+1)C2·8² + …
  2. चरण 2: = 1 + 8n + 8 + 64[(n+1)C2 + (n+1)C3·8 + …]
  3. चरण 3: अतः 9ⁿ⁺¹ − 8n − 9 = 64 × [पूर्णांक]
  4. चरण 4: अतः 64 से विभाज्य ∎
उदाहरण 9 कठिन सिद्ध कीजिए nC0 + nC1 + … + nCn = 2ⁿ।
  1. चरण 1: प्रमेय से (a+b)ⁿ = Σ nCr aⁿ⁻ʳbʳ
  2. चरण 2: a = 1, b = 1 रखें
  3. चरण 3: (1+1)ⁿ = nC0 + nC1 + … + nCn
  4. चरण 4: अतः योग = 2ⁿ ∎
उदाहरण 10 कठिन यदि (3+ax)⁹ में x² और x³ के गुणांक बराबर हों तो a ज्ञात कीजिए।
  1. चरण 1: T3 = 9C2 3⁷ (ax)² → गुणांक 9C2·3⁷·a²
  2. चरण 2: T4 = 9C3 3⁶ (ax)³ → गुणांक 9C3·3⁶·a³
  3. चरण 3: बराबर रखने पर: 36·3⁷a² = 84·3⁶a³ → 36·3 = 84a
  4. चरण 4: a = 108/84 = 9/7

9. लघु प्रश्नोत्तर

प्र.1. द्विपद प्रमेय लिखिए।

उ. प्राकृत n के लिए (a+b)ⁿ = Σ nCr aⁿ⁻ʳbʳ; इसमें n+1 पद होते हैं।

प्र.2. (a+b)ⁿ में कितने पद होते हैं?

उ. n+1 पद।

प्र.3. पास्कल त्रिभुज क्या है?

उ. त्रिभुजाकार सारणी जिसमें प्रत्येक संख्या ऊपर की दो संख्याओं का योग है; पंक्ति n, (a+b)ⁿ के गुणांक देती है।

प्र.4. व्यापक पद लिखिए।

उ. T(r+1) = nCr aⁿ⁻ʳ bʳ।

प्र.5. (1+x)ⁿ के गुणांकों का योग?

उ. x = 1 रखने पर 2ⁿ।
