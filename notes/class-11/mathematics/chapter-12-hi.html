शांकव – परवलय

कक्षा 11 • अध्याय 13 • हस्तलिखित शैली नोट्स
NCERT पर आधारित; अवतार, राजीव, विद्या व सुमित्रा अरोड़ा (यूपी बोर्ड) शैली का अभ्यास।

1. परिभाषा

परवलय उस बिंदु का बिंदुपथ है जो इस प्रकार चलता है कि एक निश्चित बिंदु (नाभि) से उसकी दूरी एक निश्चित रेखा (नियता) से उसकी दूरी के बराबर रहे, नाभि नियता पर न हो।

यह उत्केंद्रता e = 1 वाला शांकव है, जो शंकु को उसकी जनक रेखा के समांतर तल से काटने पर मिलता है।

2. नाभि, नियता, शीर्ष, अक्ष (पद)

नाभि F: निश्चित बिंदु। नियता: निश्चित रेखा।

अक्ष: नाभि से जाने वाली नियता पर लंब रेखा; परवलय इसके सापेक्ष सममित होता है।

शीर्ष V: वह बिंदु जहाँ अक्ष परवलय को काटता है (नाभि और नियता पर अक्ष के पाद का मध्य-बिंदु)।

नाभिलंब जीवा: नाभि से जाने वाली अक्ष पर लंब जीवा; लंबाई 4a। P की नाभीय दूरी = PF। द्विकोटि = अक्ष पर लंब जीवा।

3. मानक समीकरण (व्युत्पत्ति)

शीर्ष मूलबिंदु पर, नाभि F(a, 0), नियता x = −a (a > 0)। परवलय पर P(x, y) लें, PM नियता पर लंब। तब PF = PM (चित्र देखें):

√[(x−a)² + y²] = x + a

वर्ग करने पर: x² − 2ax + a² + y² = x² + 2ax + a²

y² = 4ax

4. चार मानक रूप

समीकरणखुलता हैनाभिनियताअक्षनाभिलंब
y² = 4axदाएँ(a, 0)x = −ay = 04a; सिरे (a, ±2a)
y² = −4axबाएँ(−a, 0)x = ay = 04a; सिरे (−a, ±2a)
x² = 4ayऊपर(0, a)y = −ax = 04a; सिरे (±2a, a)
x² = −4ayनीचे(0, −a)y = ax = 04a; सिरे (±2a, −a)

5. गुणधर्म

चारों का शीर्ष (0, 0) है। वक्र अपने अक्ष के सापेक्ष सममित है और अनंत तक जाता है।

y² = 4ax पर P(x₁, y₁) की नाभीय दूरी x₁ + a।

y² = 4ax का प्राचलिक रूप: (at², 2at)।

स्थानांतरित परवलय: (y − k)² = 4a(x − h): शीर्ष (h, k), नाभि (h + a, k), नियता x = h − a, अक्ष y = k।

y² = 4ax के सापेक्ष (x₁, y₁): y₁² − 4ax₁ > 0 बाहर, = 0 पर, < 0 अंदर।

वास्तविक जीवन: हेडलाइट, सैटेलाइट डिश (अक्ष के समांतर किरणें नाभि से गुज़रती हैं), पुल, प्रक्षेप्य का पथ।

6. हल किए गए उदाहरण (सरल → कठिन)

उदाहरण 1 सरल y² = 12x के लिए शीर्ष, नाभि, नियता और नाभिलंब ज्ञात कीजिए।
  1. चरण 1: y² = 4ax से तुलना: 4a = 12 → a = 3
  2. चरण 2: शीर्ष (0,0); नाभि (a,0) = (3,0)
  3. चरण 3: नियता x = −a = −3
  4. चरण 4: नाभिलंब = 4a = 12
उदाहरण 2 सरल x² = 8y के लिए नाभि, नियता और नाभिलंब ज्ञात कीजिए।
  1. चरण 1: x² = 4ay: 4a = 8 → a = 2
  2. चरण 2: नाभि (0, a) = (0, 2)
  3. चरण 3: नियता y = −2
  4. चरण 4: नाभिलंब = 8
उदाहरण 3 सरल y² = −16x की नाभि और नियता ज्ञात कीजिए।
  1. चरण 1: y² = −4ax: 4a = 16 → a = 4
  2. चरण 2: बाएँ खुलता है; नाभि (−a, 0) = (−4, 0)
  3. चरण 3: नियता x = a = 4
उदाहरण 4 मध्यम नाभि (3, 0) और नियता x = −3 वाला परवलय ज्ञात कीजिए।
  1. चरण 1: नाभि (a,0) = (3,0) → a = 3; नियता x = −3 ✔ (शीर्ष मूलबिंदु)
  2. चरण 2: अक्ष = x-अक्ष, दाएँ खुलता है: y² = 4ax
  3. चरण 3: y² = 12x
उदाहरण 5 मध्यम शीर्ष मूलबिंदु, अक्ष x-अक्ष और बिंदु (2, 3) से जाने वाला परवलय ज्ञात कीजिए।
  1. चरण 1: बिंदु प्रथम चतुर्थांश में → y² = 4ax
  2. चरण 2: (2,3) रखें: 9 = 4a·2 → a = 9/8
  3. चरण 3: y² = 4(9/8)x = (9/2)x
  4. चरण 4: 2y² = 9x
उदाहरण 6 मध्यम नाभि (0, −2) और नियता y = 2 वाला परवलय ज्ञात कीजिए।
  1. चरण 1: शीर्ष = नाभि व नियता पर पाद का मध्य-बिंदु = (0,0)
  2. चरण 2: नाभि शीर्ष के नीचे → नीचे खुलता है: x² = −4ay, a = 2
  3. चरण 3: x² = −8y
उदाहरण 7 कठिन नाभि (1, 1) और नियता x + y + 1 = 0 वाला परवलय ज्ञात कीजिए।
  1. चरण 1: PF² = (x−1)² + (y−1)²
  2. चरण 2: PM² = (x+y+1)²/2
  3. चरण 3: PF² = PM²: 2(x²+y²−2x−2y+2) = x²+y²+2xy+2x+2y+1
  4. चरण 4: x² + y² − 2xy − 6x − 6y + 3 = 0
उदाहरण 8 कठिन सिद्ध कीजिए कि y² = 4ax के नाभिलंब की लंबाई 4a है।
  1. चरण 1: नाभिलंब F(a,0) से जाता है, अक्ष पर लंब → रेखा x = a
  2. चरण 2: x = a रखें: y² = 4a·a = 4a² → y = ±2a
  3. चरण 3: सिरे (a, 2a), (a, −2a)
  4. चरण 4: लंबाई = 2a − (−2a) = 4a ∎
उदाहरण 9 कठिन सिद्ध कीजिए कि y² = 4ax पर P(x₁, y₁) की नाभीय दूरी x₁ + a है।
  1. चरण 1: नियता x = −a; PM नियता पर लंब
  2. चरण 2: PM = x₁ − (−a) = x₁ + a
  3. चरण 3: परिभाषा से PF = PM
  4. चरण 4: अतः PF = x₁ + a ∎
उदाहरण 10 कठिन y² = 8x पर वे बिंदु ज्ञात कीजिए जिनकी नाभीय दूरी 6 है।
  1. चरण 1: 4a = 8 → a = 2; नाभीय दूरी = x + a = 6
  2. चरण 2: x = 4
  3. चरण 3: y² = 8 × 4 = 32 → y = ±4√2
  4. चरण 4: बिंदु (4, 4√2) और (4, −4√2)

7. लघु प्रश्नोत्तर

प्र.1. परवलय को परिभाषित कीजिए।

उ. वह बिंदुपथ जो निश्चित बिंदु (नाभि) और निश्चित रेखा (नियता) से समदूरस्थ हो; उत्केंद्रता e = 1।

प्र.2. मानक समीकरण, नाभि और नियता लिखिए।

उ. y² = 4ax; नाभि (a, 0); नियता x = −a।

प्र.3. नाभिलंब जीवा क्या है?

उ. नाभि से जाने वाली अक्ष पर लंब जीवा; लंबाई 4a।

प्र.4. y² = 4ax का प्राचलिक रूप लिखिए।

उ. x = at², y = 2at।

प्र.5. y² = 4ax पर (x₁, y₁) की नाभीय दूरी?

उ. x₁ + a।

8. बहुविकल्पीय प्रश्न (उत्तर के लिए टैप करें)

1. परवलय की उत्केंद्रता

(a) 0 (b) <1 (c) 1 (d) >1

✔ (c) 1

2. y² = 4ax का नाभिलंब

(a) a (b) 2a (c) 4a (d) 8a

✔ (c) 4a

3. y² = 16x की नाभि

(a) (16,0) (b) (4,0) (c) (8,0) (d) (0,4)

✔ (b) (4, 0)

4. x² = 12y की नियता

(a) y = 3 (b) y = −3 (c) x = 3 (d) x = −3

✔ (b) y = −3

5. x² = 4ay का अक्ष

(a) x-अक्ष (b) y-अक्ष (c) y = a (d) x = a

✔ (b) y-अक्ष

6. (y−2)² = 8(x−1) का शीर्ष

(a) (2,1) (b) (1,2) (c) (0,0) (d) (−1,−2)

✔ (b) (1, 2)

7. y² = −8x खुलता है

(a) दाएँ (b) बाएँ (c) ऊपर (d) नीचे

✔ (b) बाएँ

8. y² = 4ax का प्राचलिक बिंदु

(a) (at, 2at) (b) (2at, at²) (c) (at², 2at) (d) (a, t)

✔ (c)
