Conic Section – Circle

Based on NCERT with practice in the style of Avtaar, Rajeev, Vidya & Sumitra Arora (UP Board).

1. Circle

A circle is the locus of a point that moves in a plane so that its distance from a fixed point (centre) is constant (radius).

It is a conic section: cutting a cone by a plane perpendicular to its axis gives a circle.

Terms: diameter = 2r (longest chord); chord joins 2 points; secant cuts at 2 points; tangent touches at 1 point; arc = part of the circle.

2. Standard Equation

Centre C(h, k), radius r. For any point P(x, y) on the circle, CP = r. By the distance formula (watch the diagram):

(x − h)² + (y − k)² = r²

Centre at origin:

x² + y² = r²

Diameter form: ends (x₁,y₁), (x₂,y₂): (x−x₁)(x−x₂) + (y−y₁)(y−y₂) = 0.

A circle is fixed by its centre and radius (or by three non-collinear points).

3. Centre & Radius (General Equation)

General form:

x² + y² + 2gx + 2fy + c = 0

Centre = (−g, −f), radius = √(g² + f² − c). (Complete the squares to get the standard form.)

g²+f²−c > 0 real circle; = 0 point circle; < 0 imaginary circle.

Second-degree equation is a circle if coefficients of x² and y² are equal and there is no xy term. If ax² + ay² + …, divide by a first.

4. Simple Properties

Position of P(x₁, y₁): S₁ = x₁² + y₁² + 2gx₁ + 2fy₁ + c; S₁ > 0 outside, = 0 on, < 0 inside the circle.

Perpendicular from the centre to a chord bisects the chord; the line from the centre to the midpoint of a chord is perpendicular to it.

Equal chords are equidistant from the centre. Angle in a semicircle = 90°.

Through 3 non-collinear points exactly one circle passes: put the points in x²+y²+2gx+2fy+c=0 and solve for g, f, c.

5. Tangent (Basic)

A tangent touches the circle at exactly one point (point of contact). Tangent ⟂ radius at the point of contact (see diagram). From an external point, 2 equal-length tangents can be drawn.

Tangent at (x₁, y₁) to x² + y² = r²:

x x₁ + y y₁ = r²

To x²+y²+2gx+2fy+c=0: x x₁ + y y₁ + g(x+x₁) + f(y+y₁) + c = 0.

Line y = mx + c touches x² + y² = r² if

c² = r²(1 + m²)

A line is tangent if (distance of centre from the line) = r. Length of tangent from (x₁, y₁) = √S₁.

6. Solved Examples (Easy → Hard)

Example 1 EASY Find the equation of the circle with centre (2, −3) and radius 5.
  1. Step 1: Use (x−h)² + (y−k)² = r²
  2. Step 2: h = 2, k = −3, r = 5
  3. Step 3: (x−2)² + (y+3)² = 25
Example 2 EASY Find the centre and radius of x² + y² − 6x + 4y − 12 = 0.
  1. Step 1: Compare with x²+y²+2gx+2fy+c = 0: 2g = −6, 2f = 4, c = −12
  2. Step 2: g = −3, f = 2 → centre (−g, −f) = (3, −2)
  3. Step 3: r = √(9 + 4 + 12) = √25 = 5
Example 3 EASY Write the equation of the circle with centre at the origin and radius 7.
  1. Step 1: Centre (0,0) → x² + y² = r²
  2. Step 2: r = 7
  3. Step 3: x² + y² = 49
Example 4 MEDIUM Find the circle with centre (1, 2) passing through (4, 6).
  1. Step 1: r = distance from (1,2) to (4,6) = √(9 + 16)
  2. Step 2: r = 5
  3. Step 3: (x−1)² + (y−2)² = 25
Example 5 MEDIUM Find the circle having (2, 3) and (−2, −1) as ends of a diameter.
  1. Step 1: Diameter form: (x−2)(x+2) + (y−3)(y+1) = 0
  2. Step 2: x² − 4 + y² − 2y − 3 = 0
  3. Step 3: x² + y² − 2y − 7 = 0
  4. Step 4: Check: centre (0,1), r = √8 = distance to (2,3) ✔
Example 6 MEDIUM Find the position of (3, 4) w.r.t. x² + y² = 16.
  1. Step 1: S₁ = 3² + 4² − 16
  2. Step 2: = 25 − 16 = 9
  3. Step 3: S₁ > 0 → the point lies outside the circle
Example 7 HARD Find the circle through (0,0), (4,0) and (0,6).
  1. Step 1: Let x²+y²+2gx+2fy+c = 0. (0,0): c = 0
  2. Step 2: (4,0): 16 + 8g = 0 → g = −2
  3. Step 3: (0,6): 36 + 12f = 0 → f = −3
  4. Step 4: x² + y² − 4x − 6y = 0; centre (2,3), r = √13
Example 8 HARD Prove that the tangent at (x₁, y₁) to x² + y² = r² is x x₁ + y y₁ = r².
  1. Step 1: Radius to (x₁,y₁) has slope y₁/x₁; tangent ⟂ radius → slope = −x₁/y₁
  2. Step 2: y − y₁ = −(x₁/y₁)(x − x₁)
  3. Step 3: y y₁ − y₁² = −x x₁ + x₁² → x x₁ + y y₁ = x₁² + y₁²
  4. Step 4: (x₁,y₁) lies on circle: x₁²+y₁² = r² → x x₁ + y y₁ = r² ∎
Example 9 HARD For what c is y = x + c tangent to x² + y² = 25?
  1. Step 1: m = 1, r² = 25; condition c² = r²(1 + m²)
  2. Step 2: c² = 25 × 2 = 50
  3. Step 3: c = ±5√2
  4. Step 4: Check: distance of origin from x − y + c = 0 is |c|/√2 = 5 ✔
Example 10 HARD Find the length of the tangent from (6, 5) to x² + y² − 2x − 4y − 4 = 0.
  1. Step 1: Length = √S₁
  2. Step 2: S₁ = 36 + 25 − 12 − 20 − 4 = 25
  3. Step 3: Length = √25 = 5
  4. Step 4: Check: centre (1,2), r = 3, d² = 34; √(34 − 9) = 5 ✔

7. Short Q&A

Q1. Define a circle.

Ans Locus of points at a constant distance (radius) from a fixed point (centre).

Q2. Write the standard equation.

Ans (x−h)² + (y−k)² = r².

Q3. Centre and radius of x²+y²+2gx+2fy+c=0?

Ans Centre (−g, −f), radius √(g²+f²−c).

Q4. What is a tangent?

Ans A line touching the circle at exactly one point; it is perpendicular to the radius there.

Q5. Write the condition for y=mx+c to touch x²+y²=r².

Ans c² = r²(1+m²).
