शांकव – दीर्घवृत्त

कक्षा 11 • अध्याय 14 • हस्तलिखित शैली नोट्स
NCERT पर आधारित; अवतार, राजीव, विद्या व सुमित्रा अरोड़ा (यूपी बोर्ड) शैली का अभ्यास।

1. परिभाषा

दीर्घवृत्त उस बिंदु P का बिंदुपथ है जो इस प्रकार चलता है कि दो निश्चित बिंदुओं (नाभियों F₁, F₂) से उसकी दूरियों का योग अचर रहे: PF₁ + PF₂ = 2a, और 2a > F₁F₂।

यह शांकव है: शंकु को (आधार या जनक के समांतर न) तल से काटने पर बंद अंडाकार वक्र मिलता है। नाभियाँ संपाती हों तो दीर्घवृत्त वृत्त बन जाता है।

अन्य परिभाषा: वह बिंदुपथ जिसकी नाभि से दूरी नियता से दूरी की e गुनी हो, 0 < e < 1।

2. नाभियाँ, दीर्घ व लघु अक्ष (पद)

नाभियाँ: F₁(−c, 0), F₂(c, 0)। केंद्र C: F₁F₂ का मध्य-बिंदु।

दीर्घ अक्ष: नाभियों से जाने वाली सबसे लंबी जीवा, लंबाई 2a; सिरे A, A′ = शीर्ष (±a, 0)।

लघु अक्ष: केंद्र से जाने वाली दीर्घ अक्ष पर लंब जीवा, लंबाई 2b; सिरे B, B′ = (0, ±b)। यहाँ a > b।

नाभिलंब: नाभि से जाने वाली दीर्घ अक्ष पर लंब जीवा। नियताएँ: x = ± a/e।

3. मानक समीकरण (व्युत्पत्ति)

F₁(−c, 0), F₂(c, 0), PF₁ + PF₂ = 2a लें (चित्र देखें):

√[(x+c)² + y²] + √[(x−c)² + y²] = 2a

एक मूल अलग कर दो बार वर्ग करें और सरल करें: (a² − c²)x² + a²y² = a²(a² − c²)

b² = a² − c² रखकर a²b² से भाग दें:

x²/a² + y²/b² = 1    (a > b)

4. उत्केंद्रता एवं नाभिलंब

e = c/a  (0 < e < 1)

c² = a² − b² ⟹ b² = a²(1 − e²)। नाभियाँ (±ae, 0), नियताएँ x = ±a/e।

e → 0: लगभग वृत्त; e → 1: अधिक चपटा दीर्घवृत्त (चित्र देखें)।

नाभिलंब = 2b²/a; सिरे (±c, ±b²/a)।

5. दो मानक रूप

सुझाव: बड़ा हर दीर्घ अक्ष की दिशा बताता है।

6. गुणधर्म

दोनों अक्षों और मूलबिंदु के सापेक्ष सममित।

P(x₁, y₁) की नाभीय दूरियाँ: PF₁ = a + ex₁, PF₂ = a − ex₁; योग = 2a।

प्राचलिक रूप: (a cos θ, b sin θ)। सहायक वृत्त: x² + y² = a²।

बिंदु (x₁, y₁): x₁²/a² + y₁²/b² − 1 < 0 अंदर, = 0 पर, > 0 बाहर।

वास्तविक जीवन: ग्रह सूर्य को एक नाभि पर रखकर दीर्घवृत्ताकार कक्षा में चलते हैं (केपलर); फुसफुसाहट दीर्घा; मेहराब।

7. हल किए गए उदाहरण (सरल → कठिन)

उदाहरण 1 सरल x²/25 + y²/9 = 1 के लिए नाभियाँ, शीर्ष, अक्ष, e और नाभिलंब ज्ञात कीजिए।
  1. चरण 1: a² = 25 → a = 5; b² = 9 → b = 3 (a > b: दीर्घ अक्ष x पर)
  2. चरण 2: c = √(a²−b²) = √16 = 4 → नाभियाँ (±4, 0); शीर्ष (±5, 0)
  3. चरण 3: दीर्घ अक्ष = 10, लघु अक्ष = 6; e = c/a = 4/5
  4. चरण 4: नाभिलंब = 2b²/a = 18/5
उदाहरण 2 सरल 16x² + 25y² = 400 की नाभियाँ और e ज्ञात कीजिए।
  1. चरण 1: 400 से भाग: x²/25 + y²/16 = 1
  2. चरण 2: a = 5, b = 4, c = √(25−16) = 3
  3. चरण 3: नाभियाँ (±3, 0)
  4. चरण 4: e = 3/5
उदाहरण 3 सरल x²/9 + y²/25 = 1 की नाभियाँ, शीर्ष और e ज्ञात कीजिए।
  1. चरण 1: 25 > 9 → दीर्घ अक्ष y पर: a² = 25, b² = 9
  2. चरण 2: c = √(25−9) = 4 → नाभियाँ (0, ±4); शीर्ष (0, ±5)
  3. चरण 3: e = 4/5
उदाहरण 4 मध्यम शीर्ष (±5, 0) और नाभियाँ (±4, 0) वाला दीर्घवृत्त ज्ञात कीजिए।
  1. चरण 1: a = 5, c = 4
  2. चरण 2: b² = a² − c² = 25 − 16 = 9
  3. चरण 3: x²/25 + y²/9 = 1
उदाहरण 5 मध्यम x-अक्ष पर दीर्घ अक्ष वाला दीर्घवृत्त ज्ञात कीजिए जो (4, 3) और (−1, 4) से जाता हो।
  1. चरण 1: x²/A + y²/B = 1 मानें। (4,3): 16/A + 9/B = 1; (−1,4): 1/A + 16/B = 1
  2. चरण 2: u = 1/A, v = 1/B: 16u + 9v = 1, u + 16v = 1
  3. चरण 3: u = 1 − 16v → 16 − 256v + 9v = 1 → v = 15/247, u = 7/247
  4. चरण 4: 7x² + 15y² = 247
उदाहरण 6 मध्यम नाभियाँ (±2, 0) और e = 1/2 वाला दीर्घवृत्त ज्ञात कीजिए।
  1. चरण 1: c = 2, e = c/a = 1/2 → a = 4
  2. चरण 2: b² = a² − c² = 16 − 4 = 12
  3. चरण 3: x²/16 + y²/12 = 1
उदाहरण 7 कठिन e ज्ञात कीजिए यदि नाभिलंब लघु अक्ष के आधे के बराबर हो।
  1. चरण 1: नाभिलंब = 2b²/a; लघु अक्ष का आधा = b
  2. चरण 2: 2b²/a = b → b = a/2
  3. चरण 3: e² = 1 − b²/a² = 1 − 1/4 = 3/4
  4. चरण 4: e = √3/2
उदाहरण 8 कठिन सिद्ध कीजिए कि दीर्घवृत्त पर P(x₁, y₁) के लिए PF₁ = a + ex₁ और PF₂ = a − ex₁; अतः PF₁ + PF₂ = 2a।
  1. चरण 1: y₁² = b²(1 − x₁²/a²); PF₁² = (x₁+c)² + y₁²
  2. चरण 2: = x₁²(1 − b²/a²) + 2cx₁ + c² + b² = e²x₁² + 2aex₁ + a²
  3. चरण 3: = (a + ex₁)² → PF₁ = a + ex₁ (a + ex₁ > 0)
  4. चरण 4: इसी प्रकार PF₂ = a − ex₁; योग = 2a ∎
उदाहरण 9 कठिन सिद्ध कीजिए कि x²/a² + y²/b² = 1 का नाभिलंब 2b²/a है।
  1. चरण 1: नाभिलंब नाभि F(c, 0) से जाता है: x = c
  2. चरण 2: c²/a² + y²/b² = 1 → y² = b²(1 − c²/a²) = b²·b²/a²
  3. चरण 3: y = ±b²/a
  4. चरण 4: लंबाई = 2b²/a ∎
उदाहरण 10 कठिन नाभियाँ (0, ±5) और दीर्घ अक्ष की लंबाई 26 वाला दीर्घवृत्त ज्ञात कीजिए।
  1. चरण 1: नाभियाँ y-अक्ष पर → x²/b² + y²/a² = 1
  2. चरण 2: 2a = 26 → a = 13; c = 5
  3. चरण 3: b² = a² − c² = 169 − 25 = 144
  4. चरण 4: x²/144 + y²/169 = 1

8. लघु प्रश्नोत्तर

प्र.1. दीर्घवृत्त को परिभाषित कीजिए।

उ. वह बिंदुपथ जिसकी दो निश्चित बिंदुओं (नाभियों) से दूरियों का योग अचर 2a (> नाभियों के बीच दूरी) हो।

प्र.2. मानक समीकरण तथा a, b, c का संबंध लिखिए।

उ. x²/a² + y²/b² = 1 (a > b); b² = a² − c²।

प्र.3. उत्केंद्रता परिभाषित कीजिए।

उ. e = c/a, 0 < e < 1; b² = a²(1 − e²)।

प्र.4. दीर्घवृत्त का नाभिलंब क्या है?

उ. नाभि से जाने वाली दीर्घ अक्ष पर लंब जीवा; लंबाई 2b²/a।

प्र.5. e = 0 होने पर क्या होता है?

उ. नाभियाँ केंद्र पर संपाती हो जाती हैं और दीर्घवृत्त वृत्त बन जाता है।
