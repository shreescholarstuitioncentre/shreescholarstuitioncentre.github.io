अनुक्रम एवं श्रेणी

कक्षा 11 • अध्याय 9 • हस्तलिखित शैली नोट्स
NCERT पर आधारित; अवतार, राजीव, विद्या व सुमित्रा अरोड़ा (यूपी बोर्ड) शैली का अभ्यास।

1. अनुक्रम

अनुक्रम किसी नियम से एक निश्चित क्रम में लिखी संख्याओं की सूची है: a₁, a₂, a₃, … उदाहरण: 2, 4, 6, 8, … (aₙ = 2n)।

परिमित अनुक्रम का अंतिम पद होता है; अनंत अनुक्रम कभी समाप्त नहीं होता। n वाँ पद aₙ, n का फलन है।

2. श्रेणी

यदि a₁, a₂, …, aₙ अनुक्रम है, तो a₁ + a₂ + … + aₙ संगत श्रेणी है। n पदों का योग Sₙ और aₙ = Sₙ − Sₙ₋₁।

अनुक्रम = सूची; श्रेणी = उस सूची का योग।

3. समांतर श्रेढ़ी (मूल बातें)

AP: प्रत्येक पद = पिछला पद + अचर d (सार्वअंतर)।

aₙ = a + (n−1)d    Sₙ = n/2 [2a + (n−1)d]

a, b का समांतर माध्य: A = (a+b)/2। AP में तीन पद: a−d, a, a+d।

4. गुणोत्तर श्रेढ़ी (GP)

GP: प्रत्येक पद = पिछला पद × अचर r (सार्वानुपात), r = a₂/a₁ ≠ 0। उदाहरण: 3, 6, 12, 24 (r = 2); 8, 4, 2, 1 (r = ½)।

GP में तीन पद: a/r, a, ar। परीक्षण: b² = ac।

5. GP का व्यापक पद

aₙ = a rⁿ⁻¹

परिमित GP में अंतिम पद l हो तो अंत से n वाँ पद = l / rⁿ⁻¹।

6. GP के n पदों का योग

Sₙ = a(rⁿ − 1)/(r − 1), r > 1    Sₙ = a(1 − rⁿ)/(1 − r), r < 1

यदि r = 1 तो Sₙ = na।

उपपत्ति: Sₙ = a + ar + … + arⁿ⁻¹; r·Sₙ = ar + … + arⁿ; घटाने पर (1−r)Sₙ = a(1−rⁿ)।

7. अनंत GP एवं उसका योग

ऐसी GP जो कभी समाप्त नहीं होती। यदि |r| < 1, तो rⁿ → 0, अतः योग परिमित है:

S∞ = a / (1 − r),  |r| < 1

यदि |r| ≥ 1 तो योग परिमित नहीं होता। चित्र: 1 + ½ + ¼ + … की कुल लंबाई 2 तक पहुँचती है।

आवर्ती दशमलव: 0.3̄ = 0.3 + 0.03 + … = 0.3/(1−0.1) = 1/3।

8. गुणोत्तर माध्य (GM)

धनात्मक a, b का GM है G = √(ab) (a, G, b GP में हैं)।

a और b के बीच n GM: r = (b/a)^(1/(n+1)); पद ar, ar², …, arⁿ। n GM का गुणनफल = Gⁿ जहाँ G = √(ab)।

9. AM–GM संबंध

धनात्मक a, b के लिए:

AM ≥ GM, अर्थात् (a+b)/2 ≥ √(ab)

समता केवल a = b पर। साथ ही AM·HM = GM²।

चित्र: a+b व्यास के अर्धवृत्त में त्रिज्या = AM और जोड़ बिंदु पर लंब CD = GM। त्रिज्या लंब से कभी छोटी नहीं होती।

उपयोग: x+y अचर हो तो xy अधिकतम तब जब x = y; xy अचर हो तो योग न्यूनतम तब जब x = y।

10. हल किए गए उदाहरण (सरल → कठिन)

उदाहरण 1 सरल GP 2, 6, 18, … का 10वाँ पद ज्ञात कीजिए।
  1. चरण 1: a = 2, r = 6/2 = 3, n = 10
  2. चरण 2: aₙ = a rⁿ⁻¹ = 2 × 3⁹
  3. चरण 3: 3⁹ = 19683, अतः a₁₀ = 39366
उदाहरण 2 सरल 3, 6, 12, … के प्रथम 6 पदों का योग ज्ञात कीजिए।
  1. चरण 1: a = 3, r = 2 (r > 1), n = 6
  2. चरण 2: S₆ = 3(2⁶ − 1)/(2 − 1) = 3 × 63
  3. चरण 3: = 189
उदाहरण 3 सरल 1 + ½ + ¼ + … ∞ तक का योग ज्ञात कीजिए।
  1. चरण 1: a = 1, r = ½, |r| < 1 ✔
  2. चरण 2: S∞ = a/(1−r) = 1/(1−½)
  3. चरण 3: = 2
उदाहरण 4 मध्यम एक GP का तीसरा पद 12 और छठा पद 96 है। a और r ज्ञात कीजिए।
  1. चरण 1: ar² = 12 … (1), ar⁵ = 96 … (2)
  2. चरण 2: (2)÷(1): r³ = 8 → r = 2
  3. चरण 3: (1) से: a × 4 = 12 → a = 3
उदाहरण 5 मध्यम 1 और 81 के बीच 3 GM रखिए।
  1. चरण 1: a = 1, b = 81, n = 3; b = ar⁴ → r⁴ = 81
  2. चरण 2: r = 3
  3. चरण 3: GM: 3, 9, 27 (अनुक्रम 1, 3, 9, 27, 81)
उदाहरण 6 मध्यम 0.777… को भिन्न के रूप में लिखिए।
  1. चरण 1: 0.777… = 0.7 + 0.07 + 0.007 + …, a = 0.7, r = 0.1
  2. चरण 2: S∞ = 0.7/(1 − 0.1) = 0.7/0.9
  3. चरण 3: = 7/9
उदाहरण 7 कठिन सिद्ध कीजिए कि दो धनात्मक संख्याओं a, b के लिए AM ≥ GM।
  1. चरण 1: AM − GM = (a+b)/2 − √(ab) = (a + b − 2√(ab))/2
  2. चरण 2: = (√a − √b)²/2
  3. चरण 3: वर्ग ≥ 0, अतः AM − GM ≥ 0
  4. चरण 4: समता तब जब √a = √b अर्थात् a = b ∎
उदाहरण 8 कठिन 7 + 77 + 777 + … के n पदों का योग ज्ञात कीजिए।
  1. चरण 1: Sₙ = 7(1 + 11 + 111 + …) = (7/9)(9 + 99 + 999 + …)
  2. चरण 2: = (7/9)[(10−1) + (10²−1) + … + (10ⁿ−1)]
  3. चरण 3: = (7/9)[10(10ⁿ − 1)/9 − n]
  4. चरण 4: = (70/81)(10ⁿ − 1) − 7n/9
उदाहरण 9 कठिन यदि a, b, c GP में हैं और a^(1/x) = b^(1/y) = c^(1/z) तो सिद्ध कीजिए x, y, z AP में हैं।
  1. चरण 1: प्रत्येक = k मानें: a = kˣ, b = kʸ, c = kᶻ
  2. चरण 2: GP ⟹ b² = ac → k²ʸ = kˣ⁺ᶻ
  3. चरण 3: अतः 2y = x + z
  4. चरण 4: इसलिए x, y, z AP में हैं ∎
उदाहरण 10 कठिन यदि x > 0 तो x + 1/x का न्यूनतम मान ज्ञात कीजिए।
  1. चरण 1: x और 1/x का AM ≥ GM: (x + 1/x)/2 ≥ √(x · 1/x) = 1
  2. चरण 2: अतः x + 1/x ≥ 2
  3. चरण 3: समता तब जब x = 1/x → x = 1
  4. चरण 4: न्यूनतम मान = 2

11. लघु प्रश्नोत्तर

प्र.1. अनुक्रम और श्रेणी को परिभाषित कीजिए।

उ. अनुक्रम नियम से बनी संख्याओं की क्रमबद्ध सूची है; श्रेणी उसके पदों का योग है।

प्र.2. GP का व्यापक पद और योग लिखिए।

उ. aₙ = arⁿ⁻¹; r≠1 के लिए Sₙ = a(rⁿ−1)/(r−1)।

प्र.3. अनंत GP का योग कब होता है?

उ. केवल |r| < 1 पर; तब S∞ = a/(1−r)।

प्र.4. गुणोत्तर माध्य परिभाषित कीजिए।

उ. धनात्मक a, b के लिए GM = √(ab); a, G, b GP में होते हैं।

प्र.5. AM–GM असमिका लिखिए।

उ. धनात्मक वास्तविक संख्याओं के लिए (a+b)/2 ≥ √(ab), समता तभी जब a = b।
