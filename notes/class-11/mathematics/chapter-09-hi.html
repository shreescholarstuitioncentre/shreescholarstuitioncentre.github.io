सरल रेखाएँ

कक्षा 11 • अध्याय 11 • हस्तलिखित शैली नोट्स
NCERT पर आधारित; अवतार, राजीव, विद्या व सुमित्रा अरोड़ा (यूपी बोर्ड) शैली का अभ्यास।

1. निर्देशांक ज्यामिति की पुनरावृत्ति

दूरी: √[(x₂−x₁)²+(y₂−y₁)²]। मध्य-बिंदु: ((x₁+x₂)/2, (y₁+y₂)/2)। अंतः विभाजन (m:n): ((mx₂+nx₁)/(m+n), (my₂+ny₁)/(m+n))।

त्रिभुज का क्षेत्रफल = ½ |x₁(y₂−y₃) + x₂(y₃−y₁) + x₃(y₁−y₂)|। क्षेत्रफल 0 हो तो तीनों बिंदु संरेख हैं।

2. मूलबिंदु का स्थानांतरण

अक्षों को समांतर रखते हुए मूलबिंदु O′(h, k) पर ले जाएँ। यदि P(x, y) नए अक्षों में P(X, Y) हो:

x = X + h,   y = Y + k  (X = x − h, Y = y − k)

उपयोग: समीकरण सरल करने के लिए (h, k) ऐसे चुनें कि पद समाप्त हों; x = X+h, y = Y+k रखकर X, Y में नया समीकरण लिखें।

3. रेखा की प्रवणता

झुकाव कोण θ = रेखा द्वारा धनात्मक x-अक्ष से वामावर्त बना कोण (0° ≤ θ < 180°)। प्रवणता m = tan θ।

m = (y₂ − y₁)/(x₂ − x₁)

x-अक्ष (या समांतर) → m = 0; y-अक्ष (या समांतर) → प्रवणता अपरिभाषित (θ = 90°)। रेखा Ax+By+C=0 → m = −A/B।

समांतर: m₁ = m₂। लंबवत: m₁·m₂ = −1। तीन बिंदु संरेख हों तो AB और BC की प्रवणता समान।

4. दो रेखाओं के बीच कोण

यदि रेखाओं की प्रवणताएँ m₁, m₂ हों, तो उनके बीच न्यून कोण θ:

tan θ = | (m₁ − m₂)/(1 + m₁m₂) |

m₁m₂ = −1 → θ = 90°। m₁ = m₂ → θ = 0° (समांतर)। अधिक कोण = 180° − θ।

5. रेखा के समीकरण के रूप

(क) अक्षों के समांतर: y-अक्ष के समांतर, दूरी a पर: x = a; x-अक्ष के समांतर: y = b। (x-अक्ष: y = 0, y-अक्ष: x = 0)।

(ख) बिंदु-प्रवणता:

y − y₁ = m(x − x₁)

(ग) प्रवणता-अंतःखंड:

y = mx + c
c = y-अंतःखंड।

(घ) द्वि-बिंदु:

y − y₁ = [(y₂−y₁)/(x₂−x₁)] (x − x₁)

(ङ) अंतःखंड रूप:

x/a + y/b = 1
a = x-अंतःखंड, b = y-अंतःखंड (चित्र देखें)।

व्यापक रूप: Ax + By + C = 0; प्रवणता −A/B, x-अंतःखंड −C/A, y-अंतःखंड −C/B।

6. बिंदु की रेखा से दूरी

P(x₁, y₁) से Ax + By + C = 0 की लंबवत दूरी:

d = |Ax₁ + By₁ + C| / √(A² + B²)

मूलबिंदु से: |C|/√(A²+B²)। समांतर रेखाओं Ax+By+C₁=0 और Ax+By+C₂=0 के बीच: |C₁ − C₂| / √(A²+B²)।

7. हल किए गए उदाहरण (सरल → कठिन)

उदाहरण 1 सरल (2, 3) और (6, 11) से जाने वाली रेखा की प्रवणता ज्ञात कीजिए।
  1. चरण 1: m = (y₂−y₁)/(x₂−x₁) = (11−3)/(6−2)
  2. चरण 2: = 8/4
  3. चरण 3: = 2
उदाहरण 2 सरल (1, 2) से जाने वाली, प्रवणता 3 वाली रेखा का समीकरण ज्ञात कीजिए।
  1. चरण 1: बिंदु-प्रवणता: y − y₁ = m(x − x₁)
  2. चरण 2: y − 2 = 3(x − 1) = 3x − 3
  3. चरण 3: 3x − y − 1 = 0
उदाहरण 3 सरल प्रवणता 2 और y-अंतःखंड −3 वाली रेखा का समीकरण ज्ञात कीजिए।
  1. चरण 1: प्रवणता-अंतःखंड: y = mx + c
  2. चरण 2: m = 2, c = −3
  3. चरण 3: y = 2x − 3, अर्थात् 2x − y − 3 = 0
उदाहरण 4 मध्यम (−1, 4) और (3, −2) से जाने वाली रेखा का समीकरण ज्ञात कीजिए।
  1. चरण 1: प्रवणता = (−2−4)/(3+1) = −6/4 = −3/2
  2. चरण 2: y − 4 = −(3/2)(x + 1)
  3. चरण 3: 2y − 8 = −3x − 3
  4. चरण 4: 3x + 2y − 5 = 0 (जाँच (3,−2): 9−4−5 = 0 ✔)
उदाहरण 5 मध्यम x-अंतःखंड 3 और y-अंतःखंड −4 वाली रेखा का समीकरण ज्ञात कीजिए।
  1. चरण 1: अंतःखंड रूप: x/a + y/b = 1, a = 3, b = −4
  2. चरण 2: x/3 − y/4 = 1
  3. चरण 3: 12 से गुणा: 4x − 3y = 12
  4. चरण 4: 4x − 3y − 12 = 0
उदाहरण 6 मध्यम प्रवणता 2 और 1/3 वाली रेखाओं के बीच न्यून कोण ज्ञात कीजिए।
  1. चरण 1: tan θ = |(m₁ − m₂)/(1 + m₁m₂)|
  2. चरण 2: = |(2 − 1/3)/(1 + 2/3)| = (5/3)/(5/3)
  3. चरण 3: tan θ = 1
  4. चरण 4: θ = 45°
उदाहरण 7 कठिन k ज्ञात कीजिए ताकि 3x + ky = 5 और 2x − 3y = 7 लंबवत हों।
  1. चरण 1: प्रवणता₁ = −3/k, प्रवणता₂ = 2/3
  2. चरण 2: लंबवत: (−3/k)(2/3) = −1
  3. चरण 3: −2/k = −1
  4. चरण 4: k = 2
उदाहरण 8 कठिन (2, 3) से जाने वाली वह रेखा ज्ञात कीजिए जिसके दोनों अक्षों पर अंतःखंड बराबर हों।
  1. चरण 1: बराबर अंतःखंड a: x/a + y/a = 1 → x + y = a
  2. चरण 2: (2, 3) से गुज़रती है: 2 + 3 = a → a = 5
  3. चरण 3: रेखा: x + y = 5, अर्थात् x + y − 5 = 0
उदाहरण 9 कठिन मूलबिंदु को (2, −3) पर ले जाकर x² + y² − 4x + 6y − 12 = 0 को रूपांतरित कीजिए।
  1. चरण 1: x = X + 2, y = Y − 3 रखें
  2. चरण 2: (X+2)² + (Y−3)² − 4(X+2) + 6(Y−3) − 12 = 0
  3. चरण 3: X²+4X+4 + Y²−6Y+9 − 4X−8 + 6Y−18 − 12 = 0

  2. चरण 2: d = |3(2) + 4(1) + 5| / √(3²+4²)
  3. चरण 3: = 15/5

8. लघु प्रश्नोत्तर

प्र.1. रेखा की प्रवणता परिभाषित कीजिए।

उ. m = tan θ, जहाँ θ झुकाव कोण है; m = (y₂−y₁)/(x₂−x₁)।

प्र.2. समांतर और लंबवत रेखाओं की शर्तें?

उ. समांतर: m₁ = m₂। लंबवत: m₁m₂ = −1।

प्र.3. अंतःखंड रूप लिखिए।

उ. x/a + y/b = 1।

प्र.4. बिंदु की रेखा से दूरी का सूत्र लिखिए।

उ. |Ax₁+By₁+C| / √(A²+B²)।

प्र.5. मूलबिंदु स्थानांतरण के सूत्र लिखिए।

उ. x = X + h, y = Y + k।
