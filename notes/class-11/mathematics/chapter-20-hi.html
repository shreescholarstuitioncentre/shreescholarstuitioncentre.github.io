कक्षा 11 गणित - अध्याय 4: ज्या और कोज्या सूत्र

0. संकेतन

त्रिभुज ABC में कोणों A, B, C के सम्मुख भुजाएँ a, b, c हैं। अर्ध-परिमाप s = (a+b+c)/2, क्षेत्रफल = Δ, परिवृत्त की त्रिज्या = R।

Triangle ABC with sides a, b, c

1. ज्या नियम (Sine Rule)

a/sin A = b/sin B = c/sin C = 2R

उपपत्ति. त्रिभुज ABC का परिवृत्त (केंद्र O, त्रिज्या R) बनाइए। व्यास BD खींचिए और CD मिलाइए। कोण BCD = 90° (अर्धवृत्त में कोण) और कोण BDC = A (एक ही चाप BC)। समकोण त्रिभुज BCD में sin A = BC/BD = a/2R। अतः a/sin A = 2R। इसी प्रकार b/sin B = c/sin C = 2R।

Circumcircle: a/sin A = b/sin B = c/sin C = 2R

उपयोगी रूप: a = 2R sin A, b = 2R sin B, c = 2R sin C; साथ ही a : b : c = sin A : sin B : sin C।

2. कोज्या नियम (Cosine Rule)

a² = b² + c² − 2bc cos A
b² = c² + a² − 2ca cos B
c² = a² + b² − 2ab cos C
cos A = (b² + c² − a²)/(2bc), cos B = (c² + a² − b²)/(2ca), cos C = (a² + b² − c²)/(2ab)
Cosine rule: c² = a² + b² − 2ab cos C

उपपत्ति (निर्देशांक से). C को मूलबिंदु, B = (a, 0), A = (b cos C, b sin C) लें। तब c² = AB² = (b cos C − a)² + (b sin C)² = b²cos²C − 2ab cos C + a² + b²sin²C = a² + b² − 2ab cos C।

त्रिभुज की प्रकृति: यदि a² > b² + c² तो A अधिक कोण है; a² = b² + c² तो A = 90° (पाइथागोरस); a² < b² + c² तो A न्यून कोण है।

3. प्रक्षेप सूत्र (Projection Formula)

a = b cos C + c cos B
b = c cos A + a cos C
c = a cos B + b cos A
CD ⟂ AB: c = b cos A + a cos B (projection)

उपपत्ति. CD ⟂ AB खींचिए। AD = b cos A और DB = a cos B। AB = AD + DB से c = b cos A + a cos B। (यदि D बाहर पड़े तो cosine ऋणात्मक हो जाता है और सूत्र फिर भी सत्य रहता है।)

4. त्रिभुज का क्षेत्रफल

Δ = ½ ab sin C = ½ bc sin A = ½ ca sin B
Δ = abc/(4R)
हेरोन: Δ = √[s(s−a)(s−b)(s−c)]
Area = ½ × base × height = ½ c h = ½ bc sin A

कारण: ऊँचाई h = b sin A, अतः Δ = ½ × c × h = ½ bc sin A। a = 2R sin A रखने पर: Δ = ½ bc (a/2R) = abc/4R।

5. अनुप्रयोग

ज्या नियम तब: दो कोण और एक भुजा दी हो (ASA, AAS), या दो भुजाएँ और एक के सम्मुख कोण दिया हो (SSA, संदिग्ध स्थिति, 0, 1 या 2 त्रिभुज संभव)।
कोज्या नियम तब: दो भुजाएँ और उनका अंतर्गत कोण (SAS) या तीनों भुजाएँ (SSS) दी हों।
ऊँचाई और दूरी: चित्र से त्रिभुज बनाइए, ज्ञात कोण अंकित कीजिए और ज्या या कोज्या नियम लगाइए।

हल किए गए उदाहरण (चरणबद्ध)

सरल ABC में a = 10, A = 30°, B = 45°। b ज्ञात कीजिए।
हल. b/sin B = a/sin A ⇒ b = 10 × sin45°/sin30° = 10 × (1/√2)/(1/2) = 10√2।
सरल a = 6, b = 8, C = 30° हो तो क्षेत्रफल ज्ञात कीजिए।
हल. Δ = ½ ab sin C = ½ × 6 × 8 × ½ = 12 वर्ग इकाई।
मध्यम त्रिभुज की भुजाएँ 3, 5, 7 हैं। सबसे बड़ा कोण ज्ञात कीजिए।
हल. सबसे बड़ा कोण 7 के सम्मुख है। cos C = (3² + 5² − 7²)/(2×3×5) = (9 + 25 − 49)/30 = −15/30 = −1/2। अतः C = 120°।
मध्यम ABC में a = 2, b = 2, C = 90°। c और A ज्ञात कीजिए।
हल. c² = 4 + 4 − 0 = 8 ⇒ c = 2√2। a = b अतः A = B = 45°।
कठिन सिद्ध कीजिए a(b cos C − c cos B) = b² − c²।
उपपत्ति. ab cos C = (a² + b² − c²)/2 और ac cos B = (a² + c² − b²)/2। घटाने पर (2b² − 2c²)/2 = b² − c²। इति सिद्धम्।
कठिन सिद्ध कीजिए (b² − c²)/a² = sin(B−C)/sin(B+C)।
उपपत्ति. ज्या नियम से b = 2R sin B, c = 2R sin C, a = 2R sin A। अतः (b²−c²)/a² = (sin²B − sin²C)/sin²A। अब sin²B − sin²C = (sin B + sin C)(sin B − sin C) = 2 sin((B+C)/2)cos((B−C)/2) × 2 cos((B+C)/2) sin((B−C)/2) = sin(B+C) sin(B−C)। चूँकि A = 180° − (B+C), sin A = sin(B+C)। अतः परिणाम = sin(B+C) sin(B−C)/sin²(B+C) = sin(B−C)/sin(B+C)।

प्रश्न-उत्तर (खोलने के लिए टैप करें)

Q1. ज्या नियम लिखिए।
a/sin A = b/sin B = c/sin C = 2R।
Q2. कोज्या नियम लिखिए।
a² = b² + c² − 2bc cos A (b, c के लिए भी इसी प्रकार)।
Q3. प्रक्षेप सूत्र लिखिए।
a = b cos C + c cos B (और चक्रीय)।
Q4. दो भुजाओं और अंतर्गत कोण से क्षेत्रफल का सूत्र लिखिए।
Δ = ½ ab sin C।
Q5. ABC में A = 60°, B = 45°, a = 6। b ज्ञात कीजिए।
b = a sin B/sin A = 6 × (1/√2)/(√3/2) = 6√2/√3 = 2√6।
Q6. a = 5, b = 7, C = 60° हो तो c ज्ञात कीजिए।
c² = 25 + 49 − 2×5×7×½ = 39, अतः c = √39।
Q7. a = 7, b = 8, c = 9 हो तो cos A ज्ञात कीजिए।
cos A = (64+81−49)/(2×8×9) = 96/144 = 2/3।
Q8. a = 5, b = 12, C = 90° हो तो क्षेत्रफल ज्ञात कीजिए।
½ × 5 × 12 = 30।
Q9. भुजाएँ 4, 5, 7 वाला त्रिभुज न्यूनकोण है या अधिककोण?
7² = 49 > 16 + 25 = 41, अतः सबसे बड़ा कोण अधिक कोण है।
Q10. a = 3, R = 3 हो तो sin A ज्ञात कीजिए।
sin A = a/2R = 3/6 = 1/2।
Q11. a = 6, A = 30° वाले त्रिभुज की परिवृत्त त्रिज्या ज्ञात कीजिए।
2R = a/sin A = 12, अतः R = 6।
Q12. A = 90° हो तो कोज्या नियम से पाइथागोरस प्रमेय निकालिए।
cos 90° = 0, अतः a² = b² + c²।
Q13. सिद्ध कीजिए a : b : c = sin A : sin B : sin C।
a = 2R sin A, b = 2R sin B, c = 2R sin C; 2R से भाग देने पर अनुपात मिलता है।
Q14. भुजा 2 के समबाहु त्रिभुज का क्षेत्रफल ½ ab sin C से ज्ञात कीजिए।
½ × 2 × 2 × sin60° = √3।
Q15. a = 1, b = 1, c = √2 हो तो कोण ज्ञात कीजिए।
cos C = (1+1−2)/2 = 0, अतः C = 90°, A = B = 45°।
Q16. सिद्ध कीजिए a = b cos C + c cos B।
AD ⟂ BC खींचिए: BD = c cos B, DC = b cos C, a = BD + DC।
Q17. सिद्ध कीजिए (a² + b² − c²) = 2ab cos C।
यह कोज्या नियम c² = a² + b² − 2ab cos C का पुनर्व्यवस्थित रूप है।
Q18. सिद्ध कीजिए a sin(B − C) + b sin(C − A) + c sin(A − B) = 0।
a = 2R sin A आदि रखिए। sin(B−C) sin(B+C) = sin²B − sin²C का प्रयोग करने पर योग 2R × [(sin²B − sin²C) + (sin²C − sin²A) + (sin²A − sin²B)] = 0।
Q19. सिद्ध कीजिए Δ = abc/4R।
Δ = ½ bc sin A और sin A = a/2R, अतः Δ = abc/4R।
Q20. MCQ: यदि a² + b² = c² तो कोण C = ? (a)30° (b)60° (c)90° (d)120°
(c) 90°।
Q21. MCQ: Δ = ? (a)½ ab cos C (b)½ ab sin C (c)ab sin C (d)½ a sin C
(b)।
Q22. MCQ: a/sin A = ? (a)R (b)2R (c)R/2 (d)4R
(b) 2R।

(a)।
