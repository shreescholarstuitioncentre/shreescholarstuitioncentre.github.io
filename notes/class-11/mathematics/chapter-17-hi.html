कक्षा 11 गणित – अध्याय 18: अवकलन (Differentiation)

हस्तलिखित शैली नोट्स • UP Board / NCERT

1. अवकलज: परिवर्तन की दर

y=f(x) की [x, x+h] पर औसत परिवर्तन दर = Δy/Δx = [f(x+h)−f(x)]/h। h→0 लेने पर तात्क्षणिक दर मिलती है:

dy/dx = limΔx→0 Δy/Δx
उदाहरण: वेग v=ds/dt; त्वरण a=dv/dt; वृत्त के क्षेत्रफल की दर dA/dr = 2πr। dy/dx>0 ⇒ y बढ़ रहा है, <0 ⇒ घट रहा है।

2. अवकलज: स्पर्श रेखा की प्रवणता

वक्र पर Q के P की ओर खिसकने पर छेदक रेखा PQ, P पर स्पर्श रेखा बन जाती है। छेदक की प्रवणता Δy/Δx → स्पर्श रेखा की प्रवणता।

x=a पर स्पर्श रेखा की प्रवणता: m = f'(a) = tan θ

(x₁,y₁) पर स्पर्श रेखा का समीकरण: y − y₁ = f'(x₁)(x − x₁)। अभिलंब की प्रवणता = −1/f'(x₁)। स्पर्श रेखा x-अक्ष के समांतर ⇔ f'=0।

3. अवकलज की परिभाषा

प्रथम सिद्धांत (ab-initio):

f'(x) = limh→0 [f(x+h) − f(x)] / h

संकेत: f'(x), dy/dx, Dy, y₁। बायाँ अवकलज (h→0⁻) और दायाँ अवकलज (h→0⁺); दोनों बराबर हों तभी अवकलज होता है।

अवकलनीय ⇒ संतत, पर विलोम सत्य नहीं: |x|, 0 पर संतत है पर अवकलनीय नहीं (कोना)।

4. अवकलजों का बीजगणित (योग, अंतर, गुणनफल, भागफल)

  • अचर गुणज: (cu)' = c·u'
  • योग: (u+v)' = u'+v'
  • अंतर: (u−v)' = u'−v'
गुणनफल: (uv)' = u'v + uv'
भागफल: (u/v)' = (u'v − uv') / v² , v≠0

गुणनफल नियम की उपपत्ति: [u(x+h)v(x+h) − u(x)v(x)]/h = u(x+h)·[v(x+h)−v(x)]/h + v(x)·[u(x+h)−u(x)]/h। h→0 (u संतत): u·v' + v·u'। ∎

5. बहुपद फलनों के अवकलज

  • d/dx (c) = 0   d/dx (x) = 1
d/dx (xⁿ) = n xⁿ⁻¹

उपपत्ति: f'(x)=limh→0 [(x+h)ⁿ − xⁿ]/h = limz→x (zⁿ−xⁿ)/(z−x) = n xⁿ⁻¹। ∎

अतः d/dx (a₀xⁿ + a₁xⁿ⁻¹ + … + aₙ) = n a₀ xⁿ⁻¹ + (n−1) a₁ xⁿ⁻² + …

एनिमेटेड चित्र: छेदक से स्पर्श रेखा

बिंदु Q (हरा) y=x² पर P(1,1) की ओर सरकता है। नीली छेदक रेखा PQ घूमकर P पर स्पर्श रेखा बन जाती है। इसकी प्रवणता f'(1)=2 की ओर जाती है।

हल किए गए उदाहरण (चरणबद्ध)

सरलx⁵ − 3x² + 7 का अवकलन कीजिए।पद-दर-पद: (x⁵)'=5x⁴, (3x²)'=6x, (7)'=0।
उत्तर: 5x⁴ − 6x।
सरलA=πr² की r के सापेक्ष परिवर्तन दर r=5 पर ज्ञात कीजिए।dA/dr = 2πr। r=5 पर: 10π।
सरलy=x² की (3,9) पर स्पर्श रेखा ज्ञात कीजिए।y'=2x ⇒ m=6।
y−9=6(x−3) ⇒ y = 6x − 9।
मध्यमf(x)=x² का प्रथम सिद्धांत से अवकलन कीजिए।[ (x+h)² − x² ]/h = (2xh+h²)/h = 2x+h।
h→0 ⇒ f'(x)=2x।
मध्यम(x²+1)(x³−2) का अवकलन कीजिए।u=x²+1, v=x³−2; u'=2x, v'=3x²।
u'v+uv' = 2x(x³−2)+(x²+1)3x² = 2x⁴−4x+3x⁴+3x²
= 5x⁴+3x²−4x।
मध्यम(x+1)/(x−1) का अवकलन कीजिए।u=x+1,v=x−1, u'=v'=1।
(u'v−uv')/v² = [(x−1)−(x+1)]/(x−1)² = −2/(x−1)²।
मध्यमx² sin x का अवकलन कीजिए।गुणनफल नियम: 2x·sin x + x²·cos x = x(2 sin x + x cos x)।
कठिनप्रथम सिद्धांत से सिद्ध कीजिए d/dx (sin x)=cos x।[sin(x+h)−sin x]/h = 2cos(x+h/2)sin(h/2)/h = cos(x+h/2)·[sin(h/2)/(h/2)]।
h→0: cos x·1 = cos x। ∎
कठिनसिद्ध कीजिए d/dx (tan x)=sec²x।tan x = sin x/cos x। भागफल नियम: [cos x·cos x − sin x·(−sin x)]/cos²x = (cos²x+sin²x)/cos²x = 1/cos²x = sec²x। ∎
कठिनsin x/(1+cos x) का अवकलन कीजिए।u'=cos x, v'=−sin x।
[cos x(1+cos x) + sin²x]/(1+cos x)² = (cos x+1)/(1+cos x)² = 1/(1+cos x)।
कठिनदिखाइए |x|, 0 पर अवकलनीय नहीं है।LHD: h<0, (|h|−0)/h = −h/h = −1। RHD: h>0 ⇒ 1। LHD≠RHD ⇒ अवकलनीय नहीं।
कठिनy=x²−4x+5 पर वह बिंदु ज्ञात कीजिए जहाँ स्पर्श रेखा x-अक्ष के समांतर हो।dy/dx=2x−4=0 ⇒ x=2। y=4−8+5=1। बिंदु (2,1)।
