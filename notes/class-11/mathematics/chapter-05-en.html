Class 11 Maths - Chapter 6: Linear Inequalities

1. Linear Inequalities

A statement in which two expressions are joined by <, >, ≤ or ≥ is an inequality. If the variable has degree 1, it is a linear inequality. Eg. 3x + 5 < 14 (one variable), 2x + 3y ≥ 6 (two variables).

Strict inequality: < or > (end value not included). Slack inequality: ≤ or ≥ (end value included). Solution set = all values of the variable which make the inequality true; it depends on the domain (N, Z or R).

2. Algebraic Solution: Rules

1. Add or subtract the same number on both sides: sign stays.
2. Multiply or divide both sides by the same positive number: sign stays.
3. Multiply or divide both sides by a negative number: sign REVERSES (< becomes >).
4. Move a term to the other side by changing its sign (transposing).

Example of rule 3: −2x < 6. Divide by −2 and reverse: x > −3.

3. Solution of One-Variable Inequality

Steps: (i) remove brackets and fractions (multiply by LCM of denominators, positive), (ii) collect x terms on one side and numbers on the other, (iii) divide by coefficient of x (reverse sign if it is negative), (iv) write the solution set, (v) show on number line. For a double inequality like a < f(x) ≤ b, operate on all three parts together.

4. Number Line Representation

Open circle ○ at the end point for < or > (not included); filled circle ● for ≤ or ≥ (included). Shade the part satisfying the inequality; the arrow shows it continues forever.

x > 2 : open circle, arrow to right
x ≥ 2 : filled circle, arrow to right
x < −1 : open circle, arrow to left
x ≤ −1 : filled circle, arrow to left
−1 ≤ x < 2 : interval [−1, 2)

Interval form: x > 2 is (2, ∞); x ≥ 2 is [2, ∞); x < −1 is (−∞, −1); −1 ≤ x < 2 is [−1, 2). Infinity always takes a round bracket.

5. Graphical Representation (Two Variables)

Steps for ax + by ≥ c (or >, ≤, <): (i) draw the line ax + by = c (find two points, such as the intercepts); (ii) line is solid for ≤ or ≥, dashed for < or >; (iii) take a test point, usually O(0,0) (if it is on the line, take another); (iv) if it satisfies the inequality, shade the side containing it, otherwise shade the other side.

x + y ≥ 3: solid line, shade side not containing O
x + y > 3: dashed line (line itself not included)

System of inequalities: draw each, and the common shaded region is the solution.

x ≥ 0, y ≥ 0, x + y ≤ 4: common region (triangle)

Solved Examples (step by step)

Easy Solve 3x + 5 < 14, x ∈ R.
Sol. 3x < 14 − 5 = 9 ⇒ x < 3. Solution set (−∞, 3).
Easy Solve −2x ≤ 6.
Sol. Divide by −2 and reverse the sign: x ≥ −3. Solution [−3, ∞).
Medium Solve 3(2 − x) ≥ 2(1 − x).
Sol. 6 − 3x ≥ 2 − 2x ⇒ 6 − 2 ≥ 3x − 2x ⇒ 4 ≥ x, i.e. x ≤ 4. Solution (−∞, 4].
Medium Solve −8 ≤ 5x − 3 < 7.
Sol. Add 3 to all parts: −5 ≤ 5x < 10. Divide by 5: −1 ≤ x < 2. Solution [−1, 2).
Hard Find pairs of consecutive odd positive integers, both smaller than 10, whose sum is more than 11.
Sol. Let the numbers be x and x + 2 (x odd). x + 2 < 10 ⇒ x < 8. x + (x+2) > 11 ⇒ 2x > 9 ⇒ x > 4.5. So 4.5 < x < 8, x odd: x = 5, 7. Pairs: (5,7) and (7,9).
Hard A solution must stay between 68°F and 77°F. Find the range in °C using C = (5/9)(F − 32).
Sol. 68 < F < 77 ⇒ 36 < F − 32 < 45 ⇒ multiply by 5/9: 20 < C < 25. So the temperature is between 20°C and 25°C.
Hard Solve graphically x ≥ 0, y ≥ 0, x + y ≤ 4.
Sol. x ≥ 0: right of y-axis. y ≥ 0: above x-axis. x + y = 4 passes (4,0) and (0,4); test O: 0 ≤ 4 true, shade towards O. Common region = triangle with vertices (0,0), (4,0), (0,4) including boundary.

Questions & Answers (tap to open)

Q1. Define a linear inequality.
An inequality in which the variable has degree 1, e.g. 2x + 3 < 9.
Q2. Difference between strict and slack inequality?
Strict uses < or > (end value excluded); slack uses ≤ or ≥ (included).
Q3. When does the inequality sign reverse?
When both sides are multiplied or divided by a negative number.
Q4. Solve x + 5 > 8.
x > 3, i.e. (3, ∞).
Q5. Solve 4x − 3 ≤ 9.
4x ≤ 12 ⇒ x ≤ 3.
Q6. Solve −3x > 12.
Divide by −3, reverse: x < −4.
Q7. Solve 5x − 3 < 3x + 1, x ∈ R.
2x < 4 ⇒ x < 2.
Q8. Solve 2x + 1 > 9, x ∈ N.
x > 4 ⇒ x = 5, 6, 7, …
Q9. Solve 3x − 1 < 8, x ∈ Z positive.
x < 3 ⇒ x = 1, 2.
Q10. Solve (x/2) + 3 ≥ 5.
x/2 ≥ 2 ⇒ x ≥ 4.
Q11. Solve (x − 1)/3 < 2.
x − 1 < 6 ⇒ x < 7.
Q12. Solve 1 ≤ 2x + 3 ≤ 7.
Subtract 3: −2 ≤ 2x ≤ 4 ⇒ −1 ≤ x ≤ 2.
Q13. Write x ≥ −2 in interval form.
[−2, ∞).
Q14. Show x < 3 on a number line.
Open circle at 3, arrow to the left.
Q15. Represent x ≤ 1 on a number line.
Filled circle at 1, arrow to the left.
Q16. Solve 6 − 3x ≥ 12.
−3x ≥ 6 ⇒ x ≤ −2.
Q17. Is x = 2 a solution of 3x − 5 > 0?
6 − 5 = 1 > 0 true, so yes.
Q18. Solve graphically x + y ≤ 5.
Draw solid line x + y = 5 through (5,0), (0,5). O satisfies 0 ≤ 5, so shade the side containing O.
Q19. Solve graphically 2x + y > 4.
Dashed line 2x + y = 4 through (2,0), (0,4). O: 0 > 4 false, so shade the side not containing O.
Q20. Why use a dashed line for strict inequality?
Points on the line do not satisfy < or >, so the boundary is excluded.
Q21. MCQ: Solution of −2x < 4? (a)x<−2 (b)x>−2 (c)x<2 (d)x>2
(b) x > −2 (sign reversed).
Q22. MCQ: Interval for −1 < x ≤ 3? (a)[−1,3] (b)(−1,3] (c)(−1,3) (d)[−1,3)
(b) (−1, 3].
Q23. MCQ: Which circle is used for x ≥ 4? (a)open (b)filled (c)none (d)half
(b) filled.
Q24. MCQ: Test point generally used? (a)(1,1) (b)(0,0) (c)(2,2) (d)(3,0)
(b) (0, 0), if it is not on the line.
