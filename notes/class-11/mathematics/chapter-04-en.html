Class 11 Maths - Chapter 5: Complex Numbers and Quadratic Equations

PART A: COMPLEX NUMBERS

1. Need of Complex Numbers

The equation x² + 1 = 0 has no real solution because no real number squares to −1. To solve such equations we extend the number system.

2. Imaginary Unit i

i = √−1, so i² = −1, i³ = −i, i⁴ = 1.
In general iⁿ depends on n mod 4: i4k = 1, i4k+1 = i, i4k+2 = −1, i4k+3 = −i.
Powers of i repeat every 4 steps; multiplying by i rotates by 90°

A complex number is z = a + ib (a, b real). a = Re(z) real part, b = Im(z) imaginary part. If b = 0, z is real; if a = 0 (b≠0), z is purely imaginary. Two complex numbers are equal if real parts and imaginary parts are both equal.

3. Algebra of Complex Numbers

(a+ib) + (c+id) = (a+c) + i(b+d)
(a+ib) − (c+id) = (a−c) + i(b−d)
(a+ib)(c+id) = (ac − bd) + i(ad + bc)
(a+ib)/(c+id) = [(ac + bd) + i(bc − ad)]/(c² + d²) (multiply top and bottom by the conjugate c − id)

Addition and multiplication are commutative, associative and distributive. Additive identity 0, additive inverse −z. Multiplicative identity 1, multiplicative inverse 1/z = z̄/|z|² (z≠0).

4. Argand Plane

The number a + ib is shown as the point (a, b). The x-axis is the real axis, the y-axis is the imaginary axis.

Argand plane: z, its conjugate z̄ (mirror in real axis) and modulus |z|

5. Modulus and Conjugate

Modulus: |z| = √(a² + b²) = distance of z from origin.
Conjugate: z̄ = a − ib (mirror image in real axis).
z z̄ = |z|², z + z̄ = 2a, z − z̄ = 2ib, |z̄| = |z|, conj(z̄) = z.
|z₁z₂| = |z₁||z₂|, |z₁/z₂| = |z₁|/|z₂|, conj(z₁ ± z₂) = z̄₁ ± z̄₂, conj(z₁z₂) = z̄₁z̄₂.

z is real ⇔ z = z̄; z is purely imaginary ⇔ z = −z̄.

6. Square Root of a Complex Number

√(a+ib) = ± [ √((|z|+a)/2) + i·sgn(b)·√((|z|−a)/2) ], where |z| = √(a²+b²) and sgn(b) = +1 if b > 0, −1 if b < 0.

Method 2: put √(a+ib) = x + iy, square, equate real and imaginary parts: x² − y² = a, 2xy = b, and solve.

PART B: QUADRATIC EQUATIONS

7. Fundamental Theorem of Algebra

Every polynomial equation of degree n ≥ 1 has at least one root in the complex numbers, and so exactly n roots (counting repeated roots). So a quadratic always has 2 roots in C.

8. Solution of ax² + bx + c = 0 (a ≠ 0)

x = [−b ± √(b² − 4ac)]/(2a). Discriminant D = b² − 4ac.
Sum of roots = −b/a. Product of roots = c/a.

Real roots

D > 0: two distinct real roots. D = 0: two equal real roots x = −b/2a.

D > 0: parabola cuts x-axis at 2 points (two real roots)
D = 0: touches x-axis (equal real roots)

Complex roots

D < 0: roots x = [−b ± i√(4ac − b²)]/(2a), which are conjugates of each other (for real a, b, c).

D < 0: no contact (two complex roots)

Solved Examples (step by step)

Easy Find i⁵⁷ + i⁷⁰.
Sol. 57 = 4×14 + 1 ⇒ i⁵⁷ = i. 70 = 4×17 + 2 ⇒ i⁷⁰ = −1. Sum = i − 1.
Easy Multiply (2+3i)(4−5i).
Sol. = 8 − 10i + 12i − 15i² = 8 + 2i + 15 = 23 + 2i.
Medium Express (1+2i)/(3−4i) as a + ib.
Sol. Multiply by (3+4i)/(3+4i): numerator = (1+2i)(3+4i) = 3 + 4i + 6i + 8i² = −5 + 10i. Denominator = 9 + 16 = 25. Result = −1/5 + (2/5)i.
Medium Solve x² + 2x + 5 = 0.
Sol. D = 4 − 20 = −16 < 0. x = (−2 ± √−16)/2 = (−2 ± 4i)/2 = −1 ± 2i.
Hard Find the square root of 3 + 4i.
Sol. Let (x+iy)² = 3+4i. Then x² − y² = 3 and 2xy = 4. |z| = 5, so x² + y² = 5. Adding: 2x² = 8, x = ±2. Subtracting: 2y² = 2, y = ±1. 2xy = 4 > 0 so x, y have same sign. Roots: ±(2 + i).
Hard Find real x, y if (x + iy)(2 − 3i) = 4 + i.
Sol. x + iy = (4+i)/(2−3i) = (4+i)(2+3i)/13 = (8 + 12i + 2i + 3i²)/13 = (5 + 14i)/13. So x = 5/13, y = 14/13.
Hard Prove |z₁+z₂|² + |z₁−z₂|² = 2(|z₁|² + |z₂|²).
Proof. |z₁+z₂|² = (z₁+z₂)(z̄₁+z̄₂) = |z₁|² + z₁z̄₂ + z̄₁z₂ + |z₂|². |z₁−z₂|² = |z₁|² − z₁z̄₂ − z̄₁z₂ + |z₂|². Adding, the middle terms cancel: 2|z₁|² + 2|z₂|².
