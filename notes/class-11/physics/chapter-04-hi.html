अदिशसदिश

द्रव्यमान, समय, चाल, दूरी, ऊर्जा, कार्य, ताप, आवेशविस्थापन, वेग, त्वरण, बल, संवेग, बल-आघूर्ण, विद्युत क्षेत्र

4A.2 निरूपण व 4A.3 परिभाषाएँ

सदिश को दिष्ट रेखा से दर्शाते हैं: लंबाई = परिमाण (पैमाने से), तीर = दिशा। लिखते हैं A या A⃗; परिमाण |A| = A। पूँछ = प्रारंभिक बिंदु, शीर्ष = अंतिम बिंदु।

समान सदिश: परिमाण व दिशा समान।
ऋणात्मक सदिश (−A): परिमाण समान, दिशा विपरीत।
मात्रक सदिश: Â = A/|A|, परिमाण 1, केवल दिशा।
शून्य सदिश: परिमाण 0, दिशा नहीं।
संरेख: एक ही/समांतर रेखाओं पर (समांतर या प्रतिसमांतर)। समतलीय: एक तल में। सह-प्रारंभिक: एक ही प्रारंभ बिंदु।
स्थिति सदिश r: मूल बिंदु से बिंदु (x,y,z) तक। विस्थापन सदिश: r₂ − r₁।
मुक्त सदिश: स्वयं के समांतर खिसकाया जा सकता है। स्थानबद्ध: किसी बिंदु से बँधा (बिंदु पर बल)।

4A.4 दो सदिशों का योग – नियम

त्रिभुज नियम

दो सदिश सिर-से-पूँछ जोड़कर त्रिभुज की दो भुजाएँ बनाएँ तो तीसरी भुजा विपरीत क्रम में परिणामी है।

समांतर चतुर्भुज नियम

एक बिंदु से खींचे दो सदिश समांतर चतुर्भुज की संलग्न भुजाएँ हों तो उस बिंदु से जाने वाला विकर्ण परिणामी है।

बहुभुज नियम (दो से अधिक सदिश, 4A.5)

सदिशों को क्रम से सिर-से-पूँछ जोड़ें; पहले की पूँछ से अंतिम के सिर तक रेखा परिणामी है। बहुभुज बंद हो तो परिणामी = 0।

विश्लेषणात्मक विधि (4A.6)

परिमाण: R = √(A² + B² + 2AB cosθ)
दिशा: tanα = B sinθ / (A + B cosθ) (α, A से)
विशेष: θ = 0° → R = A+B (अधिकतम); θ = 90° → R = √(A²+B²); θ = 180° → R = |A−B| (न्यूनतम); समान परिमाण: R = 2A cos(θ/2)।
शर्त: |A−B| ≤ R ≤ A+B।

4A.7 सदिशों का घटाना

A − B = A + (−B)। परिमाण: |A − B| = √(A² + B² − 2AB cosθ), θ = A व B के बीच कोण।

4A.8 सदिश योग के नियम

नियमकथन
क्रम-विनिमेयA + B = B + A
साहचर्य(A + B) + C = A + (B + C)
वितरणm(A + B) = mA + mB

घटाना क्रम-विनिमेय नहीं: A − B ≠ B − A (ये एक-दूसरे के ऋणात्मक हैं)।

4A.10 सदिश का वियोजन (2D)

Aₓ = A cosθ, A_y = A sinθ; A = Aₓî + A_yĵ
|A| = √(Aₓ² + A_y²); θ = tan⁻¹(A_y/Aₓ)।
अनेक सदिशों का परिणामी: Rₓ = ΣAₓ, R_y = ΣA_y → R = √(Rₓ²+R_y²)।
योग: (a₁î+b₁ĵ) + (a₂î+b₂ĵ) = (a₁+a₂)î + (b₁+b₂)ĵ।

4A.11 वियोजन (3D)

A = Aₓî + A_yĵ + A_zk̂; |A| = √(Aₓ²+A_y²+A_z²)।
दिक्-कोज्याएँ: l = cosα = Aₓ/A, m = cosβ = A_y/A, n = cosγ = A_z/A; l² + m² + n² = 1।
(x,y,z) का स्थिति सदिश: r = xî + yĵ + zk̂।

4A.12 अदिश से गुणन

λA का परिमाण |λ|A; λ > 0 पर दिशा A जैसी, λ < 0 पर विपरीत। λ का मात्रक हो तो मात्रक बदलता है (p = mv, F = ma)। λ = 0 → शून्य सदिश।

4A.13 अदिश गुणनफल (डॉट)

A · B = AB cosθ (अदिश), 0 ≤ θ ≤ 180°।
क्रम-विनिमेय A·B = B·A; वितरण A·(B+C) = A·B + A·C।
î·î = ĵ·ĵ = k̂·k̂ = 1; î·ĵ = ĵ·k̂ = k̂·î = 0।
A·B = AₓBₓ + A_yB_y + A_zB_z; A·A = A²।
लंबवत् ⇔ A·B = 0; समांतर: A·B = AB; प्रतिसमांतर: −AB।
कोण: cosθ = A·B / (AB)। B पर A का प्रक्षेप = A·B/B।
उपयोग: कार्य W = F·s; शक्ति P = F·v; फ्लक्स φ = E·A।

4A.14 सदिश गुणनफल (क्रॉस)

A × B = AB sinθ n̂ (सदिश)। दिशा दायाँ-हस्त नियम से (उँगलियाँ A से B घुमाएँ, अँगूठा दिशा) A, B के तल के लंबवत्।
क्रम-विनिमेय नहीं: A × B = − B × A; योग पर वितरण। A × A = 0; समांतर सदिशों पर 0।
î × ĵ = k̂, ĵ × k̂ = î, k̂ × î = ĵ (उल्टे क्रम में −)।
A × B = | î ĵ k̂ ; Aₓ A_y A_z ; Bₓ B_y B_z | (सारणिक)।
समांतर चतुर्भुज का क्षेत्रफल = |A×B|; त्रिभुज = ½|A×B|।
उपयोग: बल-आघूर्ण τ = r × F; कोणीय संवेग L = r × p; v = ω × r; आवेश पर बल F = q(v × B)।

4B.1 समतल में गति

स्थिति: r = xî + yĵ। विस्थापन Δr = r₂ − r₁।
वेग: v = dr/dt = (dx/dt)î + (dy/dt)ĵ = vₓî + v_yĵ, दिशा पथ की स्पर्श रेखा; |v| = √(vₓ²+v_y²), tanθ = v_y/vₓ।
त्वरण: a = dv/dt = aₓî + a_yĵ।
नियत त्वरण: v = u + at; r = r₀ + ut + ½at²; v² − u² = 2a·s (x व y पर अलग-अलग)।
प्रक्षेप्य व वृत्तीय गति विशेष स्थितियाँ हैं (a = −gĵ; अभिकेंद्र)।

4B.2 द्विविमीय आपेक्षिक वेग

vAB = vA − vB (सदिश घटाव)। परिमाण = √(v_A² + v_B² − 2v_Av_B cosθ)।
नाव–नदी: v_परिणामी = v_नाव + v_नदी (सदिश)। न्यूनतम समय: किनारे के लंबवत् खेना। न्यूनतम पथ: धारा के विपरीत sinθ = v_r/v_b।
वर्षा–मनुष्य: v_वर्षा,मनुष्य = v_वर्षा − v_मनुष्य। वर्षा ऊर्ध्वाधर (v_R) व मनुष्य v_m से चले तो आभासी वर्षा ऊर्ध्वाधर से tanθ = v_m/v_R पर आती है (छाता गति की दिशा में झुकाएँ)।
वायु–वायुयान: v_भूमि = v_वायुयान + v_वायु (सदिश)।

कठिन R = √(A²+B²+2AB cosθ) व tanα व्युत्पन्न कीजिए।
माना OP = A, OQ = B, बीच कोण θ, विकर्ण OS = R। OP के बढ़ाव पर SN ⊥ खींचें। △PSN में: PN = B cosθ, SN = B sinθ। △OSN में: OS² = ON² + SN² = (A + B cosθ)² + (B sinθ)² = A² + 2AB cosθ + B²(cos²θ+sin²θ) → R² = A²+B²+2AB cosθ ∎। tanα = SN/ON = B sinθ/(A + B cosθ) ∎।
कठिन यदि |A+B| = |A−B| तो सिद्ध कीजिए A ⊥ B।
वर्ग करने पर: A²+B²+2A·B = A²+B²−2A·B → 4A·B = 0 → A·B = 0 → cosθ = 0 → θ = 90° ∎।
कठिन सिद्ध कीजिए A·(A×B) = 0।
A×B, A के लंबवत् है, अतः कोण 90° → A·(A×B) = A|A×B|cos90° = 0 ∎। (सारणिक जाँच: Aₓ(A_yB_z−A_zB_y) − A_y(AₓB_z−A_zBₓ) + A_z(AₓB_y−A_yBₓ) = 0।)
कठिन λ ज्ञात कीजिए ताकि A = 2î+λĵ+k̂ ⊥ B = 4î−2ĵ−2k̂।
A·B = 8 − 2λ − 2 = 0 → 6 = 2λ → λ = 3।

दायाँ-हस्त नियम: A→B घुमाने पर अँगूठा ऊपर, B→A पर नीचे, परिमाण समान AB sinθ → A×B = −B×A ∎। समांतर चतुर्भुज का क्षेत्रफल = आधार × ऊँचाई = A(B sinθ) = |A×B|; त्रिभुज उसका आधा → ½|A×B| ∎।

लघु व दीर्घ प्रश्नोत्तर

प्र1. धारा में दिशा होने पर भी वह सदिश क्यों नहीं?
उ: यह सदिश योग (समांतर चतुर्भुज) नियम का पालन नहीं करती; धाराएँ बीजगणितीय रूप से जुड़ती हैं।
प्र2. क्या दो सदिशों का परिणामी दोनों से छोटा हो सकता है?
उ: हाँ, जैसे A व B प्रतिसमांतर हों: R = |A−B|।
प्र3. शून्य सदिश क्या है? उदाहरण?
उ: शून्य परिमाण वाला सदिश; जैसे पूरे चक्कर के बाद विस्थापन, A − A।
प्र4. क्या शून्य परिमाण वाले सदिश के घटक अशून्य हो सकते हैं?
उ: नहीं; |A| = √(Aₓ²+A_y²+A_z²) = 0 तभी जब सभी घटक 0 हों।
प्र5. A·B = 0 व A×B = 0 की शर्तें?
उ: A·B = 0 जब लंबवत् (या कोई शून्य); A×B = 0 जब समांतर/प्रतिसमांतर (या कोई शून्य)।
प्र6. क्या A×B = B×A? क्यों?
उ: नहीं; क्रॉस गुणनफल प्रति-क्रमविनिमेय है, दिशा उलट जाती है।
प्र7. कार्य अदिश पर बल-आघूर्ण सदिश क्यों?
उ: कार्य = F·s (डॉट); बल-आघूर्ण = r×F (क्रॉस)।
प्र8. |A| = |B| हो तो A+B व A−B के बीच कोण?
उ: (A+B)·(A−B) = A²−B² = 0 → 90°।
प्र9. चलते मनुष्य को वर्षा तिरछी क्यों दिखती है?
उ: आभासी वेग v_r − v_m में मनुष्य के वेग के विपरीत क्षैतिज घटक आ जाता है।
प्र10. (दीर्घ) समांतर चतुर्भुज नियम (परिमाण व दिशा) लिखकर सिद्ध कीजिए।
उ: कठिन उदाहरण 1 चित्र सहित देखें।
प्र11. (दीर्घ) डॉट व क्रॉस गुणनफल – परिभाषा, गुण, उपयोग।
उ: 4A.13 व 4A.14 देखें; सूत्र, मात्रक-सदिश सारणी व उदाहरण लिखें।
प्र12. (दीर्घ) सदिश वियोजन समझाइए व उपयोग लिखिए।
उ: 4A.10 देखें; उपयोग: नत समतल पर बल, प्रक्षेप्य के घटक।
