कक्षा 11 रसायन विज्ञान — अध्याय 7: रेडॉक्स अभिक्रियाएँ

हाथ से लिखे जैसे नोट्स (यूपी बोर्ड / NCERT पैटर्न)। आसान, मध्यम, कठिन।

1. ऑक्सीकरण एवं अपचयन

परंपरागत: ऑक्सीकरण = ऑक्सीजन/विद्युत ऋणात्मक तत्व का योग, या हाइड्रोजन/विद्युत धनात्मक तत्व का निष्कासन (2Mg + O₂ → 2MgO)। अपचयन = इसका उलटा।
इलेक्ट्रॉनिक: ऑक्सीकरण = इलेक्ट्रॉन त्यागना; अपचयन = इलेक्ट्रॉन ग्रहण करना। Zn → Zn²⁺ + 2e⁻ (ऑक्सीकरण); Cu²⁺ + 2e⁻ → Cu (अपचयन)।
ऑक्सीकारक इलेक्ट्रॉन ग्रहण करता है (स्वयं अपचयित); अपचायक इलेक्ट्रॉन त्यागता है (स्वयं ऑक्सीकृत)। दोनों साथ-साथ होते हैं — अतः रेडॉक्स।

2. ऑक्सीकरण संख्या एवं नियम

ऑक्सीकरण संख्या = परमाणु का काल्पनिक आवेश यदि सभी आबंध आयनिक होते। वृद्धि = ऑक्सीकरण; कमी = अपचयन।

  1. मुक्त तत्व (Na, O₂, S₈) = 0। 2. एकपरमाणुक आयन = उसका आवेश। 3. F सदैव −1। 4. O = −2 (अपवाद: परऑक्साइड H₂O₂ में −1, सुपरऑक्साइड KO₂ में −½, OF₂ में +2)। 5. H = +1 (धातु हाइड्राइड NaH में −1)। 6. वर्ग 1 = +1, वर्ग 2 = +2, Al = +3। 7. उदासीन अणु में योग = 0, आयन में = आवेश। 8. हैलोजन प्रायः −1। 9. भिन्नात्मक (औसत) हो सकती है: Fe₃O₄ = +8/3; S₄O₆²⁻ = +2.5।

3. रेडॉक्स अभिक्रियाओं के प्रकार

संयोग (C + O₂ → CO₂), अपघटन (2H₂O → 2H₂ + O₂), विस्थापन (Zn + CuSO₄; Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂), असमानुपातन (एक ही स्पीशीज़ ऑक्सीकृत व अपचयित: 2H₂O₂ → 2H₂O + O₂; Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O)। द्विविस्थापन (NaCl + AgNO₃) रेडॉक्स नहीं। धातु क्रियाशीलता: विद्युत रासायनिक श्रेणी।

4. रेडॉक्स अभिक्रियाओं का संतुलन

(क) ऑक्सीकरण संख्या विधि

(1) अस्थि-समीकरण लिखें। (2) ऑक्सीकरण संख्याएँ व परिवर्तन ज्ञात करें। (3) कुल वृद्धि = कुल कमी करें। (4) शेष परमाणु संतुलित करें: O के लिए H₂O, H के लिए H⁺ (या OH⁻)। (5) परमाणु व आवेश जाँचें।

उदा. Cu + HNO₃(तनु) → Cu(NO₃)₂ + NO + H₂O। Cu: 0 → +2 (वृद्धि 2)। N: +5 → +2 (कमी 3)। LCM 6: 3 Cu, 2 NO। कुल N = 3×2 + 2 = 8 HNO₃; 8 H → 4 H₂O। 3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 2NO + 4H₂O। O जाँच: 24 = 18 + 2 + 4 ✓।

(ख) इलेक्ट्रॉन स्थानांतरण (आयन–इलेक्ट्रॉन / अर्ध-अभिक्रिया) विधि

(1) ऑक्सीकरण व अपचयन अर्ध-अभिक्रियाएँ अलग करें। (2) H, O के अतिरिक्त परमाणु संतुलित करें। (3) O हेतु H₂O। (4) H हेतु H⁺ (अम्लीय) या दोनों ओर H⁺ के बराबर OH⁻ (क्षारीय)। (5) आवेश इलेक्ट्रॉन से संतुलित करें। (6) इलेक्ट्रॉन बराबर करके जोड़ें।

उदा. (अम्लीय) MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺। अपचयन: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O। ऑक्सीकरण: Fe²⁺ → Fe³⁺ + e⁻ (×5)। जोड़ने पर: MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O।

5. रेडॉक्स अभिक्रियाओं के अनुप्रयोग

दहन व श्वसन (ऊर्जा मुक्ति); प्रकाश संश्लेषण (CO₂ का अपचयन); बैटरी व ईंधन सेल; संक्षारण (लोहे में जंग) व रोकथाम (जस्तीकरण, पेंट); धातु निष्कर्षण (अयस्क का अपचयन); विरंजन; विद्युत लेपन; रेडॉक्स अनुमापन (KMnO₄, K₂Cr₂O₇); फोटोग्राफी; औद्योगिक निर्माण (NH₃, HNO₃)।

6. हल किए गए numerical

आसान। KMnO₄ में Mn की ऑक्सीकरण संख्या।
K = +1, O = −2। +1 + x − 8 = 0 → x = +7।
मध्यम। K₂Cr₂O₇ में Cr तथा S₄O₆²⁻ में S की ऑक्सीकरण संख्या।
(a) 2(+1) + 2x − 14 = 0 → Cr = +6। (b) 4x − 12 = −2 → S = +2.5 (औसत)।
कठिन। क्षारीय माध्यम में संतुलित करें: MnO₄⁻ + I⁻ → MnO₂ + I₂।
अपचयन: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻। ऑक्सीकरण: 2I⁻ → I₂ + 2e⁻। ×2 व ×3 → 6e⁻। जोड़ने पर: 2MnO₄⁻ + 6I⁻ + 4H₂O → 2MnO₂ + 3I₂ + 8OH⁻। जाँच: आवेश −8 = −8; O 12 = 12; H 8 = 8 ✓।

7. प्रश्नोत्तर

Q1. इलेक्ट्रॉन के आधार पर ऑक्सीकरण व अपचयन परिभाषित कीजिए।
ऑक्सीकरण: इलेक्ट्रॉन त्यागना; अपचयन: इलेक्ट्रॉन ग्रहण करना।
Q2. असमानुपातन अभिक्रिया क्या है? उदाहरण दीजिए।
एक ही तत्व एक साथ ऑक्सीकृत व अपचयित: 2H₂O₂ → 2H₂O + O₂ (O: −1 → −2 व 0)।
Q3. H₂O₂ व OF₂ में O की ऑक्सीकरण संख्या?
−1 तथा +2।
Q4. Zn, Cu से अच्छा अपचायक क्यों?
Zn इलेक्ट्रॉन अधिक आसानी से त्यागता है (विद्युत रासायनिक श्रेणी में ऊपर)।
Q5. क्या NaCl + AgNO₃ → AgCl + NaNO₃ रेडॉक्स है?
नहीं; किसी की ऑक्सीकरण संख्या नहीं बदलती।
Q6. दीर्घ: ऑक्सीकरण संख्या विधि के चरण उदाहरण सहित।
खंड 4(क): Cu + तनु HNO₃ — संख्या ज्ञात करें, वृद्धि = कमी करें, परमाणु संतुलित करें, जाँचें।
Q7. दीर्घ: अम्लीय माध्यम में MnO₄⁻ + Fe²⁺ अर्ध-अभिक्रिया विधि से संतुलित कीजिए।
खंड 4(ख): अंतिम समीकरण MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O।
Q8. MCQ: H₂SO₄ में S की ऑक्सीकरण संख्या? (a) +2 (b) +4 (c) +6 (d) −2
(c) +6: 2 + x − 8 = 0।
Q9. MCQ: अपचायक कौन है? (a) KMnO₄ (b) Zn (c) K₂Cr₂O₇ (d) HNO₃
(b) Zn।
Q10. MCQ: Mn की उच्चतम ऑक्सीकरण संख्या? (a) +4 (b) +5 (c) +6 (d) +7
(d) +7 (KMnO₄)।
