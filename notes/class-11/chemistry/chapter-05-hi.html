कक्षा 11 रसायन विज्ञान — अध्याय 5: ऊष्मागतिकी

हाथ से लिखे जैसे नोट्स (यूपी बोर्ड / NCERT पैटर्न)। आसान, मध्यम, कठिन।

1. निकाय, परिवेश एवं निकाय के प्रकार

निकाय = ब्रह्मांड का अध्ययनाधीन भाग; परिवेश = शेष ब्रह्मांड; सीमा दोनों को अलग करती है। खुला: द्रव्य व ऊर्जा दोनों का विनिमय (खुला बीकर)। बंद: केवल ऊर्जा (कॉर्क लगा फ्लास्क)। विलगित: कोई विनिमय नहीं (थर्मस, आदर्श)।

2. गुण एवं अवस्था फलन

विस्तीर्ण गुण मात्रा पर निर्भर (द्रव्यमान, आयतन, U, H, S, G)। गहन गुण नहीं (T, p, घनत्व, सांद्रता)। दो विस्तीर्ण गुणों का अनुपात गहन होता है। अवस्था फलन: मान केवल प्रारंभिक व अंतिम अवस्था पर निर्भर, पथ पर नहीं (U, H, S, G, p, V, T)। ऊष्मा q तथा कार्य w पथ फलन हैं।

3. कार्य, ऊष्मा एवं आंतरिक ऊर्जा

ऊष्मा (q): ताप-अंतर के कारण ऊर्जा स्थानांतरण। कार्य (w): दाब–आयतन कार्य w = −pext ΔV। IUPAC चिह्न: निकाय द्वारा ऊष्मा अवशोषित +q, निकाय पर कार्य +w। मुक्त प्रसार में w = 0। समतापीय उत्क्रमणीय प्रसार: w = −2.303 nRT log(V₂/V₁)। आंतरिक ऊर्जा U = निकाय की कुल ऊर्जा (अवस्था फलन)।

प्रथम नियम: ऊर्जा न उत्पन्न होती है न नष्ट। ΔU = q + w। समतापीय आदर्श गैस: ΔU = 0 → q = −w। रुद्धोष्म: ΔU = w। स्थिर आयतन: ΔU = qv।

4. एन्थैल्पी, ऊष्माधारिता एवं मापन

एन्थैल्पी H = U + pV; स्थिर दाब पर ΔH = qp। ΔH = ΔU + ΔngRT (R = 8.314 J/mol K)। ऊष्माक्षेपी ΔH < 0; ऊष्माशोषी ΔH > 0।
ऊष्माधारिता C = q/ΔT। विशिष्ट ऊष्मा c = q/(mΔT) (जल 4.18 J/g K)। मोलर: Cp − Cv = R।
ΔU मापन: बम कैलोरीमीटर (स्थिर आयतन)। ΔH मापन: खुला (स्थिर दाब) कैलोरीमीटर।

5. हेस का नियम एवं एन्थैल्पी के प्रकार

हेस का नियम: अभिक्रिया की कुल एन्थैल्पी परिवर्तन एक चरण में हो या कई चरणों में, समान रहता है (H अवस्था फलन है)।

मानक विरचन एन्थैल्पी ΔfH°: तत्वों से 1 मोल यौगिक बनना (तत्वों के लिए शून्य)। ΔrH° = ΣΔfH°(उत्पाद) − ΣΔfH°(अभिकारक)। दहन ΔcH°: 1 मोल का O₂ में पूर्ण दहन (सदैव ऋणात्मक)। परमाणुकरण ΔaH°: 1 मोल गैसीय परमाणु बनना (CH₄(g) → C(g) + 4H(g))। आबंध वियोजन एन्थैल्पी: गैस में 1 मोल आबंध टूटना (सदैव धनात्मक)। ऊर्ध्वपातन: ठोस → गैस (ΔsubH = ΔfusH + ΔvapH)। प्रावस्था परिवर्तन: बर्फ का गलन 6.01 kJ/mol, जल का वाष्पन 40.79 kJ/mol। आयनन: ΔiH। तनुकरण: विलयन में और विलायक मिलाने पर एन्थैल्पी परिवर्तन; प्रबल अम्ल–क्षार उदासीनीकरण ≈ −57.1 kJ/mol।

6. एन्ट्रॉपी एवं द्वितीय नियम

एन्ट्रॉपी S = अव्यवस्था की माप (अवस्था फलन, विस्तीर्ण)। ΔS = qrev/T (J/K)। बढ़ती है: ठोस < द्रव < गैस, विलयन बनने, गर्म करने, Δng > 0 पर। द्वितीय नियम: स्वतः प्रक्रम में ब्रह्मांड की एन्ट्रॉपी बढ़ती है: ΔSकुल = ΔSनिकाय + ΔSपरिवेश > 0; ऊष्मा स्वतः ठंडे से गर्म की ओर नहीं बहती।

7. स्वतःप्रवर्तिता एवं गिब्स मुक्त ऊर्जा

स्वतःप्रवर्तित: अपने आप होने वाला (0°C से ऊपर बर्फ का गलना)। अस्वतःप्रवर्तित: बाह्य ऊर्जा चाहिए। G = H − TS; ΔG = ΔH − TΔS। ΔG < 0 स्वतः, = 0 साम्य, > 0 अस्वतः। ΔG° = −2.303 RT log K = −nFE°।

8. तृतीय नियम

परम शून्य (0 K) पर पूर्ण क्रिस्टलीय पदार्थ की एन्ट्रॉपी शून्य होती है। इससे निरपेक्ष एन्ट्रॉपी ज्ञात होती है।

9. हल किए गए numerical

आसान। निकाय 500 J ऊष्मा अवशोषित करता है और 200 J कार्य करता है। ΔU ज्ञात करें।
q = +500 J; निकाय द्वारा कार्य → w = −200 J। ΔU = 500 − 200 = +300 J।
मध्यम (ΔH → ΔU)। N₂ + 3H₂ → 2NH₃, ΔH = −92.4 kJ (298 K)। ΔU ज्ञात करें।
Δng = 2 − 4 = −2। ΔU = ΔH − ΔngRT = −92.4 + 2 × 8.314×10⁻³ × 298 = −92.4 + 4.96 = −87.4 kJ।
मध्यम (हेस)। C + O₂ → CO₂ (−393.5) तथा CO + ½O₂ → CO₂ (−283.0) से C + ½O₂ → CO का ΔH ज्ञात करें।
पहली रखें; दूसरी उलटें: CO₂ → CO + ½O₂ (+283.0)। जोड़ने पर C + ½O₂ → CO। ΔH = −393.5 + 283.0 = −110.5 kJ।
कठिन। CaCO₃ → CaO + CO₂: ΔH = +178.3 kJ, ΔS = +160.5 J/K। 298 K पर ΔG तथा स्वतः होने का न्यूनतम ताप ज्ञात करें।
ΔG = 178.3 − 298 × 0.1605 = 178.3 − 47.8 = +130.5 kJ (अस्वतः)। ΔG < 0 हेतु T > ΔH/ΔS = 178300/160.5 = ≈ 1111 K।

10. प्रश्नोत्तर

Q1. अवस्था फलन उदाहरण सहित परिभाषित कीजिए।
वह गुण जो केवल प्रारंभिक व अंतिम अवस्था पर निर्भर करे: U, H, S, G।
Q2. विस्तीर्ण व गहन गुणों में अंतर।
विस्तीर्ण मात्रा पर निर्भर (द्रव्यमान, V); गहन नहीं (T, घनत्व)।
Q3. ऊष्मागतिकी का प्रथम नियम लिखिए।
विलगित निकाय की ऊर्जा स्थिर रहती है; ΔU = q + w।
Q4. Δng = 0 पर ΔH = ΔU क्यों?
ΔH = ΔU + ΔngRT; दूसरा पद शून्य हो जाता है।
Q5. हेस का नियम व उपयोग लिखिए।
एन्थैल्पी परिवर्तन पथ-स्वतंत्र; ऐसी अभिक्रियाओं का ΔH ज्ञात करने में जो सीधे नहीं मापी जा सकतीं (C → CO)।
Q6. दीर्घ: ΔH = ΔU + ΔngRT व्युत्पन्न कीजिए।
H = U + pV, अतः ΔH = ΔU + pΔV; आदर्श गैस के लिए pΔV = ΔngRT; अतः ΔH = ΔU + ΔngRT।
Q7. दीर्घ: ΔH, ΔS व ΔG द्वारा स्वतःप्रवर्तिता समझाइए।
ΔG = ΔH − TΔS। चारों स्थितियाँ: (−,+) सदैव स्वतः; (+,−) कभी नहीं; (−,−) निम्न T; (+,+) उच्च T।
Q8. MCQ: कौन अवस्था फलन नहीं? (a) H (b) U (c) q (d) S
(c) q।
Q9. MCQ: एन्ट्रॉपी बढ़ती है (a) जमने (b) संघनन (c) वाष्पन (d) क्रिस्टलन में
(c) वाष्पन।
Q10. MCQ: ΔG < 0 का अर्थ (a) अस्वतः (b) साम्य (c) स्वतः (d) असंभव
(c) स्वतःप्रवर्तित।
