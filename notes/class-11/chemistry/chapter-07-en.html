Class 11 Chemistry — Chapter 7: Redox Reactions

Handwritten-style notes (UP Board / NCERT pattern). Easy, Medium, Hard.

1. Oxidation and Reduction

Classical: oxidation = addition of oxygen / electronegative element, or removal of hydrogen / electropositive element (2Mg + O₂ → 2MgO; H₂S + Cl₂ → 2HCl + S). Reduction = the reverse.
Electronic: Oxidation = loss of electrons; Reduction = gain of electrons (OIL RIG). Zn → Zn²⁺ + 2e⁻ (oxidation); Cu²⁺ + 2e⁻ → Cu (reduction).
Oxidant (oxidising agent) gains electrons (is reduced); reductant loses electrons (is oxidised). Oxidation and reduction always occur together — hence redox.

2. Oxidation Number and its Rules

Oxidation number (state) = hypothetical charge an atom would have if all bonds were ionic. Increase = oxidation; decrease = reduction.

  1. Free element (Na, O₂, S₈) = 0. 2. Monatomic ion = its charge. 3. F is always −1. 4. O = −2 (exceptions: −1 in peroxides H₂O₂, −½ in superoxides KO₂, +2 in OF₂). 5. H = +1 (−1 in metal hydrides NaH). 6. Group 1 = +1, Group 2 = +2, Al = +3. 7. Sum = 0 in neutral molecule, = charge in an ion. 8. Halogens usually −1 (positive when bonded to O/F). 9. Can be fractional (average): Fe₃O₄ = +8/3; S₄O₆²⁻ = +2.5.

3. Types of Redox Reactions

Combination (C + O₂ → CO₂), decomposition (2H₂O → 2H₂ + O₂; not all decompositions), displacement (metal or non-metal: Zn + CuSO₄; Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂), disproportionation (same species oxidised and reduced: 2H₂O₂ → 2H₂O + O₂; Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O), comproportionation. Double displacement (NaCl + AgNO₃) is not redox. Reactivity of metals: electrochemical series (Zn displaces Cu, Cu cannot displace Zn).

4. Balancing Redox Reactions

(a) Oxidation Number Method

(1) Write skeleton equation. (2) Assign oxidation numbers, find changes. (3) Equalise total increase and decrease by multiplying. (4) Balance remaining atoms, first other atoms, then O with H₂O, and H with H⁺ (or OH⁻). (5) Check atoms and charge.

Eg. Cu + HNO₃(dil) → Cu(NO₃)₂ + NO + H₂O. Cu: 0 → +2 (increase 2). N: +5 → +2 (decrease 3). LCM 6: 3 Cu, 2 NO. N total = 3×2 (nitrate) + 2 = 8 HNO₃; 8 H → 4 H₂O. 3Cu + 8HNO₃ → 3Cu(NO₃)₂ + 2NO + 4H₂O. O check: 24 = 18 + 2 + 4 ✓.

(b) Electron Transfer (Ion–Electron / Half-Reaction) Method

(1) Split into oxidation and reduction half-reactions. (2) Balance atoms other than H, O. (3) Balance O with H₂O. (4) Balance H with H⁺ (acidic) or add OH⁻ equal to H⁺ on both sides (basic). (5) Balance charge with electrons. (6) Multiply so electrons equal; add and cancel.

Eg. (acidic) MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺. Reduction: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O. Oxidation: Fe²⁺ → Fe³⁺ + e⁻ (×5). Add: MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O.

5. Applications of Redox Reactions

Combustion and respiration (energy release); photosynthesis (reduction of CO₂); batteries and fuel cells; corrosion (rusting of Fe) and its prevention (galvanising, painting); extraction of metals (reduction of ores); bleaching; electroplating; redox titrations (KMnO₄ with Fe²⁺ or oxalic acid, K₂Cr₂O₇); photography; industrial manufacture (NH₃ via Haber, HNO₃).

6. Solved Numericals

Easy. Find oxidation number of Mn in KMnO₄.
K = +1, O = −2. +1 + x + 4(−2) = 0 → x = +7.
Medium. Oxidation number of Cr in K₂Cr₂O₇ and S in S₄O₆²⁻.
(a) 2(+1) + 2x + 7(−2) = 0 → 2x = 12 → Cr = +6. (b) 4x + 6(−2) = −2 → 4x = 10 → S = +2.5 (average).
Hard. Balance in basic medium: MnO₄⁻ + I⁻ → MnO₂ + I₂.
Reduction: MnO₄⁻ + 2H₂O + 3e⁻ → MnO₂ + 4OH⁻ (acidic form MnO₄⁻ + 4H⁺ + 3e⁻ → MnO₂ + 2H₂O, then add 4OH⁻ both sides). Oxidation: 2I⁻ → I₂ + 2e⁻. Multiply ×2 and ×3 → 6e⁻ each. Add: 2MnO₄⁻ + 6I⁻ + 4H₂O → 2MnO₂ + 3I₂ + 8OH⁻. Check: charge −8 = −8; O 12 = 12; H 8 = 8 ✓.

7. Questions & Answers

Q1. Define oxidation and reduction in terms of electrons.
Oxidation: loss of electrons; reduction: gain of electrons.
Q2. What is a disproportionation reaction? Give example.
Same element simultaneously oxidised and reduced: 2H₂O₂ → 2H₂O + O₂ (O: −1 → −2 and 0).
Q3. Oxidation number of O in H₂O₂ and OF₂?
−1 and +2.
Q4. Why is Zn a better reductant than Cu?
Zn loses electrons more easily (higher in the electrochemical series).
Q5. Is the reaction NaCl + AgNO₃ → AgCl + NaNO₃ redox?
No; no oxidation number changes.
Q6. Long: Explain steps of oxidation number method with example.
See section 4(a), Cu + dil. HNO₃: assign numbers, equalise increase and decrease, balance atoms, check.
Q7. Long: Balance MnO₄⁻ + Fe²⁺ in acidic medium by half-reaction method.
See section 4(b): 5 electrons balance one electron; final equation MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O.
Q8. MCQ: Oxidation number of S in H₂SO₄? (a) +2 (b) +4 (c) +6 (d) −2
(c) +6: 2 + x − 8 = 0.
Q9. MCQ: Which is a reducing agent? (a) KMnO₄ (b) Zn (c) K₂Cr₂O₇ (d) HNO₃
(b) Zn.
Q10. MCQ: Highest oxidation number of Mn? (a) +4 (b) +5 (c) +6 (d) +7
(d) +7 (KMnO₄).
