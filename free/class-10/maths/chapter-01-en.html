1. Real Numbers

Factor tree of 12 = 2 × 2 × 3

HCF and LCM relation

HCF(a,b) × LCM(a,b) = a × b

e.g. HCF = 2, LCM = 4 → product of numbers = 8.

Fundamental Theorem of Arithmetic

Every composite number can be written as a product of primes, and this factorisation is unique apart from the order of the prime factors. e.g. 230 = 2 × 5 × 23.

HCF / LCM

HCF: product of common prime factors with smallest power (HCF(2,4)=2). LCM: product of all prime factors with greatest power (LCM(4,2)=4).

Rational / Irrational

Rational: can be written as p/q, p and q co-prime integers, q ≠ 0. Irrational: cannot, e.g. √2, √5, 0.101101110…

Theorems

1. If prime P divides a², then P divides a (a positive integer). 2. √2 is irrational.

Coprime integers: pair with HCF 1, e.g. (1,3). Prime factorisation method: express numbers as a product of primes.

2. Polynomials

p(x) = –x + 3 cuts the x-axis at its zero.

A polynomial in x has the form p(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀where n is a non-negative integer and a₀…aₙ are constants (coefficients).

Types

Linear (degree 1): ax + b, a ≠ 0, e.g. 5x + 4.
Quadratic (degree 2): ax² + bx + c, a ≠ 0, e.g. 5x² + 8x + 3.
Cubic (degree 3): ax³ + bx² + cx + d, a ≠ 0, e.g. 5x³ + x² + 25x + 5.

Degree: highest power of x. e.g. y² – 5y + 7 has degree 2.

Zero: k is a zero of p(x) if p(k) = 0. e.g. p(x) = –x + 3 → p(3) = 0, so 3 is a zero.

Value at a point: put x = α in p(x) to get p(α).

Forming a quadratic from zeroes α, β

x² – (α + β)x + αβ

3. Pair of Linear Equations in Two Variables

General form: a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0

e.g. x = 2, y = 3 solves 2x + 3y – 13 = 0 and 4x – 5y + 7 = 0.

Substitution method

Express one variable in terms of the other from one equation, substitute in the other. Solve x + y = 3, x + 2y = 5: x = 3 – y → 3 – y + 2y = 5 → y = 2, x = 1.

Elimination method

Make the coefficients of one variable equal, then subtract. Solve x + 2y = 6, x + y = 5: multiply second by 2 → 2x + 2y = 10; subtract first → x = 4; then y = 1.

4. Quadratic Equations

Standard form: ax² + bx + c = 0, a ≠ 0e.g. 3x² + 5x + 2 = 0.

Roots

1. To check a value α: put x = α; if P(α) = 0 it is a root.
2. To find an unknown constant: substitute the given root and simplify.

Factorisation

Find ac, split it as p × q with p + q = b, rewrite bx = px + qx, factorise the LHS into two linear factors and equate each to zero.

Quadratic formula

x = (–b ± √(b² – 4ac)) / 2a = (–b ± √D) / 2a

D = b² – 4ac is the discriminant.

Nature of roots

D = 0: two equal real roots, x = –b/2a.
D > 0: two distinct real roots.
D < 0: √D is not real, so no real roots.

To test if an equation is quadratic, simplify it and compare with ax² + bx + c = 0, a ≠ 0.

5. Arithmetic Progression (AP)

Each term grows by the same common difference d.

Sequence: numbers in a definite order by a rule, e.g. 2, 4, 6, 8…
AP: each term is the previous term plus a fixed number, e.g. 3, 8, 13, 18, 23… (add 5).

Common difference: d = a₂ – a₁ = a₃ – a₂ = a₄ – a₃ = …Terms: a₁ = a, a₂ = a + d, a₃ = a + 2d …

nth term

aₙ = a + (n – 1)d (last term l = aₙ)

nth term from the end

l – (n – 1)d

Sum of first n terms

Sₙ = (n/2)[2a + (n – 1)d] = (n/2)(a + aₙ) = (n/2)(a + l)

6. Triangles

DE ∥ BC slides but AD/DB = AE/EC always holds.

Similar triangles: corresponding angles are equal or corresponding sides are in the same ratio.

Basic Proportionality Theorem (Thales)

In ΔABC, if DE ∥ BC meets AB at D and AC at E:

AD/DB = AE/EC

Similarity criteria

AAA: ∠A = ∠D, ∠B = ∠E, ∠C = ∠F ⇒ AB/DE = AC/DF = BC/EF and ΔABC ~ ΔDEF.

SSS: AB/DE = BC/EF = CA/FD ⇒ corresponding angles equal, ΔABC ~ ΔDEF.

SAS: AB/DE = AC/DF and ∠A = ∠D ⇒ ΔABC ~ ΔDEF.

7. Coordinate Geometry

P divides AB internally in the ratio m₁ : m₂.

Distance formula

PQ = √[(x₂ – x₁)² + (y₂ – y₁)²]

i.e. √[(difference of abscissas)² + (difference of ordinates)²].

Problems on distance

Collinearity: find AB, BC, CA; if the sum of the two shorter lengths equals the longest (AB + BC = AC), the points are collinear.
Equidistant point X: take AX = BX and simplify.

Section formula (internal division)

AP : BP = m₁ : m₂, then

P = ( (m₁x₂ + m₂x₁)/(m₁ + m₂) , (m₁y₂ + m₂y₁)/(m₁ + m₂) )

Problems on section formula

I. Collinearity: assume C divides AB in k : 1, write C's coordinates and equate to the given ones; same k from both ⇒ collinear.
II. Section ratio/point: when an axis divides a segment, use the formula to find the ratio and point.
III. Unknown vertex: use the figure's properties (parallelogram, triangle, circle) with the section formula.

9. Circles

Tangent (red) stays perpendicular to the radius (blue) at the point of contact.

Tangent: a line that touches the circle at only one point, the point of contact.

Length of tangent: the segment of the tangent between the external point and the point of contact.

Number of tangents from a point P

(i) P outside: two tangents. (ii) P on the circle: exactly one. (iii) P inside: none.

Theorem

The tangent at any point of a circle is perpendicular to the radius through the point of contact: OP ⊥ AB.

10. Areas Related to Circles

Segment: region bounded by a chord and its arc (minor segment holds the minor arc, major segment the major arc).
Sector: region enclosed by two radii and the arc (minor sector / major sector).

Area of sector = (θ/360°) × πr²
Length of arc l = (θ/360°) × 2πr
Area of sector in terms of arc = ½ lr

Area of segment

= Area of corresponding sector – area of the triangle formed by the chord and radii.

Area of major segment = πr² – area of minor segment.
Area of major sector = πr² – area of minor sector.

11. Statistics

Mean

Sum of all observations divided by the number of observations.

x̄ = (x₁ + x₂ + … + xₙ)/n = Σxᵢ/n
With frequencies: x̄ = Σfᵢxᵢ / Σfᵢ

Assumed mean method

For large xᵢ, fᵢ choose assumed mean a, dᵢ = xᵢ – a:

x̄ = a + Σfᵢdᵢ / Σfᵢ

Step deviation method

When every dᵢ is a multiple of class size h, uᵢ = dᵢ/h = (xᵢ – a)/h:

x̄ = a + (Σfᵢuᵢ / Σfᵢ) × h

Mode of grouped data

First find the class with the maximum frequency (modal class).

Mode = l + [(f₁ – f₀) / (2f₁ – f₀ – f₂)] × h

l = lower limit of modal class, h = class size, f₁ = frequency of modal class, f₀ = frequency of the preceding class, f₂ = frequency of the succeeding class.

12. Probability

123456

Rolling a die…

Experiments

Random: repeated under identical conditions it does not give the same outcome every time; each trial gives one of several possible outcomes.
Deterministic: repeated under identical conditions it always gives the same outcome.

Event (E): collection of some outcomes, e.g. an odd number on a die = {1, 3, 5}.
Elementary event: only one outcome, e.g. Head (H) or Tail (T).
Occurrence: E occurs if the trial's outcome favours E (rolling 4 means "even number" occurred).
Complement Ē: occurs if and only if E does not. E = {2, 4, 6} ⇒ Ē = {1, 3, 5}.

Experimental approach

P(E) = Number of trials in which the event happened / Total number of trials

Theoretical approach

It has limits, as repeating the experiment is not possible in every situation.
