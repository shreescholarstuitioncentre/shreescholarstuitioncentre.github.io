1. वास्तविक संख्याएँ

12 का गुणनखंड वृक्ष: 12 = 2 × 2 × 3

HCF और LCM का संबंध

HCF(a,b) × LCM(a,b) = a × b

उदा. HCF = 2, LCM = 4 हो तो संख्याओं का गुणनफल = 2 × 4 = 8।

अंकगणित की आधारभूत प्रमेय

प्रत्येक भाज्य संख्या को अभाज्य संख्याओं के गुणनफल के रूप में लिखा जा सकता है, और यह गुणनखंडन अद्वितीय होता है (केवल क्रम बदल सकता है)। उदा. 230 = 2 × 5 × 23।

HCF / LCM

HCF: उभयनिष्ठ अभाज्य गुणनखंडों का उनकी सबसे छोटी घात सहित गुणनफल (HCF(2,4)=2)। LCM: सभी अभाज्य गुणनखंडों का उनकी सबसे बड़ी घात सहित गुणनफल (LCM(4,2)=4)।

परिमेय / अपरिमेय संख्याएँ

परिमेय: जो p/q के रूप में लिखी जा सके, जहाँ p, q सह-अभाज्य पूर्णांक हैं और q ≠ 0। अपरिमेय: जो इस रूप में न लिखी जा सके, उदा. √2, √5, 0.101101110…

प्रमेयें

1. यदि अभाज्य संख्या P, a² को विभाजित करती है, तो P, a को भी विभाजित करती है (a धनात्मक पूर्णांक)। 2. √2 अपरिमेय है।

सह-अभाज्य पूर्णांक: ऐसे पूर्णांक जिनका HCF 1 हो, उदा. (1,3)। अभाज्य गुणनखंडन विधि: संख्याओं को उनके अभाज्य गुणनखंडों के गुणनफल के रूप में लिखना।

2. बहुपद

p(x) = –x + 3 अपने शून्यक पर x-अक्ष को काटता है।

एक चर x में बहुपद का रूप: p(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀जहाँ n एक अऋणात्मक पूर्णांक है और a₀…aₙ अचर (गुणांक) हैं।

प्रकार

रैखिक (घात 1): ax + b, a ≠ 0, उदा. 5x + 4।
द्विघात (घात 2): ax² + bx + c, a ≠ 0, उदा. 5x² + 8x + 3।
त्रिघात (घात 3): ax³ + bx² + cx + d, a ≠ 0, उदा. 5x³ + x² + 25x + 5।

घात: बहुपद में x की सबसे बड़ी घात। उदा. y² – 5y + 7 की घात 2 है।

शून्यक: यदि p(k) = 0 हो तो k, p(x) का शून्यक है। उदा. p(x) = –x + 3 में p(3) = 0, अतः 3 शून्यक है।

किसी बिंदु पर मान: p(x) में x = α रखने पर प्राप्त मान p(α) है।

शून्यकों α, β से द्विघात बहुपद

x² – (α + β)x + αβ

3. दो चरों वाले रैखिक समीकरण युग्म

व्यापक रूप: a₁x + b₁y + c₁ = 0 और a₂x + b₂y + c₂ = 0

अनुपातरेखाएँहलनिकाय
a₁/a₂ ≠ b₁/b₂प्रतिच्छेदीएक अद्वितीय हलसंगत
a₁/a₂ = b₁/b₂ = c₁/c₂संपातीअपरिमित हलसंगत (आश्रित)
a₁/a₂ = b₁/b₂ ≠ c₁/c₂समांतरकोई हल नहींअसंगत

उदा. x = 2, y = 3, समीकरण 2x + 3y – 13 = 0 और 4x – 5y + 7 = 0 का हल है।

प्रतिस्थापन विधि

एक समीकरण से एक चर को दूसरे के पदों में लिखकर दूसरे समीकरण में रखते हैं। हल करें x + y = 3, x + 2y = 5: x = 3 – y → 3 – y + 2y = 5 → y = 2, x = 1।

विलोपन विधि

किसी एक चर के गुणांक बराबर करके समीकरणों को घटाते हैं। हल करें x + 2y = 6, x + y = 5: दूसरे को 2 से गुणा → 2x + 2y = 10; पहले को घटाने पर x = 4; तब y = 1।

4. द्विघात समीकरण

मानक रूप: ax² + bx + c = 0, a ≠ 0उदा. 3x² + 5x + 2 = 0।

मूल (हल)

1. दिया गया मान α हल है या नहीं: x = α रखें; यदि P(α) = 0 तो α हल है।
2. अज्ञात अचर ज्ञात करना: दिया गया मूल समीकरण में रखकर सरल करें।

गुणनखंडन विधि

ac ज्ञात करें, उसे p × q के रूप में लिखें जहाँ p + q = b, bx = px + qx लिखें, बाएँ पक्ष के दो रैखिक गुणनखंड बनाएँ और प्रत्येक को शून्य के बराबर रखें।

द्विघाती सूत्र

x = (–b ± √(b² – 4ac)) / 2a = (–b ± √D) / 2a

D = b² – 4ac विविक्तकर (Discriminant) है।

मूलों की प्रकृति

D = 0: दो समान वास्तविक मूल, x = –b/2a।
D > 0: दो भिन्न वास्तविक मूल।
D < 0: √D वास्तविक नहीं, अतः कोई वास्तविक मूल नहीं।

जाँचने के लिए कि समीकरण द्विघात है या नहीं, उसे सरलतम रूप में लिखकर ax² + bx + c = 0, a ≠ 0 से मिलाएँ।

6. त्रिभुज

DE ∥ BC खिसकती है, फिर भी AD/DB = AE/EC सदा सत्य रहता है।

समरूप त्रिभुज: संगत कोण बराबर हों या संगत भुजाओं का अनुपात समान हो।

आधारभूत समानुपातिकता प्रमेय (थेल्स)

ΔABC में यदि DE ∥ BC हो और DE भुजा AB को D पर तथा AC को E पर काटे:

AD/DB = AE/EC

समरूपता की कसौटियाँ

AAA: ∠A = ∠D, ∠B = ∠E, ∠C = ∠F ⇒ AB/DE = AC/DF = BC/EF और ΔABC ~ ΔDEF।

SSS: AB/DE = BC/EF = CA/FD ⇒ संगत कोण बराबर, ΔABC ~ ΔDEF।

SAS: AB/DE = AC/DF और ∠A = ∠D ⇒ ΔABC ~ ΔDEF।

7. निर्देशांक ज्यामिति

P, रेखाखंड AB को m₁ : m₂ अनुपात में आंतरिक रूप से विभाजित करता है।

दूरी सूत्र

PQ = √[(x₂ – x₁)² + (y₂ – y₁)²]

अर्थात् √[(भुजों का अंतर)² + (कोटियों का अंतर)²]।

दूरी सूत्र पर आधारित प्रश्न

सरेखता: AB, BC, CA ज्ञात करें; यदि दो छोटी दूरियों का योग सबसे बड़ी दूरी के बराबर हो (AB + BC = AC), तो बिंदु सरेख हैं।
समदूरस्थ बिंदु X: AX = BX लेकर सरल करें।

विभाजन सूत्र (आंतरिक विभाजन)

AP : BP = m₁ : m₂ हो तो

P = ( (m₁x₂ + m₂x₁)/(m₁ + m₂) , (m₁y₂ + m₂y₁)/(m₁ + m₂) )

विभाजन सूत्र पर आधारित प्रश्न

I. सरेखता: मानें C, AB को k : 1 में बाँटता है; C के निर्देशांक सूत्र से निकालकर दिए गए निर्देशांकों से बराबर करें; दोनों से k समान आए तो बिंदु सरेख हैं।
II. विभाजन अनुपात/बिंदु: जब कोई अक्ष रेखाखंड को बाँटे, तो सूत्र से अनुपात और बिंदु ज्ञात करें।
III. अज्ञात शीर्ष: आकृति (समांतर चतुर्भुज, त्रिभुज, वृत्त) के गुणों और विभाजन सूत्र का प्रयोग करें।

9. वृत्त

स्पर्श रेखा (लाल) स्पर्श बिंदु पर त्रिज्या (नीली) पर सदा लंब रहती है।

स्पर्श रेखा: वह रेखा जो वृत्त को केवल एक बिंदु पर स्पर्श करे; वह बिंदु स्पर्श बिंदु कहलाता है।

स्पर्श रेखा की लंबाई: बाह्य बिंदु से स्पर्श बिंदु तक स्पर्श रेखा का खंड।

बिंदु P से स्पर्श रेखाओं की संख्या

(i) P वृत्त के बाहर: दो स्पर्श रेखाएँ। (ii) P वृत्त पर: केवल एक। (iii) P वृत्त के अंदर: कोई नहीं।

प्रमेय

वृत्त के किसी बिंदु पर स्पर्श रेखा, स्पर्श बिंदु से जाने वाली त्रिज्या पर लंब होती है: OP ⊥ AB।

10. वृत्तों से संबंधित क्षेत्रफल

वृत्तखंड: जीवा और संगत चाप से घिरा क्षेत्र (लघु चाप वाला लघु वृत्तखंड, दीर्घ चाप वाला दीर्घ वृत्तखंड)।
त्रिज्यखंड: दो त्रिज्याओं और संगत चाप से घिरा क्षेत्र (लघु / दीर्घ त्रिज्यखंड)।

त्रिज्यखंड का क्षेत्रफल = (θ/360°) × πr²
चाप की लंबाई l = (θ/360°) × 2πr
चाप के पदों में त्रिज्यखंड का क्षेत्रफल = ½ lr

वृत्तखंड का क्षेत्रफल

= संगत त्रिज्यखंड का क्षेत्रफल – जीवा और त्रिज्याओं से बने त्रिभुज का क्षेत्रफल।

दीर्घ वृत्तखंड का क्षेत्रफल = πr² – लघु वृत्तखंड का क्षेत्रफल।
दीर्घ त्रिज्यखंड का क्षेत्रफल = πr² – लघु त्रिज्यखंड का क्षेत्रफल।

11. सांख्यिकी

माध्य

सभी प्रेक्षणों के योग को प्रेक्षणों की कुल संख्या से भाग देना।

x̄ = (x₁ + x₂ + … + xₙ)/n = Σxᵢ/n
बारंबारता सहित: x̄ = Σfᵢxᵢ / Σfᵢ

कल्पित माध्य विधि

xᵢ, fᵢ बड़े हों तो कल्पित माध्य a लें, dᵢ = xᵢ – a:

x̄ = a + Σfᵢdᵢ / Σfᵢ

पद विचलन विधि

जब सभी dᵢ वर्ग-माप h के गुणज हों, uᵢ = dᵢ/h = (xᵢ – a)/h:

x̄ = a + (Σfᵢuᵢ / Σfᵢ) × h

समूहित आँकड़ों का बहुलक

पहले अधिकतम बारंबारता वाला वर्ग (बहुलक वर्ग) ज्ञात करें।

बहुलक = l + [(f₁ – f₀) / (2f₁ – f₀ – f₂)] × h

l = बहुलक वर्ग की निम्न सीमा, h = वर्ग-माप, f₁ = बहुलक वर्ग की बारंबारता, f₀ = बहुलक वर्ग से पहले वाले वर्ग की बारंबारता, f₂ = बहुलक वर्ग के बाद वाले वर्ग की बारंबारता।

प्रारंभिक घटना: केवल एक परिणाम वाली घटना, उदा. चित (H) या पट (T)।
घटना का घटित होना: प्रयास का परिणाम E के अनुकूल हो तो E घटित हुई (पासे पर 4 आए तो "सम संख्या" घटित हुई)।
पूरक घटना Ē: वह घटना जो तभी घटित होती है जब E घटित न हो। E = {2, 4, 6} ⇒ Ē = {1, 3, 5}।
