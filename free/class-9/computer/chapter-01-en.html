Class 9 Computer – Revision

16 lessons · summary, key points, fun facts and practice questions

🖥️Introduction and Development of Computer

Summary

A computer is an electronic machine that takes input, processes it and gives output. From the abacus to smart machines, its journey is divided into five generations.

Key points

  • Charles Babbage – father of the computer; Ada Lovelace – first programmer
  • 1st gen: vacuum tubes; 2nd: transistors
  • 3rd: IC; 4th: microprocessor; 5th: artificial intelligence
💡 Did you know? ENIAC weighed about 27 tonnes!

✍️ Practice question (tap to see the answer)

Which technology marked the third generation?

Integrated circuits (IC).

🧩Computer Fundamentals, Parts and Types

Summary

A computer has three main parts – input unit, CPU and output unit. Computers are classified by size and by working principle.

Key points

  • CPU = ALU + control unit + memory
  • By size: super, mainframe, mini, micro
  • By working: analog, digital, hybrid
💡 Did you know? PARAM is India's famous series of supercomputers.

✍️ Practice question (tap to see the answer)

Name two parts of the CPU.

ALU and control unit.

🔌Input/Output Devices, Hardware and Software

Summary

Parts we can touch are hardware; sets of instructions are software. Together they make a computer work.

Key points

  • Hardware: keyboard, mouse, monitor, CPU
  • Software: system and application
  • Input gives data; output shows results
💡 Did you know? You can touch hardware, but never software.

✍️ Practice question (tap to see the answer)

Name the two types of software.

System software and application software.

🔢Number System and Conversion

Summary

A computer understands only 0 and 1, so we must learn binary and other number systems and how to convert them.

Key points

  • Bases: decimal 10, binary 2, octal 8, hexadecimal 16
  • Decimal → binary: divide by 2, read remainders bottom to top
  • Example: 13 = 1101
  • Hex uses digits 0–9 and A–F
💡 Did you know? Circuits have two states (ON/OFF), so computers use binary.

✍️ Practice question (tap to see the answer)

Write decimal 5 in binary.

101

➕Binary Arithmetic

Summary

Binary addition, subtraction and multiplication follow a few simple rules.

Key points

  • 0+0=0, 0+1=1, 1+1=10 (carry 1)
  • 1+1+1 = 11
  • Subtraction uses borrowing; 2's complement is also used
  • Example: 101 + 11 = 1000 (5+3=8)
💡 Did you know? In binary, 1 + 1 is not 2 – it is 10!

✍️ Practice question (tap to see the answer)

What is 1 + 1 in binary?

10 (0 with carry 1).

📘Introduction to Computer

Summary

A computer is a fast, accurate, tireless machine used in education, banking, railways and healthcare.

Key points

  • Features: speed, accuracy, diligence, storage, versatility
  • Limit: cannot think; has no IQ
  • Uses: ticket booking, online study, ATMs
💡 Did you know? The word 'computer' comes from 'compute', meaning to calculate.

✍️ Practice question (tap to see the answer)

Give two features of a computer.

Speed and accuracy.

⚙️Computer Fundamentals (Data, Information, IPO)

Summary

A computer processes raw data into useful information. This cycle is called input–process–output.

Key points

  • Data = raw facts; information = processed data
  • 1 byte = 8 bits; 1 KB = 1024 bytes
  • Bit is the smallest unit (0 or 1)
💡 Did you know? One character takes about 1 byte of storage.

✍️ Practice question (tap to see the answer)

How many bits are in a byte?

8 bits.

⌨️Input and Output Devices

Summary

Input devices give data to the computer; output devices show the results.

Key points

  • Input: keyboard, mouse, scanner, mic, barcode reader
  • Output: monitor, printer, speaker, plotter, projector
  • Printers: impact and non-impact
💡 Did you know? The first mouse was made of wood (1964).

✍️ Practice question (tap to see the answer)

Name two output devices.

Monitor and printer.

💾Computer Memory

Summary

Memory stores data and instructions. It is divided into primary and secondary memory.

Key points

  • RAM is temporary (lost on power-off); ROM is permanent
  • Cache memory is the fastest
  • Secondary: hard disk, SSD, CD/DVD, pen drive
💡 Did you know? Cache sits between the CPU and RAM like a fast bridge.

✍️ Practice question (tap to see the answer)

Why is RAM called volatile?

Its data is lost when power is switched off.

📀Computer Software

Summary

Software is a set of instructions that makes hardware do its job.

Key points

  • System software: OS, utilities, compiler, interpreter, assembler
  • Application: word processor, spreadsheet, paint
  • Open source, freeware, shareware
💡 Did you know? A compiler translates the whole program at once; an interpreter goes line by line.

✍️ Practice question (tap to see the answer)

Differentiate compiler and interpreter.

A compiler translates the whole code at once; an interpreter translates one line at a time.

🪟Operating System

Summary

The operating system manages computer resources and acts as a bridge between the user and the machine.

Key points

  • Functions: process, memory, file and device management
  • Types: single-user, multi-user, batch, real-time
  • GUI uses icons and mouse; CLI uses commands
  • Examples: Windows, Linux, Android
💡 Did you know? The Linux mascot is a penguin named Tux.

✍️ Practice question (tap to see the answer)

Name two operating systems.

Windows and Linux.

🌐Introduction to Internet

Summary

The internet is a global network of networks connecting computers worldwide.

Key points

  • Began as ARPANET (1969); WWW by Tim Berners-Lee
  • Needs: ISP, browser, modem, IP address
  • Uses: e-mail, search, online learning, banking
💡 Did you know? The Internet and the WWW are not the same; the WWW is a service on the internet.

✍️ Practice question (tap to see the answer)

Expand URL.

Uniform Resource Locator.

🛡️Computer Virus and Security

Summary

A virus is a harmful program that copies itself and damages a computer.

Key points

  • Types: boot sector, file, macro virus; worms, trojans
  • Spread: pen drives, e-mail, downloads
  • Protection: antivirus, updates, firewall, backup, strong passwords
💡 Did you know? The first PC virus, 'Brain', appeared in 1986.

✍️ Practice question (tap to see the answer)

Give two ways to protect from viruses.

Install antivirus and avoid opening suspicious files.

🔗Computer Network

Summary

A computer network connects computers to share resources and data.

Key points

  • Types: LAN, MAN, WAN
  • Topologies: bus, star, ring, mesh
  • Devices: modem, router, switch, hub
💡 Did you know? The internet is considered the largest WAN.

✍️ Practice question (tap to see the answer)

Expand LAN.

Local Area Network.

🔀Computer Flowcharts and Algorithms

Summary

An algorithm is a list of steps to solve a problem; a flowchart is its picture form.

Key points

  • Oval: start/end; parallelogram: input/output
  • Rectangle: process; diamond: decision
  • Arrows show the flow
💡 Did you know? The word 'algorithm' comes from the name al-Khwarizmi.

✍️ Practice question (tap to see the answer)

Which shape shows a decision?

The diamond.

👨‍💻Introduction to Programming Techniques

Summary

A program is an ordered set of instructions. Good programs are built step by step with planning.

Key points

  • Steps: analyse, algorithm, code, test, debug, document
  • Languages: machine, assembly, high-level (C, Python)
  • Techniques: top-down, modular, structured
💡 Did you know? The first computer 'bug' was a real moth stuck in a machine (1947).

✍️ Practice question (tap to see the answer)

What is debugging?

Finding and fixing errors in a program.
