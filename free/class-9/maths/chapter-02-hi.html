🔢अध्याय 1: संख्या पद्धति

परिमेय संख्याp/q , q ≠ 0 (p, q integers)
अपरिमेय संख्याNon-terminating & non-recurring (√2, π)
वास्तविक संख्याएँRational ∪ Irrational
मूलों का गुणन√a × √b = √(ab)
मूलों का भाग√a ÷ √b = √(a/b)
वर्गों का अंतर(√a + √b)(√a − √b) = a − b
सांत दशमलवDenominator = 2ᵐ × 5ⁿ only
💡 ट्रिक: आवर्ती दशमलव सदा परिमेय है; π अपरिमेय है (22/7 केवल सन्निकट मान)।

⬆️अध्याय 2: घातांक

समान आधार, गुणाaᵐ × aⁿ = aᵐ⁺ⁿ
समान आधार, भागaᵐ ÷ aⁿ = aᵐ⁻ⁿ
घात की घात(aᵐ)ⁿ = aᵐⁿ
समान घातaᵐ × bᵐ = (ab)ᵐ
शून्य घातa⁰ = 1
ऋणात्मक घातa⁻ⁿ = 1 ÷ aⁿ
भिन्नात्मक घातa^(1/n) = ⁿ√a ; a^(m/n) = (ⁿ√a)ᵐ
💡 ट्रिक: गुणा → घात जोड़ो। घात की घात → घात गुणा करो।

🎯अध्याय 3: हर का परिमेयकरण

मूल रूप1/√a = √a / a
प्रकार 11/(a + √b) = (a − √b)/(a² − b)
प्रकार 21/(a − √b) = (a + √b)/(a² − b)
दो मूल1/(√a + √b) = (√a − √b)/(a − b)
मुख्य सर्वसमिका(a + √b)(a − √b) = a² − b
💡 ट्रिक: ऊपर-नीचे संयुग्मी (चिह्न बदला हुआ) से गुणा करो।

🧩अध्याय 4: बीजीय सर्वसमिकाएँ

सर्वसमिका 1(a + b)² = a² + 2ab + b²
सर्वसमिका 2(a − b)² = a² − 2ab + b²
सर्वसमिका 3a² − b² = (a + b)(a − b)
सर्वसमिका 4(x + a)(x + b) = x² + (a + b)x + ab
तीन पद(a+b+c)² = a²+b²+c²+2ab+2bc+2ca
योग का घन(a + b)³ = a³ + b³ + 3ab(a + b)
अंतर का घन(a − b)³ = a³ − b³ − 3ab(a − b)
घनों का योगa³ + b³ = (a + b)(a² − ab + b²)
घनों का अंतरa³ − b³ = (a − b)(a² + ab + b²)
विशेषx³+y³+z³−3xyz = (x+y+z)(x²+y²+z²−xy−yz−zx)
यदि x + y + z = 0x³ + y³ + z³ = 3xyz
💡 ट्रिक: a³±b³ में: पहला कोष्ठक वही चिह्न, दूसरे कोष्ठक में बीच का चिह्न उल्टा।

📈अध्याय 5: बहुपद

घातHighest power of x
रैखिक / द्विघात / त्रिघातDegree 1 / 2 / 3
शून्यकx = − b/a
अधिकतम शून्यक≤ degree of polynomial

💡 ट्रिक: x की घात पूर्ण संख्या होनी चाहिए: x + 1/x बहुपद नहीं है।

➗अध्याय 6: शेषफल और गुणनखंड प्रमेय

🧊अध्याय 14: पृष्ठीय क्षेत्रफल और आयतन

घनाभ TSA / LSA2(lb+bh+hl) / 2h(l+b)
घनाभ आयतनV = l × b × h
घनाभ विकर्ण√(l² + b² + h²)
घन TSA / LSA6a² / 4a²
घन V / विकर्णa³ / a√3
बेलन CSA / TSA2πrh / 2πr(r + h)
बेलन आयतनV = πr²h
शंकु तिर्यक ऊँचाईl = √(r² + h²)
शंकु CSA / TSAπrl / πr(r + l)
शंकु आयतनV = ⅓πr²h
गोला SA / V4πr² / (4/3)πr³
अर्धगोला CSA / TSA2πr² / 3πr²
अर्धगोला आयतनV = (2/3)πr³
💡 ट्रिक: शंकु = बेलन का ⅓ (समान r, h)। अर्धगोला = गोले का आधा।

🏺अध्याय 17: हीरोन का सूत्र

अर्ध-परिमापs = (a + b + c) ÷ 2
हीरोन सूत्रArea = √[ s(s − a)(s − b)(s − c) ]
समबाहु ΔArea = (√3/4) a²
समद्विबाहु ΔArea = (b/4) √(4a² − b²)
समकोण ΔArea = ½ × base × height
चतुर्भुजSplit by diagonal into 2 triangles, add areas
💡 ट्रिक: पहले s, फिर s−a, s−b, s−c निकालो, गुणा करो और वर्गमूल लो।
